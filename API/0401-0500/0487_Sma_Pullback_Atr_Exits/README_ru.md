## Правила торговли

На завершённой свече после формирования двух SMA закрытия и ATR Уайлдера купить только при close < быстрая SMA и быстрая SMA > медленная; продать в шорт только при close > быстрая SMA и быстрая SMA < медленная. Равенства не дают входа. Вход объёмом Volume только из нуля с ожиданием активных заявок. На сигнале фиксируются SL = ATR×AtrMultiplierSl и TP = ATR×AtrMultiplierTp. Локальная рыночная native-защита привязывает расстояния к фактическому исполнению и отслеживает bid/ask. Поздний ATR не двигает уровни. Защита закрывает весь остаток; противоположный сигнал не разворачивает открытую позицию.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `CandleType` | TimeSpan.FromMinutes(30).TimeFrame() |
| `FastSmaLength` | 8 |
| `SlowSmaLength` | 30 |
| `AtrLength` | 14 |
| `AtrMultiplierSl` | 1.2 |
| `AtrMultiplierTp` | 2 |

## Проверка

Оба языка проверяются на имеющемся архиве BTC/TON: независимые формулы, стороны и объёмы заявок, реальные исполнения, позиции и выходы. Датированные ценовые/факторные и календарные данные проверяют механику; перенос дат OHLC/объёмов не является многолетней рыночной историей. Две корзины рангов, TopN=1 и SMA=2 — явные профили для малого универсума. Исходные длинные периоды и defaults проверяются отдельно. Доходность не заявляется.
