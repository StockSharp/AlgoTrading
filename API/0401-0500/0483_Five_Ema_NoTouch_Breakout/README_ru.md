## Правила торговли

Обрабатываются только завершённые свечи после формирования EMA. Свеча целиком ниже EMA готовит лонг выше её максимума; целиком выше EMA — шорт ниже минимума. Предыдущая установка проверяется до замены новой; касание границы не является пробоем. Вход только из нуля объёмом Volume; при удержании установка очищается. Стоп фиксируется на противоположном экстремуме установки. При первом фактическом исполнении фиксируются риск — расстояние до стопа — и расстояние тейка RewardRisk×риск. Локальная рыночная native-защита получает bid/ask между свечами. Если исполнение уже за стопом, фактическая позиция сразу закрывается. Задержки и наращивания нет.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `CandleType` | TimeSpan.FromMinutes(5).TimeFrame() |
| `EmaPeriod` | 5 |
| `RewardRisk` | 3 |

## Проверка

Оба языка проверяются на имеющемся архиве BTC/TON: независимые формулы, стороны и объёмы заявок, реальные исполнения, позиции и выходы. Датированные ценовые/факторные и календарные данные проверяют механику; перенос дат OHLC/объёмов не является многолетней рыночной историей. Две корзины рангов, TopN=1 и SMA=2 — явные профили для малого универсума. Исходные длинные периоды и defaults проверяются отдельно. Доходность не заявляется.
