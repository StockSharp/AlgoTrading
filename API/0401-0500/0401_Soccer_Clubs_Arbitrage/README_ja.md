# サッカークラブ裁定取引戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この戦略は、関連する2銘柄の確定足終値を比較します。相対プレミアムを `主銘柄 / 第2銘柄 - 1` で計算し、その絶対値がエントリー閾値を超えると両方のレッグを取引します。

主銘柄の方が高ければ、主銘柄を売り、第2銘柄を同じ単位数量だけ買います。第2銘柄の方が高ければ方向を逆にします。絶対プレミアムが決済閾値を下回ると、両方のポジションを閉じます。

## 詳細

- **データ**: 主銘柄と `Security2Id` の確定足。既定の時間枠は5分です。
- **エントリー**: いずれかの方向のプレミアムが `EntryThreshold` を超えたとき、単位数量が等しく方向が反対の成行注文を出します。
- **エグジット**: 絶対プレミアムが `ExitThreshold` を下回ったとき、各レッグの実際のポジションを閉じます。
- **クールダウン**: エントリー、決済、または反転の後、`CooldownBars` 回のペアになった足更新を待ちます。
- **執行リスク**: 2つの成行注文は別々に送信され、アトミックではありません。同じ単位数量でも想定元本が等しいとは限らないため、片側約定、流動性、契約サイズのリスクが残ります。
