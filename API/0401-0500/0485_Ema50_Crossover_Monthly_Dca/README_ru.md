## Правила торговли

Используются завершённые недельные свечи и сформированная EMA закрытий за EmaLength; начальное значение — среднее первого полного окна. Закрытия допускаются с StartDate. В первом наблюдаемом подходящем календарном месяце начисляется один DcaAmount, далее — за прошедшие месяцы, в том числе при прогреве EMA. Взносы за десятилетия до первой наблюдаемой свечи не создаются. Выше EMA накопленные деньги инвестируются с округлением объёма; ниже EMA весь фактический лонг продаётся, при равенстве удерживается. Денежный остаток учитывает реальные исполнения и выручку без комиссий; это регистр распределения средств стратегии, не внесение денег на счёт и не модель кредитования. Активные заявки ожидаются, ограничения объёма соблюдаются, остаток денег сохраняется. Шортов, RSI-фильтра, задержки и защитных стопов нет.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `CandleType` | TimeSpan.FromMinutes(10080).TimeFrame() |
| `EmaLength` | 50 |
| `DcaAmount` | 100000 |
| `StartDate` | 1980-01-01 |

## Проверка

Оба языка проверяются на имеющемся архиве BTC/TON: независимые формулы, стороны и объёмы заявок, реальные исполнения, позиции и выходы. Датированные ценовые/факторные и календарные данные проверяют механику; перенос дат OHLC/объёмов не является многолетней рыночной историей. Две корзины рангов, TopN=1 и SMA=2 — явные профили для малого универсума. Исходные длинные периоды и defaults проверяются отдельно. Доходность не заявляется.
