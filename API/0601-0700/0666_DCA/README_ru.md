# Стратегия DCA
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия покупает фиксированную сумму котируемой валюты через равные промежутки времени: либо в выбранный день недели, либо через заданное число свечей. При достижении конечной даты при необходимости закрывает все позиции.

### Выполняемые правила и расчёт объёма

Параметры по умолчанию: `CandleType=5m`, `CapitalToInvest=200` **единиц котируемой валюты**, `StartDate=DateTime.MinValue`, `EndDate=DateTime.MaxValue`, `CloseAllOnLastCandle=false`, `UseDayOfWeek=false`, `DayOfWeek=Wednesday`, `EveryXCandles=72`.

На завершённых свечах в диапазоне `StartDate <= дата свечи < EndDate` режим интервала покупает **каждые 72 подходящие свечи**. Режим дня недели покупает **на первой подходящей свече каждой среды**, максимум один раз за дату. Объём `200 / Close` округляется **вниз** до `Security.VolumeStep` с учётом допустимых объёмов инструмента. Это только **рыночные покупки** с накоплением лонга; ни EMA, ни шортов нет. Начиная с EndDate покупки прекращаются, а при `CloseAllOnLastCandle=true` выполняется однократное закрытие **фактического остатка** на первой подходящей свече. Отдельного ценового стопа нет. Из-за проскальзывания итоговая стоимость исполнения может отличаться. Числовые значения defaults выбраны при реализации: исходный README их не задавал.



## Параметры
- Тип свечей
- Сумма на сделку
- Начальная дата
- Конечная дата
- Закрывать на последней свече
- Режим дня недели
- День недели
- Каждые X свечей
