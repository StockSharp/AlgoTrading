# Стратегия Dema RSI
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия торгует пересечения RSI двойной экспоненциальной скользящей средней и её сглаженного значения. Длинная позиция открывается при пересечении RSI выше сглаженной линии, короткая – при обратном пересечении. Позиции защищаются тейк‑профитом, трейлинг‑стопом и опциональным фильтром торговой сессии.

## Параметры
- Тип свечей
- Длина MA
- Длина RSI
- Длина сглаживания RSI
- Тейк-профит в пунктах
- Трейлинг-стоп в пунктах
- Использовать сессию
- Начало сессии
- Конец сессии

### Исполняемый контракт RSI(DEMA)

Значения по умолчанию: `CandleType=1m`, `MaLength=20`, `RsiLength=14`, `RsiSmoothingLength=5`, `TakeProfitPoints=0`, `TrailStopPoints=0`, `UseSession=false`, `SessionStart=09:00`, `SessionEnd=17:00`. По завершённой свече вычисляем `EMA1=EMA(Close,20)`, `EMA2=EMA(EMA1,20)`, `DEMA=2×EMA1−EMA2`, `R=RSI(DEMA,14)`, `S=SMA(R,5)`. Покупка при **предыдущем** `R <= S` и **текущем** `R > S` из нуля или шорта; продажа при предыдущем `R >= S` и текущем `R < S` из нуля или лонга. Разворотный объём — `Volume + abs(Position)`. При `UseSession=true` входы разрешены в интервале `[SessionStart,SessionEnd)` (поддерживается переход через полночь); выходы по защите не зависят от расписания. `TakeProfitPoints` и `TrailStopPoints` — **минимальные шаги цены инструмента**, а не проценты. Ненулевые значения включают нативный тейк-профит и трейлинг-стоп с абсолютным расстоянием, нуль отключает соответствующую защиту. В исходном README числовых defaults не было; они выбраны явно. Прежняя логика пересечения ценовых EMA120/450 не соответствовала стратегии.
