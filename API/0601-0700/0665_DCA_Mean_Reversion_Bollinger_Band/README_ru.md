# Стратегия DCA с возвращением к среднему и полосами Боллинджера
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Покупает фиксированную сумму долларов при пересечении цены ниже нижней полосы Боллинджера или в первый день каждого месяца. Все позиции закрываются в заданную дату.

### Точные торговые правила C# и Python

По умолчанию: `InvestmentAmount=200` единиц **котируемой валюты**, `OpenDate=DateTime.MinValue`, `CloseDate=DateTime.MaxValue`, `StrategyMode=Combined`, `BollingerPeriod=20`, `BollingerMultiplier=2`, `CandleType=5 минут`. На **завершённых свечах** нижняя полоса Боллинджера равна SMA20 минус два стандартных отклонения. Сигнал покупки Bollinger: на предыдущей свече `Close >= lower band`, на текущей `Close < lower band`. Сигнал Monthly — **одна покупка за календарный месяц**, на первой подходящей завершённой свече после прогрева индикатора. Режимы: `Bollinger` (только пробой вниз), `Monthly` (раз в месяц), `Combined` (любой из них; один ордер при совпадении). В диапазоне `OpenDate <= дата < CloseDate` покупаемый объём равен `floor((InvestmentAmount / Close) / VolumeStep) × VolumeStep` с учётом допустимых границ. Покупки накапливают **только лонг**. При наступлении CloseDate на первой доступной свече продаётся **весь фактический остаток**, далее покупок нет. Стопов, шортов и сигналов EMA нет; проскальзывание меняет фактическую сумму сделки. Числовые defaults исходный README не задавал, поэтому они явно определены в этой реализации.



## Параметры
- `InvestmentAmount` - сумма покупки
- `OpenDate` - начало покупок
- `CloseDate` - дата закрытия всех позиций
- `StrategyMode` - BB mean reversion, monthly DCA или комбинированный режим
- `BollingerPeriod` - период полос Боллинджера
- `BollingerMultiplier` - множитель стандартного отклонения
- `CandleType` - таймфрейм для расчёта полос
