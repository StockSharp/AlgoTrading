# Demo GPT - デイトレードスキャルピング戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

2本連続の陽線が現れ、2本目が1本目の終値より高く始まり、出来高が20本平均を超えたときにロングエントリーします。2本連続の陰線が現れ、2本目が1本目の終値より低く始まり、同じ出来高条件を満たしたときにポジションを決済します。参考として EMA(20)、VWAP、Camarilla レベルを計算します。

### 実際の条件と既定値

既定値: `EmaLength=20`、`VolumeLookback=20`、`CandleType=1分足`。**直前20本の確定足**を蓄積後、`volumeHigh = 現在のTotalVolume > 直前20本の平均TotalVolume`（現在の足は平均に含めない）。ノーポジションで前後2本が陽線（`Close > Open`）、現在足に**`Open > 前足のClose`**のギャップアップがあり、出来高条件も満たす場合に**ロングのみ**建てます。2本連続陰線（`Close < Open`）、現在の `Open < 前足のClose`、高出来高なら**実際のロング残高を全決済**。厳密な始値ギャップや出来高の確認がなければ**信号ではありません**。ショートは行いません。参考情報のみ: 終値EMA20、日ごとにリセットするVWAP `sum(典型価格 × 出来高)/sum(出来高)`、前日Camarilla `H3/L3 = 前日終値 ± 1.1 × (前日高値 − 安値) / 4`。参考値は売買フィルターではなく、独立した損切りもありません。
