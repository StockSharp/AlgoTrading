# Стратегия «Demo GPT - внутридневной скальпинг»
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Открывает длинную позицию после двух подряд зелёных свечей, когда вторая открывается выше закрытия первой и объём превышает среднее за 20 баров. Закрывает позицию при двух подряд красных свечах, когда вторая открывается ниже закрытия первой при том же условии по объёму. Для справки рассчитываются EMA(20), VWAP и уровни Camarilla.

### Исполняемые условия и параметры

По умолчанию: `EmaLength=20`, `VolumeLookback=20`, `CandleType=1 минута`. После накопления **20 предыдущих завершённых свечей** объёмный фильтр: `текущий TotalVolume > среднее предыдущих 20 TotalVolume` (текущая свеча не входит в свою среднюю). Из нуля открывается **только лонг**, если обе свечи зелёные (`Close > Open`), **`Open текущей > Close предыдущей`**, и объёмный фильтр выполнен. **Весь фактический остаток** лонга закрывается, если обе свечи красные (`Close < Open`), `Open текущей < Close предыдущей` и объём выше среднего. Без строгого разрыва открытия или подтверждения объёмом **сигнала нет**, шорт не открывается. Только для справки, не для фильтра входа: EMA20 по закрытиям; VWAP дня `sum(typical price × volume) / sum(volume)` с ежедневным сбросом; уровни Camarilla предыдущего дня `H3/L3 = Close ± 1.1 × (High − Low) / 4`. Эти величины рассчитываются, но не участвуют в сигналах. Отдельного стоп-лосса нет.
