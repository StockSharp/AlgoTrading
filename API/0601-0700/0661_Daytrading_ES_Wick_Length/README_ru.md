# Стратегия "Дэйтрейдинг ES по длине теней"
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия открывает длинную позицию, когда суммарная длина верхней и нижней тени свечи превышает её скользящую среднюю плюс смещение, и закрывает позицию после удержания фиксированного числа баров.

### Проверяемый контракт сигналов (C# и Python)

По **завершённой минутной свече** суммарная длина теней `W = max(0, High − max(Open, Close)) + max(0, min(Open, Close) − Low)`. Для порога берутся **предыдущие 20 закрытых свечей** без текущей: `VWMA(W) = sum(Wᵢ × Volumeᵢ) / sum(Volumeᵢ)`; если все объёмы нулевые, используется простая средняя SMA. При `MaType=Simple` берётся невзвешенное среднее. `MaOffset=10` означает **10 минимальных шагов цены инструмента**, поэтому порог равен `VWMA(W) + 10 × Security.PriceStep`, а не десяти единицам котируемой валюты. После прогрева из нулевой позиции открывается **только лонг** при `W > порог`. После **18 следующих завершённых свечей** продаётся весь оставшийся объём. Шортов, стоп-лосса и тейк-профита нет. Параметры: `MaLength=20`, `MaType=VolumeWeighted`, `MaOffset=10`, `HoldPeriods=18`, `CandleType=1 minute`.



## Детали

- **Условия входа**: суммарная длина теней больше скользящей средней со смещением.
- **Условия выхода**: позиция закрывается после удержания `Hold periods` баров.
- **Длинная/короткая**: только длинная.
- **Стопы**: отсутствуют.
- **Значения по умолчанию**:
  - `MA length` = 20
  - `MA type` = VolumeWeighted
  - `MA offset` = 10
  - `Hold periods` = 18
  - `Candle type` = 1‑минутные свечи
- **Фильтры**:
  - Категория: волатильность
  - Направление: длинное
  - Индикаторы: скользящая средняя, длина теней
  - Стопы: нет
  - Сложность: простая
  - Таймфрейм: внутридневной
  - Сезонность: нет
  - Нейросети: нет
  - Дивергенция: нет
  - Уровень риска: средний
