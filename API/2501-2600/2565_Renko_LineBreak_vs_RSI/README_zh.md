# Renko Line Break vs RSI 策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该策略基于 MetaTrader 的 “RenkoLineBreak vs RSI” 专家顾问，使用 StockSharp 的高级 API 重新实现。策略利用 Renko 砖块判断趋势方向，同时通过 RSI 回调过滤信号，并在三根 K 线结构确认信号后立即以市价入场。Renko 砖块由策略内部根据时间 K 线的收盘价计算，因此整个策略只依赖一条 K 线订阅。

## 细节

- **入场条件**：
  - **做多**：Renko 趋势保持上行，且 RSI 下降到 `50 - RsiShift` 或更低。策略以三根柱之前的最高价加上 `IndentFromHighLow` 作为参考价位校验信号，并在信号 K 线收盘时发出市价买单。
  - **做空**：Renko 趋势保持下行，且 RSI 上升到 `50 + RsiShift` 或更高。策略以三根柱之前的最低价减去 `IndentFromHighLow` 作为参考价位校验信号，并在信号 K 线收盘时发出市价卖单。
  - 当 Renko 处于过渡状态（`ToUp` / `ToDown`）时不会开新仓，已保存的信号会被清除。
- **方向**：多空双向。
- **出场条件**：
  - 出现相反的 Renko 过渡信号（做多遇到 `ToDown`，做空遇到 `ToUp`）。
  - RSI 回到中线附近（`50 ± RsiShift`）。
  - K 线触及预设的止损或止盈价格。
- **止损/止盈**：
  - 止损放在最近三根 K 线的极值，并加上 `IndentFromHighLow` 缓冲。
  - 止盈距离参考突破价位 `TakeProfit` 个价格单位（设置为 0 可关闭）。
- **默认参数**：
  - `BoxSize` = 100m。
  - `RsiPeriod` = 4。
  - `RsiShift` = 10m。
  - `TakeProfit` = 1000m。
  - `IndentFromHighLow` = 50m。
  - `Volume` = 1m。
  - `CandleType` = 2 小时周期。
- **筛选标签**：
  - 类型：趋势跟随。
  - 方向：多空皆可。
  - 指标：Renko、RSI。
  - 止损：固定止损和止盈。
  - 复杂度：中等。
  - 周期：单一时间周期（Renko 砖块由 K 线收盘价生成）。
  - 季节性：无。
  - 神经网络：无。
  - 背离：无。
  - 风险等级：中等。

## 工作流程

1. Renko 砖块在策略内部由时间 K 线的收盘价生成：延续当前方向的砖块只需收盘价相对基准价移动一个 `BoxSize`，而反转方向的砖块需要两个 `BoxSize`。在第一块砖确定方向之前，任一方向移动一个 `BoxSize` 即可。移动覆盖多少就生成多少块砖，基准价随之推移。砖块翻转时，趋势状态会暂时变为 `ToUp` 或 `ToDown`，模拟原指标的信号。
2. 同一条 K 线数据流用于计算 RSI，并提供最近三根柱体的高低点以确定突破价位，因此策略只需要一个行情订阅。
3. 当 Renko 趋势和 RSI 条件同时满足时，策略发出相应方向的市价单，并保存计划中的止损/止盈价格。
4. 仓位建立后，保存的保护价位开始生效。每根后续 K 线都会检查是否触碰止损或止盈，若触及则以市价平仓。
5. 若 RSI 再次穿越中线或 Renko 指示趋势扭转，仓位会提前平掉。

## 使用的指标

- **Renko 砖块**：以 `BoxSize` 为步长、由时间 K 线收盘价生成，用于识别趋势方向及其过渡阶段。
- **RSI 指标**：要求顺势中的回调，从而过滤入场信号。

## 补充说明

- `IndentFromHighLow` 重现了原策略中的缓冲距离，使参考突破价位和止损远离最近的高低点。
- 将 `TakeProfit` 设为 0 时，不再设置止盈，止损逻辑仍然保留。
- 策略同一时间只持有一个仓位：只有在空仓时才考虑新的入场，条件失效时会立即清除已保存的信号。
