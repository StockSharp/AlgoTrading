# Стратегия Renko Line Break vs RSI
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия повторяет логику советника «RenkoLineBreak vs RSI» из MetaTrader с использованием высокоуровневого API StockSharp. Для определения направления используются кирпичи Renko, фильтрация входов выполняется по RSI, а вход выполняется рыночной заявкой, как только структура из трёх свечей подтверждает сетап. Кирпичи Renko рассчитываются внутри самой стратегии по ценам закрытия временных свечей, поэтому всю работу обеспечивает одна подписка на свечи.

## Подробности

- **Условия входа**:
  - **Покупка**: тренд Renko остаётся восходящим, а RSI опускается до уровня `50 - RsiShift` или ниже. Сетап проверяется по опорному уровню, равному максимуму свечи три бара назад плюс `IndentFromHighLow`, а вход выполняется рыночной заявкой на покупку по закрытию сигнальной свечи.
  - **Продажа**: тренд Renko остаётся нисходящим, а RSI поднимается до уровня `50 + RsiShift` или выше. Сетап проверяется по опорному уровню, равному минимуму свечи три бара назад минус `IndentFromHighLow`, а вход выполняется рыночной заявкой на продажу по закрытию сигнальной свечи.
  - Пока тренд Renko находится в переходном состоянии (`ToUp` / `ToDown`), новые входы не выполняются, а сохранённый сетап сбрасывается.
- **Направление**: Покупка и продажа.
- **Условия выхода**:
  - Сигнал к закрытию при обратном переходе тренда Renko (`ToDown` для лонга, `ToUp` для шорта).
  - RSI возвращается через середину диапазона (`50 ± RsiShift`).
  - Достижение свечой уровней запланированного стоп-лосса или тейк-профита.
- **Стопы**:
  - Стоп-лосс привязан к экстремуму последних трёх свечей с поправкой `IndentFromHighLow`.
  - Тейк-профит отстоит от опорного уровня пробоя на `TakeProfit` (можно отключить, установив 0).
- **Значения по умолчанию**:
  - `BoxSize` = 100m.
  - `RsiPeriod` = 4.
  - `RsiShift` = 10m.
  - `TakeProfit` = 1000m.
  - `IndentFromHighLow` = 50m.
  - `Volume` = 1m.
  - `CandleType` = таймфрейм 2 часа.
- **Фильтры**:
  - Категория: Следование за трендом.
  - Направление: Обе стороны.
  - Индикаторы: Renko, RSI.
  - Стопы: Жёсткий стоп и тейк-профит.
  - Сложность: Средняя.
  - Таймфрейм: Один таймфрейм (кирпичи Renko строятся по закрытиям свечей).
  - Сезонность: Нет.
  - Нейросети: Нет.
  - Дивергенции: Нет.
  - Уровень риска: Средний.

## Как это работает

1. Кирпичи Renko строятся внутри стратегии по ценам закрытия временных свечей: кирпич по текущему направлению формируется, когда закрытие уходит от опорной точки на полный `BoxSize`, а кирпичу разворота требуется уже два `BoxSize`. Пока первый кирпич не задал направление, достаточно одного бокса в любую сторону. Формируется столько кирпичей, сколько укладывается в движение, и опорная точка сдвигается вслед за ними. При смене направления кирпича тренд переводится в состояние `ToUp` или `ToDown`, что имитирует оригинальный индикатор.
2. Тот же поток свечей рассчитывает RSI и предоставляет максимум/минимум последних трёх баров для расчёта уровней пробоя, поэтому стратегия открывает ровно одну подписку на рыночные данные.
3. Когда условия по Renko и RSI совпадают, отправляется рыночная заявка на покупку или продажу. Пара стоп-лосс/тейк-профит сохраняется и начинает отслеживаться после открытия позиции.
4. После открытия позиции уровни защиты активируются, и каждую новую свечу стратегия проверяет, достигла ли цена стопа или цели; при достижении позиция закрывается по рынку.
5. Если импульс ослабевает (RSI возвращается за середину) или Renko сигнализирует разворот, позиция закрывается досрочно.

## Используемые индикаторы

- **Кирпичи Renko** — строятся по закрытиям временных свечей с шагом `BoxSize` и определяют направление и переходные состояния тренда.
- **Индекс относительной силы (RSI)** — фильтрует входы, требуя отката против тренда.

## Дополнительные замечания

- `IndentFromHighLow` повторяет буфер оригинального советника, удерживая опорный уровень пробоя и стоп-лосс на расстоянии от ближайших экстремумов.
- При значении `TakeProfit = 0` тейк-профит отключается, но стоп-лосс продолжает работать.
- Одновременно удерживается только одна позиция: новый вход рассматривается лишь когда стратегия вне рынка, а сохранённый сетап сбрасывается, как только условия перестают его подтверждать.
