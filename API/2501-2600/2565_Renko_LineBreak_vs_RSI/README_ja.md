# Renko Line Break vs RSI戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この戦略はStockSharpの高レベルAPIを使用してMetaTraderのエキスパート「RenkoLineBreak vs RSI」を再現します。Renkoのトレンド検出とRSI押し目フィルターを組み合わせ、3本ローソク足の価格構造がセットアップを確認した時点で成行注文により参入します。Renkoブリックは戦略内部で時間ローソク足の終値から計算されるため、1つのローソク足購読だけで全体が動作します。

## 詳細

- **エントリー条件**:
  - **ロング**: Renkoトレンドが強気を維持し、RSIが`50 - RsiShift`以下に下落する。3バー前のローソク足の高値プラス`IndentFromHighLow`を基準水準としてセットアップを検証し、シグナル足の終値で成行の買い注文を送信する。
  - **ショート**: Renkoトレンドが弱気を維持し、RSIが`50 + RsiShift`以上に上昇する。3バー前のローソク足の安値マイナス`IndentFromHighLow`を基準水準としてセットアップを検証し、シグナル足の終値で成行の売り注文を送信する。
  - Renkoトレンドが遷移状態（`ToUp` / `ToDown`）にある間は新規エントリーを行わず、保存されたセットアップは破棄されます。
- **ロング/ショート**: 両方。
- **エグジット条件**:
  - 反対のRenko遷移が現れた時の成行エグジット（ロングには`ToDown`、ショートには`ToUp`）。
  - RSIが中間点を戻りクロス（`50 ± RsiShift`）。
  - 計画されたストップロスまたはテイクプロフィットレベルに到達するローソク足の範囲。
- **ストップ**:
  - ストップロスは最後の3本のローソク足の極値プラス`IndentFromHighLow`に固定されます。
  - テイクプロフィットは基準となるブレイクアウト水準から`TakeProfit`価格単位離れています（ゼロに設定した場合はオプション）。
- **デフォルト値**:
  - `BoxSize` = 100m.
  - `RsiPeriod` = 4.
  - `RsiShift` = 10m.
  - `TakeProfit` = 1000m.
  - `IndentFromHighLow` = 50m.
  - `Volume` = 1m.
  - `CandleType` = 2時間足。
- **フィルター**:
  - カテゴリ: トレンドフォロー。
  - 方向: 両方。
  - インジケーター: Renko、RSI。
  - ストップ: ハードストップとテイクプロフィット。
  - 複雑さ: 中級。
  - 時間軸: 単一の時間軸（Renkoブリックはローソク足の終値から生成）。
  - 季節性: いいえ。
  - ニューラルネットワーク: いいえ。
  - ダイバージェンス: いいえ。
  - リスクレベル: 中。

## 機能の仕組み

1. Renkoブリックは戦略内部で時間ローソク足の終値から生成されます。現在の方向を継続するブリックは終値が基準値から`BoxSize`分だけ離れれば生成されますが、方向を反転するブリックには`BoxSize`の2倍の値動きが必要です。最初のブリックが方向を決めるまでは、どちらの方向でも1ボックスで足ります。値動きが収まる分だけブリックが生成され、基準値もそれに合わせて移動します。ブリックが方向を反転すると、元のインジケーターの動作を模倣するためにトレンド状態が1ステップの間`ToUp`または`ToDown`に設定されます。
2. 同じローソク足ストリームがRSIインジケーターを供給し、ブレイクアウトレベルに使用される最後の3つの高値/安値を提供するため、戦略が開く市場データ購読は1つだけです。
3. Renkoトレンドとの条件とRSI条件の両方が一致すると、戦略は成行注文（買いまたは売り）を送信します。計画されたストップロスとテイクプロフィットのレベルが保存され、ポジションが建った後で監視されます。
4. ポジションが建つと、保存された保護レベルがアクティブになります。後続のローソク足は価格がストップまたはターゲット範囲に到達するかどうかをチェックします。到達した場合、ポジションは成行で閉じられます。
5. モメンタムが衰える（RSIが中間点を戻りクロス）かRenkoトレンドが変わると、ポジションは早期に閉じられます。

## 使用するインジケーター

- **Renkoブリック**（`BoxSize`刻みで時間ローソク足の終値から生成）で方向バイアスを推定し、上昇と下降状態間の遷移を検出します。
- **Relative Strength Index (RSI)** でトレンドに対する押し目を要求することでエントリーを絞ります。

## 追加の注意事項

- `IndentFromHighLow`は元のエキスパートのバッファーをモデル化し、基準となるブレイクアウト水準とストップロスを最近の高値と安値から離れた位置に保ちます。
- `TakeProfit`をゼロに設定して、ストップロスロジックをそのまま維持しながら利益目標を無効にすることができます。
- 戦略は一度に1つのポジションのみを保持します。新規エントリーはノーポジションのときにのみ検討され、市場の条件がセットアップを無効にすると保存されたセットアップは破棄されます。
