# Стратегия VininI Trend LRMA
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Отслеживает конечное значение `L` скользящей линейной регрессии по закрытиям завершённых свечей. Параметры: `CandleType = 4 часа`, `Period = 13`, `UpLevel = 10`, `DnLevel = -10`, `Mode = Breakdown`. Торговля ожидает сформированных индикаторов и разрешения.

В **Breakdown** пороги относятся к относительному осциллятору `O = 100 × (Close − L) / L`, в процентах. Покупка при `previousO <= UpLevel && O > UpLevel`; продажа при `previousO >= DnLevel && O < DnLevel`. Это не абсолютные ценовые уровни LRMA.

В **Twist** покупка происходит при переходе наклона конечного значения регрессии в положительное направление после отрицательного; продажа — при обратном переходе. Горизонтальный участок сохраняет предыдущее ненулевое направление.

Покупка разрешена при `Position <= 0`, продажа — при `Position >= 0`. Противоположная исполненная позиция сначала закрывается, затем открывается `Volume` в новом направлении рыночными заявками. Однонаправленный сигнал не наращивает существующую позицию. Стоп-лосса и тейк-профита нет.
