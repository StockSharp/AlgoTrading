# Ultimate戦略テンプレート
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

2本のEMAをトレンドフィルターとして使うRSIモメンタム戦略。確定足でシグナルを判定し、80本のシグナル・クールダウン中もパーセント指定のテイクプロフィットとストップロスは有効なままです。

## 詳細

- **エントリー条件**: RSIが50を上抜け、かつ高速EMAが低速EMAより上ならロング。RSIが50を下抜け、かつ高速EMAが低速EMAより下ならショート。
- **ロング/ショート**: 両方。
- **エグジット条件**: RSIの逆方向クロス、テイクプロフィット、またはストップロス。
- **ストップ**: パーセントストップロスとテイクプロフィット。
- **クールダウン**: シグナルによるエントリーまたはRSIによる決済後、確定足80本。テイクプロフィットとストップロスは停止しません。
- **デフォルト値**:
  - `FastLength` = 9
  - `SlowLength` = 21
  - `StopLossPercent` = 1
  - `TakeProfitPercent` = 3
  - `CandleType` = 5分
- **フィルター**:
  - カテゴリ: トレンドフォロー
  - 方向: 両方
  - インジケーター: RSI、EMA
  - ストップ: はい
  - 複雑さ: 基本
  - 時間軸: 中期
  - 季節性: いいえ
  - ニューラルネットワーク: いいえ
  - ダイバージェンス: いいえ
  - リスクレベル: 中
