# Стратегия Ultimate Strategy Template
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия импульса RSI с трендовым фильтром из двух EMA. Сигналы рассчитываются по завершённым свечам, а процентные тейк-профит и стоп-лосс остаются активны во время сигнальной паузы длительностью 80 свечей.

## Подробности

- **Условия входа**: Лонг при пересечении RSI уровня 50 снизу вверх, если быстрая EMA выше медленной; шорт при пересечении 50 сверху вниз, если быстрая EMA ниже медленной.
- **Направление**: Длинные и короткие позиции.
- **Условия выхода**: Обратное пересечение RSI, тейк-профит или стоп-лосс.
- **Стопы**: Процентные стоп-лосс и тейк-профит.
- **Пауза**: 80 завершённых свечей после сигнального входа или выхода по RSI; она не отключает тейк-профит и стоп-лосс.
- **Значения по умолчанию**:
  - `FastLength` = 9
  - `SlowLength` = 21
  - `StopLossPercent` = 1
  - `TakeProfitPercent` = 3
  - `CandleType` = 5 минут
- **Фильтры**:
  - Категория: Следование тренду
  - Направление: Оба
  - Индикаторы: RSI, EMA
  - Стопы: Да
  - Сложность: Базовая
  - Таймфрейм: Средний
  - Сезонность: Нет
  - Нейросети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний
