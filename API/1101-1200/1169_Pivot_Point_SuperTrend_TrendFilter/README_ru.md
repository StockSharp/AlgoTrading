# Стратегия Pivot Point SuperTrend TrendFilter
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Комбинирует SuperTrend, рассчитанный по пивотам, с фильтром тренда на основе SuperTrend и подтверждением скользящей средней. Торгует при смене тренда или сигнале от пивотного SuperTrend в заданном диапазоне дат.

## Подробности

- **Условия входа**:
  - Long: ценовой SuperTrend переключается вверх и close выше SMA цен закрытия либо пивотный SuperTrend переключается вверх в диапазоне дат.
  - Short: ценовой SuperTrend переключается вниз и close ниже SMA либо пивотный SuperTrend переключается вниз в диапазоне дат.
- **Условия выхода**:
  - Любое переключение вниз полностью закрывает long, любое переключение вверх полностью закрывает short независимо от SMA и дат.
  - Разворот разрешён только при подтверждённом встречном входе. Одновременные разнонаправленные переключения закрывают позицию без нового входа.
- **Стопы**: Нет
- **Значения по умолчанию**:
  - `PivotPeriod` = 2
  - `Factor` = 3
  - `AtrPeriod` = 10
  - `TrendAtrPeriod` = 10
  - `TrendMultiplier` = 3
  - `MaPeriod` = 20
  - `CandleType` = 5 минут
  - `StartDate` / `EndDate` = UTC `DateTime.MinValue` / `DateTime.MaxValue`
- **Фильтры**:
  - Категория: Trend
  - Направление: Обе стороны
  - Индикаторы: Pivot, SuperTrend, SMA
  - Стопы: Нет
  - Сложность: Средняя
  - Таймфрейм: Любой
  - Сезонность: Опционально
  - Нейросети: Нет
  - Дивергенция: Нет
  - Риск: Средний

## Расчёт и исполнение

Используются только завершённые свечи. Pivot high/low должен быть строго выше/ниже всех `PivotPeriod` свечей с каждой стороны и подтверждается только после завершения правых свечей. Если свеча подходит для обоих pivot, приоритет имеет high. Первый подтверждённый pivot задаёт `center`, следующие обновляют его по формуле `(2 * center + pivot) / 3`.

Полосы pivot используют Wilder ATR: первые `AtrPeriod` true range усредняются, затем сглаживаются с весом `1 / AtrPeriod`. Базовые поддержка/сопротивление равны `center ± Factor * ATR`. Поддержка сохраняет максимум базового и предыдущего значения, когда previous close выше previous support; иначе сбрасывается. Сопротивление сохраняет минимум, когда previous close ниже previous resistance; иначе сбрасывается. Close строго выше предыдущего сопротивления переключает вверх, строго ниже предыдущей поддержки — вниз; иначе направление сохраняется. Начальное направление — вверх, инициализация не даёт сигнал.

Отдельный ценовой фильтр — штатный SuperTrend StockSharp (`TrendAtrPeriod`, `TrendMultiplier`). SMA включает текущий close. Сигналом служит смена направления; до готовности обоих ATR, SMA и pivot center входов нет. Условие `StartDate <= candle.OpenTime <= EndDate` действует только на пивотные входы. Даты должны быть упорядочены и заданы в UTC. Вход открывает `Volume`, разворот требует `Volume + abs(Position)`, закрытие — `abs(Position)`. Cooldown и защитных стопов нет.

Пивотная концепция: [Pivot Point Supertrend автора LonesomeTheBlue](https://www.tradingview.com/script/L0AIiLvH-Pivot-Point-Supertrend/). Правила выше определяют двунаправленную модель этого примера.
