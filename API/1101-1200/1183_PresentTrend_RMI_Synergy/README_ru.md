# PresentTrend RMI Synergy
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Вход по штатному Relative Momentum Index и SMA закрытий, затем ценовой трейлинг по SMA/ATR, который движется только в сторону защиты. Пример реализует импульс, среднюю и ATR из исходного описания; подтверждений доходности нет.

## Индикаторы и вход

По умолчанию завершённые пятиминутные свечи. Штатный RMI использует `d[t] = close[t] - close[t-RmiMomentum]`, lag3. За последние `RmiPeriod=21` значений импульса U — среднее положительных d (иначе ноль), D — среднее модулей отрицательных d (иначе ноль). `RMI = 100 * U / (U + D)`; при нулевом знаменателе значения для входа нет. Это штатный расчёт относительного импульса со скользящим средним.

SMA и штатный Wilder ATR используют общий `SuperTrendLength=5`. ATR учитывает разрывы относительно прошлого close, начинает со среднего растущего окна, затем использует Wilder. Вход ждёт прогрева трёх индикаторов:

- Лонг: RMI >60 и текущий close > SMA.
- Шорт: RMI <40 и текущий close < SMA.
- Вход только из нулевой позиции, рыночным ордером на `Volume` в разрешённую сторону. При удержании позиции новые входные сигналы игнорируются.

`Direction` — необязательный типизированный фильтр `Sides`: отсутствие значения (`null` в C#, `None` в Python) разрешает обе стороны; `Sides.Buy` — только long, `Sides.Sell` — только short. Фильтр ограничивает входы, но стоп всегда закрывает фактическую удерживаемую сторону. Строковых и числовых кодов направления нет.

## Трейлинг и исполнение

`width = SuperTrendMultiplier * ATR`, множитель по умолчанию 4:

- При входе в long стоп = `SMA - width`; следующая завершённая свеча обновляет его до `max(previousStop, SMA - width)`.
- При входе в short стоп = `SMA + width`; обновление до `min(previousStop, SMA + width)`.

Стоп не ослабляется, пока позиция открыта. Начальный уровень берётся из SMA/ATR сигнальной свечи независимо от последующей цены исполнения. Сохранённые имена SuperTrend-параметров задают именно эти явно определённые полосы вокруг SMA.

Положительный bid ≤ стопу long либо ask ≥ стопу short вызывает рыночное закрытие всего фактического объёма. После обновления стопа проверяется и завершённый close: достижение нового уровня может закрыть позицию сразу. Котировка между свечами тоже может вызвать выход. Новый уровень применяется к текущей и последующим наблюдаемым ценам, без проверки по более ранним high/low этой свечи. SMA/ATR продолжают обновлять защиту и при пустом текущем RMI.

Это локальный мониторинг цены; для выхода по котировкам внутри свечи нужны Level1 bid/ask. При отсутствии котировок доступны закрытия свечей. Биржевой стоп-ордер не отправляется, цена исполнения может отличаться от порога. Любой незавершённый ордер блокирует дубли до терминального состояния; индикаторы и стоп продолжают обновляться. На свече выхода нового входа нет, на более поздней подходящей свече он возможен. EMA, шестичасового cooldown, немедленного разворота по встречному сигналу и отдельного тейк-профита нет.

## Настройки и проверки

| Параметр | Значение по умолчанию |
|---|---:|
| `RmiPeriod` | 21, положительный |
| `RmiMomentum` | 3, положительный lag закрытий |
| `SuperTrendLength` | 5, положительный общий период SMA/ATR |
| `SuperTrendMultiplier` | 4, положительная ширина ATR |
| `Direction` | Без значения: обе стороны |
| `CandleType` | 5 минут |

Тесты C# и Python независимо рассчитывают суммы импульса, SMA, Wilder ATR и уровни трейлинга на имеющемся архиве BTC/TON. Проверяются каждый вход, выход по исполнимой цене и фактическая позиция, обе стороны и их фильтры, игнорирование встречного входного сигнала при удержании, тесные intrabar-стопы и входы ближе шести часов.
