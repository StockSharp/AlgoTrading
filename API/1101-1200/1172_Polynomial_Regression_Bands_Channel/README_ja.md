# 多項式回帰バンドチャネル戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この戦略は直近の価格に多項式回帰線を当てはめ、残差の標準偏差から上下バンドを構築します。価格が下バンドを下回るとロングポジションを開き、価格が上バンドを上回るとショートポジションを開きます。

## 詳細

- **エントリー条件**:
  - **ロング**: `Close < LowerBand`.
  - **ショート**: `Close > UpperBand`.
- **ロング/ショート**: 両方。
- **エグジット条件**:
  - 逆のシグナル。
- **ストップ**: なし。
- **デフォルト値**:
  - `Length` = 100.
  - `Degree` = 2.
  - `StdDevMultiplier` = 2.
  - `CandleType` = TimeSpan.FromMinutes(5).TimeFrame().
- **フィルター**:
  - カテゴリ: 平均回帰
  - 方向: 両方
  - インジケーター: 多項式回帰
  - ストップ: いいえ
  - 複雑さ: 中程度
  - 時間軸: 中期
  - 季節性: いいえ
  - ニューラルネットワーク: いいえ
  - ダイバージェンス: いいえ
  - リスクレベル: 中

## 計算と執行

確定足ごとに、現在の終値を含む直近 `Length` 個の終値に対し、-1から1までの等間隔格子上で次数 `Degree` の多項式を最小二乗法で当てはめる。チャネル中心は最新点の当てはめ値。幅は `StdDevMultiplier * sqrt(sum((close[i] - fitted[i])^2) / Length)`、自由度補正なしの残差の母標準偏差となる。

終値が下限を厳密に下回るとロング、上限を厳密に上回るとショート。反対エントリーは数量 `Volume + abs(Position)` の1件の成行注文で全反転し、保有なしの新規注文は `Volume`。バンド内では保有を維持する。全ウィンドウが揃うまで取引せず、待機時間や保護ストップはない。

有効設定：`0 <= Degree <= 6`、`Length >= Degree + 2`、正の `StdDevMultiplier`。次数0は定数。固定の正規化格子で2回の直交化を行った正規直交多項式基底を事前計算し、各ウィンドウの価格差分をdouble精度で射影する。C#とPythonで計算は共通、注文数量はdecimalを維持する。
