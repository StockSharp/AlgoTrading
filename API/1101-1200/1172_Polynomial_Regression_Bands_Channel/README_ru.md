# Стратегия Polynomial Regression Bands Channel
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта стратегия строит полиномиальную регрессию по последним ценам и формирует верхнюю и нижнюю полосы на основе стандартного отклонения остатков. Длинные позиции открываются, когда цена падает ниже нижней полосы, а короткие — когда цена поднимается выше верхней полосы.

## Детали

- **Условия входа**:
  - **Long**: `Close < LowerBand`.
  - **Short**: `Close > UpperBand`.
- **Long/Short**: Оба направления.
- **Условия выхода**:
  - Противоположный сигнал.
- **Стопы**: Нет.
- **Значения по умолчанию**:
  - `Length` = 100.
  - `Degree` = 2.
  - `StdDevMultiplier` = 2.
  - `CandleType` = TimeSpan.FromMinutes(5).TimeFrame().
- **Фильтры**:
  - Категория: Среднее возвращение
  - Направление: Оба
  - Индикаторы: Полиномиальная регрессия
  - Стопы: Нет
  - Сложность: Средняя
  - Таймфрейм: Среднесрочный
  - Сезонность: Нет
  - Нейронные сети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний

## Расчёт и исполнение

На каждой завершённой свече полином степени `Degree` подбирается методом наименьших квадратов по последним `Length` ценам закрытия, включая текущую, на равномерной сетке от -1 до 1. Центр канала — значение полинома на самой новой точке. Ширина равна `StdDevMultiplier * sqrt(sum((close[i] - fitted[i])^2) / Length)`: стандартное отклонение остатков с делителем Length, без поправки на число степеней свободы.

Close строго ниже нижней полосы открывает long, строго выше верхней — short. Встречный вход полностью разворачивает позицию одним рыночным ордером `Volume + abs(Position)`; вход из flat использует `Volume`. Внутри полос позиция сохраняется. До накопления полного окна торговли нет; cooldown и защитных стопов нет.

Допустимые настройки: `0 <= Degree <= 6`, `Length >= Degree + 2`, положительный `StdDevMultiplier`. Нулевая степень задаёт постоянную. Для фиксированной нормированной сетки заранее вычисляется ортонормированный полиномиальный базис с двумя проходами ортогонализации; каждое окно проецирует на него ценовые смещения с точностью double. C# и Python считают одинаково; объёмы ордеров остаются decimal.
