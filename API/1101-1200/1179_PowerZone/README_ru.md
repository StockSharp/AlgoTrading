# Стратегия PowerZone
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия определяет "PowerZone" — область, образованную медвежьей свечой и последовательностью бычьих свечей (и наоборот). Пробой верхней границы бычьей зоны открывает длинную позицию, пробой нижней границы медвежьей зоны — короткую. Цели и стопы рассчитываются от ширины зоны.

## Детали

- **Условия входа**:
  - **Long**: медвежья свеча `Periods+1` бар назад, затем `Periods` бычьих свечей и пробой выше максимума зоны.
  - **Short**: бычья свеча `Periods+1` бар назад, затем `Periods` медвежьих свечей и пробой ниже минимума зоны.
- **Long/Short**: обе стороны.
- **Условия выхода**: тейк и стоп — множители диапазона зоны.
- **Индикаторы**: нет.
- **Значения по умолчанию**:
  - `Periods` = 5
  - `Threshold` = 0
  - `UseWicks` = false
  - `Take Profit Factor` = 1.5
  - `Stop Loss Factor` = 1
- **Фильтры**:
  - Категория: Breakout
  - Направление: обе стороны
  - Индикаторы: нет
  - Стопы: да
  - Сложность: средняя
  - Таймфрейм: любой
  - Сезонность: нет
  - Нейросети: нет
  - Дивергенция: нет
  - Уровень риска: умеренный

## Расчёт и исполнение

C# и Python используют завершённые свечи. На баре решения `t` опорная свеча — `t - Periods - 1`; следующие `Periods` баров до `t - 1` должны все закрыться строго выше открытия для бычьей зоны или ниже для медвежьей. Опорная свеча имеет строго противоположный цвет. Доджи не подходят. Текущая свеча решения не входит в подтверждение, поэтому зона не известна раньше завершения подтверждающей серии.

Требуется `100 * abs(Close[t - 1] - Close опорной свечи) / abs(Close опорной свечи) >= Threshold`; нулевой Close опорной свечи недопустим. Зона — её тело `[min(Open, Close), max(Open, Close)]` или `[Low, High]` при `UseWicks=true`. Экстремумы подтверждающих свечей не расширяют зону. Ширина положительна. Последние бычья и медвежья зоны сохраняются независимо до замены; каждая допускает не более одного принятого входа.

Лонг требует текущий `Close > максимум бычьей зоны`, шорт — `Close < минимум медвежьей зоны`. Равенство сохраняет позицию. Новая подтверждённая зона может открыть сделку на первой свече решения, даже если цена уже за границей. Из нулевой позиции открывается `Volume`, встречная полностью разворачивается объёмом `Volume + abs(Position)`; наращивания той же стороны нет. Если из нулевой позиции подходят оба направления, приоритет у лонга. Ордер в работе блокирует следующие. EMA, cooldown и другие индикаторы не используются.

При принятии входа фиксируются `ширина зоны * StopLossFactor` и `ширина зоны * TakeProfitFactor`. Расстояния считаются от фактической цены исполнения, средневзвешенной при частичном увеличении той же стороны; уменьшение сохраняет основу, разворот сбрасывает её. Новые зоны не меняют расстояния открытой позиции. Локальная защита проверяет исполнимый bid для лонга, ask для шорта и закрытия завершённых свечей, затем рыночным ордером закрывает весь оставшийся объём. На той же свече защита приоритетна перед новым входом. Касания high/low не считаются внутрисвечным исполнением; при разрывах цена исполнения может отличаться.

Значения по умолчанию выше общие: API-параметры `TakeProfitFactor=1.5`, `StopLossFactor=1`, `CandleType` — пять минут. Опубликованное имя параметра — `UseWicks`, C#-свойство — `IsUseWicks`. `Periods` и множители положительны, `Threshold` — неотрицательный процент. Эти определения уточняют ранее не заданные правила порога, границ, однократного использования и основы цены исполнения.
