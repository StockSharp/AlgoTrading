# PowerZone 戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この戦略は、弱気のローソク足に続く連続した強気のローソク足（またはその逆）によって形成される"PowerZone"オーダーブロックを識別します。強気ゾーンを上回るブレイクアウトがロングトレードを発動し、弱気ゾーンを下回る崩落がショートポジションを開きます。ターゲットとストップはゾーンのレンジに基づきます。

## 詳細

- **エントリー条件**:
  - **ロング**: `Periods+1`本前の弱気ローソク足に続く`Periods`本の強気ローソク足とゾーン高値を上抜ける価格。
  - **ショート**: `Periods+1`本前の強気ローソク足に続く`Periods`本の弱気ローソク足とゾーン安値を下抜ける価格。
- **ロング/ショート**: 両方。
- **エグジット条件**: ゾーンレンジの倍数によるテイクプロフィットとストップロス。
- **インジケーター**: なし。
- **デフォルト値**:
  - `Periods` = 5
  - `Threshold` = 0
  - `UseWicks` = false
  - `Take Profit Factor` = 1.5
  - `Stop Loss Factor` = 1
- **フィルター**:
  - カテゴリ: ブレイクアウト
  - 方向: 両方
  - インジケーター: なし
  - Stops: はい
  - 複雑さ: 中程度
  - 時間軸: 任意
  - 季節性: いいえ
  - ニューラルネットワーク: いいえ
  - ダイバージェンス: いいえ
  - リスクレベル: 中程度

## 計算と執行

C# と Python は確定足を使います。判断足 `t` の基準足は `t - Periods - 1` です。その後の `t - 1` までの `Periods` 本がすべて始値より厳密に高く引ければ強気ゾーン、低く引ければ弱気ゾーンになります。基準足は厳密に逆の色で、同値の足は対象外です。現在の判断足は確認に含めず、確認の完了前にゾーンを利用しません。

`100 * abs(Close[t - 1] - 基準 Close) / abs(基準 Close) >= Threshold` を要求し、基準終値0は無効です。ゾーンは基準足の実体 `[min(Open, Close), max(Open, Close)]`、`UseWicks=true` なら `[Low, High]` です。確認足の極値でゾーンを拡大せず、幅は正とします。最新の強気・弱気ゾーンを別々に更新まで保持し、各ゾーンは受理したエントリー1回だけに使います。

ロングは現在の `Close > 強気ゾーン高値`、ショートは `Close < 弱気ゾーン安値` を要求し、同値は維持します。新ゾーンは価格がすでに境界外でも最初の判断足で入れます。ポジションなしでは `Volume`、反対ポジションでは `Volume + abs(Position)` で完全反転し、同方向の追加はしません。両方向が空の状態で適格ならロング優先です。未完了注文中は次の注文を禁止します。EMA、待機時間、その他の指標は使いません。

エントリー受理時に `ゾーン幅 * StopLossFactor` と `ゾーン幅 * TakeProfitFactor` を固定し、実際の約定価格を基準にします。同方向の部分追加は出来高加重平均、縮小は基準保持、反転はリセットです。後のゾーンは距離を動かしません。ローカル保護はロングの実行可能 bid、ショートの ask、確定足の終値を確認し、全残量を成行決済します。同じ足の新規エントリーより保護を優先します。高値・安値への接触を足内約定と想定せず、ギャップで約定価格が変わる場合があります。

共通標準値：API パラメーター `TakeProfitFactor=1.5`、`StopLossFactor=1`、`CandleType` は5分。公開パラメーター名は `UseWicks`、C# プロパティは `IsUseWicks` です。`Periods` と倍率は正、`Threshold` は非負の割合です。これらは以前未指定だった閾値、境界、単一使用、約定基準のルールを明確にします。
