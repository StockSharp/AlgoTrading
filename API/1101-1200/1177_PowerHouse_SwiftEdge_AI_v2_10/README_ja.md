# PowerHouse SwiftEdge AI v2.10 戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

ピボットベースのブレイクアウト戦略で、モメンタムフィルターとシンプルなリスク管理を備えています。
価格が直近のピボット高値を十分なモメンタムと前回シグナルからの最小距離で突破したときにロングエントリーが発生します。
ショートエントリーは、負のモメンタムでピボット安値を割り込んだときに発動します。
ポジションはポイント単位で指定されたテイクプロフィットとストップロスを使用します。

## 計算と執行

決定論的なサンプルであり、歴史的な名称は学習済み AI モデルを意味しません。C# と Python は上記の説明を次のように明確化して実装します。

確定した基本足を使います。ピボット高値は左右それぞれ `PivotPeriod` 本の隣接足の高値すべてより厳密に高く、ピボット安値は安値すべてより厳密に低い必要があります。同値はピボットを形成しません。右側の足が確定してから確認し、過去へのシグナル追加はしません。直近の確定高値と安値を別々に保持します。

ロングは `前の Close <= ピボット高値` かつ `現在の Close > ピボット高値`、ショートはピボット安値の逆方向交差を要求します。モメンタムは `現在の Close - MomentumPeriod 本前の Close` で、ロングは `MomentumThreshold` より厳密に大きく、ショートはその負値より小さい必要があります。両方向とも前回の受理したエントリーから `MinSignalBars` 本以上の確定足が必要で、0は間隔を無効化します。拒否したシグナルは後で実行しません。EMA フィルターや6時間の待機はありません。

ポジションなしでは `Volume`、反対ポジションでは `Volume + abs(Position)` で完全反転します。未完了注文中は新しい注文を禁止します。距離は絶対的な気配価格単位で、1ポイントは価格差1を意味し、tick、`PriceStep` 倍率、割合ではありません。銘柄に合わせて調整します。基準は実際の約定価格で、同方向への部分追加は出来高加重平均とし、縮小は基準を保持、反転は新しい基準にします。

ローカル保護はロングの現在 bid またはショートの現在 ask がストップかテイクに達すると全量を成行決済します。確定足の終値も保護を確認します。高値・安値への接触を順序のある足内イベントとして扱いません。保護はエントリー間隔に制限されず、同じ足の新規エントリーより優先します。価格ギャップ時は約定価格がトリガーと異なる場合があります。

標準値：`PivotPeriod=2`、`MomentumPeriod=10`、`MomentumThreshold=0`、`MinSignalBars=5`、`StopLossPoints=50`、`TakeProfitPoints=100`、`CandleType=TimeSpan.FromMinutes(5).TimeFrame()`。期間と決済距離は正、モメンタム閾値と間隔は非負にします。
