# Стратегия PowerHouse SwiftEdge AI v2.10
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия пробоя пивотов с фильтром импульса и простым управлением рисками.
Длинная позиция открывается при пробое последнего пивота вверх при достаточном импульсе и минимальном интервале между сигналами.
Короткая позиция открывается при пробое пивота вниз и отрицательном импульсе.
Позиции закрываются по тейк‑профиту и стоп‑лоссу в пунктах.

## Расчёт и исполнение

Это детерминированный пример: историческое название не подразумевает обученную ИИ-модель. C# и Python одинаково реализуют следующее явное уточнение описания выше.

Используются завершённые базовые свечи. Пивотный максимум строго выше highs `PivotPeriod` соседних баров с каждой стороны; минимум строго ниже их lows. Равенство исключает пивот. Подтверждение поступает лишь после завершения правых баров, без сигналов задним числом. Последние подтверждённые максимум и минимум хранятся независимо.

Лонг требует `предыдущий Close <= пивотный максимум` и `текущий Close > пивотный максимум`; шорт — обратного пересечения пивотного минимума. Импульс равен `текущий Close - Close[MomentumPeriod баров назад]`. Для лонга он строго выше `MomentumThreshold`, для шорта — строго ниже отрицательного порога. Для обеих сторон нужно не менее `MinSignalBars` завершённых баров после последнего принятого входа; ноль отключает интервал. Отклонённые сигналы не откладываются. EMA-фильтра и шестичасового cooldown нет.

Из нулевой позиции открывается `Volume`, встречная полностью разворачивается объёмом `Volume + abs(Position)`. Ордер в работе блокирует новые ордера. Стоп и тейк заданы фиксированными единицами цены котировки: один пункт — разница цены 1, а не тик, множитель `PriceStep` или процент. Значения нужно настроить под инструмент. Основа — фактическая цена исполнения, средневзвешенная при частичном увеличении той же стороны; уменьшение сохраняет основу, разворот начинает новую.

Локальная защита рыночным ордером закрывает весь объём при достижении стопа или тейка текущим bid для лонга либо ask для шорта. Закрытия завершённых свечей тоже проверяют защиту; касания high/low не выдаются за упорядоченные внутрисвечные события. Защита не ограничена интервалом входов и приоритетна перед новым входом на той же свече. При разрывах цена исполнения может отличаться от уровня срабатывания.

Значения по умолчанию: `PivotPeriod=2`, `MomentumPeriod=10`, `MomentumThreshold=0`, `MinSignalBars=5`, `StopLossPoints=50`, `TakeProfitPoints=100`, `CandleType=TimeSpan.FromMinutes(5).TimeFrame()`. Периоды и оба расстояния выхода положительны; порог импульса и интервал неотрицательны.
