# PresentTrend

終値RSIまたは典型価格と出来高のMFIで制御する因果ATRラインです。2本前のライン値との確認済みクロスで、エントリー、完全反転、決済を行います。

## ラインとシグナル

確定足のみで、既定は5分足です。標準Wilder ATRと選択したオシレーターは正の共通期間`Length=14`を使い、未選択のオシレーターは登録しません。両方が形成されてから計算します。

- オシレーター ≥50：候補`low - Multiplier * ATR`。ラインは候補と前回ラインの最大値。
- オシレーター <50：候補`high + Multiplier * ATR`。ラインは候補と前回ラインの最小値。
- 最初のラインは選択した候補そのものとし、以前の値を仮定しません。`Multiplier=1`で正が必要です。

ATRは前回終値からのギャップを含み、拡大する平均から始まり、その後Wilder平滑化を使います。RSIは終値の上昇・下落をWilder平滑化し、終値不変なら前回結果を保持します。MFIは`typical=(high+low+close)/3`と出来高の積を使い、typical上昇なら正流、下落なら負流、不変ならどちらにも計上しません。直近`Length`足で`100 * positiveSum / (positiveSum + negativeSum)`、負流ゼロなら100です。

tでの生ロングクロスは`line[t-1] <= line[t-3]`かつ`line[t] > line[t-2]`、ショートはそれぞれ≥と<です。形成済みライン4本が必要です。

ロングの確認には、以前の生ショートが存在し、以前の生ロングより新しいこと（または生ロングがまだないこと）が必要です。ショートは対称です。比較後に各生シグナルを記録し、取引を拒否されたものも含めます。観測済みの反対シグナルがない最初の生シグナルは取引しません。同方向の繰り返しには間に反対シグナルが必要です。

## 執行と既定値

両方向有効なら、ポジションなしで`Volume`、反対ポジションなら`Volume + abs(Position)`で完全反転します。同方向は保持します。ロング専用なら確認済みショートで全ロングを閉じ、ショートは開きません。ショート専用は対称です。無効方向でポジションなしなら何もしません。未完了注文は重複を防ぎますが、ラインと生シグナル履歴は進みます。拒否したシグナルを持ち越さず、6時間待機もありません。

独立した価格ストップロスや利確はありません。単方向モードの決済は確認済みの反対シグナルによるもので、ATR価格ストップ注文ではありません。

| パラメーター | 既定値 |
|---|---:|
| `Length` | 14、正の共通期間 |
| `Multiplier` | 1、正のATR距離 |
| `IsUseMfi` | falseでRSI、trueでMFI |
| `IsLongEnabled` / `IsShortEnabled` | true / true、少なくとも片側が有効 |
| `CandleType` | 5分 |

C#とPythonは既存BTC/TON履歴からATR、RSI/MFI、ライン、生・確認済みクロスを独立計算し、各注文と実際のポジションの時刻、方向、完全反転、単方向決済を検証します。両オシレーターと6時間未満のシグナル間隔を試します。収益性を証明しません。
