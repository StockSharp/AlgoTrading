# PresentTrend
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Каузальная ATR-линия под управлением RSI закрытий либо MFI типичной цены и объёма. Подтверждённые пересечения со значением линии два бара назад открывают, полностью разворачивают или закрывают позиции.

## Расчёт линии

Только завершённые свечи, по умолчанию пятиминутные. Штатные Wilder ATR и выбранный осциллятор используют общий `Length` (14). Невыбранный осциллятор не регистрируется. Оба выбранных индикатора должны прогреться.

На каждой прогретой свече осциллятор ≥50 выбирает бычий режим, <50 — медвежий:

- Бычий кандидат: `low - Multiplier * ATR`. PresentTrend — максимум кандидата и предыдущей линии.
- Медвежий кандидат: `high + Multiplier * ATR`. PresentTrend — минимум кандидата и предыдущей линии.
- Первая сформированная линия равна выбранному кандидату; более ранние значения не выдумываются.

`Multiplier` по умолчанию 1. ATR учитывает разрывы относительно предыдущего close, начинает со среднего по растущему окну и затем применяет Wilder-сглаживание. RSI сглаживает рост/падение close по Wilder и сохраняет прошлый результат при неизменном close. MFI использует `typical=(high+low+close)/3` и объём: при росте typical поток положительный, при снижении отрицательный, при равенстве отсутствует. MFI равен `100 * positiveSum / (positiveSum + negativeSum)` за последние `Length` свечей либо 100 при нулевом отрицательном потоке.

## Сигналы и исполнение

Исходное пересечение вверх в t: `line[t-1] <= line[t-3]` и `line[t] > line[t-2]`. Вниз используются ≥ и < соответственно. Нужны четыре сформированных значения линии.

Лонг подтверждается, только если ранее наблюдался исходный шорт, более новый, чем предыдущий исходный лонг, либо предыдущего лонга ещё не было. Для шорта симметрично. Каждый исходный сигнал записывается после сравнения, включая отклонённые для торговли. Первый исходный сигнал без наблюдаемого встречного не торгует. Повторные исходные сигналы одной стороны не дают новый вход до появления встречного.

При разрешении обеих сторон подтверждённый сигнал открывает `Volume` из нулевой позиции либо отправляет `Volume + abs(Position)` для полного разворота встречной. Сигнал в сторону открытой позиции её сохраняет. В long-only подтверждённый шорт полностью закрывает long без открытия short; short-only симметричен. Запрещённое направление из нулевой позиции ничего не делает. Незавершённый ордер блокирует дубли, но линия и история исходных сигналов продолжают обновляться. Отклонённые сигналы не откладываются. Шестичасового cooldown нет.

Отдельных ценовых стоп-лосса и тейк-профита нет. Выход одностороннего режима происходит по подтверждённому встречному сигналу, а не по ATR стоп-ордеру.

## Настройки и проверки

| Параметр | Значение по умолчанию |
|---|---:|
| `Length` | 14, положительный общий период ATR/осциллятора |
| `Multiplier` | 1, положительное расстояние ATR |
| `IsUseMfi` | false выбирает RSI, true — MFI |
| `IsLongEnabled` / `IsShortEnabled` | true / true; хотя бы одна сторона разрешена |
| `CandleType` | 5 минут |

Поведенческие тесты C# и Python независимо считают ATR, RSI/MFI, линию и исходные/подтверждённые пересечения на имеющемся архиве BTC/TON. Каждый ордер и фактическая позиция проверяются по моменту, стороне, полному развороту или одностороннему закрытию. Проверяются оба осциллятора и сигналы ближе шести часов. Доходность не доказывается.
