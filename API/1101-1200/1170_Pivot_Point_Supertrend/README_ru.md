# Стратегия Pivot Point Supertrend
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия, объединяющая pivot points и основанный на ATR Supertrend для ловли разворотов тренда.

Pivot points формируют динамическую центральную линию. ATR задаёт верхние и нижние полосы, которые следуют за ценой. Когда тренд меняется, стратегия открывает позицию в новом направлении.

## Детали

- **Критерии входа**: сигналы на основе pivot points и ATR Supertrend.
- **Длинные/короткие**: оба направления.
- **Критерии выхода**: противоположный сигнал.
- **Стопы**: нет.
- **Значения по умолчанию**:
  - `PivotPeriod` = 2
  - `AtrFactor` = 3m
  - `AtrPeriod` = 10
  - `CandleType` = TimeSpan.FromMinutes(5)
- **Фильтры**:
  - Категория: Тренд
  - Направление: Оба
  - Индикаторы: Pivot Points, ATR
  - Стопы: Нет
  - Сложность: Базовая
  - Таймфрейм: Внутридневной (5m)
  - Сезонность: Нет
  - Нейросети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний

## Расчёт и исполнение

Используются только завершённые свечи. Pivot high/low должен быть строго выше/ниже всех `PivotPeriod` свечей с каждой стороны и подтверждается только после завершения правых свечей. Если свеча подходит для обоих pivot, приоритет имеет high. Первый подтверждённый pivot задаёт `center`, следующие обновляют его по формуле `(2 * center + pivot) / 3`.

Полосы pivot используют Wilder ATR: первые `AtrPeriod` true range усредняются, затем сглаживаются с весом `1 / AtrPeriod`. Базовые поддержка/сопротивление равны `center ± AtrFactor * ATR`. Поддержка сохраняет максимум базового и предыдущего значения, когда previous close выше previous support; иначе сбрасывается. Сопротивление сохраняет минимум, когда previous close ниже previous resistance; иначе сбрасывается. Close строго выше предыдущего сопротивления переключает вверх, строго ниже предыдущей поддержки — вниз; иначе направление сохраняется. Начальное направление — вверх, инициализация не даёт сигнал.

До готовности Wilder ATR и подтверждённого pivot center входов нет. Сигналом служит только смена направления пивотных полос: вверх открывает long, вниз — short. Начальное направление — вверх; инициализация не создаёт ордер. Каждый встречный сигнал полностью разворачивает позицию одним рыночным ордером `Volume + abs(Position)`; вход из flat использует `Volume`. SMA, отдельного ценового SuperTrend, фильтра дат, cooldown и защитного стопа нет.

Пивотная концепция: [Pivot Point Supertrend автора LonesomeTheBlue](https://www.tradingview.com/script/L0AIiLvH-Pivot-Point-Supertrend/). Правила выше определяют двунаправленную модель этого примера.
