# Previous Day High Low Long
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Только long по пересечению вверх наблюдаемых high или low предыдущего UTC-дня, с растущим штатным ADX внутри UTC-сессии. Выход по цели от фактического исполнения, трейлингу наблюдаемой цены или окончанию сессии.

## Уровни и вход

Только завершённые свечи, по умолчанию пятиминутные. High/low группируются по UTC-дате открытия свечи. При начале следующей даты фиксируются наблюдаемые максимальный high и минимальный low прошлого дня. Он доступен, только если его первая наблюдаемая свеча открылась в полночь и даты соседние. Для неполного начального дня или пропущенной даты уровни не выдумываются.

Пробой high: `previousClose <= previousDayHigh && close > previousDayHigh`; для low — такое же пересечение вверх его уровня. Свечи текущего дня не изменяют эти фиксированные уровни. Штатный ADX с `AdxLength=11` должен сформироваться и строго превысить своё предыдущее сформированное значение. Дополнительного порога ADX и проверки направления DI нет.

Вход только из нулевой позиции рыночной покупкой `Volume`, если UTC-время отправки входит в `[SessionStart, SessionEnd)`, по умолчанию 09:30–16:00. Отклонённый пробой не откладывается: история close, дня и ADX обновляется на каждой завершённой свече. После закрытия возможен вход по новому пересечению; суточного лимита и шестичасового cooldown нет. Short не открывается.

## Защита и завершение сессии

Расстояния заданы в абсолютных единицах цены: `MaxProfit=150`, `MaxStopLoss=15`, а не процентах или шагах цены инструмента. Начальная цена и максимум берутся из фактического исполнения покупки; дополнительные частичные покупки обновляют средневзвешенную цену входа. Уменьшение позиции сохраняет её базу, нулевая позиция сбрасывает её.

Каждый положительный исполнимый bid или завершённый close обновляет наблюдаемый максимум до большего из прошлого значения и текущей цены. Полный фактический long закрывается рыночной продажей при цене ≤ `highWater - MaxStopLoss` либо ≥ `entryPrice + MaxProfit`. Приоритет: конец сессии, трейлинг, цель прибыли. High свечи не подставляется вместо наблюдаемой исполнимой цены.

Минутный таймер рыночного времени, bid и завершённые свечи закрывают long при/после `SessionEnd` либо на следующей UTC-дате. Времена упорядочены внутри одного дня; 00:00–24:00 закрывается в следующую полночь. Незавершённый ордер блокирует дубли до терминального состояния; история дней/ADX продолжает обновляться. Свечной callback после закрытия возвращается без повторного входа.

Это локальный мониторинг, не биржевой стоп-ордер. Для intrabar-защиты по котировкам нужен Level1 bid; без него доступны закрытия свечей. Цена исполнения может отличаться от порога.

## Настройки и проверки

| Параметр | Значение по умолчанию |
|---|---:|
| `MaxProfit` / `MaxStopLoss` | 150 / 15, положительные абсолютные расстояния цены |
| `AdxLength` | 11, положительный |
| `SessionStart` / `SessionEnd` | 09:30 / 16:00 UTC, начало включено, конец исключён |
| `CandleType` | 5 минут |

Тесты C#/Python независимо группируют наблюдаемые дни и рассчитывают Wilder ATR/DI/DX/ADX. Проверяются каждый фактический вход/выход, оба уровня прошлого дня, отказы растущего ADX, неполное начало истории, фактические исполнения, трейлинг/цель по котировкам и обязательное закрытие сессии на имеющемся архиве BTC/TON. Доходность не заявляется.
