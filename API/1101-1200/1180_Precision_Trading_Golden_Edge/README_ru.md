# Precision Trading: Golden Edge
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия пересечения EMA с подтверждением направления Hull, импульса RSI и волатильности ATR/диапазона high-low. Историческое описание относилось к скальпингу золота; пример работает с выбранным инструментом и не доказывает результативность на золоте.

## Сигналы и исполнение

Используются только завершённые свечи, по умолчанию пятиминутные. Все семь индикаторов должны сформироваться. Первая полностью прогретая свеча запоминает предыдущие EMA/HMA без входа.

- Лонг: предыдущая быстрая EMA ≤ предыдущей медленной EMA, текущая быстрая EMA > текущей медленной EMA, текущая HMA > предыдущей HMA и RSI > `RsiLongThreshold` (55).
- Шорт: предыдущая быстрая EMA ≥ предыдущей медленной EMA, текущая быстрая EMA < текущей медленной EMA, текущая HMA < предыдущей HMA и RSI < `RsiShortThreshold` (45).
- Для обоих направлений нужны положительные close и ATR, `100 * ATR / close >= MinAtrPercent` (0.05) и `Highest(high) - Lowest(low) >= ATR * RangeAtrMultiplier` (3). Окно high/low включает текущую свечу.

Подтверждённое пересечение открывает `Volume` из нулевой позиции либо отправляет `Volume + abs(Position)` для полного разворота встречной позиции. Сигнал в сторону уже открытой позиции её сохраняет. Незавершённый ордер блокирует повторную отправку. Предыдущие EMA/HMA обновляются на каждой полностью прогретой свече: отклонённое пересечение не откладывается для последующего входа. Шестичасового cooldown нет. Отдельных стоп-лосса и тейк-профита нет; встречное подтверждённое пересечение разворачивает позицию.

## Индикаторы и настройки по умолчанию

| Параметр | Значение | Смысл |
|---|---:|---|
| `FastLength` / `SlowLength` | 14 / 40 | Штатные EMA закрытий; быстрая короче медленной |
| `HmaLength` | 55 | `WMA(floor(sqrt(L)), 2 * WMA(floor(L/2), close) - WMA(L, close))`; длина ≥ 2 |
| `RsiLength` | 14 | Штатный RSI с Wilder-сглаживанием положительных и отрицательных изменений close |
| `RsiLongThreshold` / `RsiShortThreshold` | 55 / 45 | Строгие пороги; `0 <= short < long <= 100` |
| `AtrLength` | 14 | Штатный Wilder ATR с учётом разрывов относительно предыдущего close |
| `RangeLength` | 20 | Максимальный high и минимальный low, включая текущую свечу |
| `MinAtrPercent` | 0.05 | Включительный минимум ATR в процентах текущего close; неотрицательный |
| `RangeAtrMultiplier` | 3 | Включительный минимум диапазона high-low в единицах ATR; положительный |
| `CandleType` | 5 минут | Завершённые свечи для всех индикаторов |

Веса WMA растут от 1 для старого наблюдения до длины окна для нового. EMA начинается со штатного среднего арифметического, затем использует `2 / (length + 1)`. ATR начинает со среднего по растущему окну, затем использует сглаживание Wilder. Периоды положительны; Hull дополнительно прогревает заключительную WMA длины квадратного корня.

Поведенческие тесты C# и Python независимо рассчитывают EMA, HMA, RSI, ATR и скользящие экстремумы на имеющемся архиве BTC/TON. Проверяются каждый отправленный ордер, полные развороты, отклонённые подтверждения и сигналы ближе шести часов. Это проверка поведения, а не доходности или пригодности для реальной торговли.
