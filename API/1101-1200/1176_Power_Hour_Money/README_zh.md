# Power Hour Money 策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该策略在所选纽约交易时段运行，只有当月、周、日和小时K线同向时才开仓。
当所有这些周期的收盘价高于开盘价时做多；
当它们全部收盘价低于开盘价时做空。
可选的跟踪止损用于保护利润，并可在16:45自动平仓。

## 细节

- **入场**：所有周期为绿色时做多，全部为红色时做空。
- **交易时段过滤**：纽约 9:30-11:30，扩展时段 8:00-16:00 或不限制。
- **跟踪止损**：多空各自的百分比设置。
- **收盘**：可选择在16:45全部平仓。

## 计算与执行

C# 和 Python 使用相同的因果模型：每根基础K线完成后，其收盘价就是当前已知的正在形成的月、周、日和小时K线收盘价，与各周期开盘价严格比较。颜色混合或价格相等时保持仓位。不会使用未来的最终高周期收盘价。

月、从星期一开始的周和日按纽约日历计算，并处理夏令时。小时用 UTC 标识，以区分秋季重复的小时。观察到周期变化后，以第一根可用基础K线的开盘价作为新周期开盘价。历史开始时已经进行中的周期，在下次边界前保持未知；不会用第一笔观察价格代替缺失的开盘价。入场前必须知道四个开盘价。

默认 `CandleType` 为五分钟。`SessionStart=09:30`、`SessionEnd=11:30` 使用纽约市场时间，包含开始、不包含结束。延长时段设为 `08:00`–`16:00`，或设置 `IsAllSessions=true`。`IsAllSessions`、`IsTrailingEnabled`、`IsEndOfDayCloseEnabled` 默认均为 `false`；`LongTrailingPercent=2`、`ShortTrailingPercent=2`、`EndOfDayTime=16:45`。

颜色一致时，空仓以 `Volume` 入场，已有反向仓位以 `Volume + abs(Position)` 完全反转。有未完成订单时不再发出订单，没有冷却期。可选跟踪止损从实际成交价开始：多仓在当前 bid 达到 `已观察最高 bid * (1 - LongTrailingPercent / 100)` 时平仓；空仓在当前 ask 达到 `已观察最低 ask * (1 + ShortTrailingPercent / 100)` 时平仓。成交价也更新有利极值。两个百分比都必须严格大于 0、小于 100。反转会重置极值。

可选日终平仓在截止时间或之后的第一个市场时间回调中，用市价单平掉全部仓位，并禁止入场直到纽约午夜。报价回调和一分钟市场时间计时器独立于K线预热和交易时段进行检查。跟踪止损和日终平仓需要市场事件；发生价格跳空时不保证准确的成交价。
