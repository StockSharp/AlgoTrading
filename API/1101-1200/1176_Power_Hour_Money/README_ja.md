# Power Hour Money 戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この戦略は選択されたニューヨークセッション中に取引し、主要な時間軸すべてが一致したときにポジションを建てます。
月足、週足、日足、時間足のローソク足が始値より高く引けたときにロングポジションを建てます。
すべてが低く引けたときにショートポジションを建てます。
オプションのトレーリングストップが利益を保護し、16:45にポジションを決済することができます。

## 詳細

- **エントリー**: すべての時間軸が緑のときロング、すべて赤のときショート。
- **セッションフィルター**: NY 9:30-11:30、拡張 8:00-16:00 またはすべてのセッション。
- **トレーリングストップ**: ロングとショート両側のパーセントベース。
- **デイエンド**: 16:45にすべてのポジションをオプションで決済。

## 計算と執行

C# と Python は同じ因果モデルを使います。基本足が確定するたびに、その終値を形成中の月足・週足・日足・時間足の現在判明している終値として、各始値と厳密に比較します。色の不一致や同値ではポジションを維持します。将来の上位足の確定終値は参照しません。

月、月曜日始まりの週、日は夏時間を含むニューヨークの暦に従います。秋の重複する時間を区別するため、時間足は UTC で識別します。期間の切り替わりを観測した後、最初の利用可能な基本足の始値を新期間の始値とします。履歴開始前から進行中の期間は次の境界まで不明とし、最初に観測した価格で欠けた始値を代用しません。エントリーには四つの始値が必要です。

標準の `CandleType` は5分です。`SessionStart=09:30` と `SessionEnd=11:30` はニューヨークの市場時刻で、開始を含み終了を含みません。拡張時間は `08:00`–`16:00` に設定し、全時間は `IsAllSessions=true` にします。`IsAllSessions`、`IsTrailingEnabled`、`IsEndOfDayCloseEnabled` の標準値は `false`、`LongTrailingPercent=2`、`ShortTrailingPercent=2`、`EndOfDayTime=16:45` です。

色が一致すれば、ポジションなしでは `Volume`、反対ポジションでは `Volume + abs(Position)` で完全反転します。未完了注文中は追加注文を禁止し、待機時間はありません。任意のトレーリングは実際の約定価格から開始します。ロングは現在の bid が `観測した最高 bid * (1 - LongTrailingPercent / 100)`、ショートは現在の ask が `観測した最低 ask * (1 + ShortTrailingPercent / 100)` に達すると決済します。約定価格も有利な極値を更新します。両割合は厳密に0より大きく100より小さく設定します。反転で極値をリセットします。

任意の日次決済は締切時刻以後の最初の市場時刻イベントで全ポジションの成行決済を送り、ニューヨークの午前0時まで新規エントリーを禁止します。気配値と1分の市場時刻タイマーが、セッションや足の準備とは独立に確認します。これらの決済には市場イベントが必要で、価格のギャップ時に正確な約定価格を保証しません。
