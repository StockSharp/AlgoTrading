# Premarket Gap MomoTrader
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

ロング専用の足の勢いを使う例で、ニューヨークの暦日ごとに1回だけ入ります。「ギャップ」は前回終値から現在終値への上昇を指し、夜間の始値ギャップやEMAクロスは不要です。

## エントリーと数量

確定足のみを使い、既定は5分足です。最初の足は前回終値と出来高を保存します。ポジションなしからのエントリーは、厳密な陽線、正のhigh-low幅、総出来高 > `MinVolume`、正の前回終値、`100 * (close - previousClose) / previousClose >= MinGainPct`を要求します。

`bodyPercent = 100 * (close - open) / (high - low)`：90%以上は戦略`Volume`の100%、85%以上90%未満は50%、75%以上85%未満は25%、75%未満は入りません。下限を含みます。

銘柄に正の`VolumeStep`があれば数量をその刻みに切り下げます。ゼロ数量や指定された銘柄の最小・最大数量範囲外は拒否します。既存ポジションを増やしません。

`UseSession=true`では、注文時刻がニューヨーク時間の`[SessionStart, SessionEnd)`にある必要があります。既定は04:00–09:30で夏時間を反映します。時間フィルターを無効にしても日次制限は有効です。エントリー注文の送信でその日の機会を消費し、後から失敗しても戻しません。

## 保有と決済

最初の陰線（`close < open`）または`volume <= previousVolume`の足で実際のロング全量を決済します。陽線かつ出来高増加なら保有し、同時線も出来高増加なら保有します。決済はエントリー時間帯の外でも判定し、上昇率・実体比率・最低出来高の条件に依存しません。決済した足で再エントリーしません。未完了注文は重複を防ぎますが、前回終値と出来高は毎確定足で更新します。

指標、ショートのエントリー、6時間待機、個別のストップロスや利確はありません。次のエントリーには次の条件を満たすニューヨーク日付が必要です。

## 既定値

| パラメーター | 既定値 | 意味 |
|---|---:|---|
| `MinGainPct` | 5 | 上昇率の下限百分率。境界を含み、非負 |
| `MinVolume` | 15000 | 厳密な出来高下限。非負でデータの単位を使う |
| `UseSession` | true | エントリー時刻フィルター。C#プロパティ`IsUseSession` |
| `SessionStart` / `SessionEnd` | 04:00 / 09:30 | 同じニューヨーク日の順序付き時刻。開始を含み、終了を含まない |
| `CandleType` | 5分 | 確定シグナル足 |

既存BTC/TON履歴を使い、各注文と実際のポジション、3段階の数量、ロット切り下げ、日次制限、2種類の決済、保有、春のニューヨーク夏時間移行をテストします。公開既定値5%/15000にはTONで適合足があり、BTCの動作検証はしきい値を明示的に変更します。収益性は証明しません。
