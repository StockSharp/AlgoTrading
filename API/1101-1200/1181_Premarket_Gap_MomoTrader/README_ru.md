# Premarket Gap MomoTrader
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Пример свечного импульса только в long, с одним входом за календарный день Нью-Йорка. «Гэп» здесь означает рост close относительно предыдущего close; ночной разрыв открытия и пересечение EMA не требуются.

## Вход и размер позиции

Используются только завершённые свечи, по умолчанию пятиминутные. Первая запоминает предыдущие close и объём.

Из нулевой позиции текущая свеча должна быть строго бычьей, с положительным диапазоном high-low и общим объёмом строго больше `MinVolume`. Рост удовлетворяет `100 * (close - previousClose) / previousClose >= MinGainPct`, предыдущий close положителен. Доля тела: `bodyPercent = 100 * (close - open) / (high - low)`.

| Доля тела, включая границу | Запрошенный объём входа |
|---|---:|
| ≥ 90 | 100% от `Volume` стратегии |
| ≥ 85 и < 90 | 50% |
| ≥ 75 и < 85 | 25% |
| < 75 | Входа нет |

Если инструмент задаёт положительный `VolumeStep`, объём округляется вниз до этого шага. Нулевой объём или выход за заданные инструментом минимальный/максимальный пределы запрещают вход. Наращивания открытой позиции нет.

При `UseSession=true` отправка происходит по времени Нью-Йорка в `[SessionStart, SessionEnd)`, по умолчанию 04:00–09:30, с учётом летнего времени. Суточный лимит действует и при отключённом фильтре сессии. Отправленный вход расходует разрешение этой даты, даже если ордер позднее завершился ошибкой.

## Удержание и выход

Первая красная свеча (`close < open`) или свеча с `volume <= previousVolume` полностью закрывает фактический long. Бычьи свечи с растущим объёмом удерживают позицию; doji тоже удерживает её при росте объёма. Выход проверяется и за пределами входной сессии, независимо от порогов роста, тела и минимального объёма. На свече выхода повторного входа нет. Незавершённый ордер блокирует повторную отправку, но предыдущие close/объём обновляются на каждой завершённой свече.

Индикаторов, short-входов, шестичасового cooldown и отдельных стоп-лосса/тейк-профита нет. Новый вход возможен на следующей подходящей дате Нью-Йорка.

## Настройки по умолчанию

| Параметр | Значение | Смысл |
|---|---:|---|
| `MinGainPct` | 5 | Включительный минимум роста в процентах; неотрицательный |
| `MinVolume` | 15000 | Строгий нижний порог объёма свечи; неотрицательный, в единицах исходных данных |
| `UseSession` | true | Фильтр времени входа; C# свойство `IsUseSession` |
| `SessionStart` / `SessionEnd` | 04:00 / 09:30 | Упорядоченные времена одного дня Нью-Йорка; начало включено, конец исключён |
| `CandleType` | 5 минут | Завершённые сигнальные свечи |

Поведенческие тесты используют имеющийся архив BTC/TON и проверяют каждый отправленный ордер и фактическую позицию, три доли тела, округление лотов, один вход за дату, обе причины выхода, удержания и сессию Нью-Йорка с весенним переходом на летнее время. Опубликованные defaults 5%/15000 дают подходящую свечу на TON; BTC-сценарии используют явно изменённые пороги. Доходность этими проверками не доказывается.
