# Powertrend - стратегия с фильтром диапазона по объёму
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия строит динамические диапазоны на основе объёма и диапазона цен. Покупка происходит при пробое верхней границы в восходящем тренде, выход — при пробое нижней. Дополнительно можно включить фильтры ADX, тренда по максимумам/минимумам и VWMA.

## Расчёт и исполнение

C# и Python используют следующее явное причинное определение. На завершённых свечах `d = abs(Close - предыдущий Close)`, `V = TotalVolume`. После `RangePeriod` изменений `r = RangeMultiplier * sum(d * V) / sum(V)` по окну с текущей свечой. Суммарный объём должен быть положительным. Первое сформированное значение фильтра `f` равно текущему Close; далее предыдущее `f` ограничивается интервалом `[Close - r, Close + r]`. Границы текущего решения — `предыдущее f + r` и `предыдущее f - r`, до изменения центра. Поэтому верхняя граница не подменяется ценой пробоя после движения фильтра.

Вход объёмом `Volume` только из нулевой позиции при `Close > верхняя граница` и росте фильтра. При `Close < нижняя граница` рыночным ордером закрывается весь лонг независимо от фильтров входа. Равенство сохраняет позицию. Ордер в работе блокирует дополнительные ордера. Шортов, EMA-пересечений и cooldown нет.

Опциональный ADX должен сформироваться и строго превысить `AdxThreshold`; отключённый ADX не регистрируется и не навязывает прогрев. Подтверждение high/low требует одновременно `текущий High > предыдущий High` и `текущий Low > предыдущий Low`. VWMA значений фильтра — `sum(f * V) / sum(V)` по последним `VwmaPeriod` сформированным значениям, включая текущее. Нужны полное окно, положительный суммарный объём и `Close > VWMA`. Отключённые фильтры не требуют прогрева. Это рыночные решения по закрытию свечей, без биржевых стоп-заявок и предполагаемого исполнения по внутрисвечным high/low.

По умолчанию: `RangePeriod=40`, `RangeMultiplier=1.5`, `AdxPeriod=14`, `AdxThreshold=20`, `VwmaPeriod=20`, `CandleType=TimeSpan.FromMinutes(5).TimeFrame()`. `IsAdxFilterEnabled`, `IsHighLowFilterEnabled`, `IsVwmaFilterEnabled` — все `false`. Периоды и множитель положительны; порог ADX в `[0, 100]`. Эти формула и значения уточняют пример: исходное краткое описание не задавало формулу оригинального индикатора.
