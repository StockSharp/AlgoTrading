# MACD с адаптивной гистограммой
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Торгует статистически большие значения гистограммы MACD. Использует завершённые 15-минутные свечи и `H = MACD(12,26) − Signal(9)`. По H рассчитываются `A = SMA(20)` и `D = StandardDeviation(20)`. Нужны сформированные индикаторы и `D > 0`.

Из нулевой позиции покупка при `H >= A + 2 × D && H > 0`, продажа при `H <= A − 2 × D && H < 0`. Весь лонг закрывается при `H <= A`, весь шорт — при `H >= A`. Каждая сигнальная заявка запускает паузу `CooldownBars = 16` завершённых свечей для следующих сигнальных решений.

Исполненные позиции защищает штатный локальный процентный стоп `StopLossPercent = 2` от фактической цены исполнения входа. Защита отслеживает bid/ask инструмента и отправляет рыночный выход независимо от сигнальной паузы; для работы между свечами нужен поток котировок. Тейк-профит не задан.

`FastPeriod = 12; SlowPeriod = 26; SignalPeriod = 9; HistogramAvgPeriod = 20; StdDevMultiplier = 2; StopLossPercent = 2; CooldownBars = 16`.
