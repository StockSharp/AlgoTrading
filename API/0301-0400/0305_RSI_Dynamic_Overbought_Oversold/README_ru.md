# RSI с динамическими уровнями перекупленности/перепроданности
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия **RSI Dynamic Overbought Oversold** построена на индикаторе RSI с динамическими уровнями перекупленности и перепроданности.

Тестирование показывает среднегодичную доходность около 178%\. Стратегию лучше запускать на фондовом рынке.

### Исполняемые правила торговли (C# и Python)

На **завершённых 5-минутных свечах** рассчитываются RSI(14), SMA цены(50), SMA(50) и стандартное отклонение(50) **самого RSI**. Динамические границы: `upper = min(RSI_MA + 2 * RSI_STD, 85)`, `lower = max(RSI_MA - 2 * RSI_STD, 15)`. Из нулевой позиции: покупка только при `RSI <= lower` и `Close >= Price_SMA * 0.995`; продажа только при `RSI >= upper` и `Close <= Price_SMA * 1.005`. Лонг закрывается при `RSI >= RSI_MA` или `Close < Price_SMA * 0.995`; шорт — при `RSI <= RSI_MA` или `Close > Price_SMA * 1.005`. После заявки пауза **48 завершённых свечей**. Для исполненных позиций действует **нативный стоп-лосс 2%**, а не стоп по ATR. Указанная выше доходность не подтверждена архивом BTC/TON.



## Подробности
- **Критерии входа**: см. реализацию условий индикаторов.
- **Длинные/короткие**: обе стороны.
- **Критерии выхода**: противоположный сигнал или логика стопов.
- **Стопы**: да, расчёт на основе индикаторов.
- **Значения по умолчанию**:
  - `RsiPeriod = 14`
  - `MovingAvgPeriod = 50`
  - `StdDevMultiplier = 2.0m`
  - `StopLossPercent = 2.0m`
  - `CandleType = TimeSpan.FromMinutes(5).TimeFrame()`
- **Фильтры**:
  - Категория: Следование за трендом
  - Направление: Оба
  - Индикаторы: перекупленность, перепроданность
  - Стопы: Да
  - Сложность: Средняя
  - Таймфрейм: Внутридневной (5м)
  - Сезонность: Нет
  - Нейронные сети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний
