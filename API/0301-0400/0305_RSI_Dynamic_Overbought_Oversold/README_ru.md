# RSI с динамическими уровнями перекупленности/перепроданности
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Торгует экстремумы RSI относительно адаптивных границ перекупленности/перепроданности с ценовым фильтром тренда. Использует завершённые 5-минутные свечи. `R = RSI(14)`, `P = SMA(50)` цены закрытия, `A = SMA(50)` и `D = StandardDeviation(50)` от R. Границы: `upper = min(A + 2 × D, 85)`, `lower = max(A − 2 × D, 15)`. Все индикаторы должны сформироваться.

Из нулевой позиции покупка при `R <= lower && Close >= P × 0.995`, продажа при `R >= upper && Close <= P × 1.005`. Весь лонг закрывается при `R >= A || Close < P × 0.995`, весь шорт — при `R <= A || Close > P × 1.005`. Сигнальная заявка запускает паузу `CooldownBars = 48` завершённых свечей для следующих сигнальных решений.

Исполненные позиции защищает штатный локальный процентный стоп `StopLossPercent = 2` от фактической цены исполнения входа. Защита отслеживает bid/ask инструмента и отправляет рыночный выход независимо от сигнальной паузы; для работы между свечами нужен поток котировок. Тейк-профит не задан.

`RsiPeriod = 14; MovingAvgPeriod = 50; StdDevMultiplier = 2; StopLossPercent = 2; CooldownBars = 48`.
