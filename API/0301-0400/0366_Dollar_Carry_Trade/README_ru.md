## Правила торговли

Ежемесячно ранжировать наблюдаемый годовой дифференциал «иностранная валюта минус USD». При IsUsdBase=true carry = QuoteRate − BaseRate, иначе carry = BaseRate − QuoteRate. Выбрать K нижних и K верхних значений; нужно не менее 2×K подходящих пар. Держать USD в лонге против низкого carry и в шорте против высокого. Лонг USD означает покупку пары с USD в базовой валюте и продажу пары с USD в котируемой валюте. Каждая сторона получает половину общего бюджета USD. Ориентация пары не может меняться между публикациями.

Обрабатываются только синхронизированные завершённые свечи. Для статистики считаются разные даты UTC; новая внутридневная свеча заменяет цену той же даты. Ребалансировка выполняется один раз на первой подходящей общей свече месяца; непрогретые данные откладывают решение. Равные оценки упорядочиваются по Security.Id.

Все наблюдения должны быть опубликованы к закрытию сигнальной свечи. При внутридневном исполнении дневные цены берутся строго до текущей UTC-даты; завершённая дневная свеча учитывает собственную завершённую дату. Будущие CSV-даты не прогревают решение.

Граница доступности публикаций — последний фактический CloseTime среди синхронизированных завершённых свечей. Торговая сессия может закончиться раньше полного заданного интервала свечи.

## Входные данные

RatesFile — обязательный CSV: `SecurityId,PublishedAt,BaseRate,QuoteRate,UsdPerUnit`. PublishedAt — UTC `yyyy-MM-ddTHH:mm:ssZ`; обе ставки заданы в одинаковых годовых долях. UsdPerUnit — положительная стоимость одной торговой единицы в USD на момент снимка. Подходит только последняя опубликованная запись возрастом не более MaxRateAgeDays. Дубли инструмента/публикации запрещены. Процентные ставки не выводятся из свечных цен.

Для этой стратегии добавить обязательный булев столбец `IsUsdBase` в заголовок и каждую строку ставок (`true` либо `false`).

## Исполнение

Capital — фиксированный бюджет USD, Leverage задаёт общую экспозицию. Для объёма и фильтра MinTradeUsd используется RatesFile.UsdPerUnit. Округлять к нулю по VolumeStep, сверяться с фактическими исполнениями и ждать незавершённые заявки. Соблюдать MinVolume/MaxVolume и разбивать крупные заявки между следующими свечами. Полное закрытие обходит MinTradeUsd. Стоп-лосса и тейк-профита нет.

## Проверка

Оба языка проверяются на исполнениях из имеющегося BTC/TON-архива с явными фикстурами ставок, финансовых отчётов, оценок, текстов и прогрева. Календарные фикстуры переносят даты архивных OHLC/объёмов и задают котировки исполнения; это не многолетняя рыночная история. Проверяются независимые формулы, направление/объём заявок, фактические сделки, остатки позиций и запрещённые даты решений. Два бакета, K=1 и AssetDecile=1 — явные профили механики, а не доказательство работы полного торгового универсума. Доходность не заявляется.
