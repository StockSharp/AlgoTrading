# Кельтнер с сезонным фильтром
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Торгует пробои канала Кельтнера с фильтром исторической месячной доходности. На завершённых 5-минутных свечах: `E = EMA(20)`, `A = ATR(14)`, `M = AtrMultiplier = 2`, `U = E + M × A`, `L = E − M × A`; `SeasonalThreshold = 0.5` процентного пункта. Нужны сформированные индикаторы и разрешение торговли.

Покупка при `S > SeasonalThreshold`, `Close > U`, `Position <= 0`; продажа при `S < -SeasonalThreshold`, `Close < L`, `Position >= 0`. Объём заявки `Volume + abs(Position)` полностью разворачивает противоположную позицию. Стоп сохраняется на уровне сигнального `Close − M × A` для лонга или `Close + M × A` для шорта.

На каждой завершённой свече сначала проверяется стоп: закрыть лонг при `Close <= stop` или шорт при `Close >= stop`, сбросить стоп и закончить обработку свечи. Иначе проверяются входы, затем выход оставшегося лонга ниже E или шорта выше E. Стоп ручной, проверяется по закрытию свечи и рассчитывается от сигнальной цены; внутрисвечного биржевого стопа, тейк-профита и трейлинга нет.

Обязателен `SeasonalityHistoryFile`: CSV в UTF-8 с месячными ценами открытия/закрытия и заголовком `SecurityId,Month,Open,Close`. Формат `Month` — `yyyy-MM`, десятичный разделитель — точка; цены должны быть положительными, месяцы для торгуемого инструмента — уникальными. Строки других инструментов игнорируются. Отсутствующий файл, некорректные строки или отсутствие подходящих наблюдений вызывают ошибку запуска.

На сигнальной свече `S` — среднее `100 × (Close / Open − 1)` для того же календарного месяца прошлых лет в пределах `SeasonalityLookbackYears = 10`. Требуется не менее `MinimumSeasonalSamples = 2` наблюдений. Текущий и будущие месяцы исключаются, даже если присутствуют в файле. При недостаточной истории новые позиции не открываются. Нужно передать реальные месячные цены инструмента; фиксированной таблицы сезонных оценок нет.
