# Кельтнер с сезонным фильтром
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия **Keltner Seasonal Filter** торгует по пробоям канала Кельтнера с учётом сезонного смещения.
Сигналы формируются, когда Кельтнер подтверждает отфильтрованные входы на внутридневных данных (5м). Такой подход подходит активным трейдерам.
Стопы рассчитываются исходя из кратных ATR и параметров EmaPeriod, AtrPeriod. Эти значения можно изменять для баланса риска и прибыли.

Тестирование показывает среднегодичную доходность около 94%\. Стратегию лучше запускать на фондовом рынке.

## Подробности
- **Условия входа**: см. реализацию для условий по индикаторам.
- **Длинные/короткие позиции**: обе стороны.
- **Условия выхода**: обратный сигнал или логика стопов.
- **Стопы**: да, вычисляются на основе индикаторов.
- **Значения по умолчанию**:
  - `EmaPeriod = 20`
  - `AtrPeriod = 14`
  - `AtrMultiplier = 2m`
  - `SeasonalThreshold = 0.5m`
  - `CandleType = TimeSpan.FromMinutes(5).TimeFrame()`
- **Фильтры**:
  - Категория: Следование за трендом
  - Направление: Оба
  - Индикаторы: Keltner, Seasonal
  - Стопы: Да
  - Сложность: Средняя
  - Таймфрейм: Внутридневной (5m)
  - Сезонность: Да
  - Нейросети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний

## Точные торговые правила (C# и Python)

Сигналы обрабатываются только на **завершённых** свечах, после формирования индикаторов и при разрешённой торговле. Обозначим `C` — закрытие свечи, `E = EMA(Close, EmaPeriod)`, `A = ATR(AtrPeriod)`, `M = AtrMultiplier`, `U = E + M × A`, `L = E − M × A`. Сравнения строгие, если не указано иное.

Сезонное значение `S` берётся по **месяцу открытия исторической свечи** (`candle.OpenTime.Month`), а не по аргументу `OnStarted2` или системному календарю. Используются фиксированные демонстрационные значения, не рассчитанные по исторической доходности:

| Месяц | Янв | Фев | Мар | Апр | Май | Июн | Июл | Авг | Сен | Окт | Ноя | Дек |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| `S` | 0.8 | 0.3 | 0.6 | 0.7 | 0.2 | −0.3 | −0.1 | −0.4 | −0.8 | 0.1 | 0.9 | 0.7 |

- **Лонг / разворот из шорта:** `S > SeasonalThreshold`, `C > U`, `Position <= 0`: рыночная покупка `Volume + abs(Position)`, стоп на `C − M × A`.
- **Шорт / разворот из лонга:** `S < −SeasonalThreshold`, `C < L`, `Position >= 0`: рыночная продажа `Volume + abs(Position)`, стоп на `C + M × A`.
- **Стоп имеет приоритет:** если сохранённый уровень стопа положителен, закрыть лонг при `C <= stop`, шорт при `C >= stop`; сбросить стоп и не проверять остальные сигналы этой свечи.
- **Выход по EMA:** в остальных случаях закрыть лонг при `C < E`, шорт при `C > E`; сбросить стоп. Отдельного тейк-профита и автотрейлинга нет.

Стоп **проверяется вручную на закрытии завершённой свечи**, а не срабатывает внутри бара как биржевой стоп-ордер. Уровень рассчитывается от закрытия сигнальной свечи, а не фактической цены исполнения. При пороге `0.5` лонги разрешены в январе, марте, апреле, ноябре, декабре; шорты — в сентябре; в остальные месяцы новые входы запрещены. Даже в разрешённый месяц необходим пробой канала.
