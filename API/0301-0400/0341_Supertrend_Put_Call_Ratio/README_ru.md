# Supertrend Put Call Ratio

[English](README.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [Português](README_pt.md) | [中文](README_zh.md) | [日本語](README_ja.md)

## Правила торговли

Используется штатный StockSharp SuperTrend с Period и Multiplier. Из нулевой позиции: покупка при Close > SuperTrend и текущем PCR < предыдущее среднее − PCRMultiplier × σ; шорт при Close < SuperTrend и PCR > предыдущее среднее + PCRMultiplier × σ. PCR — наблюдавшийся объём put / объём call. Лонг закрывается при Close < SuperTrend, шорт при Close > SuperTrend независимо от доступности и экстремальности PCR. Равенство не даёт сигнала.

Среднее и выборочное стандартное отклонение вычисляются по предыдущим N последовательным наблюдениям без текущего: σ = sqrt(Σ(x − mean)² / (N − 1)). Нужен полный период. Случайные значения и ценовые суррогаты не используются.

## Входные данные

Обязательный CSV имеет заголовок SecurityId,Time,Value. Time — время открытия сигнальной свечи UTC в формате yyyy-MM-ddTHH:mm:ssZ. Значение — наблюдаемая статистика для торгуемого инструмента: конечное, неотрицательное, уникальное для времени. Используется только наблюдение текущей свечи. Пропуск очищает окно фильтра и запрещает входы до нового прогрева; сигнальные выходы продолжают работать.

## Исполнение

AtrPeriod = 14 задаёт ATR Уайлдера. При входе из нулевой позиции фиксируется расстояние ATR(сигнал) × StopLossAtr. Локальная рыночная защита по котировкам привязывает его к фактическому исполнению и может закрыть позицию между сигнальными свечами. Дальнейшее изменение ATR не двигает стоп. Ноль отключает защиту для нового запуска. Обратный сигнал закрывает весь фактический остаток; разворота и наращивания в том же решении нет.

## Проверка

Исполнения проверяются только на имеющемся архиве BTC/TON. Явные тестовые отчёты, наблюдения опционов и данные прогрева проверяют механику и не выдаются за настоящую отчётность компаний или опционную историю. Сокращённые периоды, две корзины и мартовская годовая ребалансировка — отдельные тестовые профили, а не подтверждение торговли с неизменёнными долгосрочными defaults. Доходность не заявляется.
