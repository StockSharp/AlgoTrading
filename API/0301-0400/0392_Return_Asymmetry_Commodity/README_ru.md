## Правила торговли

По WindowDays завершённым дневным доходностям r вычисляются U = Σmax(r,0), D = Σmax(−r,0). Ранжирование по (U−D)/(U+D); при U+D=0 балл равен нулю. Ограниченный балл сохраняет порядок отношения U/D, включая окна только роста или падения, без произвольной подстановки в знаменатель. Это баланс положительных и отрицательных доходностей, а не статистическая асимметрия распределения. Купить TopN лидеров и продать TopN разных отстающих; нужно не менее 2×TopN подходящих инструментов.

Universe задаётся явно. Цены и Capital выражены в USD: одна единица цены соответствует одной торгуемой единице. Capital — фиксированный бюджет; Leverage задаёт валовую экспозицию. Стоп-лосс и тейк-профит не добавляются.

Обрабатываются только синхронизированные завершённые свечи. Для статистики считаются разные даты UTC; новая внутридневная свеча заменяет цену той же даты. Ребалансировка выполняется один раз на первой подходящей общей свече месяца; непрогретые данные откладывают решение. Равные оценки упорядочиваются по Security.Id.

На длинную и короткую корзины выделяется по половине Capital × Leverage. Внутри стороны капитал делится поровну, переводится в количество по цене закрытия сигнальной свечи и округляется к нулю по VolumeStep. Корректировка опирается на исполненные позиции, ждёт активные заявки, учитывает MinVolume/MaxVolume и разбивает крупные объёмы на последующие свечи. MinTradeUsd отсекает малые корректировки; полное закрытие проходит без этого фильтра.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `Universe` | обязательный |
| `Capital` | 100000 |
| `Leverage` | 1 |
| `MinTradeUsd` | 200 |
| `CandleType` | TimeSpan.FromMinutes(5).TimeFrame() |
| `PriceHistoryFile` | не задан |
| `WindowDays` | 120 |
| `TopN` | 5 |

## Входные данные

Необязательный `PriceHistoryFile`: CSV `SecurityId,Date,Close`, положительная цена, уникальная пара инструмент/дата, дата `yyyy-MM-dd`. Во внутридневных решениях участвуют только даты раньше текущей UTC-даты; завершённая дневная свеча добавляет своё закрытие. Будущие строки не прогревают прошлое решение. Свечи исполнения заменяют дневное значение своей даты.

## Проверка

Оба языка проверяются на имеющемся архиве BTC/TON: независимые формулы, стороны и объёмы заявок, реальные исполнения, позиции и выходы. Датированные ценовые/факторные и календарные данные проверяют механику; перенос дат OHLC/объёмов не является многолетней рыночной историей. Две корзины рангов, TopN=1 и SMA=2 — явные профили для малого универсума. Исходные длинные периоды и defaults проверяются отдельно. Доходность не заявляется.
