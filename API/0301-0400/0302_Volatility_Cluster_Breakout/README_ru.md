# Volatility Cluster Breakout
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия использует завершённые 5-минутные свечи и ждёт формирования индикаторов и разрешения торговли. Все скользящие расчёты включают сигнальную свечу. Обозначения: `C` — её закрытие, `M = SMA(C, 20)`, `D = стандартное отклонение(C, 20)` с делением на 20, `U = M + 2 × D`, `L = M − 2 × D`, `A = ATR(14)` со сглаживанием Уайлдера истинного диапазона.

Режим высокой волатильности: `A >= 1.15 × SMA(A, 28)`.

При нулевой позиции покупка разрешена, если подтверждена высокая волатильность и `C >= U`; продажа — если она подтверждена и `C <= L`. Объём входа равен `Volume`. Новый вход возможен после окончания паузы и при отсутствии заявки, ожидающей исполнения. Для входа требуется `A > 0`.

`k = StopMultiplier`. На входе фиксируются закрытие сигнальной свечи и её ATR: стоп длинной позиции — `C_entry − k × A_entry`, короткой — `C_entry + k × A_entry`. На каждой завершённой свече весь фактический остаток позиции закрывается рыночной заявкой, если закрытие достигло стопа, для длинной позиции `C <= M`, для короткой `C >= M` либо режим высокой волатильности завершился.

Пауза запрещает новые входы на следующих 60 завершённых свечах после заявки; выходы работают в течение всей паузы. Стоп проверяется по закрытию свечи, исполнение рыночной заявки происходит по доступной цене. Расстояние стопа остаётся неизменным во время удержания позиции. Тейк-профита и скользящего стопа нет.

## Параметры по умолчанию

```text
PriceAvgPeriod = 20
StdDevMultiplier = 2
AtrPeriod = 14
StopMultiplier = 2
CooldownBars = 60
CandleType = TimeSpan.FromMinutes(5).TimeFrame()
```
