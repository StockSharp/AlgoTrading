# 季節性調整モメンタム戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Seasonality Adjusted Momentum**戦略は、季節性の強度で調整されたモメンタムインジケーターを中心に構築されています。

テストでは平均年間リターンが約172%であることが示されています。外国為替市場で最もよいパフォーマンスを発揮します。

取引は**確定5分足**で行い、日足ではありません。`M = Momentum(14)`、`A = SMA(14) of M`、`s = score[candle.OpenTime.Month]`。ノーポジションから `s >= 0.5` かつ `M > A` で買い、`s <= -0.5` かつ `M < A` で売ります。ロングは `s < 0.5` または `M < A`、ショートは `s > -0.5` または `M > A` で決済。注文後のクールダウンは確定足120本。保護は**ネイティブ2%ストップ**でATRではありません。

1～12月のs値: `0.8, 0.2, 0.5, 0.7, 0.3, -0.2, -0.3, -0.4, -0.7, 0.4, 0.6, 0.9`。BTC/TONデータは3月のみ（s=0.5）で新規ロングは可能、ショートは禁止です。年間172%の収益率は**未検証**です。

## 詳細
- **エントリー条件**: インジケーター条件の実装を参照。
- **ロング/ショート**: 両方。
- **エグジット条件**: 反対シグナルまたはストップロジック。
- **ストップ**: はい、インジケーターに基づく計算を使用。
- **デフォルト値**:
  - `MomentumPeriod = 14`
  - `SeasonalityThreshold = 0.5m`
  - `StopLossPercent = 2.0m`
  - `CandleType = TimeSpan.FromMinutes(5).TimeFrame()`
- **フィルター**:
  - カテゴリ: トレンドフォロー
  - 方向: 両方
  - インジケーター: Seasonality, Adjusted
  - ストップ: はい
  - 複雑さ: 中級
  - 時間軸: 5分足
  - 季節性: はい
  - ニューラルネットワーク: いいえ
  - ダイバージェンス: いいえ
  - リスクレベル: 中
