# Fancy Bollinger Bands 策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该策略利用布林带突破进行交易。当收盘价上穿上轨时买入，下穿下轨时卖出。

## 细节

- **入场条件**：
  - **做多**：收盘价上穿上轨
  - **做空**：收盘价下穿下轨
- **离场条件**：反向突破
- **类型**：突破
- **指标**：布林带
- **时间框架**：1 分钟（默认）
- **止损**：无

**可验证规则及默认值。** 布林带使用包括**当前信号K线**在内的最近20根已收盘K线，标准差按总体标准差计算并乘以2。`BollingerPeriod=20`、`DeviationMultiplier=2`、`CandleType=1分钟`。空仓时收盘价从下向上穿越上轨开多，从上向下穿越下轨开空。收盘价重新跌回上轨内侧时**全部平多**，重新升回下轨内侧时**全部平空**。前一根和当前布林带均用各自时点已收盘的数据计算；不设止损、止盈目标，也不在同一根K线上反手。
