# スタイリッシュ Bollinger Bands
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この戦略はBollinger Bandsのブレイクアウトをトレードします。終値が上バンドを上抜けるときに買い、終値が下バンドを下抜けるときに売ります。

## 詳細

- **エントリー条件**:
  - **ロング**: 終値が上バンドを上抜け
  - **ショート**: 終値が下バンドを下抜け
- **エグジット条件**: 逆クロス
- **タイプ**: ブレイクアウト
- **インジケーター**: Bollinger Bands
- **時間軸**: 1分（デフォルト）
- **ストップ**: なし

**検証可能なルールと初期値。** ボリンジャーバンドはシグナル足を**含む**直近20本の確定終値を使い、母標準偏差の2倍で計算します。`BollingerPeriod=20`、`DeviationMultiplier=2`、`CandleType=1分`。ポジションなしで終値が上側バンドを下から上へ抜けたらロング、下側バンドを上から下へ抜けたらショートします。ロングは上側バンドの内側へ戻る逆クロスで**全量決済**し、ショートは下側バンドの内側へ戻る逆クロスで**全量決済**します。過去と現在のバンドはそれぞれその時点までの確定足から算出し、ストップ、利確目標、同じ足での反転はありません。
