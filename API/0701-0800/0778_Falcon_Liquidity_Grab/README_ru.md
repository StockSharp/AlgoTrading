# Стратегия Falcon Liquidity Grab
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия торгует захваты ликвидности во время основных торговых сессий, используя простую скользящую среднюю для определения тренда. Вход осуществляется при выходе цены за недавний экстремум с возвратом по направлению тренда. Каждая сделка сопровождается фиксированными стоп‑лоссом и тейк‑профитом в тиках.

## Детали

- **Условия входа**:
  - **Лонг**: `Low < минимум за период` && `Close > SMA` && `фильтр сессий`
  - **Шорт**: `High > максимум за период` && `Close < SMA` && `фильтр сессий`
- **Условия выхода**: фиксированные стоп‑лосс и тейк‑профит.
- **Тип**: Разворотная
- **Индикаторы**: SMA, Highest, Lowest
- **Таймфрейм**: 15 минут (по умолчанию)
- **Стопы**: `StopLossPoints` тиков, `TakeProfitMultiplier`× размер стопа

**Точное правило и значения по умолчанию:** `SwingPeriod=20`, `TrendLength=50`, `StopLossPoints=50`, `TakeProfitMultiplier=2`, `UseSession=true`, `SessionStart=07:00`, `SessionEnd=21:00` (UTC), `CandleType=15 минут`. После завершения свечи её минимум/максимум сравниваются с экстремумами **предыдущих** N свечей (текущая исключена): лонг, если Low строго ниже предыдущего минимума, а Close строго выше SMA; шорт, если High строго выше предыдущего максимума, а Close строго ниже SMA. SMA включает сигнальную завершённую свечу. Вход только без позиции; начало окна UTC включено, конец исключён, поддерживается окно через полночь. Нативная защита рыночными заявками отслеживает bid/ask Level1 между свечами: стоп равен `StopLossPoints × Security.PriceStep`, тейк — `TakeProfitMultiplier × стоп`. Выход по противоположному сигналу или закрытию свечи не применяется.
