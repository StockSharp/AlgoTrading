# RRS ランダム性戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

## 概要

**RRS ランダムネス戦略** は、MetaTrader 用の「自然界の RRS ランダムネス EA」の StockSharp 移植です。
疑似ランダムなロングまたはショートの成行エントリー、確定足でのストップロスとテイクプロフィット判定、任意のトレーリング、含み損が設定値に達したときの決済により、元のEAを再現します。

StockSharp は銘柄ごとにネットポジションを使用するため、ロングとショートの同時保有には対応しません。そのため `DoubleSide` はロングから開始し、エントリーごとに方向を交互に切り替えます。

## 取引ロジック

1. 確定足ごとに、保護判定には終値を使い、利用可能ならLevel 1のbid/askをスプレッドと清算価格の計算に使います。
2. ポジション保有中はストップロス、テイクプロフィット、トレーリング、含み損上限の順に確認し、1本の足で送る決済注文は最大1件です。
3. フラットの場合、新しい取引を開始する前にスプレッドとボリュームの制約を検証します。
   - **DoubleSide** はロングから始め、ロングとショートを交互に行います。
   - **OneSide** は再現可能な `[0,5]` の疑似乱数を使い、`1` または `4` でロング、`0` または `3` でショート、`2` または `5` ではその足を見送ります。開始またはリセット時に系列は先頭へ戻ります。
4. 取引量は、設定された最小値と最大値の間で均一に描画され、商品の取引量ステップに合わせて調整されます。

## パラメーター

| グループ | 名前 | 説明 |
|-------|------|-------------|
| 一般 | `Mode` | 交互エントリー（`DoubleSide`、`0`）またはランダム選別（`OneSide`、`1`）。 |
| ロット設定 | `MinVolume` / `MaxVolume` | ランダムに生成された取引のボリューム範囲。 |
| 保護 | `TakeProfitPoints` | 価格ステップでの利食い距離。 |
| 保護 | `StopLossPoints` | 価格ステップのストップロス距離。 |
| 保護 | `TrailingStartPoints` | トレーリングストップ管理を可能にする利益距離。 |
| 保護 | `TrailingGapPoints` | 市場価格とトレーリングストップの間のオフセット。 |
| フィルター | `MaxSpreadPoints` | Level 1の最大許容スプレッド。ゼロは新規エントリーを禁止し、正値はbid/ask不在時の確定足フォールバックを許可します。 |
| フィルター | `SlippagePoints` | 情報スリッページ設定 (自動的には適用されません)。 |
| リスク管理 | `MoneyRiskMode` | 固定金額（`FixedMoney`、`0`）またはポートフォリオ価値の割合（`BalancePercentage`、`1`）。 |
| リスク管理 | `RiskValue` | リスクの量 (モードに応じて通貨またはパーセント)。 |
| 一般 | `TradeComment` | エントリー注文のコメント。決済注文には発動理由が追記されます。 |
| 一般 | `CandleType` | 意思決定ループを駆動するキャンドル シリーズ。 |

## 注意事項

- Level 1相場はスプレッドと清算価格の計算を改善します。両側がない場合、正の上限は確定足フォールバックを許可し、`MaxSpreadPoints = 0` は常にエントリーを禁止します。
- 保護は確定足で判定します。利益が `TrailingStartPoints + TrailingGapPoints` ステップに達するとトレーリングが始まり、`TrailingGapPoints` の距離を維持します。
- `FixedMoney` では `RiskValue` を口座通貨額、`BalancePercentage` では現在のポートフォリオ価値に対する割合として解釈します。
