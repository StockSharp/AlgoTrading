# Стратегия Hull MA CCI
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Данная стратегия использует индикаторы Hull Moving Average и CCI. Длинная позиция открывается, когда HMA(t) > HMA(t-1), а CCI опускается ниже CciOversold, что указывает на рост HMA при перепроданности. Короткая позиция возникает, когда HMA(t) < HMA(t-1) и CCI выше CciOverbought — снижение HMA при перекупленности.

Тестирование показывает среднегодичную доходность около 52%\. Стратегию лучше запускать на крипторынке.

Она предназначена для трейдеров, работающих в смешанном рынке.

## Детали
- **Условия входа**:
  - **Лонг**: HMA(t) > HMA(t-1) и CCI < CciOversold (рост HMA при перепроданности)
  - **Шорт**: HMA(t) < HMA(t-1) и CCI > CciOverbought (падение HMA при перекупленности)
- **Лонг/Шорт**: обе стороны.
- **Условия выхода**:
  - **Лонг**: Закрыть позицию, когда HMA начинает снижаться
  - **Шорт**: Закрыть позицию, когда HMA начинает расти
- **Стопы**: да.
- **Значения по умолчанию**:
  - `HullPeriod` = 9
  - `CciPeriod` = 20
  - `CciOversold` = -100
  - `CciOverbought` = 100
  - `AtrPeriod` = 14
  - `AtrMultiplier` = 2
    -100 и 100 — значения по умолчанию уровней CCI из правил. Стоп ставится на расстоянии AtrMultiplier ATR за AtrPeriod от цены закрытия входа и проверяется по закрытию свечей; 0 отключает его. Сигнал на вход против открытой позиции разворачивает её.
  - `CandleType` = TimeSpan.FromMinutes(5)
- **Фильтры**:
  - Категория: Смешанная
  - Направление: Оба
  - Индикаторы: Hull MA CCI
  - Стопы: Да
  - Сложность: Средняя
  - Таймфрейм: Внутридневной
  - Сезонность: Нет
  - Нейросети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний
