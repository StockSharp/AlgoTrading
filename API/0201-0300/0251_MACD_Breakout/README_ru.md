# Прорыв по MACD
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия MACD Breakout отслеживает резкие расширения индикатора MACD. Когда значения выходят за пределы нормального диапазона, цена часто начинает новое движение.

Тестирование показывает среднегодичную доходность около 94%\. Стратегию лучше запускать на фондовом рынке.

Позиция открывается, как только индикатор пробивает диапазон, рассчитанный по недавним данным и множителю отклонения. Возможны сделки в обе стороны со стопом.

Система подходит трейдерам импульсных стратегий, ищущим ранние прорывы. Сделки закрываются, когда MACD возвращается к среднему. По умолчанию используется `FastEmaPeriod` = 12.

## Подробности
- **Условия входа**: индикатор превышает среднее на величину множителя отклонения.
- **Длинные/короткие**: оба направления.
- **Условия выхода**: индикатор возвращается к среднему.
- **Стопы**: да.
- **Значения по умолчанию**:
  - `FastEmaPeriod` = 12
  - `SlowEmaPeriod` = 26
  - `SignalPeriod` = 9
  - `SmaPeriod` = 20
  - `DeviationMultiplier` = 2
  - `StopLossPercent` = 2
  - `CandleType` = TimeSpan.FromMinutes(5)
    Avg и StdDev — среднее и стандартное отклонение последних SmaPeriod значений линии MACD, включая текущее. Стоп — фиксированный StopLossPercent от цены входа, он отслеживается и между свечами; 0 отключает его. Полосы — среднее плюс и минус DeviationMultiplier стандартных отклонений: линия MACD выше верхней полосы открывает лонг, ниже нижней — шорт; лонг закрывается, когда линия MACD возвращается ниже своего среднего, шорт — когда выше. Сигнал на вход против открытой позиции разворачивает её.
- **Фильтры**:
  - Категория: Breakout
  - Направление: оба
  - Индикаторы: MACD
  - Стопы: да
  - Сложность: средняя
  - Таймфрейм: краткосрочный
  - Сезонность: нет
  - Нейросети: нет
  - Дивергенция: нет
  - Уровень риска: средний
