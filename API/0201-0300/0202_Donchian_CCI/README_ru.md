# Стратегия Donchian CCI
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта стратегия использует индикаторы Donchian и CCI для формирования сигналов. Вход в длинную позицию выполняется, когда цена превышает верхнюю границу канала Donchian, а CCI поднимается выше CciOverbought, что указывает на пробой вверх с восходящим импульсом. Короткая позиция открывается, когда цена пробивает нижнюю границу и CCI опускается ниже CciOversold — пробой вниз с нисходящим импульсом.

Тестирование показывает среднегодичную доходность около 43%\. Стратегию лучше запускать на фондовом рынке.

Стратегия подходит трейдерам, ищущим возможности в смешанном рынке.

## Детали
- **Условия входа**:
  - **Лонг**: Цена > верхней границы Donchian и CCI > CciOverbought (пробой вверх с восходящим импульсом)
  - **Шорт**: Цена < нижней границы Donchian и CCI < CciOversold (пробой вниз с нисходящим импульсом)
- **Лонг/Шорт**: обе стороны.
- **Условия выхода**:
  - **Лонг**: Закрытие длинной позиции при уходе цены ниже средней линии
  - **Шорт**: Закрытие короткой позиции при уходе цены выше средней линии
- **Стопы**: да.
- **Значения по умолчанию**:
  - `DonchianPeriod` = 20
  - `CciPeriod` = 20
  - `CciOverbought` = 100
  - `CciOversold` = -100
  - `StopLossPercent` = 2
    Канал — максимум и минимум предыдущих DonchianPeriod свечей, средняя линия проходит ровно между ними. Пробой вверх подтверждается, когда CCI выше CciOverbought, вниз — когда CCI ниже CciOversold; обратное прочтение, перепроданный CCI при закрытии выше канала, практически не встречается. Сигнал на вход против открытой позиции разворачивает её.
  - `CandleType` = TimeSpan.FromMinutes(5)
- **Фильтры**:
  - Категория: Смешанная
  - Направление: Оба
  - Индикаторы: Donchian CCI
  - Стопы: Да
  - Сложность: Средняя
  - Таймфрейм: Внутридневной
  - Сезонность: Нет
  - Нейросети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний
