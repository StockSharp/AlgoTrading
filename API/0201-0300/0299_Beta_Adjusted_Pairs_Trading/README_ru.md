# Beta Adjusted Pairs Trading

[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Бета-нейтральный возврат к среднему для двух инструментов. Явно задаются отличающийся `Asset2` и `Asset2Portfolio` (он может совпадать с основным портфелем). Неявного TON и счёта нет. Обе беты положительные. Используются завершённые свечи с точно одинаковым `OpenTime`; пропуски, устаревшие данные и дубли не смешивают разные времена.

## Правила торговли

`h=BetaAsset1/BetaAsset2`; `B1,B2` — первые согласованные положительные закрытия. Спред: `s=ln(P1/B1)-h*ln(P2/B2)`. Среднее и стандартное отклонение генеральной совокупности считаются по последним `LookbackPeriod` согласованным спредам, включая текущий; `z=(s-mean)/deviation`. Нулевое отклонение запрещает вход. Лонг пары: `z[p]<=-EntryThreshold && -EntryThreshold<z<0`; шорт: `z[p]>=EntryThreshold && 0<z<EntryThreshold`. Самого нахождения за порогом недостаточно.

Лонг пары покупает `Volume` основного инструмента и продаёт `q2=floor(Volume*P1*h/P2/VolumeStep2)*VolumeStep2` второго; шорт меняет обе стороны. Цены берутся из согласованных сигнальных свечей. Объём хеджа должен проходить ограничения лота второго инструмента и не меняется во время позиции. Вход разрешён только при нулевых обеих ногах и отсутствии незавершённых заявок; разница индексов последовательных входов строго больше `CooldownBars`.

На каждой паре завершённых свечей используются средневзвешенные фактические цены входа `F1,F2` и знаковые исполненные объёмы `q1,q2`: `PnL=q1*(P1-F1)+q2*(P2-F2)`, `G=abs(q1)*F1+abs(q2)*F2`. Обе фактические позиции закрываются при `PnL<=-G*StopLoss/100`; иначе лонг выходит при `z>=-ExitThreshold`, шорт — при `z<=ExitThreshold`. Убыток имеет приоритет. Пауза между входами не задерживает выход. Это лимит убытка пары по закрытиям до комиссий, не внутрисвечной биржевой стоп.

Ноги отправляются отдельными рыночными заявками, без атомарности. Незавершённые заявки блокируют новые решения. После завершения заявок отсутствующая, отклонённая или неполная нога приводит к закрытию фактических остатков на следующей согласованной паре свечей; неудачный выход повторяется там же на следующих парах. Архивный BTC/TON replay проверяет механику, не доходность или устойчивую экономическую связь.

Входы разрешены только по завершённым свечам после прогрева индикаторов. Открытая позиция сопровождается до выхода; незавершённая рыночная заявка блокирует повторную отправку.

## Параметры

| Parameter | Default |
|---|---|
| `Asset2` | `required` |
| `Asset2Portfolio` | `required` |
| `BetaAsset1` | `1` |
| `BetaAsset2` | `1` |
| `LookbackPeriod` | `20` |
| `EntryThreshold` | `2` |
| `ExitThreshold` | `0.15` |
| `StopLoss` | `2 (%)` |
| `CooldownBars` | `120` |
| `CandleType` | `5m` |
