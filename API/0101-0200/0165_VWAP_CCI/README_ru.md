# Стратегия Vwap Cci
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Реализация стратегии №165 — VWAP + CCI. Покупка, когда цена ниже VWAP и CCI ниже -100 (перепроданность). Продажа, когда цена выше VWAP и CCI выше 100 (перекупленность).

Тестирование показывает среднегодичную доходность около 82%\. Стратегию лучше запускать на фондовом рынке.

VWAP служит ориентиром справедливой цены, а CCI показывает импульсные отклонения от него. Вход осуществляется при сильных значениях CCI относительно VWAP.

Стратегия рассчитана на дейтрейдеров, наблюдающих за взаимодействием с VWAP. Процентный стоп помогает сохранять дисциплину.

## Подробности

- **Условия входа**:
  - Длинная: `Close < VWAP && CCI < CciOversold`
  - Короткая: `Close > VWAP && CCI > CciOverbought`
- **Long/Short**: Оба
- **Условия выхода**:
  - Цена пересекает VWAP в обратную сторону
- **Стопы**: процентный уровень через `StopLossPercent`
- **Параметры по умолчанию**:
  - `CciPeriod` = 20
  - `CciOversold` = -100m
  - `CciOverbought` = 100m
  - `StopLossPercent` = 2
  - `CandleType` = TimeSpan.FromMinutes(5).TimeFrame()
    Рынок торгуется круглосуточно, поэтому сессионный VWAP начинается заново каждые сутки по UTC и взвешивает типичную цену каждой свечи по её объёму. Сигнал на вход против открытой позиции разворачивает её.
- **Фильтры**:
  - Категория: Mean reversion
  - Направление: Оба
  - Индикаторы: VWAP, CCI
  - Стопы: Да
  - Сложность: Средняя
  - Таймфрейм: Среднесрочный
  - Сезонность: Нет
  - Нейросети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний
