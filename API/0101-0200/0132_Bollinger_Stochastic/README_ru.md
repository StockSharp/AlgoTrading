# Стратегия Bollinger Stochastic
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Bollinger Stochastic объединяет полосы Боллинджера со стохастическим осциллятором для выявления чрезмерно растянутых движений.
Если цена касается внешней полосы при нахождении осциллятора в экстремальной зоне, вероятен откат.

Тестирование показывает среднегодичную доходность около 133%. Стратегию лучше запускать на крипторынке.

Система торгует против этих крайностей: покупает, когда цена достигает нижней полосы и стохастик в перепроданности, и продаёт у верхней полосы при стохастике в перекупленности.

Процентный стоп ограничивает риск, если возврат к среднему не происходит.

## Детали

- **Критерий входа**: сигнал индикатора
- **Длинная/короткая сторона**: обе
- **Критерий выхода**: стоп-лосс или противоположный сигнал
- **Стопы**: да, процентные
- **Значения по умолчанию:**
  - `CandleType` = 15 минут
  - `StopLossPercent` = 2
  - `BollingerPeriod` = 20
  - `BollingerDeviation` = 2
  - `StochPeriod` = 14
  - `StochDPeriod` = 3
  - `StochOversold` = 20
  - `StochOverbought` = 80
    Свеча, минимум которой касается нижней полосы при стохастике %K ниже StochOversold, открывает покупку; свеча, максимум которой касается верхней полосы при %K выше StochOverbought, — продажу. Противоположный сигнал разворачивает позицию.
- **Фильтры:**
  - Категория: Среднее возвращение
  - Направление: обе
  - Индикаторы: Bollinger Bands, Stochastic
  - Стопы: да
  - Сложность: средняя
  - Таймфрейм: внутридневной
  - Сезонность: нет
  - Нейросети: нет
  - Дивергенция: нет
  - Уровень риска: средний
