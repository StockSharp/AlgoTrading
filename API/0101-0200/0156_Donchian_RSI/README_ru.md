# Стратегия Donchian RSI
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия сочетает каналы Дончиана и индикатор RSI. Покупка происходит на пробоях Дончиана, если RSI подтверждает, что тренд не перекуплен. Продажа — на пробое вниз, когда RSI показывает, что тренд не перепродан.

Тестирование показывает среднегодичную доходность около 55%\. Стратегию лучше запускать на фондовом рынке.

Каналы Дончиана определяют уровни пробоя, а RSI проверяет, поддерживает ли импульс движение. Позиции открываются, когда пробой совпадает с направлением RSI.

Стратегия лучше всего подходит трейдерам, ожидающим устойчивого пробоя, а не ложного. Риск ограничивается процентным стопом.

## Подробности

- **Условия входа**:
  - Лонг: `Close > DonchianHigh && RSI < RsiOverboughtLevel`
  - Шорт: `Close < DonchianLow && RSI > RsiOversoldLevel`
- **Длинные/короткие**: обе стороны
- **Условия выхода**:
  - Неудачный пробой или противоположный сигнал
- **Стопы**: процентные через `StopLossPercent`
- **Значения по умолчанию**:
  - `DonchianPeriod` = 20
  - `RsiPeriod` = 14
  - `RsiOverboughtLevel` = 70m
  - `RsiOversoldLevel` = 30m
  - `StopLossPercent` = 2.0m
  - `CandleType` = TimeSpan.FromMinutes(5).TimeFrame()
    Пробой не перегрет, пока RSI ниже RsiOverboughtLevel (лонг) или выше RsiOversoldLevel (шорт); канал строится по предыдущим DonchianPeriod свечам. Пробой считается неудачным и позиция закрывается, когда цена закрывается обратно за пробитым уровнем. Сигнал на вход против открытой позиции разворачивает её.
- **Фильтры**:
  - Категория: Пробой
  - Направление: Оба
  - Индикаторы: Канал Дончиана, RSI
  - Стопы: Да
  - Сложность: Средняя
  - Таймфрейм: Среднесрочный
  - Сезонность: Нет
  - Нейросети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний
