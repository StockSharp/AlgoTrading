# Стратегия Post-Holiday Weakness
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Post-Holiday Weakness обозначает склонность цен снижаться сразу после крупных праздников, когда объёмы ещё низкие.
Поскольку многие участники по-прежнему отсутствуют, контртрендовые движения могут набирать силу.

Тестирование показывает среднегодичную доходность около 112%. Стратегию лучше запускать на рынке Форекс.

Стратегия продаёт на следующий день после праздника и быстро закрывается, как только возвращается обычная активность.

Небольшой стоп используется, чтобы избежать чрезмерных убытков в условиях низкой ликвидности.

## Детали

- **Критерий входа**: сигналы календарных эффектов
- **Длинная/короткая сторона**: обе
- **Критерий выхода**: стоп-лосс или противоположный сигнал
- **Стопы**: да, процентные
- **Значения по умолчанию:**
  - `CandleType` = 15 минут
  - `Holidays` = 2024 NYSE holidays
  - `StopLossPercent` = 2
    Дни — сутки по UTC, так как рынок торгуется круглосуточно; вход происходит по закрытию первой свечи дня. Holidays — список дат yyyy-MM-dd через запятую, по умолчанию праздники NYSE 2024 года (Страстная пятница — 2024-03-29). Рынок торгуется каждый день, поэтому продажа открывается в календарный день после праздника и закрывается на последней свече этого дня.
- **Фильтры:**
  - Категория: Сезонность
  - Направление: обе
  - Индикаторы: Сезонность
  - Стопы: да
  - Сложность: средняя
  - Таймфрейм: внутридневной
  - Сезонность: да
  - Нейросети: нет
  - Дивергенция: нет
  - Уровень риска: средний
