# 节前强势策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

节前强势指在主要市场假日前，由于成交减轻和乐观情绪推动，价格往往上涨。
交易者通常提前布局，使假日前一两日的行情被推高。
策略在假日前一天买入，并在下一交易日或当日收盘退出，捕捉这段短期偏强。
若预期的上涨未出现，则通过紧密止损控制风险。

测试表明年均收益约为 109%，该策略在加密市场表现最佳。

## 细节

- **入场条件**：日历效应触发
- **多/空**：均可
- **退出条件**：止损或反向信号
- **止损**：是，按百分比
- **默认值**:
  - `CandleType` = 15分钟
  - `Holidays` = 2024 NYSE holidays
  - `StopLossPercent` = 2
    由于市场全天交易，日期按UTC日计算；入场发生在当日第一根K线收盘时。 Holidays 是以逗号分隔的 yyyy-MM-dd 日期列表，默认为2024年纽交所假日（耶稣受难日为2024-03-29）。市场每天交易，因此在假日前一个自然日开多，并在当日最后一根K线平仓。
- **过滤器**:
  - 类别：季节性
  - 方向：双向
  - 指标：季节性
  - 止损：有
  - 复杂度：中等
  - 时间框架：日内
  - 季节性：是
  - 神经网络：否
  - 背离：否
  - 风险等级：中等
