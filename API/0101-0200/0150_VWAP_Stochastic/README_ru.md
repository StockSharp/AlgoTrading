# Стратегия VWAP Stochastic
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия сочетает индикаторы VWAP и Стохастик. Покупки выполняются, когда цена ниже VWAP и Стохастик находится в зоне перепроданности. Продажи — когда цена выше VWAP и Стохастик в зоне перекупленности.

Тестирование показывает среднегодичную доходность около 187%. Стратегию лучше запускать на фондовом рынке.

VWAP отражает средний уровень торговли, а Стохастик показывает состояния перекупленности или перепроданности. Лонги открываются ниже VWAP при росте осциллятора, шорты — выше VWAP при его снижении.

Дневные трейдеры, отслеживающие внутридневные уровни стоимости, могут воспользоваться этой тактикой. Стопы выставляются на фиксированном проценте от цены входа.

## Подробности

- **Условия входа**:
  - Лонг: `Close < VWAP && StochK < OversoldLevel`
  - Шорт: `Close > VWAP && StochK > OverboughtLevel`
- **Длинные/короткие**: обе стороны
- **Условия выхода**:
  - Лонг: `Close > VWAP`
  - Шорт: `Close < VWAP`
- **Стопы**: процентные с параметром `StopLossPercent`
- **Значения по умолчанию**:
  - `StochPeriod` = 14
  - `StochKPeriod` = 3
  - `OverboughtLevel` = 80m
  - `OversoldLevel` = 20m
  - `StopLossPercent` = 2m
  - `CandleType` = TimeSpan.FromMinutes(5).TimeFrame()
    Рынок торгуется круглосуточно, поэтому сессионный VWAP начинается заново каждые сутки по UTC и взвешивает типичную цену каждой свечи по её объёму. StochK в правилах — это %K: стохастик за StochPeriod свечей, сглаженный за StochKPeriod свечей; линия %D в правилах не участвует, поэтому отдельного параметра у неё нет. Сигнал на вход против открытой позиции разворачивает её.
- **Фильтры**:
  - Категория: Средняя обратная
  - Направление: Оба
  - Индикаторы: VWAP, Стохастик
  - Стопы: Да
  - Сложность: Средняя
  - Таймфрейм: Среднесрочный
  - Сезонность: Нет
  - Нейросети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний
