# Стратегия Adx Cci
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия основана на индикаторах ADX и CCI. Вход в покупки при ADX > 25 и CCI ниже -100 (перепроданность). Вход в продажи при ADX > 25 и CCI выше 100 (перекупленность).

Тестирование показывает среднегодичную доходность около 97%\. Стратегию лучше запускать на крипторынке.

ADX оценивает силу тренда, а CCI определяет момент входа после откатов. Сделки открываются по направлению ADX.

Подходит трейдерам импульсных стратегий, заходящим на коррекциях. Риском управляет процентный стоп.

## Подробности

- **Условия входа**:
  - Длинная: `ADX > 25 && CCI < -100`
  - Короткая: `ADX > 25 && CCI > 100`
- **Long/Short**: Оба
- **Условия выхода**: ослабление тренда или пересечение CCI нуля
- **Стопы**: процентный уровень через `StopLossPercent`
- **Параметры по умолчанию**:
  - `AdxPeriod` = 14
  - `AdxThreshold` = 25
  - `CciPeriod` = 20
  - `CciOversold` = -100
  - `CciOverbought` = 100
  - `StopLossPercent` = 2
  - `CandleType` = TimeSpan.FromMinutes(5).TimeFrame()
    Значения 25, -100 и 100 в правилах — это значения по умолчанию AdxThreshold, CciOversold и CciOverbought. Тренд ослабевает, когда ADX опускается ниже AdxThreshold; лонг также закрывается, когда CCI поднимается до нуля, шорт — когда опускается до нуля. Сигнал на вход против открытой позиции разворачивает её.
- **Фильтры**:
  - Категория: Mean reversion
  - Направление: Оба
  - Индикаторы: ADX, CCI
  - Стопы: Да
  - Сложность: Средняя
  - Таймфрейм: Среднесрочный
  - Сезонность: Нет
  - Нейросети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний
