# ダークプール・プリンツ戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

大口の店頭取引レポートに記載されたアグレッサー側に従って売買し、取引銘柄の SMA20 でトレンドを絞り込みます。

`Security` は売買銘柄、`DarkPoolSecurity` は同じ原資産の独立したレポート用ストリームです。証券 ID は異なる必要があります。実際の店頭約定ティック（`IsSystem = false`）、価格、数量、時刻、`OriginSide` が必要です。ソース未指定または同一 ID は起動時エラーになります。取引所約定、売買側不明、無効な値、重複、時系列に逆行するレポートからはエントリーしません。

数量が `直前20件の平均数量 × 1.5` を厳密に上回る必要があります。現在のレポートは平均に含めません。買いレポートが SMA20 より上なら買い、売りレポートが下なら売ります。ローソク足の色や出来高をレポートの代用にはしません。逆方向のシグナルでは `Volume + abs(Position)` により約定済みポジション全体を反転します。

SMA は確定した15分足を使用します。ロングは SMA20 より下、ショートは上で決済し、レポート数量やエントリー待機期間には依存しません。既定値は `CooldownBars = 0`。正の値は次のエントリーまで待つ確定足数です。未完了注文がある間は重複シグナルを処理しません。

`StopLoss = 2` は実際のエントリー約定価格から2%のローカル標準保護です。売買銘柄の bid/ask を監視して成行決済を送信するため、足と足の間の保護には気配配信が必要です。利確は設定しません。
