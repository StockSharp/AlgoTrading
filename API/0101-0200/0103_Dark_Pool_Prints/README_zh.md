# 暗池成交策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

根据大额场外成交报告的主动买卖方向交易，并以交易标的的 SMA20 过滤趋势。

`Security` 为交易标的，`DarkPoolSecurity` 为同一基础标的的独立报告流，两者的证券 ID 必须不同。报告流必须提供真实场外逐笔成交（`IsSystem = false`）、价格、数量、时间和 `OriginSide`。缺少来源或来源相同会导致启动失败。交易所成交、方向未知、价格或数量无效、重复及乱序的报告均不能触发入场。

报告数量必须严格大于 `1.5 × 前 20 份报告的平均数量`；当前报告不参与基准计算。主动买入报告价格高于 SMA20 时买入；主动卖出报告价格低于 SMA20 时卖出。K 线颜色和成交量不替代报告方向及场外活动。反向信号用 `Volume + abs(Position)` 数量反转整个已成交持仓。

SMA 使用已完成的 15 分钟 K 线。多头收盘价低于 SMA20、空头高于 SMA20 时平仓，不受报告数量和入场冷却影响。默认 `CooldownBars = 0`；正值表示后续入场需等待的已完成 K 线数。未完成订单阻止重叠信号。

`StopLoss = 2` 表示以实际入场成交价为基准的 2% 本地原生保护。保护监控交易标的的 bid/ask 并提交市价平仓单；K 线之间需要报价流。未设置止盈。
