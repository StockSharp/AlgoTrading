# 暗池成交策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

暗池成交策略追踪场外的大额交易，这些交易披露后往往会引发明显波动。
异常的成交量可能表明机构正在布局，尚未影响公开市场。
策略顺势跟随暗池的大额买卖，期待其被市场消化时继续推动价格。
若预期的动能未能出现，则在小幅百分比止损触发时离场。

测试表明年均收益约为 46%，该策略在股票市场表现最佳。

### 实际交易规则（C# 与 Python）

默认使用 1 分钟 K 线和 SMA20。积累 20 个成交量样本后，当前成交量必须**严格大于**前 19 个样本算术平均值的 1.5 倍。空仓时：阳线（`Close > Open`）且 `Close > SMA20` 买入；阴线（`Close < Open`）且 `Close < SMA20` 卖出。新开仓之间冷却 500 根已完成 K 线。持多仓在 `Close < SMA20` 时平仓；持空仓在 `Close > SMA20` 时平仓；**平仓不要求成交量激增，也不受入场冷却限制**。成交后启用原生 2% 止损，不设置止盈。上文收益率未通过 BTC/TON 回放独立验证。


## 细节

- **入场条件**：指标信号
- **多/空**：均可
- **退出条件**：止损或反向信号
- **止损**：是，按百分比
- **默认值**:
  - \`CandleType\` = 1 minute
  - `StopLossPercent` = 2%
- **过滤器**:
  - 类别：成交量
  - 方向：双向
  - 指标：成交量
  - 止损：有
  - 复杂度：中等
  - 时间框架：日内
  - 季节性：否
  - 神经网络：否
  - 背离：否
  - 风险等级：中等
