# Стратегия "Печати даркпула"
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Торгует крупные внебиржевые сделки в направлении указанной стороны агрессора; SMA20 торгуемого инструмента служит фильтром тренда.

В `Security` задаётся торгуемый инструмент, в `DarkPoolSecurity` — отдельный поток отчётов по тому же базовому инструменту. Идентификаторы должны различаться. Поток должен передавать реальные внебиржевые сделки (`IsSystem = false`), цену, объём, время и `OriginSide`. Отсутствующий или совпадающий источник вызывает ошибку при запуске. Биржевые сделки, отчёты без стороны, некорректные цены/объёмы, дубликаты и запоздавшие отчёты не создают входы.

Сигнал требует объёма строго больше `1.5 × средний объём предыдущих 20 отчётов`; текущий отчёт в среднее не входит. Покупка — по отчёту о покупке выше SMA20; продажа — по отчёту о продаже ниже SMA20. Цвет и объём свечи не подменяют сторону и активность внебиржевых сделок. Противоположный вход разворачивает всю исполненную позицию заявкой `Volume + abs(Position)`.

SMA рассчитывается по завершённым 15-минутным свечам. Лонг закрывается ниже SMA20, шорт — выше SMA20, независимо от объёма отчётов и паузы входов. По умолчанию `CooldownBars = 0`; положительное значение задаёт паузу между входами в завершённых свечах. Неисполненная заявка блокирует пересекающиеся сигналы.

`StopLoss = 2` задаёт штатную локальную защиту на 2% от фактической цены исполнения входа. Защита отслеживает bid/ask торгуемого инструмента и отправляет рыночную заявку на выход; между свечами нужен поток котировок. Тейк-профит не задан.
