# Стратегия "Печати даркпула"
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Пример оценивает необычную активность по **объёму свечей**, а не по сообщениям о сделках в dark pool. Код не различает биржевые и внебиржевые исполнения. Торгуется приближённый сигнал по цене, SMA и всплеску объёма, а не поток dark-pool-сделок. Историческая доходность исходной стратегии этим кодом и прогоном BTC/TON не доказана.

### Реальные правила торговли (C# и Python)

По умолчанию используются минутные свечи и SMA20. После накопления 20 объёмов текущий объём должен быть **строго больше** 1,5 среднего арифметического предыдущих 19. Из нулевой позиции: покупка при `Close > Open` и `Close > SMA20`; продажа при `Close < Open` и `Close < SMA20`. Между новыми входами действует пауза 500 завершённых свечей. Длинная позиция закрывается при `Close < SMA20`, короткая — при `Close > SMA20`; **объёмный всплеск и пауза не ограничивают выходы**. Для исполненной позиции включён нативный стоп-лосс 2%, тейк-профита нет. Указанная выше доходность не подтверждается данным прогоном по BTC/TON.


## Детали

- **Условия входа**: сигнал индикатора
- **Длинная/короткая**: обе
- **Условия выхода**: стоп-лосс или противоположный сигнал
- **Стопы**: да, процентные
- **Значения по умолчанию**:
  - `CandleType` = 1 minute
  - `StopLossPercent` = 2%
- **Фильтры**:
  - Категория: Объём
  - Направление: обе
  - Индикаторы: объём
  - Стопы: да
  - Сложность: средняя
  - Таймфрейм: внутридневной
  - Сезонность: нет
  - Нейронные сети: нет
  - Дивергенция: нет
  - Уровень риска: средний
