# 圣诞行情策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

“圣诞行情”指股票在十二月最后一周至翌年一月前两个交易日通常呈现上涨。
节日乐观情绪与年底仓位调整会带来短暂的上行动力。
本策略在该期间开始时买入，在新年第2个交易日后退出，捕捉季节性升幅。
止损设置较小，以防市场未能上涨造成较大亏损。

测试表明年均收益约为 100%，该策略在外汇市场表现最佳。

### 实际日历规则（C# 与 Python）

本示例将圣诞行情模式**扩展到每个月**，并非仅在12月和1月交易。每月25–31日的新交易日首个有效5分钟收盘信号，空仓时开多仓或平空仓；3–7日平多仓；12–18日若空仓且 `Close < SMA20` 则开空仓。操作按新日触发，且相邻操作之间有50根已完成K线的冷却。已成交持仓另受原生2%止损保护，独立于日期。上述年化收益未通过BTC/TON历史数据核实。


## 细节

- **入场条件**：日历效应触发
- **多/空**：均可
- **退出条件**：止损或反向信号
- **止损**：是，按百分比
- **默认值**:
  - `CandleType` = 5分钟
  - `StopLossPercent` = 2%
- **过滤器**:
  - 类别：季节性
  - 方向：双向
  - 指标：季节性
  - 止损：有
  - 复杂度：中等
  - 时间框架：日内
  - 季节性：是
  - 神经网络：否
  - 背离：否
  - 风险等级：中等
