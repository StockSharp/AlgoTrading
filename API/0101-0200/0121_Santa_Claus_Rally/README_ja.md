# サンタクロース・ラリー戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)
 
サンタクロース・ラリーとは、12月最終週から1月最初の2取引日にかけて株式が上昇する傾向のことです。
年末年始の楽観的な雰囲気やポジション調整がこの短期的な強さを生み出す可能性があります。

テストでは年平均リターン約 100% を示しています。外国為替市場で最も良いパフォーマンスを発揮します。

戦略は期間の開始時に買いを入れ、新年の2取引日目の後に決済して、季節的な上昇を捉えます。

ストップは小さく保ち、その時期に市場が上昇しない場合の大きな損失を避けます。

### 実際の月次ルール（C# / Python）

この例はサンタクロース・ラリーを**毎月**に一般化したもので、12月・1月だけを対象としません。毎月25～31日の新しい日の最初の条件成立済み5分足で、ノーポジションなら買い、ショート保有中なら買い戻します。3～7日はロングを決済し、12～18日はノーポジションかつ `Close < SMA20` でショートを建てます。取引は日付更新時だけで、確定足50本のクールダウンがあります。約定済みポジションには日付と独立したネイティブ2%ストップロスが適用されます。上記の収益率はBTC/TONで未検証です。

- **ストップ**: はい、パーセントベース
- **デフォルト値**:
  - `CandleType` = 5 minute
  - `StopLossPercent` = 2%

  - 複雑さ: 中級
  - 時間軸: イントラデイ
  - 季節性: はい

  - ダイバージェンス: いいえ
