# サンタクロース・ラリー戦略
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

年末のサンタクロースラリーを売買します。12月最後の5営業日内の最初の適格な確定足で買い、1月の2営業日目のセッション終了時に決済します。終了足がない場合は、その後最初の適格な足で決済します。

確定15分足と、明示的に設定した `Security.Board` の取引日カレンダーを使用します。祝日、特別セッション、取引所のタイムゾーンを考慮し、カレンダーがない場合は起動できません。ロングのみで、年間シーズンごとのエントリー試行は最大1回です。損切り後も同じシーズンには再エントリーしません。未完了注文がある間は重複した判断を行いません。

`StopLoss = 2` は実際のエントリー約定価格から2%のローカル標準保護です。銘柄の bid/ask 更新により、足の間でも成行決済を発動できます。利確は設定しません。

新規発注時にシーズンを記録します。次の利用可能な足が後年の12月にしか届かない場合も、保有ポジションの決済期限は元のシーズンの1月のままです。その足で決済し、新シーズンへ繰り延べません。
