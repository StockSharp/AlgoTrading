この実装は伝統的な12月末～1月初旬だけではなく、**毎月の指定日**を売買するカレンダー例です。以前の年間100%という収益率は、付属のBTC/TONリプレイでは検証されていません。

### 実際の月次ルール（C# / Python）

この例はサンタクロース・ラリーを**毎月**に一般化したもので、12月・1月だけを対象としません。毎月25～31日の新しい日の最初の条件成立済み5分足で、ノーポジションなら買い、ショート保有中なら買い戻します。3～7日はロングを決済し、12～18日はノーポジションかつ `Close < SMA20` でショートを建てます。取引は日付更新時だけで、確定足50本のクールダウンがあります。約定済みポジションには日付と独立したネイティブ2%ストップロスが適用されます。上記の収益率はBTC/TONで未検証です。


## 詳細

- **エントリー条件**: カレンダー効果トリガー
- **ロング/ショート**: 両方
- **エグジット条件**: ストップロスまたは反対シグナル
- **ストップ**: はい、パーセントベース
- **デフォルト値**:
  - `CandleType` = 5 minute
  - `StopLoss` = 2%
- **フィルター**:
  - カテゴリ: 季節性
  - 方向: 両方
  - インジケーター: 季節性
  - ストップ: はい
  - 複雑さ: 中級
  - 時間軸: イントラデイ
  - 季節性: はい
  - ニューラルネットワーク: いいえ
  - ダイバージェンス: いいえ
  - リスクレベル: 中
