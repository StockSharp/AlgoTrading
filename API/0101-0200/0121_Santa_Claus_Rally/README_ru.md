# Стратегия Santa Claus Rally
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Реализация представляет собой **календарную стратегию по дням каждого месяца**, а не ограничена традиционным рождественским периодом в конце декабря — начале января. Ранее заявленная годовая доходность 100% не подтверждена поставляемым архивом BTC/TON.

### Реальные календарные правила (C# и Python)

Это **ежемесячный вариант** календарного эффекта, а не торговля только в декабре и январе. В первый допустимый момент нового дня 25–31 открывается лонг из нуля или закрывается шорт. В дни 3–7 закрывается лонг. В дни 12–18 открывается шорт из нуля при `Close < SMA20`. Используются завершённые 5-минутные свечи, первая свеча нового дня и пауза 50 свечей между действиями. Нативный стоп-лосс 2% срабатывает по исполненной позиции независимо от календарных дней. Объявленная выше доходность не подтверждена архивом BTC/TON.


## Детали

- **Критерий входа**: сигналы календарных эффектов
- **Длинная/короткая сторона**: обе
- **Критерий выхода**: стоп-лосс или противоположный сигнал
- **Стопы**: да, процентные
- **Значения по умолчанию:**
  - `CandleType` = 5 minute
  - `StopLoss` = 2%
- **Фильтры:**
  - Категория: Сезонность
  - Направление: обе
  - Индикаторы: Сезонность
  - Стопы: да
  - Сложность: средняя
  - Таймфрейм: внутридневной
  - Сезонность: да
  - Нейросети: нет
  - Дивергенция: нет
  - Уровень риска: средний
