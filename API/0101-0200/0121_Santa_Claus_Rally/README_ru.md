# Стратегия Santa Claus Rally
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Торгует новогоднее ралли. Вход — на первой подходящей завершённой свече в пределах последних пяти торговых сессий декабря. Выход — в конце второй торговой сессии января либо на первой следующей подходящей свече, если свеча закрытия отсутствует.

Использует завершённые 15-минутные свечи и явно заданный торговый календарь `Security.Board`, включая праздники, особые сессии и часовой пояс площадки. Без календаря запуск завершается ошибкой. Открывает только лонг, не более одной попытки входа за годовой сезон; после стопа повторного входа в этом сезоне нет. Неисполненная заявка блокирует пересекающиеся решения.

`StopLoss = 2` задаёт штатную локальную защиту на 2% от фактической цены исполнения входа. Обновления bid/ask торгуемого инструмента могут вызвать рыночный выход между свечами. Тейк-профит не задан.

Сезон фиксируется при отправке входа. Открытая позиция сохраняет январский срок выхода этого сезона, даже если следующая доступная свеча поступит только в декабре более позднего года: позиция закрывается на ней, а не переносится в новый сезон.
