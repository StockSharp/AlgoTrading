# 1月効果戦略

この例は移動平均フィルターを使い、**毎月繰り返す日付の区間**を取引します。12月末～1月初旬の小型株を対象とした古典的な1月効果だけに限定されず、企業規模や節税売りのデータも使用しません。従来記載された年間103%の収益率はBTC/TONで確認されていません。

### 実際の月次ルール（C# / Python）

実装は**毎月**の変形版で、12月・1月のみに限定しません。毎月1～5日の新しい日の最初の条件成立済み5分足で、ノーポジションかつ `Close > SMA20` なら買います。14～17日はロングを決済し、ノーポジションで `Close < SMA20` ならショートを建てられます。26～31日はショートを決済します。売買には日付変更が必要で、確定足50本のクールダウンがあります。約定済みのロング・ショートには日付と独立したネイティブ2%ストップロスが適用されます。上記の収益率はBTC/TONで未検証です。


## 詳細

- **エントリー条件**: カレンダー効果のトリガー
- **ロング/ショート**: 両方
- **エグジット条件**: ストップロスまたは逆シグナル
- **ストップ**: はい、パーセントベース
- **デフォルト値**:
  - `CandleType` = 5 minute
  - `StopLoss` = 2%
- **フィルター**:
  - カテゴリ: 季節性
  - 方向: 両方
  - インジケーター: 季節性
  - ストップ: はい
  - 複雑さ: 中級
  - 時間軸: イントラデイ
  - 季節性: はい
  - ニューラルネットワーク: いいえ
  - ダイバージェンス: いいえ
  - リスクレベル: 中
