Пример торгует **повторяющиеся окна внутри каждого календарного месяца** с фильтром скользящей средней. Он **не ограничен** классическим эффектом января (конец декабря — начало января), не анализирует размер компании или налоговые продажи. Ранее заявленная доходность 103% не подтверждена архивом BTC/TON.

### Реальные календарные правила (C# и Python)

Реализован **ежемесячный** вариант эффекта, а не торговля исключительно на стыке декабря и января. На первой допустимой завершённой 5-минутной свече нового дня 1–5 при `Close > SMA20` открывается лонг из нуля. В дни 14–17 лонг закрывается; из нуля при `Close < SMA20` может открываться шорт. В дни 26–31 шорт закрывается. Действия требуют смены календарного дня и учитывают паузу 50 завершённых свечей. Для исполненных позиций действует независимый от дат нативный стоп-лосс 2%. Приведённая выше доходность не подтверждена архивом BTC/TON.


## Детали

- **Критерий входа**: сигналы календарных эффектов
- **Длинная/короткая сторона**: обе
- **Критерий выхода**: стоп-лосс или противоположный сигнал
- **Стопы**: да, процентные
- **Значения по умолчанию:**
  - `CandleType` = 5 minute
  - `StopLoss` = 2%
- **Фильтры:**
  - Категория: Сезонность
  - Направление: обе
  - Индикаторы: Сезонность
  - Стопы: да
  - Сложность: средняя
  - Таймфрейм: внутридневной
  - Сезонность: да
  - Нейросети: нет
  - Дивергенция: нет
  - Уровень риска: средний
