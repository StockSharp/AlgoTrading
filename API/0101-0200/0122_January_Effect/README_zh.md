# 一月效应策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

一月效应观察到小盘股在年初往往表现更佳，可能由于投资者在十二月进行税务亏损卖出。
交易者因此在十二月底买入，并在一月前几周卖出以获取这一优势。
策略按此时间表操作，在岁末进入，至一月中旬退出。
若效应未出现，止损可保证亏损在可控范围内。

测试表明年均收益约为 103%，该策略在股票市场表现最佳。

### 实际月度日历规则（C# 与 Python）

实现的是**每个月**的适配版本，并非仅在12月和1月交易。每月1–5日新一天首个有效的5分钟已完成K线，如果空仓且 `Close > SMA20` 则开多仓。14–17日平多仓；如空仓且 `Close < SMA20` 则可开空仓。26–31日平空仓。交易要求日期变化，且受50根已完成K线的冷却限制。已成交的多空仓位都受独立于日期的原生2%止损保护。上述收益率未通过BTC/TON历史数据确认。


## 细节

- **入场条件**：日历效应触发
- **多/空**：均可
- **退出条件**：止损或反向信号
- **止损**：是，按百分比
- **默认值**:
  - `CandleType` = 5分钟
  - `StopLossPercent` = 2%
- **过滤器**:
  - 类别：季节性
  - 方向：双向
  - 指标：季节性
  - 止损：有
  - 复杂度：中等
  - 时间框架：日内
  - 季节性：是
  - 神经网络：否
  - 背离：否
  - 风险等级：中等
