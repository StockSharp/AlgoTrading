# 一月效应策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

交易跨年的一月效应。在12月26日或之后的第一个交易日，首根可用的已完成 K 线入场；在1月15日或之后的第一个交易日结束时平仓。若缺少该收盘 K 线，则在之后首根符合条件的 K 线平仓。不重复每月窗口，也不开空仓。

使用已完成的15分钟 K 线和明确设置的 `Security.Board` 交易日历，包括节假日、特殊交易时段和交易板块时区。缺少日历时无法启动。只做多，每个年度季节最多尝试入场一次；止损后当季不再入场。未完成订单阻止重叠决策。

`StopLoss = 2` 为从实际入场成交价计算的2%本地原生保护。交易标的的 bid/ask 更新可在 K 线之间触发市价平仓。未设置止盈。
