该示例交易**每个日历月重复出现的日期窗口**，并使用移动平均线过滤，并非经典的12月底至1月初小盘股“1月效应”；也不使用公司市值或税务卖出数据。之前声称的103%年化收益未由BTC/TON回放证实。

### 实际月度日历规则（C# 与 Python）

实现的是**每个月**的适配版本，并非仅在12月和1月交易。每月1–5日新一天首个有效的5分钟已完成K线，如果空仓且 `Close > SMA20` 则开多仓。14–17日平多仓；如空仓且 `Close < SMA20` 则可开空仓。26–31日平空仓。交易要求日期变化，且受50根已完成K线的冷却限制。已成交的多空仓位都受独立于日期的原生2%止损保护。上述收益率未通过BTC/TON历史数据确认。


## 细节

- **入场条件**：日历效应触发
- **多/空**：均可
- **退出条件**：止损或反向信号
- **止损**：是，按百分比
- **默认值**:
  - `CandleType` = 5分钟
  - `StopLossPercent` = 2%
- **过滤器**:
  - 类别：季节性
  - 方向：双向
  - 指标：季节性
  - 止损：有
  - 复杂度：中等
  - 时间框架：日内
  - 季节性：是
  - 神经网络：否
  - 背离：否
  - 风险等级：中等
