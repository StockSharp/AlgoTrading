# 看跌弃婴策略
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

看跌弃婴与多头版本相反，常预示顶部的形成。
该形态先出现向上跳空的十字星，随后向下跳空，使中间蜡烛孤立在上方。
当第三根蜡烛向下跳空时做空，捕捉情绪突变后的下行。
止损放在十字星高点上方，以防价格回升。

测试表明年均收益约为 79%，该策略在股票市场表现最佳。

## 细节

- **入场条件**：形态匹配
- **多/空**：均可
- **退出条件**：止损或反向信号
- **止损**：是，按百分比
- **默认值**:
  - `CandleType` = 15分钟
  - `DojiBodyPercent` = 10
  - `StopLossPercent` = 2
    市场全天交易，K线区间几乎不会出现跳空（样本月份中此类看跌形态最多一次），因此缺口按K线实体之间计算。十字星的实体不超过其区间的 DojiBodyPercent。策略只做空，在第三根K线收盘时卖出；止损设在十字星最高点上方 StopLossPercent 处，K线收盘突破即平仓。
- **过滤器**:
  - 类别：形态
  - 方向：双向
  - 指标：蜡烛图
  - 止损：有
  - 复杂度：中等
  - 时间框架：日内
  - 季节性：否
  - 神经网络：否
  - 背离：否
  - 风险等级：中等
