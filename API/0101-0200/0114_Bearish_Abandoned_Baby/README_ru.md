# Стратегия "Медвежий покинутый младенец"
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта модель зеркально отражает бычий вариант и сигнализирует о возможной вершине. После разрыва вверх формируется доджи, а затем происходит разрыв вниз, изолируя среднюю свечу над предыдущим диапазоном.

Тестирование показывает среднегодичную доходность около 79%. Стратегию лучше запускать на фондовом рынке.

Стратегия открывает короткую позицию, когда третья свеча открывается ниже доджи, стремясь воспользоваться резкой сменой настроений.

Риск ограничивается стопом сразу над максимумом доджи на случай восстановления цены.

## Детали

- **Условия входа**: совпадение с паттерном
- **Длинная/короткая**: обе
- **Условия выхода**: стоп-лосс или противоположный сигнал
- **Стопы**: да, процентные
- **Значения по умолчанию**:
  - `CandleType` = 15 minute
  - `DojiBodyPercent` = 10
  - `StopLossPercent` = 2
    Рынок торгуется круглосуточно, поэтому диапазоны свечей почти никогда не разрываются (в месяце примеров не больше одного такого медвежьего паттерна); гэпы измеряются между телами свечей. Тело доджи — не больше DojiBodyPercent его диапазона. Стратегия только продаёт, по закрытию третьей свечи; стоп ставится на StopLossPercent выше максимума доджи, и позиция закрывается, когда свеча закрывается выше него.
- **Фильтры**:
  - Категория: Паттерн
  - Направление: обе
  - Индикаторы: свечные
  - Стопы: да
  - Сложность: средняя
  - Таймфрейм: внутридневной
  - Сезонность: нет
  - Нейронные сети: нет
  - Дивергенция: нет
  - Уровень риска: средний
