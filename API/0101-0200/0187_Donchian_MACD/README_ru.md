# Стратегия Donchian Macd
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия совмещает пробой канала Дончиана с подтверждением тренда по MACD.

Тестирование показывает среднегодичную доходность около 148%\. Стратегию лучше запускать на рынке Форекс.

Стратегия ожидает пробоя канала Дончиана и проверяет импульс с помощью MACD. Вход в длинные или короткие позиции осуществляется, когда MACD подтверждает движение.

Предназначена для любителей пробоев, которые хотят подтверждения. Стопы ставятся на фиксированном проценте от цены входа.

## Детали

- **Критерии входа**:
  - Long: `Price breaks Donchian high && MACD > Signal`
  - Short: `Price breaks Donchian low && MACD < Signal`
- **Long/Short**: Оба направления
- **Критерии выхода**: разворот MACD
- **Стопы**: процентный на основе `StopLossPercent`
- **Значения по умолчанию**:
  - `DonchianPeriod` = 20
  - `MacdFast` = 12
  - `MacdSlow` = 26
  - `MacdSignal` = 9
  - `StopLossPercent` = 2
  - `CandleType` = TimeSpan.FromMinutes(5).TimeFrame()
    Пробой — закрытие за максимумом или минимумом предыдущих DonchianPeriod свечей. Выход по развороту MACD закрывает лонг, когда MACD пересекает сигнальную линию вниз, и шорт — когда вверх. Сигнал на вход против открытой позиции разворачивает её.
- **Фильтры**:
  - Категория: Breakout
  - Направление: Оба
  - Индикаторы: Donchian Channel, MACD
  - Стопы: Да
  - Сложность: Средняя
  - Таймфрейм: Среднесрочный
  - Сезонность: Нет
  - Нейронные сети: Нет
  - Дивергенция: Нет
  - Уровень риска: Средний
