# Стратегия "Распределение по Вайкоффу"
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Распределение по Вайкоффу описывает фазу вершины, когда на ростах наблюдаются активные продажи и тесты сопротивления. Объём часто возрастает при снижении и уменьшается на откатах, что указывает на выход крупных игроков из позиций.

Тестирование показывает среднегодичную доходность около 64%. Стратегию лучше запускать на рынке Форекс.

Стратегия продаёт, когда цена пробивает границу диапазона распределения вниз, рассчитывая на продолжительное падение.

Стоп размещается немного выше диапазона, защищая от ложных пробоев, а позиция закрывается, если цена возвращается к верхней границе структуры.

## Детали

- **Условия входа**: сигнал индикатора
- **Длинная/короткая**: обе
- **Условия выхода**: стоп-лосс или противоположный сигнал
- **Стопы**: да, процентные
- **Значения по умолчанию**:
  - `CandleType` = 15 minute
  - `RangePeriod` = 20
  - `StopLossPercent` = 2
    Диапазон распределения — самый высокий максимум и самый низкий минимум предыдущих RangePeriod свечей. Стратегия только продаёт, при закрытии ниже диапазона; стоп ставится на StopLossPercent выше вершины структуры, и позиция закрывается, когда свеча закрывается выше него.
- **Фильтры**:
  - Категория: Следование тренду
  - Направление: обе
  - Индикаторы: Объём, Цена
  - Стопы: да
  - Сложность: средняя
  - Таймфрейм: внутридневной
  - Сезонность: нет
  - Нейронные сети: нет
  - Дивергенция: нет
  - Уровень риска: средний
