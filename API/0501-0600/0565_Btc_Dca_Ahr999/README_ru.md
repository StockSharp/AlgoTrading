## Правила торговли

Используются завершённые суточные UTC-свечи. По последним `Length` положительным закрытиям, включая текущее, вычисляется `G=exp(mean(ln(C)))`. Возраст BTC — целые сутки с 2009-01-03; `F=10^(5.84*log10(age)-17.01)`, `AHR999=(C/G)*(C/F)`. Требуется полное окно.

В разрешённый понедельник покупается бюджет `UsdInvest2`, если индекс строго ниже 0.45, иначе `UsdInvest1`, если он строго ниже 1.2. Другие значения, дни недели и даты покупок не дают. Границы UTC-дат включительны; на суточную свечу принимается одно решение. Объём: `floor(budget/C/VolumeStep)*VolumeStep`; объём ниже минимума пропускается. Бюджет считается по сигнальному закрытию, рыночное исполнение может отличаться. Незавершённые заявки блокируют новые. Позиция накапливается без автоматического выхода.
