## Правила торговли

На завершённых 15-минутных свечах объединяются MACD(12,26,9), RSI Уайлдера(14), стохастик(21,14,14), Awesome Oscillator(5,34), Alligator и объёмный сдвиг средней. Сырой K считается по максимуму/минимуму 21 свечи; `Ks` — его SMA за 14 значений, `D` — следующая SMA за 14. Alligator использует SMMA медианной цены: челюсть 13 со сдвигом 8, зубы 8 со сдвигом 5, губы 5 со сдвигом 3.

`BASS = 2 * (MACD - Signal) + (RSI - 50) / 5 + 0.15 * (Ks - D) + 0.6 * AO + (Lips - Teeth) + (Teeth - Jaw) + VWMA(30) - SMA(30)`. Нужны все сформированные компоненты; при настройках по умолчанию — минимум 47 завершённых свечей. Некорректные настройки вызывают явную ошибку.

Показатель строго выше `BassThreshold` задаёт лонг `Volume`, ниже `-BassThreshold` — шорт `Volume`. По умолчанию порог нулевой. Проверяется уровень, поэтому после стопа повторный вход не требует нового пересечения нуля. Разворот выполняется объёмом `Volume + abs(Position)`; активная заявка блокирует повторную. Нативный локальный рыночный стоп закрывает всю фактическую позицию на расстоянии `StopLossPercent` процентов, по умолчанию 1. Тейк-профита нет.

Нативная локальная защита получает цены свечей и подписанных ценовых потоков инструмента. Расстояния привязаны к фактическим исполнениям входа. Выходы рыночные; цена исполнения зависит от доступного рынка и шага цены.
