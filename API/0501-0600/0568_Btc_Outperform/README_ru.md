## Правила торговли

Завершённые суточные UTC-свечи объединяются в фиксированные периоды. Недельные интервалы отсчитываются от понедельника 1970-01-05, 90-дневные — от 1970-01-01. Закрытие периода доступно только после получения всех суточных свечей от начала до конца. Неполные стартовые интервалы и периоды с пропусками закрытия не публикуют.

Сравниваются последние полностью наблюдённые завершённые закрытия: недельное выше квартального — покупка, ниже — продажа, равенство сохраняет позицию. Из нуля объём равен `Volume`; при развороте — `Volume+abs(Position)`, чтобы оставить полную противоположную позицию. Незавершённые периоды не меняют сравнение. Незавершённые заявки блокируют дубли. Ценового стопа и тейк-профита нет.
