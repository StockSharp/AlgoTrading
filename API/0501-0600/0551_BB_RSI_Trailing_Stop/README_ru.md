# BB RSI Trailing Stop

[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Для входа после выхода цены за полосу Боллинджера требуется возврат RSI из экстремальной зоны. Далее работает условный сопровождающий стоп. `p` — предыдущая сформированная свеча; RSI сглаживается по Уайлдеру.

## Правила торговли

Лонг: обычный `Low < lowerBand` и `RSI[p] <= RsiOversold && RSI > RsiOversold`. Шорт: обычный `High > upperBand` и `RSI[p] >= RsiOverbought && RSI < RsiOverbought`. Самого нахождения RSI в экстремальной зоне недостаточно. Вход `Volume` только из нулевой позиции; скрытой паузы в свечах нет.

Защита использует средневзвешенную фактическую цену входа и исполнимый bid для лонга, ask для шорта. Начальный стоп отстоит на `StopLossPoints`. Отслеживается благоприятный экстремум котировки; сопровождение включается только после движения на `TrailOffsetPoints`. Затем стоп следует за экстремумом на расстоянии `TrailStopPoints`, не ослабляя начальный стоп. Пересечение котировкой закрывает всю фактически набранную позицию рыночной заявкой. Все расстояния заданы в единицах цены, не в шагах или процентах. Ранний экстремум свечи не активирует стоп, созданный позже внутри неё.

Входы разрешены только по завершённым свечам после прогрева индикаторов. Открытая позиция сопровождается до выхода; незавершённая рыночная заявка блокирует повторную отправку.

Отклонение Боллинджера — стандартное отклонение генеральной совокупности скользящего окна закрытий, включая текущую завершённую свечу.

## Параметры

| Parameter | Default |
|---|---|
| `BollingerPeriod` | `25` |
| `BollingerDeviation` | `2` |
| `RsiPeriod` | `14` |
| `RsiOversold` | `33` |
| `RsiOverbought` | `60` |
| `StopLossPoints` | `50` |
| `TrailOffsetPoints` | `99` |
| `TrailStopPoints` | `40` |
| `CandleType` | `15m` |
