## Правила торговли

Используются завершённые минутные свечи и полосы Боллинджера: 40 закрытий, две стандартные девиации генеральной совокупности. Из нулевой позиции купить `Volume` при закрытии выше верхней полосы или продать `Volume` ниже нижней. `TradeDirection = null` разрешает обе стороны, `Buy` или `Sell` ограничивает входы.

Все пять фильтров включены по умолчанию и должны подтвердить один вход: RSI(14) строго выше 50 для лонга/ниже 50 для шорта; ADX(28) не меньше 20; `100 * ATR(14) / Close >= 0.05`; закрытие выше/ниже EMA(350); гистограмма MACD(12,26,9) положительная/отрицательная. Каждый фильтр отключается отдельно. Формирование требуется только включённым индикаторам: отключённая EMA не заставляет ждать 350 свечей.

Весь лонг закрывается при завершённом закрытии не выше средней полосы, весь шорт — не ниже неё. При `IsForceTakeProfitEnabled` дополнительный выход возникает, когда благоприятное тело свечи относительно открытия не меньше `ForceTakeProfitPercent` процентов, по умолчанию 5. Это тело текущей свечи, а не прибыль от входа; по умолчанию условие выключено. Выход имеет приоритет, разворота на той же свече нет.

Нативный локальный рыночный стоп задаётся параметром `StopLossPercent`, по умолчанию 2% от фактического входа. Активная заявка предотвращает повторную отправку.

Нативная локальная защита получает цены свечей и подписанных ценовых потоков инструмента. Расстояния привязаны к фактическим исполнениям входа. Выходы рыночные; цена исполнения зависит от доступного рынка и шага цены.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `BollingerPeriod` | `40` |
| `BollingerDeviation` | `2` |
| `IsRsiFilterEnabled` | `true` |
| `RsiPeriod` | `14` |
| `RsiLongThreshold` | `50` |
| `RsiShortThreshold` | `50` |
| `IsAdxFilterEnabled` | `true` |
| `AdxPeriod` | `28` |
| `MinimumAdx` | `20` |
| `IsAtrFilterEnabled` | `true` |
| `AtrPeriod` | `14` |
| `MinimumAtrPercent` | `0.05` |
| `IsEmaFilterEnabled` | `true` |
| `EmaPeriod` | `350` |
| `IsMacdFilterEnabled` | `true` |
| `MacdFast` | `12` |
| `MacdSlow` | `26` |
| `MacdSignal` | `9` |
| `TradeDirection` | `null` |
| `StopLossPercent` | `2` |
| `IsForceTakeProfitEnabled` | `false` |
| `ForceTakeProfitPercent` | `5` |
| `CandleType` | `1m` |
