## Правила торговли

Исполнение идёт по внутридневному CandleType. Диапазон Фибоначчи — максимум и минимум предыдущих LookbackPeriod завершённых дневных свечей UTC без дня сигнала. Уровни: L+0.618×(H−L) и L+0.382×(H−L). Дневной Hurst по предыдущим HurstPeriod закрытиям: H = log(R/S)/log(N), R — диапазон накопленных отклонений от среднего, S — стандартное отклонение с делителем N. Плоское окно с нулевой дисперсией запрещает вход. Предыдущее и текущее внутридневные закрытия сравниваются с одним текущим дневным уровнем: пересечение вверх 61.8% при H>0.5 покупает, вниз 38.2% при H<0.5 открывает шорт. Вход только из нуля объёмом Volume. MaxTradesPerDay считает попытки входных заявок по исторической дате UTC, MaxTotalTrades — за запуск. Native-защита по котировкам фиксирует от фактического исполнения SL = RiskPercent% и TP = RiskPercent×RiskReward%. Разворота по обратному сигналу и задержки нет.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `CandleType` | TimeSpan.FromMinutes(15).TimeFrame() |
| `HurstPeriod` | 50 |
| `LookbackPeriod` | 20 |
| `MaxTradesPerDay` | 5 |
| `MaxTotalTrades` | 510 |
| `RiskPercent` | 2 |
| `RiskReward` | 2 |
| `DailyHistoryFile` | не задан |

## Входные данные

Необязательный `DailyHistoryFile`: CSV `Date,High,Low,Close`, дата `yyyy-MM-dd`. Даты уникальны, 0 < Low ≤ Close ≤ High. Допускаются только даты раньше дня внутридневного сигнала. Завершённые дневные свечи заменяют свою дату; будущие строки не влияют на прошлые решения.

## Проверка

Оба языка проверяются на имеющемся архиве BTC/TON: независимые формулы, стороны и объёмы заявок, реальные исполнения, позиции и выходы. Датированные ценовые/факторные и календарные данные проверяют механику; перенос дат OHLC/объёмов не является многолетней рыночной историей. Две корзины рангов, TopN=1 и SMA=2 — явные профили для малого универсума. Исходные длинные периоды и defaults проверяются отдельно. Доходность не заявляется.
