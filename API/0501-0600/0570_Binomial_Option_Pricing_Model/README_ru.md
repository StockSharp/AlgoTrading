## Правила оценки

Неторговый модуль оценки опциона по двухшаговому дереву Кокса–Росса–Рубинштейна. Заявки не подаются. `CalculatePrice(spot, volatility, timeToExpiry)` возвращает цену для заданных страйка, Call/Put, европейского/американского исполнения и класса актива. Ставки и волатильность — годовые доли: `0.05` означает 5%. Год равен 365 дням; срок поддерживает минуты и часы.

При `dt = T / 2`: `u = exp(volatility * sqrt(dt))`, `d = 1/u`, `p = (exp(b * dt) - d) / (u - d)`. Перенос `b = r - q` для `Stock`, `Index`, `Currency` (q — дивидендная доходность/иностранная ставка); `b = 0` для `Future`. Каждый обратный шаг дисконтируется через `exp(-r * dt)`. Европейское исполнение — на погашении, американское сравнивает продолжение с внутренней стоимостью в каждом узле. Нулевой срок даёт внутреннюю стоимость; при нулевой волатильности рассматривается детерминированный путь переноса с теми же правилами исполнения. Неподдерживаемые классы/стили и некорректные вероятности вызывают ошибку без принудительного ограничения.

`EvaluatePrice(candle)` обрабатывает каждую завершённую свечу один раз. После `Length` закрытий годовая волатильность оценивается как `SD(close) / mean(close) * sqrt(365 дней / интервал)` со стандартным отклонением генеральной совокупности. Рассчитывается цена для `TimeToExpiry`, обновляется `LastOptionPrice`, значение пишется в журнал; при наличии графика выводятся свечи и отклонение. Это оценка разброса уровней цены, не волатильность доходностей и не торговый сигнал.

## Параметры

| Параметр | По умолчанию |
