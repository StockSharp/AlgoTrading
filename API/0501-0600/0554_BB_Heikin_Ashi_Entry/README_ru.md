# Bollinger Heikin Ashi Entry

[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Разворот по полосам Боллинджера на свечах Heikin Ashi с фактическим закрытием половины позиции по цели и сопровождением остатка.

## Правила торговли

HA закрытие: `(Open+High+Low+Close)/4`. Первое HA открытие: `(Open+Close)/2`, последующие: `(предыдущее HA открытие+предыдущее HA закрытие)/2`. HA максимум/минимум учитывают HA открытие/закрытие и обычные максимум/минимум. Боллинджер считается по HA закрытиям с первой архивной свечи, не по обычным закрытиям. Доджи не имеет цвета. Касание: `HA low <= lower` / `HA high >= upper`.

Не менее двух подряд медвежьих HA свечей должны каждая касаться собственной нижней полосы; затем бычья HA свеча с закрытием строго выше своей нижней полосы даёт лонг. Обратные цвета, касания верхней полосы и медвежье закрытие строго ниже своей верхней полосы дают шорт.

Вход `Volume` только из нулевой позиции. Начальный стоп — минимум предыдущей завершённой обычной свечи для лонга, максимум для шорта. Уровень фиксируется до заявки; `R` — положительное расстояние от средневзвешенного фактического входа до стопа. При `1R` отправляется рыночная заявка на половину набранной позиции с округлением вниз по `VolumeStep`. Если любая половина меньше `MinVolume`, по цели закрывается вся позиция. Вход, исполненный за начальным стопом, закрывается по следующей исполнимой котировке.

Сопровождение включается только после фактического исполнения цели. Стоп остатка следует за минимумом/максимумом последней завершённой обычной свечи и не ослабляется. Исполнимый bid для лонга или ask для шорта активирует полный выход между свечами; стоп имеет приоритет перед целью. Незавершённые заявки блокируют дубли. Более ранние экстремумы не активируют уровни, созданные позже. Фиксированной процентной цели и скрытой паузы нет.

Входы разрешены только по завершённым свечам после прогрева индикаторов. Открытая позиция сопровождается до выхода; незавершённая рыночная заявка блокирует повторную отправку.

Отклонение Боллинджера — стандартное отклонение генеральной совокупности скользящего окна закрытий, включая текущую завершённую свечу.

## Параметры

| Parameter | Default |
|---|---|
| `BollingerPeriod` | `20` |
| `BollingerDeviation` | `2` |
| `CandleType` | `5m` |
