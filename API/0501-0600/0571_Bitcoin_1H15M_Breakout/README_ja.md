## 取引ルール

確定した 15 分足で、直前の完全な 1 時間足レンジのブレイクを取引します。小足を UTC 時間枠へ集約し、正確な時間始点から連続する 4 本がすべてある場合だけ有効とします。開始時の部分的な時間枠やデータ欠損ではレンジを作りません。

開始時刻が H 時間内の小足には、完成済み H−1 の高値/安値だけを使い、形成中の H は使いません。建玉がなければ、終値が高値を厳密に上回ると `Volume` を買い、安値を厳密に下回ると `Volume` を売ります。両方向を許可し、既存建玉はブレイクで追加・反転しません。未完了注文が次の注文を抑止します。

原生ローカル保護の `StopLossBuffer` は実際の新規約定からの絶対価格差で、既定 50。利確距離は `StopLossBuffer * RiskRewardRatio`、既定比率 2 では 100 です。両方とも全建玉の成行決済で、新しい時間レンジによって保護水準は移動しません。`HigherTimeFrame` は小足間隔の整数倍が必要です。

ネイティブのローカル保護は銘柄の足と購読した価格更新を使用し、距離は実際の新規約定を基準にします。決済は成行で、約定価格は市場の状況と呼値に依存します。

## パラメーター

| パラメーター | 既定値 |
|---|---|
| `CandleType` | `15m` |
| `HigherTimeFrame` | `1h` |
| `StopLossBuffer` | `50` |
| `RiskRewardRatio` | `2` |
