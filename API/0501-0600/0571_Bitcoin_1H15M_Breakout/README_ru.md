## Правила торговли

Торговля пробоем диапазона предыдущего полностью завершённого часа по закрытым 15-минутным свечам. Младшие свечи собираются в часовые UTC-интервалы. Час пригоден только при наличии всех четырёх последовательных четвертей начиная с точной границы; начальный неполный час и пропуск данных не создают диапазон.

Для младшей свечи, открывшейся внутри часа H, используются только максимум и минимум завершённого H−1. Текущий незавершённый час не участвует. Из нулевой позиции купить `Volume` при закрытии строго выше максимума или продать `Volume` строго ниже минимума. Разрешены обе стороны; открытая позиция по сигналам пробоя не наращивается и не разворачивается. Активная заявка блокирует следующую.

Нативная локальная защита задаёт `StopLossBuffer` как абсолютный отступ от фактических исполнений входа, по умолчанию 50. Расстояние тейк-профита — `StopLossBuffer * RiskRewardRatio`, по умолчанию 100 при коэффициенте 2. Оба выхода рыночные на всю позицию; уровни не перемещаются вслед за новыми часовыми диапазонами. `HigherTimeFrame` должен быть целым кратным младшего интервала.

Нативная локальная защита получает цены свечей и подписанных ценовых потоков инструмента. Расстояния привязаны к фактическим исполнениям входа. Выходы рыночные; цена исполнения зависит от доступного рынка и шага цены.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `CandleType` | `15m` |
| `HigherTimeFrame` | `1h` |
| `StopLossBuffer` | `50` |
| `RiskRewardRatio` | `2` |
