# BBSR Extreme

[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Стратегия возврата внутрь полос с фильтром наклона EMA и защитой через ATR. `C`, `L`, `U`, `E` — обычное закрытие, нижняя полоса, верхняя полоса и EMA; `p` — предыдущая сформированная свеча.

## Правила торговли

Лонг: `C[p] < L[p] && C > L && E > E[p]`. Шорт: `C[p] > U[p] && C < U && E < E[p]`. Равенство не проходит. Вход объёмом `Volume` только из нулевой позиции; без наращивания, разворота и фиксированной паузы в свечах.

До отправки входа фиксируется `A = ATR` сигнальной свечи. Нативная локальная защита рыночными заявками привязана к фактической цене исполнения: лонг — стоп/цель `fill - 2A` / `fill + 3A`, шорт — `fill + 2A` / `fill - 3A`. Множители настраиваются. Последующий ATR уровни не меняет. Подписки bid/ask позволяют закрыть фактически исполненный объём между сигнальными свечами.

Входы разрешены только по завершённым свечам после прогрева индикаторов. Открытая позиция сопровождается до выхода; незавершённая рыночная заявка блокирует повторную отправку.

Отклонение Боллинджера — стандартное отклонение генеральной совокупности скользящего окна закрытий, включая текущую завершённую свечу.

## Параметры

| Parameter | Default |
|---|---|
| `BollingerPeriod` | `20` |
| `BollingerMultiplier` | `2` |
| `MaLength` | `7 (EMA)` |
| `AtrLength` | `14 (Wilder)` |
| `AtrStopMultiplier` | `2` |
| `AtrProfitMultiplier` | `3` |
| `CandleType` | `5m` |
