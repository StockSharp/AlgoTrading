## Правила торговли

Для завершённой суточной свечи доходность равна `r=(Close-Open)/Open`. Среднее и стандартное отклонение генеральной совокупности рассчитываются по предыдущим `LookbackPeriod` завершённым дневным доходностям без текущей. Требуется полное предыдущее окно. Покупка: `r>mean+k*sd`, продажа: `r<mean-k*sd`, где `k=AbnormalThreshold`. Равенство порогу входа не даёт.

Вход разрешён только из нулевой позиции. Объём: `floor(CapitalPerTrade/Close/VolumeStep)*VolumeStep`; значения ниже минимума пропускаются, выше максимума отвергаются. Капитал считается по сигнальному закрытию, фактическое рыночное исполнение может отличаться. Вся исполненная позиция закрывается на закрытии следующей дневной свечи либо первой доступной более поздней после пропуска. Выход имеет приоритет перед новым входом на этой свече. Незавершённые заявки блокируют дубли; ценового стопа нет.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `CandleType` | `1d` |
| `LookbackPeriod` | `5` |
| `AbnormalThreshold` | `1.6` |
| `CapitalPerTrade` | `1000` |
