## Правила торговли

Покупка на развороте нижней тени завершённой минутной свечи. Только лонг: из нулевой позиции купить `Volume`, если `Close < Open` и `100 * (Low - Close) / Close <= Threshold`. Значение по умолчанию `-1` требует нижнюю тень не меньше одного процента от закрытия.

UTC-время открытия свечи должно попадать в включительное окно `StartTime`–`EndTime`. При `UseEmaFilter = true` дополнительно нужны сформированная `EMA(EmaPeriod)` и `Close > EMA`. При выключенном фильтре прогрев EMA не задерживает входы.

Закрыть весь фактически набранный лонг, когда завершённая свеча закрылась выше максимума предыдущей завершённой свечи. Окно входов и EMA не ограничивают выход. Шортов, скрытой паузы в свечах, автоматических тейк-профита и стоп-лосса нет. Активная заявка предотвращает повторную отправку.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `Threshold` | `-1` |
| `UseEmaFilter` | `false` |
| `EmaPeriod` | `200` |
| `CandleType` | `1m` |
| `StartTime` | `2014-01-01T00:00:00Z` |
| `EndTime` | `2099-01-01T00:00:00Z` |
