## Правила торговли

На завершённых свечах рассчитываются две полосы Боллинджера: 20 и 50 закрытий, две стандартные девиации генеральной совокупности. Для нижних границ `Ls/Ll`, верхних `Us/Ul` и короткой средней `Ms`: `BBTrend = 100 * (abs(Ls-Ll) - abs(Us-Ul)) / Ms`.

SuperTrend применяется к этому показателю. Предыдущее и текущее значения образуют синтетические открытие и закрытие, минимум и максимум — low/high. True range равен абсолютному изменению показателя; ATR начинается со средней десяти диапазонов и далее сглаживается по Уайлдеру. Границы строятся вокруг синтетической середины с множителем `7 * ATR` и удерживаются до пробоя. Торговля начинается после формирования обеих полос и ATR.

Восходящий SuperTrend задаёт позицию `+Volume`, нисходящий `-Volume`. Заявка на разницу полностью разворачивает позицию. `TradeDirection = Buy/Sell` разрешает вход только в выбранную сторону, но противоположный сигнал всё равно закрывает открытую позицию. `null` разрешает обе стороны. Пока заявка активна, повторная не подаётся.

`TpSlCondition`: `None`, `TP`, `SL`, `Both` (в Python 0/1/2/3). По умолчанию защита выключена. Включённые расстояния задаются в процентах параметрами `TakeProfitPerc` и `StopLossPerc`.

Нативная локальная защита получает цены свечей и подписанных ценовых потоков инструмента. Расстояния привязаны к фактическим исполнениям входа. Выходы рыночные; цена исполнения зависит от доступного рынка и шага цены.

| Параметр | По умолчанию |
|---|---|
| `ShortBbLength` | `20` |
| `LongBbLength` | `50` |
