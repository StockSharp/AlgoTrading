## Правила торговли

Все три линии Alligator используют сглаженную медианную цену (high+low)/2. Параметры Length и Shift задают сглаживание и задержку в завершённых свечах. Teeth вычисляется и должен сформироваться, но дополнительного фильтра входа не задаёт. После формирования всех линий и ATR Уайлдера переход Lips−Jaw из <=0 в >0 открывает лонг Volume из нуля; переход из >=0 в <0 закрывает весь фактический лонг. Шорт не открывается. На входе фиксируется расстояние ATR×AtrMultiplier для локального рыночного native-стопа от фактического исполнения. Bid/ask позволяют исполнить его между свечами. Задержки, тейка и перемещения стопа новым ATR нет.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `CandleType` | TimeSpan.FromMinutes(30).TimeFrame() |
| `JawLength` | 13 |
| `TeethLength` | 8 |
| `LipsLength` | 5 |
| `JawShift` | 8 |
| `TeethShift` | 5 |
| `LipsShift` | 3 |
| `AtrPeriod` | 14 |
| `AtrMultiplier` | 2 |

## Проверка

Оба языка проверяются на имеющемся архиве BTC/TON: независимые формулы, стороны и объёмы заявок, реальные исполнения, позиции и выходы. Датированные ценовые/факторные и календарные данные проверяют механику; перенос дат OHLC/объёмов не является многолетней рыночной историей. Две корзины рангов, TopN=1 и SMA=2 — явные профили для малого универсума. Исходные длинные периоды и defaults проверяются отдельно. Доходность не заявляется.
