## Правила торговли

Требуется явный `DifficultyHistoryFile` с заголовком `Time,Difficulty`. Время публикации — строго возрастающие ISO UTC-метки с `Z`; сложность положительна. Файл читается при запуске; отсутствие или неверный формат завершают запуск ошибкой. Ряд сложности не выводится из рыночных цен.

На завершённой свече доступны только наблюдения с публикацией не позднее её `OpenTime`. Первое значение задаёт базу; неизменная сложность не даёт сигнала. Изменение: `100*(difficulty/previous-1)`. При `ThresholdMode=false` рост покупает, снижение продаёт. В пороговом режиме действует только `abs(change)>=Threshold`: снижение покупает, рост продаёт. Сторону задаёт последнее подходящее наблюдаемое изменение. Из нуля открывается `Volume`, разворот требует `Volume+abs(Position)`. Незавершённая заявка блокирует пересекающиеся решения. Автоматического стопа нет.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `CandleType` | `1d` |
| `ThresholdMode` | `false` |
| `Threshold` | `10` |
| `DifficultyHistoryFile` | `обязателен` |
