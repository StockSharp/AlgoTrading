# Anomalous Holonomy Field Theory

[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Технический сигнал из шести компонентов: фиксированные EMA20/EMA50, RSI14 Уайлдера, MACD(12,26,9), ATR Уайлдера и нормированный на волатильность ROC. `C` — обычное закрытие; `A=ATR`; `clip(x,k)=max(-k,min(k,x))`. Все окна включают текущую завершённую свечу.

## Правила торговли

`T`: +1,5 выше обеих EMA, +1 выше только EMA20, -1,5 ниже обеих, -1 ниже только EMA20, иначе ноль. Свечной VWAP: `sum(((High+Low+Close)/3)*Volume)/sum(Volume)` за `VwapPeriod` свечей. `V=clip((C-VWAP)/A,2)`. Для `B=T+V` RSI добавляет `R=+1,5` ниже 30 или `+0,5` ниже 40 только при `B>0`; при `B<0` добавляет `-1,5` выше 70 или `-0,5` выше 60; иначе `R=0`.

`M=clip((MACD-EMA9(MACD))/A,1)`. `Q=clip((C-C[RocPeriod свечей назад])/A,1)` — ROC, делённый на ATR% с одинаковой базовой ценой прошлого периода. Итог: `S=T+V+R+M+Q`. Из нулевой позиции покупается `Volume` при `S>=SignalThreshold`, продаётся при `S<=-SignalThreshold`. Без прогрева, при неположительном ATR или нулевом объёме вход запрещён. Между индексами последовательных входов должно пройти строго больше `CooldownBars` свечей.

Перед каждым входом фиксируется расстояние `ATR*AtrStopMultiplier`. Нативный локальный стоп рыночной заявкой привязывает его к фактическому исполнению и реагирует на bid/ask между свечами. По умолчанию стоп равен 2 ATR. Открытая позиция выходит через защиту; противоположный сигнал её не наращивает и не разворачивает. Пауза между входами не задерживает защиту. Тейк-профита нет.

Входы разрешены только по завершённым свечам после прогрева индикаторов. Открытая позиция сопровождается до выхода; незавершённая рыночная заявка блокирует повторную отправку.

## Параметры

| Parameter | Default |
|---|---|
| `SignalThreshold` | `2` |
| `CooldownBars` | `50` |
| `AtrLength` | `14` |
| `AtrStopMultiplier` | `2` |
| `RocPeriod` | `10` |
| `VwapPeriod` | `20` |
| `CandleType` | `5m` |
