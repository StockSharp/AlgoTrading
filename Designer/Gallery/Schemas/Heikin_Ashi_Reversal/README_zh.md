# 平均K线（Heikin-Ashi）反转策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Heikin-Ashi 平滑掉了大部分噪音，所以只要行情延续，一串K线就保持同一种颜色，只有力量对比真正改变时才翻转。本图交易的正是这种翻转：熊市K线之后的第一根多头 Heikin-Ashi 买入，多头之后的第一根空头卖出；离场时机由普通收盘价的简单移动平均线决定。

![schema](schema.svg)

## 策略概览

- 一个公式方块把 Heikin-Ashi 实体算成开高低收的平均值减去前一根K线的中点：实体为正即多头 Heikin-Ashi，等于零或为负即空头。
- 一个前值方块保存前一根的实体，因此两次比较描述的是颜色的改变，而不仅仅是颜色本身。
- 移动平均线与离场价格取自普通K线而非平滑K线，与原始策略完全一致。
- 真正的 Heikin-Ashi 开盘价由它自身的前值定义，而图中无法把方块的输出回接到自己，因此改用前一根普通K线的中点；这样得到的变色时刻接近但不等同于原始代码的计算。
- 原始策略在成交后还会冻结所有信号数百根K线；这里没有计数K线的方块，因此省略该暂停并在此说明。

## 入场与出场规则

- **做多入场**: 刚收完的K线的 Heikin-Ashi 实体为正，前一根的实体为零或为负，且持仓为零。订单买入一手，开多。
- **做空入场**: 刚收完的K线的 Heikin-Ashi 实体为零或为负，前一根的实体为正，且持仓为零。订单卖出一手，开空。
- **离场**: 普通K线收在移动平均线之下时，处于平仓模式的修改持仓方块平掉多头；收在均线之上时平掉空头。原始策略既没有止损也没有止盈，本图同样没有。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SMA Length | 20 | 作用于普通收盘价、用于平仓的简单移动平均线周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期；原策略跑在1分钟K线上，这里换成随图库提供的5分钟历史数据。 |

## 图表详情

- K线方块分别送入开、高、低、收四个转换方块以及移动平均线。
- 两个前值方块把前一根K线的开盘价与收盘价送进公式，用来近似 Heikin-Ashi 的开盘价。
- 第三个前值方块把公式结果延后一根K线，四次与零常量的比较把两个实体变成当前颜色与前一颜色。
- 每个逻辑与把新颜色、相反的旧颜色和持仓判断合并并触发入场；两个平仓方块则直接由与均线的比较触发。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
