# 满实体K线动量策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

满实体K线在区间的一端开盘、另一端收盘：上下影线合计只占最高价到最低价距离的一小部分。这样的K线是一次不间断的推动，只要指数移动平均线认可这个方向，本图就顺着实体方向跟进。该交易只设一个不到一个百分点的固定目标，别无其他。

![schema](schema.svg)

## 策略概览

- 转换方块读取已完成K线的开盘价、最高价、最低价和收盘价，两个公式方块衡量影线占据了多少区间。
- 看涨的度量是阳线的上影线加下影线乘以一百，再与影线占比乘以完整区间相比较；看跌的度量与之镜像。
- 收盘价的指数移动平均线充当趋势过滤：满实体阳线只在其上方买入，满实体阴线只在其下方卖出。
- 持仓保护方块以固定止盈平掉每笔交易，这也是原策略唯一的离场方式。

## 入场与出场规则

- **做多入场**: 看涨影线度量小于零，说明K线上涨且影线控制在允许的区间占比之内；收盘价高于 EMA，且当前不是多头持仓。订单买入数量常量加上已有的空头数量，用一张单完成空翻多。
- **做空入场**: 看跌影线度量小于零，收盘价低于 EMA，且当前不是空头持仓。订单卖出数量常量加上已有的多头数量，用一张单完成多翻空。
- **离场**: 持仓保护方块在入场价 0.3% 处止盈，与原策略写死的数值一致；没有止损，因为原策略也没有。有两点差异值得注意。保护方块盯的是K线内部的价格，而原策略只检查已完成K线的收盘价，因此这里目标会稍早触发。原策略每笔交易后 15 根K线的停顿也被省略：用方块搭出计数器必须把信号回接到图中，那会让数据流形成环路，所以反转信号一出现就会执行。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| EMA Length | 20 | 作为趋势过滤的指数移动平均线周期。 |
| Shadow share, % | 10 | 上下影线合计可占K线最高价到最低价区间的最大比例（百分比）。 |
| Take profit, % | 0.3 | 止盈距入场价的百分比距离。 |
| Volume | 1 | 下单数量（手）；反转订单会在此基础上加上被平掉的持仓数量。 |
| Candles | 00:05:00 | 整张图使用的K线周期。原策略基于15分钟K线，这里改用5分钟，以便该形态在随附的历史数据上出现得足够频繁。 |

## 图表详情

- 每条公式用实际影线减去允许的影线额度，因此结果小于零就表示这是满实体K线；带影线占比的常量同时供给两条公式。
- 方向不需要单独的比较：看涨度量是按阳线写的，在阴线上以及在区间为零的K线上恒为正，所以结果小于零本身就意味着这根K线上涨。
- 持仓方块分两路：一路进入与零的比较，保护两个入场；另一路进入数量公式，把持仓绝对值加到数量常量上，使一张市价单同时平掉反向持仓并开出新仓。
- 两个入场方块都把自己的成交交给持仓保护方块，由它挂出止盈单；收盘价也接入该方块作为价格参照。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
