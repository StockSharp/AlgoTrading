# 累积/派发线趋势策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这里由成交量决定方向。累积/派发线把每根K线收盘价在自身区间中的位置按成交量加权累加：线上升表示买方消化了卖压，线下降则相反。图表把该线与前一根K线的取值比较，站在成交量支持的一侧，但必须得到简单移动平均线的许可。

![schema](schema.svg)

## 策略概览

- 累积/派发线接收整根K线，因为它同时需要最高价、最低价、收盘价和成交量。
- 前值方块保存上一根K线的读数，于是线的斜率只需一次比较即可得到，无需第二个指标。
- 简单移动平均线充当许可过滤器：即使资金在流入，也只有收盘价高于均线时才买入。
- 两个入场方块带有开仓条件，两个离场方块带有平仓条件，因此同时只持有一个仓位，且永不加仓。

## 入场与出场规则

- **做多入场**: A/D 线高于其前值，K线收盘价高于简单移动平均线，且当前无持仓。订单按市价买入共享数量。
- **做空入场**: A/D 线等于或低于其前值，K线收盘价低于简单移动平均线，且当前无持仓。订单按市价卖出共享数量。
- **离场**: 仅凭线的斜率平仓，不附加价格条件：线回落平掉多头，线转升平掉空头。与原始策略一样，没有止损也没有止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| MA Period | 20 | 决定允许入场方向的简单移动平均线周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时供给三个去处：A/D 线、移动平均线，以及取出收盘价的转换方块。
- A/D 输出既进入前值方块，也直接进入两个比较方块，因此上升与下降读自同一对数值。
- 每个逻辑与把线的斜率、均线的方位和空仓判断合并，然后触发入场方块。
- 两个离场方块直接挂在斜率比较之后并带有平仓条件，因此各自只处理一个方向。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
