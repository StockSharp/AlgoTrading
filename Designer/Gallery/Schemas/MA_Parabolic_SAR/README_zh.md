# MA + Parabolic SAR 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

简单移动平均线决定该做哪一边，Parabolic SAR 决定何时动手：本图等待收盘价沿着均线已经指向的方向穿越 SAR 线。同一条线的反向穿越则把仓位交还，因此策略要么在趋势中，要么在等待下一个趋势。

![schema](schema.svg)

## 策略概览

- SimpleMovingAverage 充当方向过滤器：只在收盘价高于它时做多，只在低于它时做空。
- ParabolicSar 负责择时，一个穿越方块把价格穿越该线变成唯一的脉冲：真代表向上穿越，假代表向下穿越。
- 入场由当前持仓把关，离场使用平仓方块，只有存在相应方向的持仓时才动作。
- 与 C# 原版的两点差异：原版用一条快速 EMA 代替 SAR，声明的 SAR 参数从未被读取，而本图使用真正的 ParabolicSar；此外入场之间 20 根K线的暂停没有复现。

## 入场与出场规则

- **做多入场**: 收盘价自下而上穿越 ParabolicSar 线，同时位于 SMA 之上，且持仓不是多头。修改持仓方块以市价买入共享数量。
- **做空入场**: 收盘价自上而下穿越 ParabolicSar 线，同时位于 SMA 之下，且持仓不是空头。修改持仓方块以市价卖出共享数量。
- **离场**: 多头在 SAR 线第一次向下穿越时平掉，空头在第一次向上穿越时平掉，不再询问均线；与原策略一样没有止损和止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SMA Length | 20 | 决定趋势方向的简单移动平均线周期。 |
| SAR Acceleration | 0.02 | Parabolic SAR 的初始加速因子。 |
| SAR Max acceleration | 0.2 | Parabolic SAR 加速因子能增长到的上限。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时喂给两个指标和一个从K线取出收盘价的转换方块。
- 穿越方块比较收盘价与 SAR 线，逻辑非把它的输出变成做空入场和多头离场所用的向下穿越。
- 比较方块把收盘价与 SMA、把持仓与零常量对比，四个逻辑与将它们组合成入场与离场信号。
- 两个修改持仓方块用共享数量常量开仓，另外两个以平仓条件了结持仓。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
