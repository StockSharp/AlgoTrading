# 布林带 + 随机指标策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这是一套要求两个独立超调信号的均值回归方案：收盘价必须触及布林带边缘，同时随机指标的 %K 线必须处于对应的极值区。价格一旦穿回同一组布林带的中轨，仓位立即交还，因此持仓时间恰好等于偏离持续的时间。

![schema](schema.svg)

## 策略概览

- 一个布林带方块同时给出三条线：上轨、下轨，以及作为离场水平的中轨均线。
- 随机指标只使用 %K 线，%D 线按照原策略的做法刻意不接线。
- 只有在空仓状态下才会入场，因此图中不会对已有仓位加码。
- 原策略在两笔交易之间还有固定 K 线数的冷却期；方块无法表达这种计数器，这里省略，所以本图的交易频率高于源代码。

## 入场与出场规则

- **做多入场**: 收盘价等于或低于布林带下轨，%K 低于超卖水平，且当前空仓。订单买入一手并建立多头。
- **做空入场**: 收盘价等于或高于布林带上轨，%K 高于超买水平，且当前空仓。订单卖出一手并建立空头。
- **离场**: 收盘价升破中轨时平多，跌破中轨时平空。两个离场方块都使用平仓模式的修改持仓方块，数量按现有持仓自动计算，没有可平仓位时保持沉默。与原始代码一致，本图没有止损与止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Bollinger Length | 20 | 布林带的平滑周期，同时决定用于离场的中轨。 |
| Bollinger Width | 2 | 标准差倍数，决定上下轨距离中轨的宽度。 |
| %K Oversold | 20 | %K 低于该水平时确认买入。 |
| %K Overbought | 80 | %K 高于该水平时确认卖出。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 一个K线方块同时供给布林带、随机指标以及提取收盘价的转换方块。
- 转换方块把指标拆成单独的线：上轨、下轨、中轨和 %K。
- 每个逻辑与把一个轨道条件、一个随机指标条件和空仓判断合并，然后触发开仓模式的修改持仓方块。
- 两个离场方块直接由中轨比较触发，是否真的发单由方块自身的平仓模式决定。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
