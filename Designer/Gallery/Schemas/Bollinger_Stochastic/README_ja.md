# ボリンジャーバンド + ストキャスティクス戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

行き過ぎのサインを二つ重ねて求める平均回帰のダイアグラムです。終値がボリンジャーバンドに到達し、同時にストキャスティクスの %K が対応する極値ゾーンにあることを条件にします。価格が同じバンドのミドルラインを越えた時点でポジションを手放すため、保有期間は乖離が続く長さとちょうど一致します。

![schema](schema.svg)

## 戦略の概要

- ボリンジャーバンドは1つの指標ブロックから3本の線を供給します。アッパーバンド、ロワーバンド、そして手仕舞い水準となるミドルの移動平均です。
- ストキャスティクスは %K だけを使用し、%D は元の戦略と同じく意図的に接続していません。
- エントリーはノーポジションからのみ行うため、保有中のポジションに買い増し・売り増しをすることはありません。
- 元の戦略は売買の間に一定本数のバーを待ちますが、このクールダウン計数はブロックで表現できないため省略しました。その分、このダイアグラムは元のコードより高い頻度で売買します。

## エントリーとエグジットの条件

- **ロングエントリー**: 終値がロワーバンド以下、%K が売られすぎ水準より下、かつノーポジションのとき。注文は1ロットを買い、ロングを建てます。
- **ショートエントリー**: 終値がアッパーバンド以上、%K が買われすぎ水準より上、かつノーポジションのとき。注文は1ロットを売り、ショートを建てます。
- **エグジット**: 終値がミドルラインを上回ればロングを、下回ればショートを手仕舞います。どちらの出口もクローズモードのポジション変更ブロックで、数量は保有ポジションから自動計算され、閉じるものがなければ何もしません。元のコードと同じくストップもターゲットもありません。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Bollinger Length | 20 | ボリンジャーバンドの平滑化期間。手仕舞いに使うミドルラインもこれで決まります。 |
| Bollinger Width | 2 | バンドがミドルラインからどれだけ離れるかを決める標準偏差の倍率。 |
| %K Oversold | 20 | %K がこの水準を下回ると買いを確認します。 |
| %K Overbought | 80 | %K がこの水準を上回ると売りを確認します。 |
| Volume | 1 | 注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- 1つのローソク足ブロックが、ボリンジャーバンド、ストキャスティクス、終値を取り出すコンバーターに同時にデータを渡します。
- コンバーターブロックが指標を個別の線に分解します。アッパーバンド、ロワーバンド、ミドルライン、そして %K です。
- 各論理積がバンドの条件、ストキャスティクスの条件、ノーポジション判定を結び、オープンモードのポジション変更ブロックを起動します。
- 2つの出口ブロックはミドルラインとの比較から直接起動され、実際に注文が要るかどうかはブロック自身のクローズモードが判断します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
