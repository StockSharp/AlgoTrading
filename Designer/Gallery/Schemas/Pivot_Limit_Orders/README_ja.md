# ピボット指値注文ストラテジー・ダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

このダイアグラムは、古典的なピボットの支持線と抵抗線を、継続管理される一対の指値注文に変えます。確定足の移動1日レンジを使い、深夜の短い時間窓でライフサイクルを進め、最新の注文参照を登録・変更・取消・チャートで共有します。

![schema](schema.svg)

## 戦略の概要

- 確定5分足を期間288のHighestとLowestへ入力し、移動1日を表します。最新の終値がピボット計算を完成させます。
- 数式は P = (H + L + C) / 3、R1 = 2P − L、S1 = 2P − H を、数式同士を直列にせず直接計算します。
- Working timeは深夜付近で日次パルスを出します。状態ラッチにより、レベルが準備済みでノーポジションの最初のパルスだけが一組を登録します。
- Order registeringはS1に買い指値、R1に売り指値を置き、計算価格をそのまま使用します。
- Combinationは最新の注文参照を保持します。次の日次パルスがOrder replacingを動かし、その出力を同じバスへ戻します。
- 約定後はPosition protectionが1%のストップを置きます。保護約定はOrder cancellationを起動し、反対側のピボット注文の約定はポジションを自然に相殺します。

## エントリーとエグジットの条件

- **ロングエントリー**: 288本のレンジ形成後、最初の有効な深夜パルスが設定数量でS1に買い指値を置きます。支持線への到達で約定し、R1の売り注文が反対側の出口になります。
- **ショートエントリー**: 同じパルスがR1に売り指値を置きます。抵抗線への到達でショートを開き、S1の買い注文が反対側の指値出口になります。
- **エグジット**: 反対側のピボット注文はレンジの向こう側でポジションをフラットにできます。別系統のPosition protectionは1%の逆行で決済し、約定後に残る注文を取り消します。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candle Time Frame | 00:05:00 | 移動日レンジ、ピボット水準、注文時刻、保護判定に使う確定足の時間軸。 |
| Order Volume | 1 | 買い・売り各指値注文の数量。 |
| Stop Loss, % | 1 | Position protectionが退出する約定価格からの不利な距離（%）。 |

## ダイアグラムの詳細

- 288本のHighest/Lowestは移動1日の近似で、別の日足購読に依存せず、取引と同じ確定足ストリームで更新されます。
- R1とS1はH・L・Cから直接展開され、ピボット式を保ちながら同じ処理層で生成されます。
- flag変数が初期注文ペアの起動済み状態を記憶し、各足での重複登録を防ぎます。
- 登録・変更された注文はCombination<Order>バスに入り、変更出力が戻るため常に最新参照が使われます。
- すべての指値登録と変更はOnlineOnly = false、ShrinkPrice = falseで、履歴再生に対応し計算価格を保持します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
