# Momentum 零轴穿越加 SMA 过滤策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这里叠加了两个想法。Momentum 是当前收盘价与十根K线之前收盘价的差值，说明这段行情把价格推向了哪一边，而该差值的符号变化就是触发条件。简单移动平均线随后充当裁判：只有收盘价认同的方向上的穿越才被执行。

![schema](schema.svg)

## 策略概览

- 零轴穿越被拆成两个比较：当前值与零、前一根K线的值与零，这正是原始代码写下的条件。
- 移动平均过滤把两个方向分开：只有收盘价高于均线时上穿才买入，只有收盘价低于均线时下穿才卖出。
- 尽管文件夹名如此，这里的指标是 Momentum，即以点数计的绝对价差，而不是百分比变动率。
- 每个信号都是反手：下单数量为共享数量加上当前持仓的绝对值，因此一笔成交就平掉旧方向并建立新方向。
- 原版在每次成交后冻结30根K线；方块中没有K线计数器，因此该暂停未被移植，本图会响应每一次符合条件的穿越。

## 入场与出场规则

- **做多入场**: 上一根K线 Momentum 等于或低于零，当前高于零，收盘价高于 SMA，且持仓不是多头。订单按市价买入反手数量。
- **做空入场**: 上一根K线 Momentum 等于或高于零，当前低于零，收盘价低于 SMA，且持仓不是空头。订单按市价卖出反手数量。
- **离场**: 与原始代码一样，没有单独的离场方块，也没有保护性止损：持仓一直保留到反向穿越用一笔订单将其反手。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Momentum Length | 10 | Momentum 回看的K线根数；数值等于当前收盘价减去该根数之前的收盘价。 |
| SMA Length | 20 | 用于过滤穿越方向的简单移动平均线周期。 |
| Volume | 1 | 基础下单数量（手）；反手订单会在此基础上加上持仓的绝对值。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动三条分支：Momentum 指标、简单移动平均线，以及取收盘价的转换方块。
- 前值方块保存上一根K线的 Momentum 读数，四个比较方块把当前值与前值分别放在同一个零常量的两侧。
- 另外两个比较方块把收盘价与均线对比，还有两个把持仓与同一个零常量对比。
- 每个逻辑与把前一根所在的零轴一侧、当前所在的一侧、均线过滤和持仓判断合并，触发修改持仓方块，其数量来自「数量加持仓绝对值」的公式方块。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
