# 成交量激增策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

当一根K线的成交量远高于前一根时，通常意味着有人刚刚做了一笔大单。本图等待这样的跳升，由简单移动平均线判断多头还是空头在主导，并在成交量继续放大的期间跟随。一旦成交量回落到低于前一根K线，交易即告结束。

![schema](schema.svg)

## 策略概览

- 本图把当根K线的成交量与前一根K线的成交量比较，而不是与多根K线的均值比较，与原始代码完全一致。
- 该比较写成乘法而非除法，因此成交量为零的K线不会破坏运行。
- 20 周期收盘价简单移动平均线选择方向：在均线之上买入激增，在均线之下卖出激增。
- 入场只在空仓时进行；离场既不需要均线也不需要激增，只要成交量不再放大即可。

## 入场与出场规则

- **做多入场**: 当根K线成交量不低于前一根成交量乘以倍数，收盘高于均线，且持仓为零。订单以市价买入一手。
- **做空入场**: 当根K线成交量不低于前一根成交量乘以倍数，收盘低于均线，且持仓为零。订单以市价卖出一手。
- **离场**: 多空双方都在第一根成交量低于前一根的K线上离场，通过设为平仓模式的修改持仓方块完成。原策略没有止损和止盈，本图同样没有。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Spike Multiplier | 2 | 当根K线成交量需要达到前一根的多少倍才算激增。 |
| SMA Length | 20 | 选择入场方向的简单移动平均线周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块供给成交量转换方块、收盘价转换方块和均线方块；位移为一根K线的前值方块给出上一根的成交量。
- 公式方块把该成交量乘以激增倍数常量，比较方块再用当根成交量与结果对比。
- 每个逻辑与把激增、均线选定的方向和空仓判断合并，触发设为“仅开仓”的修改持仓方块。
- 成交量下降的比较直接接入两个平仓方块；它们处于平仓模式，空仓时不会动作。原策略还在每笔交易后暂停500根K线并使用1分钟K线；图中没有对应的计数方块，随包历史数据也粗于1分钟，因此本图使用5分钟K线并交易每一次激增。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
