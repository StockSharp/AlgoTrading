# ハンマー／逆ハンマーと SMA フィルターの戦略ダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

ハンマーは実体が小さく下ヒゲが長い、上ヒゲはほとんどない足です。足の中で価格が大きく下へ押された後、引けまでに買い戻されたことを示します。逆ハンマーはその鏡像です。これらの形だけならどこにでも現れるため、どこで取るに値するかは単純移動平均が決めます。ハンマーは平均線より下でのみ買い、逆ハンマーは平均線より上でのみ売ります。

![schema](schema.svg)

## 戦略の概要

- 2つのローソク足パターンブロックは、元の戦略とまったく同じ式を持ちます。実体がゼロより大きく、片側のヒゲが実体の2倍より長く、反対側のヒゲが実体の半分より短いという条件です。
- 組み込みの Hammer と Inverted Hammer はあえて使いません。これらはヒゲを実体ではなく足の全長と比べているためです。
- 終値の単純移動平均が相場を安い側と高い側に分け、エントリーのフィルターとエグジットのラインを兼ねます。
- ポジション判定により、パターンはノーポジションのときだけ執行されます。

## エントリーとエグジットの条件

- **ロングエントリー**: ローソク足パターンブロックがハンマーを報告し、その足が移動平均線より下で引け、かつポジションがゼロのとき。注文は1ロットを買って新規の買いを建てます。
- **ショートエントリー**: ローソク足パターンブロックが逆ハンマーを報告し、その足が移動平均線より上で引け、かつポジションがゼロのとき。注文は1ロットを売って新規の売りを建てます。
- **エグジット**: 買い建ては足が移動平均線を上回って引けたときに、売り建ては下回って引けたときに、いずれもクローズモードのポジション変更ブロックで手仕舞います。元の戦略はエントリーと同じ側で手仕舞い、その間は数百本の休止で建玉を保持していました。ここには本数を数えるブロックがないため、その条件をそのまま写すと毎回の売買が次の足で手仕舞われてしまいます。平均線の反対側への回帰が、ある程度の期間ポジションを保持できる最も近い条件です。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| SMA Length | 20 | パターンを絞り込み、手仕舞いにも使う単純移動平均の期間。 |
| Volume | 1 | 注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが2つのパターンブロック、移動平均、そして足から終値を取り出すコンバーターにデータを供給します。
- 2つの比較ブロックが終値と平均線を突き合わせ、それぞれ2回ずつ使われます。一方のエントリーのフィルターであり、同時に他方のエグジットのトリガーです。
- ポジションブロックはゼロ定数と比較され、各論理積がパターン、平均線のどちら側か、そしてこの保護を結びます。
- 2つのエントリーブロックは成行注文を出し、数量は共通の定数から取ります。2つのエグジットブロックはクローズモードで動き、手仕舞う建玉があるときだけ動作します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
