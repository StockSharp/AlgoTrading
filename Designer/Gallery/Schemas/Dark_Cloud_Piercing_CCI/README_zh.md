# 乌云盖顶 / 刺透形态配合 CCI 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

两个经典的双K线反转形态决定方向，Commodity Channel Index 决定这次反转是否值得参与。只有当 CCI 深陷负值区时才买入刺透形态，只有当 CCI 向上拉伸时才卖出乌云盖顶。没有任何信号负责平仓：由开仓时挂出的止盈和止损完成。

![schema](schema.svg)

## 策略概览

- 两个K线形态指标方块使用手写表达式描述形态：前一根K线的方向、当前K线的方向、开盘位置，以及收盘是否越过前一根实体的中点。
- 十四周期的 Commodity Channel Index 充当确认条件：市场必须已经朝着形态所要反转的方向被拉伸，否则忽略该形态。
- 一个入场水平常量同时服务多空两侧，公式方块把它取负供做多比较使用。
- 只有空仓时才允许入场，因此形态在下一根K线重复出现也不会加倍下单。

## 入场与出场规则

- **做多入场**: 前一根K线为阴线，当前K线为阳线，其开盘低于前一根收盘，收盘高于前一根实体的中点，CCI 低于入场水平的负值，且持仓为零。订单以市价买入一手。
- **做空入场**: 前一根K线为阳线，当前K线为阴线，其开盘高于前一根收盘，收盘低于前一根实体的中点，CCI 高于入场水平，且持仓为零。订单以市价卖出一手。
- **离场**: 只有持仓保护方块：距离开仓价百分之二的止盈和百分之一的止损。原始策略同样没有信号离场，因此这里并未缺失任何内容。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| CCI Length | 14 | Commodity Channel Index 的平滑周期。 |
| Entry Level | 50 | CCI 需要偏离零轴多少才算确认形态；做多一侧使用该数值的负数。 |
| Take Profit % | 2 | 止盈相对开仓价的百分比距离。 |
| Stop Loss % | 1 | 止损相对开仓价的百分比距离。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时供给两个形态方块、Commodity Channel Index 以及为保护方块读取收盘价的转换方块。
- 常量保存入场水平，公式方块为其取负，因此两个 CCI 比较由同一个可优化数值驱动。
- 每个逻辑与把形态、对应的 CCI 确认和空仓判断合并，触发设为“仅开仓”的修改持仓方块。
- 相对原版做了两处简化：原版还要求开盘真正跳空越过前一根K线的最低价或最高价，而连续交易的品种几乎不会出现这种跳空；原版还有六根K线的交易间隔，而图中没有计数方块。因此这里只要求开盘位于前一根收盘价的另一侧，并且每个确认形态都会交易。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
