# Диаграмма стратегии Dark Cloud Cover / Piercing Line с подтверждением CCI
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Две классические разворотные модели из двух свечей задают сторону, а Commodity Channel Index решает, стоит ли брать разворот. Piercing Line покупается только тогда, когда CCI глубоко в отрицательной зоне, Dark Cloud Cover продаётся только при вытянутом вверх CCI. Сигналов на выход нет вовсе: сделку закрывают тейк-профит и стоп-лосс, выставленные от цены входа.

![schema](schema.svg)

## Обзор стратегии

- Два кубика индикатора свечных моделей несут написанные вручную выражения: направление предыдущей свечи, направление текущей, где она открылась и закрылась ли за серединой тела предыдущей.
- Commodity Channel Index за четырнадцать свечей выступает подтверждением: рынок уже должен быть вытянут в ту сторону, которую модель разворачивает, иначе фигура игнорируется.
- Один кубик-константа задаёт уровень входа для обеих сторон — формула превращает его в отрицательное число для лонгового сравнения.
- Входить разрешено только из нулевой позиции, поэтому повторение модели на следующей свече не удваивает сделку.

## Правила входа и выхода

- **Вход в лонг**: Предыдущая свеча медвежья, текущая бычья, она открылась ниже закрытия предыдущей и закрылась выше середины её тела, CCI ниже минус уровня входа, позиция нулевая. Заявка покупает один лот по рынку.
- **Вход в шорт**: Предыдущая свеча бычья, текущая медвежья, она открылась выше закрытия предыдущей и закрылась ниже середины её тела, CCI выше уровня входа, позиция нулевая. Заявка продаёт один лот по рынку.
- **Выход**: Только кубик защиты позиции: тейк-профит в двух процентах от цены входа и стоп-лосс в одном проценте. Сигнального выхода нет.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| CCI Length | 14 | Период усреднения Commodity Channel Index. |
| Entry Level | 50 | Насколько CCI должен отойти от нуля, чтобы модель считалась подтверждённой; для лонга берётся это же число со знаком минус. |
| Take Profit % | 2 | Расстояние тейк-профита от цены входа в процентах. |
| Stop Loss % | 1 | Расстояние стоп-лосса от цены входа в процентах. |
| Volume | 1 | Объём заявки в лотах. |
| Candles | 00:05:00 | Таймфрейм свечей, на котором работает вся диаграмма. |

## Детали диаграммы

- Кубик свечей питает оба кубика свечных моделей, Commodity Channel Index и конвертер, который отдаёт цену закрытия кубику защиты.
- Константа хранит уровень входа, а формула меняет ему знак, поэтому обоими сравнениями CCI управляет одно оптимизируемое число.
- Каждое логическое И объединяет модель, её подтверждение по CCI и проверку нулевой позиции и запускает кубик изменения позиции в режиме только открытия.
- Открытие должно оказаться по другую сторону от закрытия предыдущей свечи — это практичное условие для непрерывно торгуемых инструментов; торгуется каждая подтверждённая модель.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
