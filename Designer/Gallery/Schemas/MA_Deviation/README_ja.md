# 移動平均乖離戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

単純移動平均を適正価格とみなし、終値とのパーセント乖離だけをシグナルにします。価格が平均から離れすぎたところで逆方向に仕掛け、価格が平均に戻ったらすぐ手仕舞います。

![schema](schema.svg)

## 戦略の概要

- 乖離は数式ブロック1つでそのまま計算します：(Close - SMA) / SMA * 100。
- しきい値は1つで両側を賄います。乖離をその値のプラスとマイナスの両方と比較するため、買いと売りは対称です。
- エントリーはノーポジションからのみで、2つのエントリーブロックには「ポジションを開く」条件も付いているため、ナンピンは起こりません。
- 元の戦略は1分足・しきい値2%・売買後500本のクールダウンで動きます。同梱の履歴は5分足なので、このダイアグラムは5分足としきい値1%（この系列のおよそ2標準偏差）を使います。クールダウンは Designer にロックアウト用のカウンターがないため再現しておらず、その分だけ元の戦略より売買回数が多くなります。

## エントリーとエグジットの条件

- **ロングエントリー**: 乖離がマイナスのしきい値を下回る、つまり終値が移動平均より設定した割合以上に低く、かつノーポジションのとき。注文は設定数量を買います。
- **ショートエントリー**: 乖離がプラスのしきい値を上回る、つまり終値が移動平均より設定した割合以上に高く、かつノーポジションのとき。注文は設定数量を売ります。
- **エグジット**: 終値が移動平均に戻るか上回れば買い建てを、移動平均に戻るか下回れば売り建てを手仕舞います。元の戦略と同じく損切りも利益確定もありません。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| SMA Length | 20 | 単純移動平均の平滑化期間。 |
| Deviation, % | 1 | エントリーに必要な平均からの乖離（％）。 |
| Volume | 1 | 注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが、終値を取り出す変換ブロックと移動平均を持つ指標ブロックの両方に値を渡します。
- 数式ブロックがこの2つをパーセント乖離に変え、もう1つの小さな数式がしきい値定数の符号を反転させて、公開したパラメーター1つで両側を賄います。
- 2つの比較ブロックが乖離としきい値を比べ、さらに2つが終値と平均を比べてエグジットを判断します。
- ポジションブロックはゼロと3回比較され、ノーポジション・買い持ち・売り持ちの判定を作り、論理積が価格条件と結び付けます。
- エントリーは「ポジションを開く」条件のポジション変更ブロックへ共通の数量定数とともに入り、エグジットは数量の要らない「ポジションを閉じる」条件のブロックへ入ります。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
