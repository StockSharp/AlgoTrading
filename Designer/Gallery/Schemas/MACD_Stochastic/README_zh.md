# MACD + 随机指标零轴同侧交叉策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

MACD 交叉发生的位置不同，含义也不同。本图只接受 MACD 线仍在零轴之下时的金叉——新一轮上涨正是从那里开始的——以及仍在零轴之上时的死叉。随机指标的两条线确认方向，入场前必须空仓，最后由百分比止损和止盈带出行情。

![schema](schema.svg)

## 策略概览

- 触发条件是 MACD 线与信号线的交叉；符号过滤同时检查 MACD 线的当前值与前一根K线的值，因此一根同时跨越零轴与信号线的K线不会被误认为新的交叉。
- 随机指标提供第二意见：做多要求 %K 高于 %D，做空要求 %K 低于 %D。
- 只允许在空仓状态入场：本图不加仓也不因信号反手，唯一的出路是止损或止盈。
- 原策略是 MetaTrader 智能交易系统的移植，止损止盈以点数计量，还带有三个交易时段和多级追踪止损。本图把距离改成入场价的百分比，时段窗口被省略，因为默认窗口覆盖全天。
- 另有两处简化：随机指标确认在图中始终启用，而代码里它是一个默认关闭的开关；并且只比较两条线的当前关系，不再额外检查四根K线之前的相对位置。原策略使用4小时K线，本图为配合随附样本历史改用5分钟K线。

## 入场与出场规则

- **做多入场**: MACD 线上穿信号线，当前与前一根K线的 MACD 值均低于零，%K 高于 %D，且当前空仓。订单以市价买入一手。
- **做空入场**: MACD 线下穿信号线，当前与前一根K线的 MACD 值均高于零，%K 低于 %D，且当前空仓。订单以市价卖出一手。
- **离场**: 持仓保护方块在距入场价固定百分比处平仓，或止盈或止损。与原策略一样，不会因 MACD 反向交叉而离场。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| MACD fast length | 12 | MACD 内部快速 EMA 的周期。 |
| MACD slow length | 26 | MACD 内部慢速 EMA 的周期。 |
| MACD signal length | 9 | 把 MACD 平滑成信号线的 EMA 周期。 |
| Stochastic %K length | 5 | 随机指标 %K 线的回溯周期。 |
| Stochastic %D length | 3 | %D 线的平滑周期，即 %K 的移动平均长度。 |
| Volume | 1 | 下单数量（手）。 |
| Take profit, % | 1 | 止盈距离，占入场价的百分比；用以替代原策略的100点。 |
| Stop loss, % | 1 | 止损距离，占入场价的百分比；用以替代原策略的100点。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动 MACD 与随机指标；四个转换方块从两个指标数值中取出 Macd、Signal、%K 与 %D。
- 交叉方块把 MACD 这一对变成看涨触发，“非”方块将其取反为看跌触发，前值方块保存上一根K线的 MACD 线用于符号检查。
- 七个比较方块构成过滤条件：四个用于两项零轴检查，两个用于随机指标两线，一个用于持仓与零的比较。
- 每个逻辑与合并五个条件并触发修改持仓方块，以共享的数量常量发出市价单；两个下单方块把各自的成交送入持仓保护方块，后者还读取K线收盘价作为当前价格。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
