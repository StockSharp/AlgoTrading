# Диаграмма стратегии MACD + Stochastic с пересечением по свою сторону нуля
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Пересечение MACD значит разное в зависимости от того, где оно случилось. Схема принимает бычье пересечение только пока линия MACD ещё ниже нуля — там и начинается новый подъём, — а медвежье только пока она ещё выше нуля. Линии стохастика подтверждают направление, позиция перед входом должна быть нулевой, а выводят из сделки процентные стоп и тейк.

![schema](schema.svg)

## Обзор стратегии

- Триггер — пересечение линии MACD с сигнальной; фильтр знака проверяет и текущее, и предыдущее значение линии MACD, поэтому бар, который за раз перепрыгнул и через ноль, и через сигнальную, не будет принят за свежее пересечение.
- Стохастик — второе мнение: для лонга нужно %K выше %D, для шорта — %K ниже %D.
- Вход разрешён только из нулевой позиции: схема не наращивает сделку и не разворачивается по сигналу, единственный выход — стоп или тейк.
- В диаграмме дистанции стопа и цели выражены в процентах от цены входа, а работа идёт круглые сутки.
- Подтверждение по стохастику включено постоянно и сравнивает текущие значения двух линий. Диаграмма использует пятиминутные свечи из поставляемой истории.

## Правила входа и выхода

- **Вход в лонг**: Линия MACD пересекает сигнальную снизу вверх, текущее и предыдущее значения MACD ниже нуля, %K выше %D, позиции нет. Заявка покупает один лот по рынку.
- **Вход в шорт**: Линия MACD пересекает сигнальную сверху вниз, текущее и предыдущее значения MACD выше нуля, %K ниже %D, позиции нет. Заявка продаёт один лот по рынку.
- **Выход**: Кубик защиты позиции закрывает сделку на фиксированном проценте от цены входа — по тейк-профиту или по стоп-лоссу. Выхода по встречному пересечению MACD нет.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| MACD fast length | 12 | Период быстрой EMA внутри MACD. |
| MACD slow length | 26 | Период медленной EMA внутри MACD. |
| MACD signal length | 9 | Период EMA, которая сглаживает MACD в сигнальную линию. |
| Stochastic %K length | 5 | Период расчёта линии %K стохастика. |
| Stochastic %D length | 3 | Период сглаживания линии %D — скользящей средней по %K. |
| Volume | 1 | Объём заявки в лотах. |
| Take profit, % | 1 | Дистанция тейк-профита в процентах от цены входа. |
| Stop loss, % | 1 | Дистанция стоп-лосса в процентах от цены входа. |
| Candles | 00:05:00 | Таймфрейм свечей, на котором работает вся диаграмма. |

## Детали диаграммы

- Кубик свечей питает MACD и стохастик; четыре конвертера достают из двух индикаторных значений линии Macd, Signal, %K и %D.
- Кубик пересечения превращает пару MACD в бычий триггер, кубик НЕ инвертирует его в медвежий, а кубик предыдущего значения хранит линию MACD прошлой свечи для проверки знака.
- Семь кубиков сравнения собирают фильтры: четыре на две проверки нуля, два на линии стохастика и один на сравнение позиции с нулём.
- Каждое логическое И объединяет пять условий и запускает кубик изменения позиции с рыночной заявкой на общую константу объёма; оба кубика заявок передают свою сделку в кубик защиты позиции, который дополнительно берёт закрытие свечи как текущую цену.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
