# ATR 跟踪止损策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

入场部分很简单：空仓时，收盘价高于移动平均线就买入，低于就卖出。有意思的是出场部分——ATR 跟踪止损：这条线与价格保持若干个平均真实波幅的距离，随盈利方向推进且从不回退，一旦收盘价击穿它就平仓。

![schema](schema.svg)

## 策略概览

- 二十周期简单移动平均线把行情分成上下两侧，收盘价相对它的位置决定入场方向。
- 跟踪止损由 SuperTrend 方块实现：它本身就是带棘轮的 ATR 通道，因此止损距离随波动率呼吸，而不是固定的点数。
- 每次入场只在空仓时进行，每次出场只在对应方向有持仓时进行，这正是四个下单方块互不干扰的原因。
- 止损位有意设得较宽——十四周期 ATR 的三倍——让持仓能承受正常噪音，只有行情真正转向时才放弃。

## 入场与出场规则

- **做多入场**: 当前空仓且K线收盘价高于简单移动平均线。订单以市价买入共享数量，价格下方的 ATR 跟踪线成为该多头持仓的止损。
- **做空入场**: 当前空仓且K线收盘价低于简单移动平均线。订单以市价卖出共享数量，价格上方的 ATR 跟踪线成为该空头持仓的止损。
- **离场**: 收盘价跌破 ATR 跟踪线时平多，涨破时平空。没有止盈也没有反手：止损之后，图会空仓等待移动平均线的下一个信号。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| MA Period | 20 | 决定入场方向的简单移动平均线周期。 |
| ATR Period | 14 | 跟踪线内部的 ATR 周期；数值越大，止损对波动率变化的反应越慢。 |
| ATR Multiplier | 3 | 跟踪线与价格相距多少个 ATR；数值越大，持仓空间越大，出场越少。 |
| Volume | 1 | 四个下单方块共用的下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动移动平均线、SuperTrend 跟踪线以及读取收盘价的转换方块。
- 两个比较方块把收盘价与移动平均线对比，另外两个把它与跟踪线对比，同一个价格只读取一次，供图的两个部分共用。
- 三个与零常量的比较把持仓转换成空仓、多头、空头三个标志，分别为入场和出场放行。
- 两个入场方块带开仓条件，两个出场方块带平仓条件，因此与当前持仓不匹配的信号不会产生任何动作。
- 原策略把止损位重算为收盘价减去若干 ATR 的运行最大值；这种棘轮无法用方块链表达，因此由同样带棘轮的 SuperTrend 线代替。
- 还有两处简化值得了解：原策略每笔交易后的五百根K线暂停没有对应方块，已被去掉；本图使用五分钟K线而非 C# 代码中的一分钟K线，因为图库随附的历史数据就是五分钟的。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
