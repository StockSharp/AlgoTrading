# 平均K线（Heikin-Ashi）连续同色策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Heikin-Ashi 把噪音平均掉，因此只要行情真的在延续，颜色就会保持不变。本图衡量的正是这种持续性：连续七根多头实体被视为已确立的上升趋势并买入，连续七根空头实体则卖出，百分比止损限制假信号的代价。

![schema](schema.svg)

## 策略概览

- 一个公式方块把 Heikin-Ashi 实体算成开高低收的平均值减去前一根K线的中点：实体为正是多头K线，为负是空头K线。
- 同色序列不用计数器来衡量：最近七个实体的最小值大于零，说明七根全是多头；最大值小于零，说明七根全是空头。
- 订单数量等于基础数量加上持仓绝对值，因此一张订单就能把空头直接翻成多头，反之亦然，与 C# 原版一致。
- Heikin-Ashi 的开盘价由它自身的前值定义，而图中无法把方块输出回接给自己，这里改用前一根普通K线的中点，因此找到的序列接近但不等同于源代码统计的结果。

## 入场与出场规则

- **做多入场**: 最近七个 Heikin-Ashi 实体的最小值大于零，即七根K线全为多头，且持仓不是多头。订单买入“数量加持仓绝对值”：空仓时开多，持空时反手。
- **做空入场**: 最近七个 Heikin-Ashi 实体的最大值小于零，即七根K线全为空头，且持仓不是空头。订单卖出“数量加持仓绝对值”：空仓时开空，持多时反手。
- **离场**: 与原始策略一样没有独立的离场规则：持仓要么被相反的序列反手，要么被持仓保护方块的止损带走，该止损按成交价的固定百分比放置。没有止盈也没有移动止损。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Consecutive candles | 7 | 连续多少根同色 Heikin-Ashi K线构成信号；它同时是 Lowest 与 Highest 方块的周期。 |
| Stop loss, % | 2 | 止损距离入场价的百分比。 |
| Volume | 1 | 基础下单数量（手）；再加上持仓绝对值，使反手只需一张订单。 |
| Candles | 00:30:00 | 整张图使用的K线周期，与原策略相同的半小时。 |

## 图表详情

- K线方块送入开、高、低、收四个转换方块，两个前值方块把前一根K线交给公式。
- 公式输出进入周期相同的 Lowest 与 Highest 方块，两次与零常量的比较把它们变成两个序列条件。
- 持仓方块与零比较两次后，通过逻辑与并入各自的序列条件，因此不会给方向已经正确的持仓加码。
- 两个修改持仓方块的数量来自把持仓绝对值加到共享数量上的公式，其成交则送入带止损的持仓保护方块。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
