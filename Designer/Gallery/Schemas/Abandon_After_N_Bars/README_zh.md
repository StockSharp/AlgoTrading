# N 根 K 线后放弃持仓策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

两条短周期均线和一个 2 周期 RSI 决定何时开仓，但本图的重点在于结束交易的规则。一笔交易若在固定数量的 K 线之内既没有到达目标位、也没有触及止损，就被放弃并以市价平仓。倒计时由 N 值（N values）方块计量，且从真正开出持仓的那笔成交开始，而不是从发出开仓信号的那一刻开始。

![schema](schema.svg)

## 策略概览

- 已完成的 5 分钟 K 线送入一条快速指数移动平均线、一条慢速指数移动平均线、一个 2 周期 RSI，以及一个从每根 K 线中取出收盘价的转换方块。
- 两个比较方块从均线读取趋势：快线在慢线之上，以及快线在慢线之下。另外两个比较方块把动能与一个阈值变量对比：RSI 低于阈值，以及 RSI 高于阈值。
- 持仓（Position）方块与零比较了两次，一次判相等、一次判不等，因此本图既有供开仓使用的空仓判定，也有供放弃规则使用的持仓判定。
- 每次开仓都是三个信号的逻辑与——趋势、动能和空仓；两个开仓方块都设为仅开仓，因此本图同一时间只持有一个仓位，也从不加仓。
- 持仓保护（Position protection）监视开仓成交，用百分比止盈和跟踪止损管理这笔交易；一旦价格朝有利于持仓的方向运行，跟踪止损就随价格移动。
- 策略成交（Strategy trades）汇报本策略的每一笔自有成交。标志（Flag）方块在空仓期间被复位，因此只放行一笔交易的第一笔成交，也就是开出持仓的那笔成交。
- 这一个脉冲激活 N 值方块，它随后开始计数已完成的 K 线，达到设定数量时输出一次。
- 放弃信号要先与持仓判定一起通过第二个逻辑与，才能到达设为平仓的持仓修改（Position modify）方块，因此倒计时只能结束一笔仍在进行中的交易。

## 入场与出场规则

- **做多入场**: 快线在慢线之上，RSI 低于阈值，且当前空仓。这一组合是在上升的短期趋势中买入回落。持仓修改以市价买入设定的下单量，且仅开仓。
- **做空入场**: 快线在慢线之下，RSI 高于阈值，且当前空仓——即下降的短期趋势中的走强。持仓修改以市价卖出设定的下单量，且仅开仓。
- **离场**: 离场有两条互相独立的路径。持仓保护可能先行平仓：在 1.2% 的盈利处，或在落后于已达到的最优价 0.6% 的跟踪止损处。若二者都没有发生，就轮到放弃规则：开仓成交之后第十二根已完成 K 线时，N 值方块触发，持仓判定确认确实还有仓位可平，设为平仓的持仓修改方块便把当前持有的一边平掉。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Candles | 00:05:00 | 整张图所依据的 K 线周期；放弃倒计时也以这些 K 线计数。 |
| Fast EMA Length | 3 | 快速指数移动平均线的周期长度。 |
| Slow EMA Length | 7 | 慢速指数移动平均线的周期长度；要保持它长于快线，否则趋势判定就失去意义。 |
| RSI Length | 2 | RSI 的周期长度。周期非常短会让它频繁穿越阈值，这正是开仓频繁的原因。 |
| RSI Threshold | 50 | 用来比较 RSI 的水平值。多头在其下方买入，空头在其上方卖出，因此调高它会让多头开仓更频繁、空头开仓更稀少。 |
| Order Volume | 1 | 每笔开仓委托的数量，以品种单位计。 |
| Take Profit, % | 1.2 | 止盈距离，以开仓价的百分比表示。 |
| Trailing Stop, % | 0.6 | 跟踪止损距离，以百分比表示：止损起初与开仓价相距这么远，随后跟随已达到的最优价移动，且从不回退。 |
| Bars Before Abandon | 12 | 一笔交易在被放弃并以市价平仓之前，允许持续多少根已完成的 K 线。调小可以更快放弃；调大则把离场更多地交给止盈和跟踪止损。 |

## 图表详情

- 倒计时由成交而非信号启动，因此计时衡量的是这笔交易实际存在了多久，而不是本图在多久之前想要它。
- 策略成交方块同样会汇报离场成交，若不加处理，每一笔平仓成交都会让倒计时重新开始。标志方块阻止了这一点：它只在空仓期间被复位，因此交易一旦进行中，之后的成交都会被忽略。
- 第二个逻辑与上的持仓判定，使得在空仓状态下走完的倒计时不会造成任何后果——只有确实有仓位可平时，平仓方块才会被触发。
- 两个开仓方块都把各自的成交送入组合（Combination）方块，因此无论开的是哪一边，持仓保护都由同一个输入激活；收盘价也接入同一个方块，让止盈和跟踪止损在每根已完成 K 线上都有可用的数值。
- 图表面板绘出 K 线、两条均线、RSI、开仓与放弃产生的委托、保护性委托以及每一笔成交，因此被放弃的交易与到达目标位的交易一眼就能区分开。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
