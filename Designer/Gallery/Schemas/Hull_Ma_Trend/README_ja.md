# Hull MA 傾き戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

Hull Moving Average は遅れが非常に小さく価格に追随するため、その傾きの向き自体がトレンドのシグナルになります。本ダイアグラムは、平均が1本前のローソク足からどれだけ動いたかを自身の値に対する割合で測り、小さなしきい値を超えたらその方向へポジションを転換します。原典は1分足500本ですが、ここでは5分足100本とし、同梱データ上で同じ長さの時間に相当させています。

![schema](schema.svg)

## 戦略の概要

- 取引するのは Hull Moving Average の傾きだけで、価格そのものを平均と比較することはありません。
- 傾きは1本前の値に対する割合として表す相対値なので、同じしきい値がどの価格帯でも機能します。
- +0.02% を超えれば買い、−0.02% を下回れば売り。その帯の内側では何も起こらず、保有中のポジションはそのままです。
- 最初のシグナル以降は常に建玉を持ちます。損切りも利確もなく、売買の間にノーポジションの状態もありません。原典コードと同じ挙動です。

## エントリーとエグジットの条件

- **ロングエントリー**: Hull Moving Average が1本前から上昇しきい値を超えて上昇し、ポジションが買いではないとき。注文は共通数量に既存の売り建玉を加えた数量を買い、1回の注文でポジションを転換します。
- **ショートエントリー**: Hull Moving Average が1本前から下落しきい値を超えて下落し、ポジションが売りではないとき。注文は共通数量に既存の買い建玉を加えた数量を売ります。
- **エグジット**: エグジット用のブロックはありません。反対向きの傾きシグナルがポジションを転換し、注文数量にポジションの絶対値が含まれているため、1本の成行注文で一方を閉じ他方を建てます。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Hull MA Length | 100 | Hull Moving Average の期間。1分足500本から5分足100本へ換算しています。 |
| Rise Threshold | 0.0002 | ロングを建てる、1本あたりの平均の相対的な上昇率。0.0002 は 0.02% です。 |
| Fall Threshold | -0.0002 | ショートを建てる、1本あたりの平均の相対的な下落率。上昇しきい値と対称です。 |
| Volume | 1 | 保有ポジションを足す前の注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- 前値ブロックが1本前の Hull 値を保持し、最初の値では何も出力しません。これは原典が最初の値を読み飛ばす挙動を再現しています。
- 傾きの数式は現在値から前値を引き、前値で割ることで、値動きを割合に変換します。
- 2つの比較ブロックが、正と負のしきい値定数によってこの割合を3つの状態に分けます。
- それぞれの論理積が傾きの条件とポジション判定を結び、数量の数式が共通数量にポジションの絶対値を加えることで、エントリーが転換になります。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
