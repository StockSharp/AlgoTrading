# Parabolic SAR + RSI 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

方向由 Parabolic SAR 决定，相对强弱指数只负责否决那些已经走到强弩之末的入场。开仓的 SAR 线同时也是平仓线，因此离场价位随趋势移动，而不是固定在某个价格上。

![schema](schema.svg)

## 策略概览

- Parabolic SAR 基于已完成K线计算，并与每根K线的收盘价比较：收盘价在线上方为上涨趋势，在下方为下跌趋势。
- 相对强弱指数是宽松过滤器，与原始代码完全一致：做多要求 RSI 低于超买水平，做空要求 RSI 高于超卖水平，因此只有直接冲进极端区的入场才会被拦下。
- 仅在空仓时开仓，唯一的离场方式是价格越过 SAR 线——图中没有固定止损，也没有止盈。

## 入场与出场规则

- **做多入场**: K线收盘价高于 Parabolic SAR，RSI 仍低于超买水平，且当前空仓。修改持仓方块以市价买入公共数量。
- **做空入场**: K线收盘价低于 Parabolic SAR，RSI 仍高于超卖水平，且当前空仓。修改持仓方块以市价卖出公共数量。
- **离场**: 只要有一根K线收在 SAR 线下方，多头即被平掉；收在上方则平掉空头。两个平仓方块都按当前持仓量工作。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| RSI Length | 14 | 相对强弱指数的平滑周期。 |
| RSI Overbought | 70 | 允许做多时，指数必须低于的水平。 |
| RSI Oversold | 30 | 允许做空时，指数必须高于的水平。 |
| SAR Acceleration | 0.02 | Parabolic SAR 的初始加速因子。 |
| SAR Max acceleration | 0.2 | SAR 加速因子的上限。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时供给 Parabolic SAR、相对强弱指数以及提取收盘价的转换方块。
- 两个比较方块把收盘价与 SAR 线对照，另两个把指数与常量对照，还有三个把持仓与零对照。
- 每个逻辑与先集齐一个价格条件、一个过滤条件和一个持仓条件，然后才触发修改持仓方块；平仓方块使用平仓模式，无需数量输入。
- C# 策略每次交易后等待 130 根K线的暂停在 Designer 中没有对应方块，因此本图会更早重新入场，交易次数多于原策略。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
