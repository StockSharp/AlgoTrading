# Williams %R 水平穿越策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Williams %R 表示最新收盘价在近期窗口的最高价与最低价之间所处的位置，取值从最底部的 -100 到最顶部的 0。本图交易的不是停留在极端区间的时间，而是离开该区间的那一刻：回升到 -80 之上做多，回落到 -20 之下做空。

![schema](schema.svg)

## 策略概览

- Williams %R 基于单一品种的已完成K线计算，与原始策略手工编写的最高价/最低价公式完全等价。
- 两个水平把量程分开：低于 -80 视为超卖，高于 -20 视为超买。
- 前值方块保存上一根K线的读数，因此每个水平被检查两次，只有发生穿越的那根K线才发出信号。
- 当前持仓参与两侧判断，所以订单不会给已有持仓加码。

## 入场与出场规则

- **做多入场**: 上一根K线的 %R 低于下水平，当前读数等于或高于该水平，且持仓不是多头。订单买入一手：空仓时开多，持空时把持仓拉回零。
- **做空入场**: 上一根K线的 %R 高于上水平，当前读数等于或低于该水平，且持仓不是空头。订单卖出一手：空仓时开空，持多时把持仓拉回零。
- **离场**: 没有单独的离场方块：反向穿越会以相同数量发出市价单，与原始策略一样把持仓归零。原始策略在每笔交易后还会停顿五十根K线；这里没有专门的计数方块，因此完全由水平穿越承担这一职责，图的交易频率略高于源代码。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Williams %R Length | 14 | 计算 Williams %R 所用的最高价与最低价窗口。 |
| Lower Level | -80 | 指标需要向上回穿才给出买入信号的水平。 |
| Upper Level | -20 | 指标需要向下回穿才给出卖出信号的水平。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块把数据送入 Williams %R 指标方块，其输出同时进入比较方块和前值方块。
- 四个比较方块构成两次穿越：先前读数与水平比较，当前读数与同一水平比较。
- 持仓方块与零常量比较两次，为买入侧提供“非多头”保护，为卖出侧提供“非空头”保护。
- 每个逻辑与把穿越的两半与持仓保护合并，触发修改持仓方块；两者的数量取自同一个常量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
