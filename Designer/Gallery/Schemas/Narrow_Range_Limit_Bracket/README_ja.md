# ナローレンジ・リミットブラケット戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

動きを止めた市場は、動き出す準備をしている市場です。このダイアグラムはすべての足の値幅を測り、その値幅が直近数本のなかで最も小さい水準まで縮んだ瞬間を見つけ、その足を高値と安値という2つの水準で挟みます。価格がどちらの水準を先に終値で抜けるかが、売買の方向を決めます。

![schema](schema.svg)

## 戦略の概要

- 確定した15分足が、各足の高値・安値・終値を読み取る3つのコンバーターに供給されます。
- 数式が高値から安値を引き、すべての足は1つの数値、すなわち値幅に置き換えられます。
- Lowestインジケーターは価格ではなくこの数値に対して動作し、直近6本の最小値幅を示します。数式がそれにスクイーズ係数を掛け、足がナローと見なされるために収まらなければならない幅を求めます。
- 2つ目の分岐は、同じ計測を1本前の足について組み立て直します。前の値（Previous value）が1本前の足を渡し、2つのコンバーターと数式がその値幅を求め、もう1つの前の値がその時点でLowestインジケーターが示していた値を取り出します。
- 論理条件が3つの答えを組み合わせます。今回の足がナローであること、その1本前の足はナローでなかったこと、そしてポジションがないこと。これがスクイーズです。
- スクイーズが発生すると、その足の高値と安値が2つの変数に取り込まれ、以後の足でもその2つの価格が保持され続けます。これがブラケットです。3つ目の変数がそれを有効化します。
- 次の足からは、2つの比較が終値を2つの水準と照らし合わせ、終値がいずれかを抜け、ブラケットが有効で、ポジションがない場合に、論理条件が成行のエントリーを発生させます。
- 2つのチャートパネルが結果を描画します。一方にはブラケットの水準・注文・約定を伴う価格、もう一方には足の値幅とそのスクイーズ上限が表示されます。

## エントリーとエグジットの条件

- **ロングエントリー**: 足の終値がブラケットの上側の水準を上回り、ブラケットが有効で、ポジションがない状態です。ポジション変更（Position modify）が注文数量を成行で買います。
- **ショートエントリー**: 足の終値がブラケットの下側の水準を下回り、同じくブラケットが有効でポジションがないという条件を満たす状態です。ポジション変更が注文数量を成行で売ります。
- **エグジット**: このダイアグラムには独自の決済シグナルはありません。2つのエントリーは結合（Combination）によって1つの約定ストリームにまとめられ、それがポジション保護（Position protection）に渡されます。ポジション保護はポジションを引き継ぎ、約定価格を基準に利益550価格単位または損失550価格単位で決済します。同じ約定ストリームがブラケットを無効化するため、すでに執行された水準が再び執行されることはありません。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candles | 00:15:00 | ダイアグラム全体が対象とする足の時間軸。 |
| Period | 6 | Lowestインジケーターが最小値幅を測定する足の本数。 |
| Squeeze Factor | 1.08 | 現在の足が直近の最小値幅よりどれだけ広くてもナローと見なされるか。 |
| Expansion Factor | 1.05 | スクイーズが新しいものと見なされるために、1本前の足が自身の直近の最小値幅よりどれだけ広くなければならなかったか。 |
| Order Volume | 1 | 注文数量（ロット）。 |
| Take Profit | 550 | 約定価格からのテイクプロフィット距離（価格単位）。 |
| Stop Loss | 550 | 約定価格からのストップロス距離（価格単位）。 |

## ダイアグラムの詳細

- スクイーズは足を自身の直近の履歴と比較するものなので、ナローな足とは何かという固定的な定義を必要としません。スクイーズ係数は、直近の最小値幅にどこまで近づけばよいかを指定するだけです。
- エクスパンション係数は、同じ考え方のもう一方の側を守ります。これがなければ、同じように静かな足が続くあいだシグナルが繰り返し発生してしまいます。1本前の足がその時点の上限より広かったことを求めることで、シグナルは静かな期間全体ではなく、ボラティリティが縮小したその瞬間を示すようになります。
- Lowestインジケーターには足ではなく数値が供給されます。これにより、通常の価格インジケーターをボラティリティの計測器として動かすことができます。
- ブラケットはスクイーズによって有効化され、エントリーの約定によって無効化されます。その水準は次のスクイーズが置き換えるまで維持されます。したがってブラケットは、本数で失効するのではなく、執行されるか新しいスクイーズが現れるまで生き続けます。
- スクイーズにはポジションがないことも条件となるため、取引中に水準が書き換えられることはありません。また、両方のエントリーブロックにあるポジション条件が、保有中のポジションに上乗せする2つ目の注文を拒否します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
