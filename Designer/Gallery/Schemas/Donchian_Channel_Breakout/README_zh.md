# 唐奇安通道突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

最经典的趋势跟随思路：Donchian Channels 指标绘制最近 N 根K线的最高价与最低价，只要K线收盘价越出通道，策略立刻顺势入场。它始终持仓，遇到反向突破就从多头翻成空头，反之亦然。

![schema](schema.svg)

## 策略概览

- Donchian Channels 基于已完成K线计算：上轨为周期内最高价，下轨为周期内最低价。
- 两条轨道都向后延迟一根K线，因此当前K线的收盘价与已经封闭的通道比较；否则当前K线会抬高它本该突破的轨道。
- 当前持仓参与每一次判断，下单数量还会加上持仓绝对值，因此一张市价单即可平掉旧方向并开出新方向。

## 入场与出场规则

- **做多入场**: K线收盘价高于上一根K线的上轨，且持仓不是多头。订单买入基础数量加持仓绝对值：空头翻成多头，空仓则开多。
- **做空入场**: K线收盘价低于上一根K线的下轨，且持仓不是空头。订单卖出基础数量加持仓绝对值：多头翻成空头，空仓则开空。
- **离场**: 没有止损、没有止盈，也没有单独的离场方块：持仓一直保留到反向突破将其反转为止，与原始策略完全一致。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Channel period | 20 | 计算最高价与最低价所用的K线数量。 |
| Volume | 1 | 基础下单数量（手）；反转时再加上持仓绝对值。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块把数据送入 Donchian Channels 指标，并通过转换方块取得收盘价。
- 两个转换方块从指标中读取 UpperBand 与 LowerBand，两个前值方块把它们向后平移一根K线。
- 两个比较方块把收盘价与平移后的轨道对比，另外两个把持仓与零对比，逻辑与将两类条件合成入场信号。
- 公式方块把反转数量算成基础数量加持仓绝对值，并送入两个修改持仓方块。
- 原始代码默认在1分钟K线上使用1000根通道；本图采用5分钟K线与20根通道，这正是该策略 README 和优化区间给出的取值，这样在一个月的历史数据上才会真正产生交易。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
