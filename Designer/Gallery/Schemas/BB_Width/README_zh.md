# 布林带宽度扩张策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

信号来自两条布林带之间的距离，而非价格触碰轨道。公式方块用上轨减去下轨，结果再延迟一根K线，以便比较前后两次读数。轨道一旦开始张开，图表就建仓，方向仅由收盘价位于中轨上方还是下方决定。

![schema](schema.svg)

## 策略概览

- 布林带一次给出三条线；三个转换方块从同一个指标值中取出上轨、下轨和中轨。
- 带宽由公式方块计算，并由前值方块保存，于是扩张变成两个数字的普通比较。
- 方向并非突破判断：任何扩张都会开仓，中轨只说明是做多还是做空。原始策略正是这样分支的。
- 带宽一停止增长，两个平仓方块同时触发，持有的那一侧被平掉。

## 入场与出场规则

- **做多入场**: 带宽大于前一根K线，收盘价高于中轨，且当前无持仓。订单按市价买入共享数量。
- **做空入场**: 带宽大于前一根K线，收盘价等于或低于中轨，且当前无持仓。订单按市价卖出共享数量。
- **离场**: 带宽不再增长，即等于或小于前一根K线的带宽。两个平仓方块被触发，与持仓方向匹配的那个按市价平仓。原始策略没有止损和止盈，本图同样没有。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Bollinger Period | 20 | 布林带的平滑周期，决定带宽反应的快慢。 |
| Bollinger Width | 2 | 布林带的标准差倍数；数值越大，轨道及其间距越宽。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块供给布林带指标，并另行供给读取收盘价的转换方块。
- 公式方块把上轨作为 a、下轨作为 b，返回二者之差作为带宽。
- 带宽既进入前值方块，也直接进入两个比较方块，因此扩张与否读自同一对数值。
- 每个逻辑与把扩张、中轨方位和空仓判断合并；离场方块直接挂在收缩比较之后。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
