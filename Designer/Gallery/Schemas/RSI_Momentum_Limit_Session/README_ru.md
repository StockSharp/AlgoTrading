# Схема сессии лимитных заявок по RSI и Momentum
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Схема объединяет RSI(14), Momentum(14), суточный фильтр Working time и управляемые отложенные лимиты. При перепроданности и слабом импульсе покупка ставится ниже открытия свечи, при перекупленности и сильном импульсе продажа ставится выше; исчезнувший сигнал явно снимает свою заявку.

![schema](schema.svg)

## Обзор стратегии

- Завершённые пятиминутные свечи питают RSI, Momentum, цену открытия для входа и close для проверки защиты.
- Working time пропускает свечи с 00:00 до 23:59, сохраняя фактически круглосуточную сессию исходника и показывая настраиваемый кубик времени.
- RSI ниже 30, Momentum ниже 1 и Position <= 0 разрешают покупку; RSI выше 70, Momentum выше 1 и Position >= 0 разрешают продажу.
- Одноразовые флаги удерживают не более одной заявки на эпизод сигнала. Устаревшая своя или встречная заявка явно снимается.
- После исполнения лимита позиция получает абсолютный тейк 35 и стоп 8; завершённый close подключён к ценовому входу защиты.

## Правила входа и выхода

- **Вход в лонг**: Внутри сессии условия RSI < 30, Momentum < 1 и Position <= 0 регистрируют лимитную покупку объёмом один по OpenPrice − 25. Активная продажа предварительно снимается.
- **Вход в шорт**: Внутри сессии условия RSI > 70, Momentum > 1 и Position >= 0 регистрируют лимитную продажу объёмом один по OpenPrice + 25. Активная покупка предварительно снимается.
- **Выход**: Защита закрывает исполненный вход при абсолютной прибыли 35 или убытке 8 ценовых единиц. Buy снимается при нарушении условия RSI, Momentum или позиции; для sell логика зеркальна.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Candle Time Frame | 00:05:00 | Интервал завершённых свечей: пять минут — replay-адаптация, в C# по умолчанию пятнадцать минут. |
| RSI Period | 14 | Число значений в RelativeStrengthIndex. |
| Momentum Period | 14 | Число значений в Momentum. |
| Session Start | 00:00:00 | Начало окна Working time. |
| Session End | 23:59:00 | Конец окна Working time; 23:59 сохраняет круглосуточное поведение исходника. |
| RSI Buy Threshold | 30 | Для покупки RSI должен быть ниже этого значения. |
| RSI Sell Threshold | 70 | Для продажи RSI должен быть выше этого значения. |
| Momentum Threshold | 1 | Для покупки Momentum должен быть ниже порога, для продажи — выше. |
| Limit Offset, price units | 25 | Абсолютный отступ от OpenPrice вниз или вверх в replay-схеме. |
| Order Volume | 1 | Объём каждой отложенной лимитной заявки. |
| Take Profit, price units | 35 | Абсолютная благоприятная дистанция от цены исполнения. |
| Stop Loss, price units | 8 | Абсолютная неблагоприятная дистанция от цены исполнения. |

## Детали диаграммы

- В C# таймфрейм по умолчанию равен 15 минутам. Схема использует пятиминутные replay-свечи для достаточного числа наблюдаемых сигналов и заявочных циклов; периоды обоих индикаторов остаются 14, поэтому это явная адаптация частоты.
- Исходник отступает на 5 × PriceStep. Схема не получает шаг replay-инструмента отдельным кубиком и использует 25 абсолютных единиц цены; это настройка исполнения галереи, а не дефолт C#.
- Лимиты считаются от OpenPrice в точности как в ProcessCandle. ClosePrice отделён и служит только потоком текущей цены для Position protection.
- Защита исходника задаётся как 35 × PriceStep и 8 × PriceStep. Схема сохраняет числа 35 и 8 абсолютными ценовыми единицами, не выдавая их ошибочно за проценты.
- Одноразовые флаги моделируют проверку активной заявки в коде. Они сбрасываются, когда RSI, Momentum или условие позиции перестают подходить стороне, и разрешают новую заявку в следующем валидном эпизоде.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
