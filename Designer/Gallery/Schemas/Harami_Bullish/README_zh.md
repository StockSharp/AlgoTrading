# 看涨孕线策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

孕线是一根完全包含在前一根之内的K线，意味着刚刚推动行情的一方已经力竭。原始代码按最高价与最低价而非实体来检验这种包含关系，因此这里识别的其实是一根同时改变颜色的内包K线：前一根朝一个方向走，内部的小K线朝另一个方向走。这样的反转只在空仓时入场，并交由一条简单移动平均线来了结。

![schema](schema.svg)

## 策略概览

- 两个K线形态方块承载与原始代码检验方式完全一致的自定义形态：前一根K线是一种颜色，当前一根是另一种颜色，且其最高价与最低价都落在前一根的区间之内。
- 基于收盘价的简单移动平均线完全不参与入场过滤，它只是判定交易何时结束的裁判。
- 只有在持仓恰好为零时才允许入场，正是这一点让孕线成为一次反转尝试，而不是加仓的手段。
- 离场由独立的修改持仓方块以平仓模式完成，因此它们绝不会意外开仓。

## 入场与出场规则

- **做多入场**: 看涨形态方块报告出现一根阴线，随后是一根更小的阳线，其最高价低于前一根最高价、最低价高于前一根最低价，且持仓为零。订单买入一手并开多。
- **做空入场**: 看跌形态方块报告出现一根阳线，随后是一根以同样方式被包含的更小阴线，且持仓为零。订单卖出一手并开空。
- **离场**: 只要有一根K线收在移动平均线之下，多头即被平掉；收在其上时空头即被平掉。两个离场都由平仓模式的修改持仓方块完成，与原策略完全一致。原策略还会在每次下单后停止交易五百根K线；没有任何方块能在K线之间保存计数器，因此该暂停被去掉，本图在空仓时会交易它发现的每一个形态。原策略运行在一分钟K线上，而随附的历史数据是五分钟的，所以本图改用五分钟K线。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SMA Length | 20 | 用于平仓的简单移动平均线的平滑周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时驱动两个形态方块、移动平均线以及读取收盘价的转换方块。
- 两个比较方块把收盘价放在移动平均线的这一侧或那一侧；同样这两个信号驱动两个平仓方块。
- 一个比较方块把持仓与零常量对比，其输出被两个入场条件共用。
- 每个逻辑与把一个形态与空仓判断合并，触发一个从共享常量取数量的修改持仓方块。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
