# Zigzag Candles – Strategiediagramm
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Dieses Diagramm hält zwei Swing-Niveaus bereit — das höchste Hoch und das tiefste Tief der letzten fünf abgeschlossenen Stundenkerzen — und handelt auf der Kerze, die eines davon erreicht. Zwei Flag-Bausteine, die sich gegenseitig zurücksetzen, lassen genau eine Aktion je Swing zu, sodass ein Niveau, das innerhalb derselben Bewegung immer wieder berührt wird, eine einzige Order erzeugt und nicht mehr. Jeder Swing stellt zuerst glatt, was offen ist; der darauffolgende Swing eröffnet die Gegenseite.

![schema](schema.svg)

## Strategieübersicht

- Eine einzige Serie von Stundenkerzen speist alles, und sie liefert ausschließlich abgeschlossene Kerzen, sodass weder ein Niveau noch eine Order jemals aus einem Kurs entsteht, den ein späterer Tick noch zurücknehmen könnte.
- Zwei Converter lesen das Hoch und das Tief jeder Kerze und speisen ein Highest über fünf und ein Lowest über fünf. Beide Indikatoren veröffentlichen erst, wenn sie ausgeformt sind, sodass es kein Niveau gibt, bevor fünf Kerzen geschlossen haben.
- Zwei Variable-Bausteine halten die Niveaus. Jeder übernimmt den neuesten Indikatorwert, ohne ihn weiterzugeben, und veröffentlicht auf jeder Kerze erneut, was er hält, sodass ein Niveau den Vergleichen auf jedem Bar zur Verfügung steht und nicht nur auf dem Bar, der es verändert hat.
- Zwei weitere Converter lesen das Hoch und das Tief der soeben geschlossenen Kerze, und zwei Comparison-Bausteine messen sie an den gehaltenen Niveaus: ein Hoch, das das obere Niveau erreicht oder überschreitet, ein Tief, das das untere Niveau erreicht oder unterschreitet.
- Ein Position-Schnappschuss wird einmal je Kerze eingerastet und zweimal mit null verglichen, was einen Nicht-Short-Test und einen Nicht-Long-Test ergibt. Jeder der beiden Ausbrüche wird über eine Logical condition AND mit dem passenden Test verknüpft, sodass das obere Niveau nur gehandelt wird, solange die Position nicht bereits short ist, und das untere nur, solange sie nicht bereits long ist.
- Jedes AND steuert den Trigger eines Flag, und der jeweils entgegengesetzte Ausbruch steuert dessen Reset. Ein Flag lässt ein einziges true durch und schweigt dann, bis es zurückgesetzt wird — damit wird aus einem Niveau, das innerhalb eines Swings vielfach berührt wird, genau eine Aktion.
- Ein Flag, das auslöst, erreicht gleichzeitig ein Modify position mit Close position und ein Modify position mit Open position. Nur eines von beiden greift: eine bestehende Position wird zum Marktpreis glattgestellt, eine flache Position wird auf der vom Swing verlangten Seite eröffnet, und der Baustein, der nicht greift, weist das Signal ab.
- Das Chart panel zeichnet die Stundenkerzen, beide Extremlinien, alle drei Orderströme und jede Ausführung, sodass sich die Swing-Niveaus und die darauf ergriffenen Aktionen aus einem einzigen Bild ablesen lassen.

## Ein- und Ausstiegsregeln

- **Long-Einstieg**: Das Tief einer abgeschlossenen Kerze erreicht oder unterschreitet das gehaltene untere Niveau, während die Position nicht long ist. Das untere Flag löst einmal aus: eine Short-Position wird zum Marktpreis zurückgekauft und wird flach, eine flache Position wird in einen Long über Order Volume verwandelt. Danach schweigt das Flag, wie oft das Tief auch erneut berührt wird, bis das obere Niveau genommen ist.
- **Short-Einstieg**: Das Hoch einer abgeschlossenen Kerze erreicht oder überschreitet das gehaltene obere Niveau, während die Position nicht short ist. Das obere Flag löst einmal aus: eine Long-Position wird zum Marktpreis verkauft und wird flach, eine flache Position wird in einen Short über Order Volume verwandelt. Dieses Flag schweigt, bis das untere Niveau genommen ist.
- **Ausstieg**: Es gibt keinen Stop, kein Ziel und keinen Timer — die Position wird durch den entgegengesetzten Swing geschlossen. Dasselbe Flag, das eine Seite eröffnet, speist auch den Close position-Baustein, sodass die erste Berührung des anderen Niveaus glattstellt, was offen ist. Da das Einstiegsvolumen fest ist und der eröffnende Baustein nur eine flache Position annimmt, braucht eine vollständige Umkehr immer zwei Swings: einen zum Glattstellen, den nächsten zum Eröffnen der Gegenseite.

## Parameter

| Parameter | Standard | Beschreibung |
|---|---|---|
| Candles | 01:00:00 | Zeitrahmen der Kerzenserie. Es werden nur abgeschlossene Kerzen geliefert, sodass einmal je Bar entschieden wird. |
| Swing High Length | 5 | Anzahl abgeschlossener Kerzen, über die das obere Extremum gebildet wird. Ein längeres Fenster macht das obere Niveau schwerer erreichbar und die Swings länger, ein kürzeres macht fast jede Kerze zu einem neuen Extremum. |
| Swing Low Length | 5 | Anzahl abgeschlossener Kerzen, über die das untere Extremum gebildet wird. Sie wird getrennt von der oberen gehalten, damit sich die beiden Seiten bewusst asymmetrisch einstellen lassen. |
| Initial Swing High | 999999999 | Wert, den das obere Niveau hält, bis der obere Indikator ausgeformt ist. Er ist absichtlich unerreichbar, damit ihn während der Aufwärmphase kein Hoch berühren kann und kein Short eröffnet wird, bevor ein echtes Extremum existiert. |
| Initial Swing Low | 0 | Wert, den das untere Niveau hält, bis der untere Indikator ausgeformt ist. Null kann von einem gehandelten Kurs nicht von oben erreicht werden, was die Long-Seite aus demselben Grund ruhig hält. |
| Order Volume | 1 | Stückzahl, die von beiden Eröffnungsaktionen verwendet wird. Die schließende Aktion braucht kein Volumen — sie stellt glatt, was offen ist —, sodass sich die Position bei fester Stückzahl nur zwischen einem Lot short, flach und einem Lot long bewegt. |

## Diagrammdetails

- Der [Candles](https://doc.stocksharp.com/en/topics/designer/strategies/using_visual_designer/elements/data_sources/candles.html)-Baustein ist ausschließlich auf abgeschlossene Kerzen abonniert, und genau das macht die Niveaus ehrlich. Die Indikatoren werden über [Converters](https://doc.stocksharp.com/en/topics/designer/strategies/using_visual_designer/elements/converters/converter.html) gespeist, und ein Converter gibt eine nackte Zahl aus, die immer als endgültig gilt; eine noch laufende Kerze ginge daher in die Fenster von Highest und Lowest ein, als wäre sie fertig, und das Extremum enthielte am Ende sich selbst. Dasselbe Abonnement hält auch die Orders zulässig: eine Order, die aus einem Update einer unfertigen Kerze entsteht, trägt die Eröffnungszeit dieses Bars und wird als aus der Vergangenheit eintreffend abgelehnt.
- Ein Ausbruch wird an den Niveaus gemessen, wie sie vor der beurteilten Kerze standen: die haltenden Variablen veröffentlichen erneut, was sie bereits hatten, und die Indikatoren nehmen die neue Kerze auf demselben Bar auf, sodass das Niveau, gegen das eine Kerze geprüft wird, das Extremum der fünf vorangegangenen Kerzen ist und keines, das sie selbst einschließt.
- Die beiden [Flag](https://doc.stocksharp.com/en/topics/designer/strategies/using_visual_designer/elements/common/flag.html)-Bausteine sind über Kreuz verdrahtet: der obere Ausbruch setzt das untere Flag zurück und der untere Ausbruch das obere. Dieses Paar ist das gesamte Gedächtnis des Diagramms — es sagt, in welche Richtung der letzte Swing lief und ob er bereits gehandelt wurde. Ein Flag ignoriert ein false an beiden Eingängen, sodass die Vergleiche, die auf jedem Kerzenupdate false veröffentlichen, nichts kosten, und es sendet erst wieder, nachdem das entgegengesetzte Niveau erreicht wurde.
- Die Niveaus werden von [Variable](https://doc.stocksharp.com/en/topics/designer/strategies/using_visual_designer/elements/data_sources/variable.html)-Bausteinen gehalten, deren Eingang nicht als Trigger wirkt; stattdessen steuert die Kerzenserie deren Trigger. Dasselbe Muster rastet den [Position](https://doc.stocksharp.com/en/topics/designer/strategies/using_visual_designer/elements/positions/current.html)-Wert einmal je Kerze ein, sodass die beiden Positions-[Comparisons](https://doc.stocksharp.com/en/topics/designer/strategies/using_visual_designer/elements/common/comparison.html) und die beiden [Logical condition](https://doc.stocksharp.com/en/topics/designer/strategies/using_visual_designer/elements/common/logical_condition.html)-AND-Bausteine alle denselben Schnappschuss lesen und keinen Wert, der sich unter ihnen verschiebt.
- Drei [Modify position](https://doc.stocksharp.com/en/topics/designer/strategies/using_visual_designer/elements/positions/modify.html)-Bausteine handeln, alle zum Marktpreis: einer mit Close position, der beide Flags entgegennimmt, und je einer mit Open position für jede Seite. Auf einer Außenkerze, die sowohl das vorherige Hoch nimmt als auch das vorherige Tief unterschreitet, können beide Flags im selben Durchlauf auslösen, und zwei Marktorders werden gesendet; sie heben sich in der Position gegenseitig auf, erscheinen aber beide als Ausführungen im Log und auf dem [Chart panel](https://doc.stocksharp.com/en/topics/designer/strategies/using_visual_designer/elements/common/chart.html).

## Verwendung

Importieren Sie die `.json`-Datei in Designer, testen Sie sie im Backtester mit historischen Daten und passen Sie danach Parameter oder Bausteine an Ihr Instrument an, bevor Sie live handeln.
