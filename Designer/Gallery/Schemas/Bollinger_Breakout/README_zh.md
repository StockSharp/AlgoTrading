# 布林带区域突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

名字叫突破，实际交易的是回抽：当某根K线的下部区域刺穿布林带下轨、而价格仍站在 EMA 50 之上时，图表买入这次下探；镜像条件则在上轨被刺穿时卖出。只要价格回到中轨，持仓立即了结。原始代码中的 RSI 确认（多头低于 45、空头高于 55）在这里被省略，以保持图表易读；对于已经要求K线穿出轨道的信号来说，它几乎不起筛选作用。

![schema](schema.svg)

## 策略概览

- 布林带（20，1.5）在30分钟K线上标出区间被拉伸的边缘，EMA 50 则说明市场处在趋势的哪一侧。
- 图表不是拿单一价格与轨道比较，而是用K线本身构造穿透区域：做多取自最低价向上30%的振幅，做空取自最高价向下30%的振幅。
- 只有空仓时才入场，中轨是两个方向共同的唯一离场条件。

## 入场与出场规则

- **做多入场**: 区域「最低价 + 30% 振幅」低于布林带下轨，K线为阴线（收盘价低于开盘价），收盘价高于 EMA 50，且当前无持仓。以市价买入一手。
- **做空入场**: 区域「最高价 - 30% 振幅」高于布林带上轨，K线为阳线（收盘价高于开盘价），收盘价低于 EMA 50，且当前无持仓。以市价卖出一手。
- **离场**: 多头在第一根收盘价达到或高于中轨的K线上平仓，空头在第一根收盘价达到或低于中轨的K线上平仓；两个离场都使用平仓方块，因此各自只对真正持有的方向生效。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Bollinger Length | 20 | 布林带的平滑周期。 |
| Bollinger Width | 1.5 | 轨道的标准差倍数：1.5 使轨道较窄，K线经常触及。 |
| EMA Length | 50 | 判断趋势方向的 EMA 周期。 |
| Candle Zone, share of range | 0.3 | K线振幅中必须越过轨道的比例，达到该比例才算穿透。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:30:00 | 整张图使用的K线周期。 |

## 图表详情

- 四个转换方块从K线中取出开盘价、最高价、最低价和收盘价，另外三个取出布林带的上轨、下轨和中轨。
- 两个公式方块用同一个比例常量构造穿透区域：最低价 +（最高价 - 最低价）× 比例，以及最高价 -（最高价 - 最低价）× 比例。
- 每个逻辑与汇合四个标志：区域越过轨道、K线方向、EMA 的一侧，以及由持仓方块与零比较得到的空仓状态。
- 两个离场比较把收盘价与中轨对比并驱动两个平仓方块，使图表随时准备接收下一个信号。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
