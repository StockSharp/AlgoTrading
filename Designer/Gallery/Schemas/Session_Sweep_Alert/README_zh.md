# 前一日区间扫单提醒策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该图表交易前一个 UTC 日区间的假突破。它在午夜固定该日的最高价和最低价，等待十五分钟蜡烛越过边界后重新收在区间内，随后逆向入场，并为每根被接受的信号蜡烛写入一条日志消息。

![schema](schema.svg)

## 策略概览

- 已完成的十五分钟蜡烛为所有决策提供最高价、最低价和收盘价。
- Highest(96) 与 Lowest(96) 覆盖完整一天。偏移为 1 的 Previous value 块会在捕获区间前排除新的午夜蜡烛。
- 捕获的最高价和最低价从 00:00 UTC 到该日结束始终固定。入场判断从 00:15 UTC 开始。
- 对已保存最高价的失败向上突破形成空头设置；对已保存最低价的失败向下突破形成多头设置。
- 只有空仓时才允许入场，并使用一单位市价单。如果同一根蜡烛同时满足两种扫单条件，则最高价扫单优先。
- 每笔已成交入场都配置固定 1% 止盈和 1% 止损，并依据已完成蜡烛的收盘价触发市价退出。

## 入场与退出规则

- **多头入场**：在 00:15 至 23:59:59 UTC 内，蜡烛最低价必须低于保存的前一日最低价，收盘价必须高于该水平，同时不能出现最高价扫单，且 Position 必须等于零。以市价买入一单位。
- **空头入场**：在同一时段内，蜡烛最高价必须高于保存的前一日最高价，收盘价必须低于该水平，且 Position 必须等于零。以市价卖出一单位。
- **提醒**：每个被接受的多头或空头信号只通过一次逐蜡烛 Flag。String Formatter 将信号蜡烛收盘价写入消息，再由 Notification 发送到策略日志。
- **退出**：Position protection 在入场成交后价格有利移动 1% 或不利移动 1% 时平仓。两种保护性退出都使用市价单。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 蜡烛 | 00:15:00 | 用于构建区间和决策的已完成蜡烛周期。 |
| Highest 长度 | 96 | 完整日区间中的十五分钟最高价数量。 |
| Highest 数据源 | 未设置 | 未选择其他指标输入字段。 |
| Lowest 长度 | 96 | 完整日区间中的十五分钟最低价数量。 |
| Lowest 数据源 | 未设置 | 未选择其他指标输入字段。 |
| 成交量 | 1 | 每笔市价入场单的大小。 |
| 止盈 | 1% | 从入场成交价开始、触发保护的有利变动。 |
| 止损 | 1% | 从入场成交价开始、触发保护的不利变动。 |
| 跟踪止损 | false | 保持止损边界固定。 |
| 使用市价单 | true | 将触发的保护性退出作为市价单发送。 |

## 图表细节

- HighPrice 和 LowPrice 转换器为两个 96 值滚动指标提供输入；ClosePrice 用于回归区间测试、提醒文本和保护检查。
- 每个滚动结果都经过偏移为 1、仅处理完成值的 Previous value 块。在 00:00-00:14:59 UTC 内，捕获 Variable 接收前一个值，保持 Variable 则在每根蜡烛上发布该值。
- 四个比较块检测最高价上穿后收在已保存最高价下方，或最低价下穿后收在已保存最低价上方。Working time 将两种组合限制在 00:15-23:59:59 UTC。
- 持仓值在每根蜡烛上采样并与零比较。空头门将最高价扫单与空仓检查组合；多头门还要求最高价扫单的反向信号，以保留优先顺序。
- 两个被接受的门触发 Modify position 块中的 Buy 和 Sell，并合并用于报告。每根蜡烛重置的 Flag 会阻止同一信号事件内的重复消息，同时不压制当天稍后的信号。
- 入场成交会启动共享的 Position protection 块。其参考价格由已完成收盘价更新，因此不会观察到收盘前已回撤的蜡烛内触碰。
- 首个可用区间需要此前 96 根十五分钟蜡烛。水平只在午夜快照时更新，并保持不变直到下一个 UTC 日。
- 图表显示蜡烛、滚动与保存的日边界、买卖成交，以及包括保护性退出在内的全部策略成交。

## 使用方法

将 `.json` 文件导入 Designer，使用足够形成首个日区间的历史数据在回测器中运行，并在实盘交易前针对交易品种调整周期、区间长度、保护距离和成交量。
