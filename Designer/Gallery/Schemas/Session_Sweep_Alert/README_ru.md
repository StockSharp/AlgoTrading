# Схема стратегии «Вынос диапазона предыдущего дня с оповещением»
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема торгует ложные пробои диапазона предыдущих суток по UTC. В полночь она фиксирует максимум и минимум этих суток, ждёт выхода пятнадцатиминутной свечи за границу с закрытием обратно внутри, входит против выноса и записывает в журнал одно сообщение для каждой принятой сигнальной свечи.

![schema](schema.svg)

## Обзор стратегии

- Завершённые пятнадцатиминутные свечи дают максимум, минимум и закрытие для всех решений.
- Highest(96) и Lowest(96) охватывают полные сутки. Кубики Previous value со сдвигом 1 исключают новую полуночную свечу перед фиксацией диапазона.
- Зафиксированные максимум и минимум остаются неизменными с 00:00 UTC до конца календарного дня. Проверка входов начинается в 00:15 UTC.
- Ложный пробой сохранённого максимума формирует сетап в шорт, а ложный пробой сохранённого минимума — сетап в лонг.
- Вход разрешён только из нулевой позиции и выполняется рыночной заявкой объёмом одна единица. Если на одной свече выполнены оба условия, приоритет имеет вынос максимума.
- Каждый исполненный вход получает фиксированные тейк-профит 1% и стоп-лосс 1%, активируемые по закрытиям завершённых свечей рыночными выходами.

## Правила входа и выхода

- **Вход в лонг**: С 00:15 до 23:59:59 UTC минимум свечи должен быть ниже сохранённого минимума предыдущего дня, закрытие — выше этого уровня, одновременного выноса максимума быть не должно, а Position должна равняться нулю. Покупается одна единица по рынку.
- **Вход в шорт**: В том же окне максимум свечи должен быть выше сохранённого максимума предыдущего дня, закрытие — ниже этого уровня, а Position должна равняться нулю. Продаётся одна единица по рынку.
- **Оповещение**: Каждый принятый сигнал лонга или шорта один раз проходит через посвечной Flag. String Formatter включает закрытие сигнальной свечи в сообщение, которое Notification отправляет в журнал стратегии.
- **Выход**: Position protection закрывает исполненный вход после благоприятного движения 1% или неблагоприятного движения 1%. Оба защитных выхода являются рыночными заявками.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Свечи | 00:15:00 | Таймфрейм завершённых свечей для построения диапазона и принятия решений. |
| Период Highest | 96 | Число пятнадцатиминутных максимумов в полном суточном диапазоне. |
| Поле Highest | Не задано | Альтернативное поле входных данных индикатора не выбрано. |
| Период Lowest | 96 | Число пятнадцатиминутных минимумов в полном суточном диапазоне. |
| Поле Lowest | Не задано | Альтернативное поле входных данных индикатора не выбрано. |
| Объём | 1 | Размер каждой рыночной заявки на вход. |
| Тейк-профит | 1% | Благоприятное движение от цены исполнения, включающее защиту. |
| Стоп-лосс | 1% | Неблагоприятное движение от цены исполнения, включающее защиту. |
| Скользящий стоп | false | Оставляет границу стопа фиксированной. |
| Рыночные заявки | true | Отправляет сработавшие защитные выходы рыночными заявками. |

## Детали диаграммы

- Конвертеры HighPrice и LowPrice питают два скользящих индикатора на 96 значений; ClosePrice используется для проверок возврата внутрь, текста оповещения и защиты.
- Каждый скользящий результат проходит через завершённый Previous value со сдвигом 1. В окне 00:00-00:14:59 UTC захватывающие Variable принимают предыдущее значение, а удерживающие Variable публикуют его на каждой свече.
- Четыре сравнения находят прокол максимума с закрытием ниже сохранённого максимума либо прокол минимума с закрытием выше сохранённого минимума. Working time ограничивает обе комбинации окном 00:15-23:59:59 UTC.
- Значение позиции выбирается на каждой свече и сравнивается с нулём. Гейт шорта объединяет вынос максимума с проверкой плоской позиции; гейт лонга дополнительно требует инвертированный сигнал выноса максимума для сохранения приоритета.
- Два принятых гейта запускают Buy и Sell в кубиках Modify position и объединяются для журналирования. Сбрасываемый каждой свечой Flag исключает дубли внутри одного сигнального события, не подавляя более поздние сигналы в тот же день.
- Сделки входа взводят общий кубик Position protection. Его контрольная цена обновляется завершённым закрытием, поэтому внутрисвечные касания с возвратом до закрытия не учитываются.
- Для первого пригодного диапазона нужны 96 предшествующих пятнадцатиминутных свечей. Уровни обновляются только на полуночном снимке и не меняются до следующих суток UTC.
- График показывает свечи, скользящие и сохранённые суточные границы, исполнения покупок и продаж, а также все сделки стратегии, включая защитные выходы.

## Использование

Импортируйте файл `.json` в Designer, прогоните его в тестере с историей, достаточной для формирования первого суточного диапазона, и настройте таймфрейм, периоды диапазона, расстояния защиты и объём под инструмент перед реальной торговлей.
