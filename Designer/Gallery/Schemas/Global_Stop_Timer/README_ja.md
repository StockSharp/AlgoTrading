# Global Stop Timer 戦略ダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

エントリーは価格で決まり、エグジットは金額で決まります。モメンタムが中立レベルをクロスすると、移動平均がすでに示している方向へポジションを建て、その瞬間から取引を支配するのは戦略の含み損益です。「戦略損益」（Strategy P&L）ブロックが未実現損益の変化をすべて監視し、それが Money Stop まで下がるか Money Target に達した時点で、指標が何を示していようとポジションをフラットにします。

![schema](schema.svg)

## 戦略の概要

- 5 分足の確定したローソク足のみを扱う 1 本のローソク足系列が、すべてに値を供給します。2 つの指標、終値の変換ブロック、そして定数変数のトリガーです。
- モメンタムは、自身の期間の間に価格がどれだけ動いたかを測ります。「クロス」（Crossing）ブロックはそれを変数に保持されたレベルと比較し、両者の上下関係が入れ替わった瞬間にのみ出力します。上抜けなら true、下抜けなら false です。
- 論理 NOT が同じクロスを下抜けのイベントに変えるため、1 つの「クロス」ブロックが両方向をまかない、2 つが同じ足で同時に発生することはありません。
- 変換ブロックがローソク足から終値を取り出し、2 つの比較がそれを移動平均の上か下かに振り分けます。これが、両方のエントリーが通過しなければならないトレンドフィルターです。
- 「ポジション」（Position）ブロックはゼロと 3 回比較されます。フラットはエントリーを守り、ロングとショートは 2 つのシグナル決済を有効にします。
- 各エントリーのゲートは、クロス、移動平均のどちら側か、ポジションがフラットかという 3 つの判定の論理 AND です。エントリー自体はフラットからのみ出される成行注文なので、取引中に届いたシグナルは何も変えません。
- 「戦略損益」ブロックには入力もローソク足の拍動もありません。未実現損益を変化のたびに出力し、2 つの比較がその数値を、変数に保持された Money Stop と Money Target に突き合わせます。
- 金額による判定と、逆方向クロスによる 2 つの判定は 1 つの「結合」（Combination）ブロックに集まり、決済に設定された単一の「ポジション変更」（Position modify）を動かします。どの理由が先に来ても、ポジションは同じ成行注文でフラットにされます。

## エントリーとエグジットの条件

- **ロングエントリー**: モメンタムがレベルを上抜け、ローソク足の終値が移動平均を上回り、ポジションがフラットであること。「ポジション変更」が Order Volume 分を成行で買います。
- **ショートエントリー**: モメンタムがレベルを下抜け（同じ「クロス」ブロックの出力を論理 NOT 経由で読んだもの）、ローソク足の終値が移動平均を下回り、ポジションがフラットであること。「ポジション変更」が Order Volume 分を成行で売ります。
- **エグジット**: 取引を終わらせる理由は 3 つあり、いずれも同じブロックに行き着きます。戦略の未実現損益が Money Stop まで下がる、Money Target に達する、あるいはポジションが逆方向に建っている間にモメンタムがレベルを逆にクロスする、のいずれかです。最初の 2 つはローソク足の拍動ではなく損益が変化するたびに確認されるため、急な動きには足の途中で対応できます。3 つ目は確定したローソク足ごとに 1 回確認されます。決済注文の数量は現在のポジションから決まるため、常に戦略をフラットにし、一度にドテンすることはありません。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candles | 00:05:00 | ダイアグラム全体が動作するローソク足系列の時間足。確定したローソク足のみを使用します。 |
| Momentum Length | 10 | モメンタム指標の期間。価格の変動をどれだけ過去まで遡って測るかを決めます。 |
| EMA Length | 20 | エントリーが許されるトレンドの側を決める移動平均の期間。 |
| Momentum Level | 0 | モメンタムを比較するレベル。0 が中立値で、これより上なら価格は期間分だけ前より高く、下なら低いことを意味します。 |
| Order Volume | 1 | 両方のエントリーで使う注文数量（ロット単位）。決済注文はこれを無視し、数量はポジションから決まります。 |
| Money Stop | -250 | ポジションを決済する、建玉の損失額（口座通貨）。負の値です。 |
| Money Target | 500 | ポジションを決済する、建玉の利益額（口座通貨）。 |

## ダイアグラムの詳細

- 両方の指標は、形成済みかつ確定した値のみを出力するよう設定されています。そのため、未確定のローソク足からクロスが生じることはありません。
- モメンタムを比較する基準となるレベルは、比較ブロックの内部ではなく変数に置かれています。これにより、ダイアグラムを開かずに変更・最適化できるスキーマのパラメータになります。
- 定数変数はすべてトリガーされます。ローソク足に駆動される 3 つはローソク足系列によって、2 つの金額しきい値は未実現損益によってです。変数は値を保持しますが、何かが要求したときにのみ出力するためです。
- エントリーには建玉の状態に関する条件が組み込まれているため、フラットからのみ発動します。これがないと、ポジションが変化するたびに成行注文が送られ、実行結果は不要な約定で埋まってしまいます。
- Money Stop と Money Target は口座通貨での金額であり、価格の値幅ではありません。そのため、ダイアグラムを別の銘柄に移すときは、注文数量と合わせて規模を調整する必要があります。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
