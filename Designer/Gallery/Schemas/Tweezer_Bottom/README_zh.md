# 平底镊子策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

镊子形态由相邻两根方向相反、却停在同一价位的K线组成：一根阴线之后，阳线几乎停在同一最低价，这一对便标出了底部；最高价上的镜像形态则标出顶部。两个最低价几乎不可能分毫不差，因此本图把它们之间的距离换算成百分比，只要距离不超过容差就视为相等。

![schema](schema.svg)

## 策略概览

- K线形态方块只识别这一对K线的颜色变化：底部是先阴线后阳线，顶部是先阳线后阴线。
- 极值是否相等由公式单独衡量，因此容差仍是可优化的图表参数，而不会被写死在形态表达式里。
- 简单移动平均线完全不参与入场，只负责判断交易何时结束。
- 每次入场都有持仓判断把关，因此镊子始终是一次反转尝试，绝不会给已有仓位加码。

## 入场与出场规则

- **做多入场**: 形态方块报告先阴线后阳线，两个最低价之间的距离不超过前一根最低价的容差百分比，且持仓为零。订单按市价买入共享数量。
- **做空入场**: 形态方块报告先阳线后阴线，两个最高价之间的距离不超过前一根最高价的容差百分比，且持仓为零。订单按市价卖出共享数量。
- **离场**: 第一根收在简单移动平均线之下的K线平掉多头，第一根收在其上的K线平掉空头；两个离场都是平仓模式的修改持仓方块，绝不会开仓。原策略没有止损也没有止盈，本图同样没有。原策略中有两点无法用现有方块表达：每次交易后停歇五百根K线，因为没有方块能跨K线保存计数器；以及一分钟周期，这里改用随附历史数据的五分钟K线。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Tolerance, % | 0.1 | 两个极值允许相差多远，按前一根K线价位的百分比计。 |
| SMA Length | 20 | 用于平仓的简单移动平均线的平滑周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动两个形态方块、移动平均线，以及读取最低价、最高价和收盘价的三个转换方块。
- 两个历史值方块保存前一根K线的最低价与最高价，两个公式把每一对换算成极值之间的百分比距离。
- 两个比较方块把这些距离与共享的容差常量对比，另一个比较方块把持仓与零对比。
- 每个逻辑与把形态、极值相符和空仓判断合并，然后触发从共享常量取数量的入场方块。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
