# 早晨之星反转策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

早晨之星是经典的三根K线底部形态：一根较长的阴线、一根犹豫的小实体K线，再加一根收回第一根一半以上的长阳线。它的镜像形态黄昏之星则标示顶部。本图用蜡烛形态方块识别这两种形状，只在空仓时开仓，一旦收盘价落到简单移动平均线的另一侧就交还仓位。

![schema](schema.svg)

## 策略概览

- 两个蜡烛形态指标方块装载自定义的三根K线表达式：第一根K线有实体且方向与入场相反，中间实体小于它的一半，第三根K线收在第一根中点之外。
- 收盘价的简单移动平均线是唯一的离场参照；图中没有止损，也没有止盈。
- 持仓方块与零比较，因此只有空仓时才会依据形态下单，绝不加仓。

## 入场与出场规则

- **做多入场**: 早晨之星方块在刚刚收完的K线上报告形态，且持仓为零。订单买入一手，开多。
- **做空入场**: 黄昏之星方块在刚刚收完的K线上报告形态，且持仓为零。订单卖出一手，开空。
- **离场**: 只要有K线收在移动平均线之下，处于平仓模式的修改持仓方块就平掉多头；有K线收在均线之上时同样平掉空头。没有保护性止损。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SMA Length | 20 | 用于平仓的简单移动平均线周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图与随附图库历史数据使用的五分钟K线周期。 |

## 图表详情

- K线方块分出四条支路：两个形态指标、移动平均线，以及读取收盘价的转换方块。
- 每个形态方块内含三条件表达式形态，因此无需用一串公式方块来识别图形。
- 两个比较方块把收盘价放到均线的某一侧，并直接触发两个平仓方块。
- 每个逻辑与把一个形态与持仓判断合并并触发入场；两张入场订单的数量取自共享常量，平仓方块则按已有持仓自行计算。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
