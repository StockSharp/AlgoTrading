# Схема стратегии с отложенными заявками по DeMarker
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема превращает пересечения уровней DeMarker в лимитные заявки на откат вместо немедленного входа. Каждая отложенная заявка живёт четыре свечи, а процентные тейк-профит и стоп-лосс подключаются только после её фактического исполнения.

![schema](schema.svg)

## Обзор стратегии

- Завершённые пятнадцатиминутные свечи подаются в осциллятор DeMarker с периодом 14 и в поток цены закрытия.
- Нижний и верхний уровни равны 0,3 и 0,7; кубики пересечения обнаруживают падение через нижний уровень и подъём через верхний.
- Входы разрешены только с 07:00:00 до 20:59:59 по времени свечи и только при нулевой позиции.
- Новая установка заменяет прежнюю отложенную заявку, а неисполненная заявка также снимается после четырёх следующих завершённых свечей.
- График показывает свечи, осциллятор, оба уровня и все исполнения стратегии.

## Правила входа и выхода

- **Вход в лонг**: Когда DeMarker падает через 0,3 внутри окна входа и позиция равна нулю, выставляется лимитная заявка на покупку на заданный процент ниже текущего закрытия.
- **Вход в шорт**: Когда DeMarker поднимается через 0,7 внутри окна входа и позиция равна нулю, выставляется лимитная заявка на продажу на заданный процент выше текущего закрытия.
- **Выход**: Неисполненный лимит снимается при замене новой установкой или после завершения его четырёхсвечного таймера. После исполнения защита позиции закрывает её либо по тейк-профиту 1,2%, либо по стоп-лоссу 0,6%.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| DeMarker Length | 14 | Период усреднения осциллятора DeMarker. |
| Lower level | 0.3 | Пересечение этого значения вниз создаёт установку в лонг. |
| Upper level | 0.7 | Пересечение этого значения вверх создаёт установку в шорт. |
| Pending indent, % | 0.1 | Расстояние от закрытия сигнальной свечи до цены отложенной заявки. |
| Pending life, bars | 4 | Число следующих завершённых свечей до снятия неисполненной заявки. |
| Entry window start | 07:00:00 | Первое время свечи, разрешённое фильтром входа. |
| Entry window end | 20:59:59 | Последнее время свечи, разрешённое фильтром входа. |
| Volume | 1 | Объём каждой отложенной заявки на вход. |
| Take profit, % | 1.2 | Благоприятное процентное движение от цены исполненного входа. |
| Stop loss, % | 0.6 | Неблагоприятное процентное движение от цены исполненного входа. |
| Candles | 00:15:00 | Таймфрейм завершённых сигнальных свечей. |

## Детали диаграммы

- Для нижнего пересечения константа 0,3 подключена к Input Up кубика Crossing, а DeMarker — к Input Down; для верхнего пересечения DeMarker подключён к Input Up, а 0,7 — к Input Down.
- Два логических AND объединяют нужное пересечение, результат рабочего времени и проверку нулевой позиции; флаги на каждую свечу превращают принятую установку в одиночный импульс.
- Формулы считают `close × (1 − indent / 100)` для Buy и `close × (1 + indent / 100)` для Sell, после чего два кубика регистрации выставляют лимиты по этим ценам.
- Каждая установка запускает свой счётчик N values. Через четыре следующие свечи его выход приходит в соответствующий кубик отмены, а перед каждой новой заявкой оба кубика отмены получают команду снять прежние лимиты.
- За каждым зарегистрированным лимитом следит отдельный кубик Trades for order. Только событие исполнения из него поступает в Position protection, поэтому ожидающая или снятая заявка не может включить стоп или тейк-профит.
- В актуальных версиях Designer кубики регистрации также имеют выход MyTrade; отдельные Trades for order оставлены, чтобы явно показать цепочку от заявки к исполнению.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
