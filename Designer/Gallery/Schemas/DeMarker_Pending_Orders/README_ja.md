# DeMarker 指値注文ストラテジー図
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

このダイアグラムは、DeMarker のしきい値交差ですぐにエントリーせず、押し戻りを待つ指値注文へ変換します。各注文の有効期間は4本のローソク足で、実際に約定した後にだけパーセント指定の利確と損切りが有効になります。

![schema](schema.svg)

## 戦略の概要

- 確定した15分足を、期間14の DeMarker オシレーターと終値ストリームへ入力します。
- 下側と上側のしきい値は0.3と0.7で、Crossing ブロックが下側を下抜ける動きと上側を上抜ける動きを検出します。
- エントリーはローソク足時刻が07:00:00から20:59:59までで、ポジションがゼロの場合にだけ許可されます。
- 新しいセットアップは以前の未約定注文を置き換え、未約定のままなら後続の確定足4本でも期限切れになります。
- チャートにはローソク足、オシレーター、2本のしきい値、およびストラテジーの全約定が表示されます。

## エントリーとエグジットの条件

- **ロングエントリー**: エントリー時間内に DeMarker が0.3を下抜け、ポジションがゼロなら、現在の終値より指定パーセント下に買い指値を登録します。
- **ショートエントリー**: エントリー時間内に DeMarker が0.7を上抜け、ポジションがゼロなら、現在の終値より指定パーセント上に売り指値を登録します。
- **エグジット**: 未約定の指値は、新しいセットアップに置き換えられたとき、または4本のカウンターが完了したときに取り消されます。約定後は、1.2%の利確または0.6%の損切りでポジション保護が決済します。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| DeMarker Length | 14 | DeMarker オシレーターの平均期間です。 |
| Lower level | 0.3 | この値を下抜けるとロングのセットアップになります。 |
| Upper level | 0.7 | この値を上抜けるとショートのセットアップになります。 |
| Pending indent, % | 0.1 | シグナル足の終値から指値価格までの距離です。 |
| Pending life, bars | 4 | 未約定注文を取り消すまでに許容する後続の確定足数です。 |
| Entry window start | 07:00:00 | エントリーフィルターが許可する最初のローソク足時刻です。 |
| Entry window end | 20:59:59 | エントリーフィルターが許可する最後のローソク足時刻です。 |
| Volume | 1 | 各エントリー指値注文の数量です。 |
| Take profit, % | 1.2 | 約定したエントリー価格から有利な方向への変化率です。 |
| Stop loss, % | 0.6 | 約定したエントリー価格から不利な方向への変化率です。 |
| Candles | 00:15:00 | 確定シグナル足の時間枠です。 |

## ダイアグラムの詳細

- 下側交差では定数0.3を Crossing の Input Up、DeMarker を Input Down に接続します。上側交差では DeMarker を Input Up、0.7を Input Down に接続します。
- 2つの論理 AND が対応する交差、稼働時間の結果、ポジションゼロの確認を結合し、足ごとの Flag が有効なセットアップを1回のトリガーにします。
- Formula ブロックは Buy 用に `close × (1 − indent / 100)`、Sell 用に `close × (1 + indent / 100)` を計算し、2つの注文登録ブロックがその価格で指値を送信します。
- 各セットアップは専用の N values カウンターを開始します。後続4本の足で出力が対応する取消ブロックを起動し、新規注文の前にも両方の取消ブロックが以前の未約定注文を削除します。
- 登録された各指値は Trades for order ブロックが監視します。その約定出力だけが Position protection に届くため、待機中または取消済みの注文が損切りや利確を有効にすることはありません。
- 現在の Designer では注文登録ブロックにも MyTrade 出力がありますが、注文から約定イベントまでの流れを明確に示すため、独立した Trades for order ブロックを残しています。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
