# Схема процентной сеточной лестницы
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Схема строит симметричную процентную сетку вокруг цены закрытия первой завершённой пятиминутной свечи. Три отложенных лимита на покупку находятся ниже якоря, три лимита на продажу — выше; после первого исполнения остальные заявки снимаются, а позиция передаётся процентной защите.

![schema](schema.svg)

## Обзор стратегии

- Закрытие первой завершённой пятиминутной свечи фиксируется как якорь; котировки Level1 и середина bid/ask не используются.
- Шаг 1,5% формирует до трёх уровней покупки ниже якоря и трёх уровней продажи выше него.
- Параметр числа уровней включает ступени с первой по третью, а переключатели лонга и шорта независимо разрешают стороны сетки.
- Первое исполнение входа снимает все оставшиеся заявки сетки и запускает тейк-профит 2% и стоп-лосс 3%.
- Защитный выход снимает остаточные заявки, сохраняет последний close как новый якорь и регистрирует свежую лестницу.

## Правила входа и выхода

- **Вход в лонг**: Если лонг разрешён, лимитные покупки объёмом одна единица ставятся по цене anchor × (1 − spacing × номер ступени). Число активных нижних ступеней задаётся параметром Grid Levels per Side.
- **Вход в шорт**: Если шорт разрешён, лимитные продажи объёмом одна единица ставятся по цене anchor × (1 + spacing × номер ступени). Число активных верхних ступеней задаётся параметром Grid Levels per Side.
- **Выход**: Первая исполненная заявка начинает единственный активный цикл позиции. Защита закрывает её при +2% или −3%, после чего следующая сетка из шести заявок получает якорь по последнему завершённому close.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Grid Spacing, % | 1.5 | Расстояние между соседними ступенями в процентах; 1,5 означает 1,5%. |
| Grid Levels per Side | 3 | Число включённых ступеней с каждой стороны: от одной до максимальных трёх. |
| Enable Long | true | Разрешает регистрацию лимитных покупок ниже якоря. |
| Enable Short | true | Разрешает регистрацию лимитных продаж выше якоря. |
| Take Profit, % | 2 | Расстояние прибыли от цены исполнения для блока защиты позиции. |
| Stop Loss, % | 3 | Расстояние убытка от цены исполнения для блока защиты позиции. |

## Детали диаграммы

- C#-стратегия хранит виртуальные уровни и посылает рыночные заявки, когда close свечи достигает уровня. Схема намеренно использует реальные отложенные лимиты, чтобы показать кубики заявок и цикл их отмены.
- Исходник может последовательно активировать несколько уровней. Здесь применено осознанное упрощение до одного цикла позиции: одно исполнение снимает остальные ступени, торгует фиксированным объёмом один и ждёт защитного выхода перед перестроением.
- Grid Levels per Side поддерживает значения от одного до трёх. В схеме физически нарисованы три ступени, поэтому значение выше трёх не добавит новых блоков.
- Переякоривание выполняется отменой и новой регистрацией заявок, без блока замены. Округление цены отключено для replay-инструментов без заданного шага цены.
- Начальным и последующими якорями служит точный close свечи, как цена сброса в исходнике; зависимость от Level1 не требуется.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
