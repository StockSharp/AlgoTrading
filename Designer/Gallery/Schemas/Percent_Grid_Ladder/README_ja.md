# パーセント・グリッド階段戦略図
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この図は最初に確定した5分足終値を中心に対称なパーセント・グリッドを構築します。アンカーの下に買い指値を3本、上に売り指値を3本置き、最初の約定後は残りを取り消してポジションをパーセント保護へ渡します。

![schema](schema.svg)

## 戦略の概要

- 最初の確定5分足終値をアンカーとして保持し、Level1気配値やbid/ask中間値は使いません。
- 1.5%の間隔でアンカー下に最大3段の買い、上に最大3段の売りを作ります。
- Grid Levels per Sideは1段目から3段目を有効化し、longとshortのスイッチは両側を個別に制御します。
- 最初のエントリー約定で稼働中の全グリッド注文を取り消し、2%利確と3%損切り保護を開始します。
- 保護決済後は残存注文を取り消し、最新終値を新しいアンカーとして階段を再登録します。

## エントリーとエグジットの条件

- **ロングエントリー**: long有効時はanchor × (1 − spacing × 段番号)に数量1の買い指値を置き、設定に応じて下側1～3段を有効にします。
- **ショートエントリー**: short有効時はanchor × (1 + spacing × 段番号)に数量1の売り指値を置き、設定に応じて上側1～3段を有効にします。
- **エグジット**: 最初の約定が唯一のポジション周期を始めます。保護は+2%または−3%で決済し、最新の確定終値を基準に次の6注文を再構築します。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Grid Spacing, % | 1.5 | 隣接する段のパーセント距離。1.5は1.5%を意味します。 |
| Grid Levels per Side | 3 | 片側で有効にする段数。1から図の上限3までです。 |
| Enable Long | true | アンカー下の買い指値登録を有効にします。 |
| Enable Short | true | アンカー上の売り指値登録を有効にします。 |
| Take Profit, % | 2 | ポジション保護が使う約定価格からの利確距離です。 |
| Stop Loss, % | 3 | ポジション保護が使う約定価格からの損切り距離です。 |

## ダイアグラムの詳細

- C#戦略は仮想レベルを保持し、足の終値が到達すると成行注文を出します。この図は注文ブロックと取消周期を示すため、実際の保留指値として具体化しています。
- 元コードは複数レベルを順次発動できます。本図は意図的に1ポジション周期へ簡略化し、1約定で他の段を取り消し、固定数量1を取引して保護決済まで再構築を待ちます。
- Grid Levels per Sideは1～3をサポートします。図には最大3段しかないため、3を超える値で追加ブロックは作られません。
- 再アンカーは取消後の新規登録で行い、注文置換ブロックは使いません。価格刻み未設定のリプレイ銘柄向けに価格丸めを無効化しています。
- 初回と以後のアンカーは正確な足終値で、元コードのリセット価格と一致し、不要なLevel1依存もありません。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
