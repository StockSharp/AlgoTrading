# Диаграмма стратегии пробоя по кумулятивной дельте
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Схема строит дельту направленного объёма по завершённым минутным свечам. Скользящий Sum(100) задаёт меру пробоя, SMA(20) фильтрует входы, а противоположный порог дельты закрывает открытую позицию.

![schema](schema.svg)

## Обзор стратегии

- Каждая завершённая свеча разделяется на значения Open, Close и TotalVolume.
- Бычьи свечи и доджи дают положительный объём, а медвежьи свечи — отрицательный.
- Sum(100) суммирует последние сто значений направленного объёма, а SMA(20) следует за ценами закрытия; оба индикатора выдают только сформированные значения.
- Проверки позиции разрешают вход только при нулевой позиции и направляют противоположное событие дельты в соответствующий уменьшающий выход.
- Все четыре действия выполняются по рынку объёмом 1, а блок Strategy trades передаёт каждое исполнение на график.

## Правила входа и выхода

- **Вход в лонг**: Когда скользящая дельта не ниже +2, Close выше SMA(20), а позиция равна нулю, купить одну единицу по рынку.
- **Вход в шорт**: Когда скользящая дельта не выше -2, Close ниже SMA(20), а позиция равна нулю, продать одну единицу по рынку.
- **Выход**: Уменьшить лонг на одну единицу при дельте -2 или ниже, а шорт — при дельте +2 или выше. В выходных затворах SMA не используется. В схеме нет стоп-лосса и тейк-профита.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Candles Series | 00:01:00 | Завершённые минутные свечи для всех расчётов и решений. |
| Delta Sum Length | 100 | Число значений направленного объёма в окне скользящего индикатора Sum. |
| Delta Sum Source | Not set | Дополнительное поле входа индикатора не выбрано; формула направленного объёма подключена напрямую. |
| SMA Length | 20 | Число цен закрытия в скользящей средней, фильтрующей входы. |
| SMA Source | Not set | Дополнительное поле входа индикатора не выбрано; Candle close подключён напрямую. |
| Delta Threshold | 2 | Абсолютный уровень дельты: +2 для бычьих событий и -2 для медвежьих. |
| Order Volume | 1 | Фиксированный рыночный объём входов и уменьшающих выходов. |

## Детали диаграммы

- Формула направленного объёма положительна при Close не ниже Open, поэтому доджи добавляет +TotalVolume; знак меняется только при Close ниже Open.
- Дельта представляет собой скользящую сумму ста свечей: после заполнения окна каждое новое значение заменяет самое старое.
- Положительный и отрицательный пороги получаются из одного настраиваемого значения; отдельная формула меняет знак для медвежьей ветви.
- Финальный импульс вычисления поступает в четыре AND-затвора после обновления полей свечи, индикаторов, сравнений и снимка позиции.
- Ожидания заданного числа баров нет. Затворы нулевой, длинной и короткой позиции запрещают наращивание и выбирают допустимое действие для каждой свечи.
- График получает шесть потоков: свечи, скользящую дельту, положительный порог, отрицательный порог, SMA(20) и все исполнения входов и выходов.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
