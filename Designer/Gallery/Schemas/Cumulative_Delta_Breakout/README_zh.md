# 累积成交量差突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该图表使用已完成的一分钟 K 线构建方向成交量差。滚动 Sum(100) 提供突破度量，SMA(20) 过滤入场，反向的成交量差阈值用于平仓。

![schema](schema.svg)

## 策略概览

- 每根已完成 K 线被拆分为 Open、Close 和 TotalVolume 数值。
- 上涨 K 线和平盘 K 线计入正成交量，下跌 K 线计入负成交量。
- Sum(100) 汇总最近一百个方向成交量值，SMA(20) 跟踪收盘价；两个指标都只输出已形成的值。
- 仓位判断只允许空仓入场，并把反向成交量差事件送到相应的减仓离场动作。
- 四个动作均为数量 1 的市价操作，Strategy trades 将每笔成交发送到图表。

## 入场与出场规则

- **做多入场**: 当滚动成交量差不低于 +2、Close 高于 SMA(20) 且仓位为空时，以市价买入一个单位。
- **做空入场**: 当滚动成交量差不高于 -2、Close 低于 SMA(20) 且仓位为空时，以市价卖出一个单位。
- **离场**: 成交量差达到 -2 或更低时减持一个单位多仓，达到 +2 或更高时减持一个单位空仓。离场门不使用 SMA。图中没有止损或止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Candles Series | 00:01:00 | 用于全部计算和决策的已完成一分钟 K 线。 |
| Delta Sum Length | 100 | 滚动 Sum 指标保留的方向成交量值数量。 |
| Delta Sum Source | Not set | 未选择其他指标输入字段；方向成交量公式直接连接。 |
| SMA Length | 20 | 入场过滤移动平均所包含的收盘价数量。 |
| SMA Source | Not set | 未选择其他指标输入字段；Candle close 直接连接。 |
| Delta Threshold | 2 | 成交量差的绝对阈值：看涨事件为 +2，看跌事件为 -2。 |
| Order Volume | 1 | 入场和减仓离场使用的固定市价数量。 |

## 图表详情

- 当 Close 大于或等于 Open 时，方向成交量公式为正，因此十字星计入 +TotalVolume；只有 Close 低于 Open 时符号才变为负。
- 成交量差是一个滚动的一百根 K 线总和：窗口填满后，每个新值都会替换最早的值。
- 正负阈值来自同一个公开参数，负向分支通过单独公式改变符号。
- 在 K 线字段、指标、比较结果和仓位快照全部刷新后，最终计算脉冲才到达四个 AND 门。
- 图中没有按 K 线计数的等待期。空仓、多仓和空头仓位门阻止加仓，并为每根 K 线选择有效动作。
- 图表接收六个数据流：K 线、滚动成交量差、正阈值、负阈值、SMA(20) 以及全部入场和离场成交。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
