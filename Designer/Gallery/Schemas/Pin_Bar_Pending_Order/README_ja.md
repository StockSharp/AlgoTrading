# ピンバー指値エントリーストラテジーダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

このロング専用ダイアグラムは、上昇する移動平均線の並びの中で長い下ヒゲを探します。シグナル終値で買わず、ヒゲ内に買い指値を置き、所定の確定足数で未約定注文を取り消し、約定後は割合ベースの出口で保護し、高速EMAが中速EMAを下回った場合にも終了します。

![schema](schema.svg)

## 戦略の概要

- 確定済み30分足をopen、high、low、closeのコンバーターと、形成済みEMA 6、EMA 18、SMA 50へ送ります。
- Formulaは(min(open, close) - low) / (high - low)を計算し、下ヒゲは全値幅の0.45を超える必要があります。
- トレンド条件はEMA 6 > EMA 18 > SMA 50です。安値がEMA 6を下抜け、終値が再びその上へ戻る必要もあります。
- エントリーゲートは全パターン条件、フラットなPosition、直近ストラテジー約定から6本のクールダウンを要求します。
- Order registering（注文登録）はlow * (1 + 0.25 / 100)にOrder Volumeの買い指値を、価格丸めなしで出します。
- N values（N値）は登録後の確定足6本を数え、活動中ならOrder cancellation（注文取消）を起動します。Trades for orderが約定を保護へ渡します。
- Position protection（ポジション保護）は1.4%利確と0.7%損切りを置き、EMA 6がEMA 18未満なら成行ClosePositionも起動します。

## エントリーとエグジットの条件

- **ロングエントリー**: 下ヒゲ比率が0.45を超え、EMA 6 > EMA 18 > SMA 50、安値がEMA 6未満、終値がEMA 6超、Positionがフラットで、直近約定から6本以上経過した確定足で、安値より0.25%上に買い指値を登録します。その後の価格が注文を約定させた場合だけエントリーします。
- **ショートエントリー**: ショートエントリーはありません。平均線の並びが弱まることは終了条件であり、ショート開始シグナルではありません。
- **エグジット**: 未約定指値は確定足6本後に取り消します。約定したロングはPosition protectionにより+1.4%または-0.7%で、またはEMA 6がEMA 18を下回ったときの成行ClosePositionで終了します。成行終了約定は保護へ戻り、その状態を消去します。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candles | 00:30:00 | パターン、指標、注文寿命、クールダウン、終了に使う確定足の時間枠。 |
| Fast EMA Length | 6 | ヒゲが下抜け、終値が回復する高速ExponentialMovingAverageの長さ。 |
| Medium EMA Length | 18 | 上昇する並びの中間ExponentialMovingAverageの長さ。 |
| Slow SMA Length | 50 | 並びの基礎となる低速SimpleMovingAverageの長さ。 |
| Wick Share | 0.45 | 全値幅に占める下ヒゲの最小比率。 |
| Entry Offset, % | 0.25 | 買い指値をシグナル安値より上へ置く割合。 |
| Order Volume | 1 | 各買い指値の数量。 |
| Order Life, candles | 6 | 未約定指値を取り消すまでの確定足数。 |
| Take Profit, % | 1.4 | エントリー約定から有利方向への距離（%）。 |
| Stop Loss, % | 0.7 | エントリー約定から不利方向への距離（%）。 |
| Cooldown, candles | 6 | 直近ストラテジー約定から次のエントリーまでに必要な最小確定足数。 |

## ダイアグラムの詳細

- 価格項目、指標、状態判定、カウンターは同じ確定済み30分足を使うため、注文時刻は取引クロック上に保たれます。
- ANDゲートはヒゲ、2つの平均線比較、高速EMAの下抜けと回復、フラットなPosition、クールダウン完了をまとめます。
- Order registrationは同じ注文をN values、Order cancellation、Trades for order、チャートへ渡します。寿命カウンターは登録イベントで始まり確定足で進みます。
- Strategy tradesは各自己約定でクールダウンを0へ戻し、足ごとに上限まで増加させます。大きな初期値により最初のセットアップはすぐ利用できます。
- フラット条件は約定後の新規エントリーを防ぎます。以前の指値が未約定の間は、別の適格足が独立した指値試行となり、各注文に同じ6本後取消ルールが適用されます。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
