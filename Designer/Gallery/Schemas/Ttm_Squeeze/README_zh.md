# TTM Squeeze 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

行情不会一直安静。本图把布林带宽度表示为中轨的百分比，只要宽度低于自身的移动平均，就视为处于挤压状态，并在带宽重新扩张的第一根K线上入场。方向由 RSI 决定。

![schema](schema.svg)

## 策略概览

- 带宽 =（上轨 - 下轨）/ 中轨 × 100，因此挤压的判断与品种价格水平无关。
- 带宽的简单移动平均乘以挤压系数，就是判定「被压缩」的分界线。
- 交易发生在扩张而非压缩之时：上一根K线必须处于挤压之中，而当前带宽必须大于它。
- RSI 与中轴线的关系给出方向，相反一侧的布林带则是放弃这笔交易的位置。

## 入场与出场规则

- **做多入场**: 带宽大于上一根K线的带宽，上一根的带宽不高于挤压水平，RSI 高于 50，且当前空仓。买单开一手多单。
- **做空入场**: 带宽大于上一根K线的带宽，上一根的带宽不高于挤压水平，RSI 低于 50，且当前空仓。卖单开一手空单。
- **离场**: 收盘价跌破布林带下轨时平多，升破上轨时平空：说明突破失败并走向反面。两个离场方块均为平仓模式；原策略同样没有止损与止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Bollinger Period | 20 | 布林带的平滑周期。 |
| Bollinger Width | 2 | 布林带宽度，以标准差为单位。 |
| RSI Length | 14 | 用于确认方向的 RSI 周期。 |
| Width Average Length | 20 | 对带宽本身取移动平均的长度。 |
| Squeeze Factor | 0.9 | 低于该平均值的比例即视为挤压；调小可让信号更少更严格。 |
| RSI Midline | 50 | 区分多空的 RSI 分界水平。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:30:00 | 整张图使用的K线周期。 |

## 图表详情

- 布林带方块由三个转换方块读取：上轨、下轨与中轨；第四个转换方块取K线收盘价。
- 一个公式方块把三条轨道换算成百分比带宽，再分别送入移动平均方块与前值方块，从而与自身的历史相比较。
- 第二个公式把平均带宽乘以挤压系数，两个比较方块给出挤压与扩张两个标志位。
- 每个入场都是四项条件的逻辑与：扩张、挤压、RSI 方向和空仓；两个入场方块的数量取自同一个常量。
- 原策略还维护带宽的滚动最小值、统计三根窄幅K线、用 EMA(20) 过滤方向，并在每次交易后暂停十五根K线；本图用带宽的移动平均代替滚动最小值，并舍弃计数器、EMA 与无法用方块表达的暂停。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
