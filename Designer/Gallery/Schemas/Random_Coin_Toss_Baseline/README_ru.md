# Диаграмма стратегии Random Coin Toss Baseline
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема намеренно торгует без рыночного сигнала. Когда при нулевой позиции приходит завершённая четырёхчасовая свеча, случайное значение выбирает между входом в лонг и шорт. Позиция удерживается ещё десять завершённых свечей, закрывается по рынку, и на следующей свече цикл может начаться заново. Это учебная базовая линия для сравнения систем, основанных на правилах, а не стратегия для реальной торговли.

![schema](schema.svg)

## Обзор стратегии

- Один поток только завершённых четырёхчасовых свечей задаёт такт как случайным решениям, так и счётчику периода удержания.
- Кубик Random выдаёт значение между нулём и единицей. Порог 0.5 делит диапазон на два взаимоисключающих направления.
- Текущая позиция фиксируется при поступлении каждой завершённой свечи и сравнивается с нулём. Оба кубика входа также используют условие Open position, поэтому сделка может начаться, только если при поступлении свечи схема находилась без позиции.
- Сделка входа активирует кубик N values, который отсчитывает десять последующих завершённых свечей, прежде чем разрешить закрытие позиции.
- Схема не использует индикаторы, стоп-лосс или тейк-профит. Последовательность случайных значений не получает начальное значение внутри схемы и может различаться между запусками.

## Правила входа и выхода

- **Вход в лонг**: Случайное значение ниже порога монетки, а позиция равна нулю. Схема покупает заданный объём по рынку.
- **Вход в шорт**: Случайное значение находится на пороге монетки или выше него, а позиция равна нулю. Схема продаёт заданный объём по рынку.
- **Выход**: После исполнения входа схема отсчитывает десять последующих завершённых четырёхчасовых свечей. Затем кубик N values запускает рыночное закрытие всей позиции. На свече выхода новая сделка не открывается; первая следующая завершённая свеча даёт новую возможность для входа.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Hold Bars | 10 | Число завершённых свечей, отсчитываемых после исполнения входа до закрытия позиции; значение должно быть больше нуля. |
| Volume | 1 | Объём заявок на вход и выход, в лотах. Один и тот же заданный объём используется для открытия и уменьшения позиции. |
| Coin Threshold | 0.5 | Случайные значения ниже этого уровня выбирают вход в лонг; значения на этом уровне или выше выбирают вход в шорт. |
| Candles | 04:00:00 | Четырёхчасовой таймфрейм свечей для решений о входе и отсчёта периода удержания; обрабатываются только завершённые свечи. |

## Детали диаграммы

- Выход кубика [Candles](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/data_sources/candles.html) поступает в кубик [Random](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/common/random.html), запускает фиксацию снимка позиции, поступает во вход Input кубика [N values](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/common/delay_value.html) и в панель графика.
- Кубик [Comparison](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/common/comparison.html) проверяет, находится ли случайное значение на пороге монетки или выше него. Этот сигнал выбирает ветку шорта, а кубик [Logical condition](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/common/logical_condition.html) в режиме NOT формирует ветку лонга.
- Выход кубика [Position](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/positions/current.html) поступает в запускаемый триггером кубик Variable, который фиксирует снимок позиции при поступлении свечи. Снимок сравнивается с общей нулевой константой, а его сигнал отсутствия позиции объединяется с сигналом направления в каждом кубике AND для входа. Этот снимок не позволяет свече закрытия открыть новую позицию сразу после исполнения выхода.
- Оба кубика входа [Modify position](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/positions/modify.html) используют рыночные заявки с условием Open position и получают объём из одной общей константы.
- Выходы MyTrade кубиков входа в лонг и шорт поступают во вход Trigger кубика N values. Пока активен отсчёт десяти свечей, последующие триггеры игнорируются.
- Выход N values запускает два кубика Modify position в режиме Reduce only. Кубик продажи может уменьшать только длинную позицию, а кубик покупки — только короткую; оба получают общий объём, поэтому заявку на выход регистрирует только подходящая ветка.
- [Chart panel](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/common/chart.html) получает поток свечей и сделки, созданные обоими кубиками входа и обоими кубиками выхода.

## Использование

Импортируйте файл `.json` в Designer и запустите его в бэктестере на исторических данных, затем сравните результат со схемами, основанными на правилах, на том же инструменте и периоде. Используйте этот пример как учебную базовую линию, а не как систему для реальной торговли.
