# 整数关口订单阶梯策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该图管理整数关口被动入场订单的完整生命周期。已完成的五分钟蜡烛驱动考夫曼自适应均线、方向交叉、买卖价位计算、订单替换、定时撤单和绝对距离移动止损。

![schema](schema.svg)

## 策略概览

- 已完成的五分钟蜡烛输入 KAMA(15)，快速周期为 2，慢速周期为 30；信号链只接收已形成的指标值。
- Previous value 块将已形成的 KAMA 延后一项，Crossing 将每个收盘价与该前一项自适应均线值比较。
- 最近的舍入中心使用 floor(close / step + 0.5) 计算。买入限价位于中心下方一个 200 价格单位步长，卖出限价位于中心上方一个步长。
- 买入和卖出各有独立的订单总线保存当前活动订单。计算价位变化时，Order replacing 把活动限价移到新价位。
- 每个方向都有独立的十二蜡烛周期标志和计时器。反向交叉或计时器撤销仍活动的限价，成交则启动移动保护。

## 入场与出场规则

- **做多入场**: 当收盘价向上穿过前一个已形成 KAMA、采样仓位为零且买入周期标志可用时，以 (floor(close / step + 0.5) - 1) × step 的价格登记 0.1 单位买入限价。
- **做空入场**: 当收盘价向下穿过前一个已形成 KAMA、采样仓位为零且卖出周期标志可用时，以 (floor(close / step + 0.5) + 1) × step 的价格登记 0.1 单位卖出限价。
- **离场**: 入场成交后启用绝对距离为 10 的移动止损，按已完成蜡烛的收盘价评估，并以市价单退出。止盈关闭。挂单在出现反向交叉或经过十二根已完成蜡烛后撤销。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Candles Series | 00:05:00 | 用于信号、定价、计时、保护更新和图表的已完成蜡烛周期。 |
| KAMA Fast SC Period | 2 | 考夫曼自适应移动平均线的快速平滑周期。 |
| KAMA Slow SC Period | 30 | 考夫曼自适应移动平均线的慢速平滑周期。 |
| KAMA Length | 15 | 考夫曼自适应移动平均线的回看长度。 |
| KAMA Source | Not set | 未选择其他指标输入字段；蜡烛直接连接。 |
| Round Level Step | 200 | 相邻整数关口之间的距离，以价格单位表示。 |
| Order Volume | 0.1 | 每次登记和替换的入场限价单所用固定数量。 |
| Buy Order Life (N) | 12 | 买入订单周期在定时撤单和重置标志前计算的已完成蜡烛数。 |
| Sell Order Life (N) | 12 | 卖出订单周期在定时撤单和重置标志前计算的已完成蜡烛数。 |
| Take Profit | 0 | 绝对值为零时关闭止盈保护。 |
| Stop Loss | 10 | 移动止损与已观察到的最佳保护价格之间的绝对距离。 |
| Trailing Stop Loss | true | 价格向持仓有利方向移动时随之调整止损边界。 |
| Use Market Orders | true | 移动止损触发后使用市价单退出。 |

## 图表详情

- 蜡烛收盘价先到达 Crossing，随后才移入新形成的 KAMA。因此 Crossing 得到当前收盘价和前一次已形成更新的自适应均线值。
- 两个价位公式共用相同的收盘价和步长。Previous value 块保存上一买卖价位，NotEqual 比较仅在价位改变时产生替换脉冲。
- 每个 Combination 块接收登记时发出的订单以及每次替换后发出的订单。其输出同时把最新订单交给 Order replacing 和 Order cancellation。
- N values 块由成功登记启动并计算十二根已完成蜡烛。输出同时请求撤单并释放对应的周期标志，以便之后建立新订单。
- 图表显示五分钟蜡烛、KAMA、两个整数关口、当前买卖限价、移动止损订单以及全部成交。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
