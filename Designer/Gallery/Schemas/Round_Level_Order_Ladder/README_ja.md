# ラウンド水準注文ラダー戦略図
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この図は、ラウンド水準に置く受動的なエントリー注文のライフサイクル全体を管理します。確定5分足が、Kaufman 適応平均、方向交差、売買水準の計算、注文の差し替え、時間による取消し、絶対距離のトレーリングストップを動かします。

![schema](schema.svg)

## 戦略の概要

- 確定5分足を KAMA(15) に入力し、高速期間を2、低速期間を30とします。シグナル経路には形成済みの指標値だけを渡します。
- Previous value ブロックが形成済み KAMA を1更新分ずらし、Crossing が各終値をその1つ前の適応平均値と比較します。
- 最寄りの丸め中心は floor(close / step + 0.5) で求めます。買い指値は中心から200価格単位の1ステップ下、売り指値は1ステップ上です。
- 買いと売りの注文バスが別々に現在の有効注文を保持します。計算水準が変わると、Order replacing が有効な指値を新しい水準へ移します。
- 各方向に12本周期のフラグとタイマーがあります。反対交差またはタイマーが有効な指値を取り消し、約定するとトレーリング保護が起動します。

## エントリーとエグジットの条件

- **ロングエントリー**: 終値が1つ前の形成済み KAMA を上抜け、採取したポジションがゼロで買い周期フラグが空いているとき、(floor(close / step + 0.5) - 1) × step の価格で0.1単位の買い指値を登録します。
- **ショートエントリー**: 終値が1つ前の形成済み KAMA を下抜け、採取したポジションがゼロで売り周期フラグが空いているとき、(floor(close / step + 0.5) + 1) × step の価格で0.1単位の売り指値を登録します。
- **エグジット**: エントリー約定により絶対距離10のトレーリングストップが有効になります。確定足の終値で判定し、成行注文で決済します。テイクプロフィットは無効です。未約定エントリーは反対交差または確定足12本後に取り消します。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candles Series | 00:05:00 | シグナル、価格、タイマー、保護更新、チャートに使う確定ローソク足の時間枠。 |
| KAMA Fast SC Period | 2 | Kaufman 適応移動平均の高速平滑化期間。 |
| KAMA Slow SC Period | 30 | Kaufman 適応移動平均の低速平滑化期間。 |
| KAMA Length | 15 | Kaufman 適応移動平均の計算期間。 |
| KAMA Source | Not set | 別の指標入力フィールドは未選択で、ローソク足を直接接続します。 |
| Round Level Step | 200 | 隣り合うラウンド水準の間隔を価格単位で指定します。 |
| Order Volume | 0.1 | 登録および差し替えを行う各エントリー指値の固定数量。 |
| Buy Order Life (N) | 12 | 買い注文周期で時間取消しとフラグ解除までに数える確定足の本数。 |
| Sell Order Life (N) | 12 | 売り注文周期で時間取消しとフラグ解除までに数える確定足の本数。 |
| Take Profit | 0 | 絶対値ゼロによりテイクプロフィットを無効にします。 |
| Stop Loss | 10 | 観測した最良の保護価格からのトレーリングストップ絶対距離。 |
| Trailing Stop Loss | true | 価格がポジションに有利な方向へ進むとストップ境界を移動します。 |
| Use Market Orders | true | トレーリングストップによる決済を成行注文で送信します。 |

## ダイアグラムの詳細

- ローソク足の終値は、新しく形成された KAMA 値をずらす前に Crossing へ届きます。これにより、Crossing は現在の終値と1つ前の形成済み更新における適応平均値を受け取ります。
- 2つの水準式は同じ終値とステップを共有します。Previous value ブロックが前回の買い水準と売り水準を保持し、NotEqual 比較は水準が変化したときだけ差し替えパルスを出します。
- 各 Combination ブロックは登録時に出力された注文と、差し替え後に出力された各注文を受け取ります。その出力が最新注文を Order replacing と Order cancellation の両方へ渡します。
- N values ブロックは登録成功で起動し、確定足を12本数えます。出力は取消しを要求すると同時に、対応する周期フラグを解除して次の設定を可能にします。
- チャートには5分足、KAMA、2つのラウンド水準、現在の買い指値と売り指値、トレーリングストップ注文、全約定を表示します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
