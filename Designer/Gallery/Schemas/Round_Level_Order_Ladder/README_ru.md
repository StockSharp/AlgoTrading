# Схема стратегии лестницы заявок по круглым уровням
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Схема управляет полным жизненным циклом пассивных входных заявок у круглых уровней. Завершённые пятиминутные свечи задают адаптивную среднюю Кауфмана, пересечения направления, расчёт уровней покупки и продажи, перестановку заявок, отмену по времени и абсолютный скользящий стоп.

![schema](schema.svg)

## Обзор стратегии

- Завершённые пятиминутные свечи поступают в KAMA(15) с быстрым периодом 2 и медленным периодом 30; дальше проходят только сформированные значения индикатора.
- Блок Previous value сдвигает сформированную KAMA на одно обновление, а Crossing сравнивает каждое закрытие с этим предыдущим значением адаптивной средней.
- Ближайший округлённый центр рассчитывается как floor(close / step + 0.5). Лимит покупки находится на один шаг 200 ниже центра, а лимит продажи — на один шаг выше.
- Раздельные шины покупки и продажи хранят текущую активную заявку. Когда рассчитанный уровень меняется, Order replacing переносит активный лимит на новую цену.
- Для каждой стороны есть свой двенадцатисвечный цикл с флагом и таймером. Встречное пересечение или таймер отменяет ещё активный лимит, а исполнение включает скользящую защиту.

## Правила входа и выхода

- **Вход в лонг**: Когда закрытие пересекает предыдущую сформированную KAMA снизу вверх, зафиксированная позиция равна нулю и флаг цикла покупки свободен, зарегистрировать лимитную покупку объёмом 0.1 по цене (floor(close / step + 0.5) - 1) × step.
- **Вход в шорт**: Когда закрытие пересекает предыдущую сформированную KAMA сверху вниз, зафиксированная позиция равна нулю и флаг цикла продажи свободен, зарегистрировать лимитную продажу объёмом 0.1 по цене (floor(close / step + 0.5) + 1) × step.
- **Выход**: Исполнение входа включает абсолютный скользящий стоп с расстоянием 10, который проверяется по закрытиям завершённых свечей и выходит рыночной заявкой. Тейк-профит отключён. Отложенный вход отменяется при встречном пересечении или через двенадцать завершённых свечей.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Candles Series | 00:05:00 | Таймфрейм завершённых свечей для сигналов, цен, таймеров, обновления защиты и графика. |
| KAMA Fast SC Period | 2 | Быстрый период сглаживания адаптивной скользящей средней Кауфмана. |
| KAMA Slow SC Period | 30 | Медленный период сглаживания адаптивной скользящей средней Кауфмана. |
| KAMA Length | 15 | Период расчёта адаптивной скользящей средней Кауфмана. |
| KAMA Source | Not set | Дополнительное поле входа индикатора не выбрано; свечи подключены напрямую. |
| Round Level Step | 200 | Расстояние между соседними круглыми уровнями в единицах цены. |
| Order Volume | 0.1 | Фиксированный объём каждой зарегистрированной и переставленной входной заявки. |
| Buy Order Life (N) | 12 | Число завершённых свечей в цикле покупки до отмены по времени и сброса флага. |
| Sell Order Life (N) | 12 | Число завершённых свечей в цикле продажи до отмены по времени и сброса флага. |
| Take Profit | 0 | Нулевое абсолютное значение отключает тейк-профит. |
| Stop Loss | 10 | Абсолютное расстояние скользящего стопа от лучшей наблюдавшейся защищаемой цены. |
| Trailing Stop Loss | true | Перемещает границу стопа вслед за благоприятным движением цены. |
| Use Market Orders | true | Отправляет сработавший скользящий выход рыночной заявкой. |

## Детали диаграммы

- Закрытие свечи приходит в Crossing до сдвига нового сформированного значения KAMA. Поэтому блок получает текущее закрытие и значение адаптивной средней с предыдущего сформированного обновления.
- Обе формулы уровней используют одно закрытие и один шаг. Блоки Previous value сохраняют прошлые уровни покупки и продажи, а сравнения NotEqual дают импульс перестановки только при изменении уровня.
- Каждый блок Combination принимает заявку от регистрации и каждую заявку после перестановки. Его выход передаёт последнюю заявку одновременно в Order replacing и Order cancellation.
- Блоки N values взводятся после успешной регистрации и считают двенадцать завершённых свечей. Их выход запрашивает отмену и освобождает соответствующий флаг цикла для следующей настройки.
- График показывает пятиминутные свечи, KAMA, оба круглых уровня, текущие лимиты покупки и продажи, заявки скользящего стопа и все исполнения.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
