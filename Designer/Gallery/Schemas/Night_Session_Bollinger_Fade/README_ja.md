# ナイトセッション・ボリンジャーフェード戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

バンドは価格が通常どおりに振る舞わなくなった場所を示し、時計はそれに手を出す価値のある時間帯を示します。このダイアグラムは、確定した1時間足の上で両者を組み合わせます。ボリンジャーバンドへのタッチをフェード（逆張り）しますが、仕掛けるのは夕方の時間帯に限られ、しかもチャネル自体が狭いあいだだけです。出口はミドルラインであり、そちら側は時計で区切られていません。夜遅くに建てたポジションでも、価格が戻ってきた時点で、それが何時であろうとクローズされます。

## 戦略の概要

- すべてを駆動するのはローソク足系列ひとつです。確定した1時間足だけが出力されるため、あらゆる比較、あらゆるゲート、あらゆる注文が確定したバーの上で決まります。
- 20本のローソク足、偏差2.0のボリンジャーバンドは、形成が完了してから値を出力します。3つの変換（Converter）ブロックが指標値を上バンド、下バンド、ミドルラインに分解します。
- 数式（Formula）ブロックが上バンドから下バンドを引いてチャネル幅を求め、比較（Comparison）ブロックがそれを幅のしきい値と突き合わせます。この1つの答えが、両方のエントリーが共有する「市場が静かか」というゲートです。
- 稼働時間（Working time）ブロックは各ローソク足が持つタイムスタンプ、すなわちその開始時刻を読み、19:00:00から23:59:59までの間はtrueを返します。これを参照するのは2つのエントリーゲートだけです。
- ロングは、同じローソク足で4つの答えが揃ったときに受け付けられます。安値が下バンドに達したこと、チャネルがしきい値以内であること、そのローソク足がセッション内に始まったこと、そしてポジションがフラットであることです。
- ショートはその鏡像で、高値が上バンドに達し、同じ幅・セッション・フラットポジションの条件を満たしたときです。
- どちらのエントリーも、「ポジションを開く」（Open position）条件のもとでポジション変更（Position modify）が送る成行注文です。そのため、すでにポジションがあるときに届いたシグナルは、追加の比較ではなく注文ブロック自身が拒否します。
- 手仕舞いは終値をミドルラインと比較し、両方向とも「縮小のみ」（Reduce only）注文として送られます。チャートパネルにはローソク足、3本のバンドライン、そして4つの注文ブロックすべての注文と約定が描画されます。

## エントリーとエグジットの条件

- **ロングエントリー**: 夕方のウィンドウ内で、安値が下バンドに到達または割り込んだ確定ローソク足において、チャネル幅がしきい値以下でポジションがフラットであれば、ポジション変更（Position modify）が「ポジションを開く」条件のもとで注文数量を成行で買います。
- **ショートエントリー**: 同じウィンドウ内で、高値が上バンドに到達または超えた確定ローソク足において、チャネル幅がしきい値以下でポジションがフラットであれば、ポジション変更（Position modify）が「ポジションを開く」条件のもとで注文数量を成行で売ります。
- **エグジット**: ミドルラインが両サイドの目標です。確定したローソク足の終値がミドルライン以上であれば「縮小のみ」（Reduce only）の売り注文が送られ、終値がミドルライン以下であれば「縮小のみ」の買い注文が送られます。「縮小のみ」ブロックは、すでに保有しているポジションと同じ方向を渡されると自ら注文を拒否するため、ショート中は売り側の経路が沈黙し、ロング中は買い側の経路が沈黙します。どちらの手仕舞いもセッションやチャネル幅による制限を受けず、24時間、確定したローソク足ごとに動きます。ストップロスもテイクプロフィットもなく、ミドルラインへの回帰がトレードから抜ける唯一の手段です。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candles | 01:00:00 | ダイアグラム全体が動く唯一のローソク足系列の時間軸。確定したローソク足だけがここから出ていきます。 |
| Bollinger Period | 20 | バンドの平均を取るローソク足の本数。 |
| Bollinger Deviation | 2.0 | 2本のバンドがミドルラインからどれだけ離れて位置するかを決める標準偏差の倍率。 |
| Width Threshold | 3000 | エントリーできるほど静かとみなされるチャネル幅の上限。銘柄の価格単位で指定します。 |
| Session From | 19:00:00 | エントリーが許可されるウィンドウの開始時刻。ローソク足の開始時刻と突き合わせられます。 |
| Session Until | 23:59:59 | そのウィンドウの終了時刻。この時刻以前に始まったローソク足は内側として扱われます。 |
| Order Volume | 0.01 | 両方のエントリーと両方の手仕舞いが送る注文数量。 |

## ダイアグラムの詳細

- エントリーは終値ではなくローソク足の高値・安値を読みます。ザラ場中にバンドを突き抜けて内側に戻って引けたバーもタッチとして数えられ、これが終値のブレイクアウトではなく行き過ぎのフェードたるゆえんです。
- 幅のゲートはパーセントではなく、その銘柄の価格単位で測られます。価格が数単位で表示される銘柄ではほぼすべてのローソク足がこれを通過し、ゲートは実質的に開いたままになります。価格が数万単位で表示される銘柄では、本来意図された選択的なフィルターとして働きます。しきい値がパラメータとして公開されているのは、銘柄に合わせて設定できるようにするためです。
- 「縮小のみ」が方向を自ら決めるにもかかわらず、両方の手仕舞いは方向を持っています。この方向こそが、それぞれの経路に誤ったポジションを拒否させるものです。だからこそダイアグラムの手仕舞い側にはロングやショートの比較が現れません。その判定は2つの注文ブロックが担っています。
- 1つのボリューム（Volume）変数が4つの注文ブロックすべてに供給されます。手仕舞い側では「縮小のみ」が注文数量を実際の保有分まで切り詰めるため、一部しか約定しなかったエントリーでもドテンにならず、ちょうど決済されます。
- セッションはフリーランのクロックからではなくローソク足ごとに評価されるため、バンドと幅の答えと同じ拍で値が変わり、エントリーゲートの4つの入力は常に同じバーを表します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
