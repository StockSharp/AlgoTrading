# 波动率自适应均线策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该图用一条围绕简单移动平均线的通道来交易，通道半宽等于若干倍真实波幅：市场紧张时边界张开，平静时收拢。收盘价越过边界即视为真正的突破，而价格回到均线时就把仓位交还。

![schema](schema.svg)

## 策略概览

- SimpleMovingAverage 画出中轴线，AverageTrueRange 决定边界离中轴多远，因此通道会跟随当前波动率伸缩。
- 两个公式方块用同样的三个来源拼出边界：SMA + 倍数 * ATR 与 SMA - 倍数 * ATR。
- 只在空仓时入场，唯一的离场方式是收盘价重新穿回中轴线；与 C# 原版一样没有止损和止盈。
- 与原版的两点差异：每笔交易后 500 根K线的暂停没有复现，因此本图交易更频繁；工作周期用五分钟而不是一分钟，因为随附的历史数据就是五分钟。

## 入场与出场规则

- **做多入场**: 收盘价高于上边界 SMA + 倍数 * ATR，且当前空仓。修改持仓方块以市价买入共享数量。
- **做空入场**: 收盘价低于下边界 SMA - 倍数 * ATR，且当前空仓。修改持仓方块以市价卖出共享数量。
- **离场**: 多头在第一根收于 SMA 之下的K线上了结，空头在第一根收于 SMA 之上的K线上了结；平仓方块只有在确有持仓时才动作。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SMA Length | 20 | 构成中轴线和离场水平的简单移动平均线周期。 |
| ATR Length | 14 | 衡量当前波动率的真实波幅周期。 |
| ATR multiplier | 2 | 通道边界距离中轴线的 ATR 倍数。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时喂给两个指标和一个取出收盘价的转换方块。
- 两个公式方块把均线、波幅和倍数常量合成上下边界。
- 四个比较方块构成信号：两个对比通道边界用于入场，两个对比中轴线用于离场。
- 持仓方块与零常量比较后进入每一个逻辑与，因此任何订单都不会给已有持仓加码。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
