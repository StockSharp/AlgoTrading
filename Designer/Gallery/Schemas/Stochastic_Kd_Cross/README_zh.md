# 随机指标 %K/%D 极值区交叉策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

两条随机指标线的交叉常见却嘈杂，因此本图只在它有意义的位置接受它：金叉必须发生在 %K 仍处于超卖区时，死叉必须发生在 %K 仍处于超买区时。每个被接受的信号都会反手，所以图中要么持多、要么持空，不会空等。

![schema](schema.svg)

## 策略概览

- 一个随机指标方块提供两条线，转换方块把它的数值拆成 %K 和 %D。
- 交叉方块比较两条线：它的信号代表金叉，同一信号经过“非”方块取反即代表死叉。
- 区间过滤只是把 %K 与超卖、超买常量相比较，因此发生在区间中部的交叉会被忽略。
- 下单数量为基础数量加持仓绝对值，一张市价单即可平掉反向持仓并建立新仓。
- 尽管原策略的文件夹名里带有 RSI，代码中并没有 RSI，也没有止损；成交后等待五根K线的暂停无法用方块表达，因此省略。
- 原策略使用15分钟K线；为配合随附的样本历史数据，本图改用5分钟K线。

## 入场与出场规则

- **做多入场**: %K 上穿 %D，且此时 %K 低于超卖水平，同时当前不是多头持仓。订单买入基础数量加上未平空头，从而反手做多。
- **做空入场**: %K 下穿 %D，且此时 %K 高于超买水平，同时当前不是空头持仓。订单卖出基础数量加上未平多头，从而反手做空。
- **离场**: 没有单独的离场方块：持仓一直保留到对侧区间出现反向交叉，同一张订单同时完成平仓与开仓。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| %K Length | 14 | 随机指标 %K 线的回溯周期。 |
| %D Length | 3 | %D 线的平滑周期，即 %K 的移动平均长度。 |
| Oversold | 20 | 低于该水平时金叉才被接受为买入信号。 |
| Overbought | 80 | 高于该水平时死叉才被接受为卖出信号。 |
| Volume | 1 | 基础下单数量（手）；反手时再加上已有持仓。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动唯一的随机指标，两个转换方块从其数值中取出 %K 与 %D。
- 交叉方块只在两线互换位置的那根K线上触发，这正是本图不会在两线分离的每一根K线上交易的原因。
- 每个逻辑与把交叉、区间比较和持仓判断合并，然后触发修改持仓方块。
- 公式方块把基础数量与持仓绝对值相加，供给两个下单方块，因此一张市价单即可完成整个反手。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
