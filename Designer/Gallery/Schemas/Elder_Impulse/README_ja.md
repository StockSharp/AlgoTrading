# Elder Impulse System 戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

アレキサンダー・エルダーは、トレンドを示す指数移動平均の傾きと、その背後の勢いを示す MACD ヒストグラムの傾きという2つの要素で各バーに色を付けます。両方が上向きならバーは緑でダイアグラムは買い、両方が下向きなら赤で売ります。注文数量は Volume に建玉を加えた大きさなので、どのシグナルも保有ポジションをドテンさせます。

![schema](schema.svg)

## 戦略の概要

- EMA と MACD の各ラインは単一銘柄の確定足で計算し、ヒストグラムはダイアグラム内で MACD から Signal を引いて作ります。
- 2つの前値ブロックが1本前の EMA とヒストグラムを保持するため、現在値と比べてそれぞれの向きを判定できます。
- バーの色は2つの傾きの組み合わせです。EMA 上向きかつヒストグラム上昇なら緑、EMA 下向きかつヒストグラムが上昇していなければ赤、それ以外は中立として無視します。
- 元の戦略は約定後 65 本のあいだ手を出しません。この休止はカウンターであり、Designer のブロックはそうした状態を保持しないためダイアグラムでは省略しました。ポジション判定があるので同じ方向への連続エントリーは起きません。

## エントリーとエグジットの条件

- **ロングエントリー**: EMA が1本前の値より高く、ヒストグラムも1本前の値より高く、かつポジションが買いではないとき。注文は Volume にポジションの絶対値を加えた数量を買い、ノーポジションなら新規の買い、売り持ちなら一度でドテンします。
- **ショートエントリー**: EMA が1本前の値より低く、ヒストグラムが1本前の値以下で、かつポジションが売りではないとき。注文は Volume にポジションの絶対値を加えた数量を売り、新規の売り、または買い持ちのドテンになります。
- **エグジット**: 専用のエグジットはありません。反対の色がポジションをドテンさせ、注文数量に建玉が含まれるため、ドテンが古い建玉の手仕舞いと新規建てを同時に行います。元の戦略にも損切りと利食いはありません。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| EMA Length | 13 | バーの色を決める指数移動平均の期間。 |
| MACD Fast Length | 12 | MACD の短期移動平均。 |
| MACD Slow Length | 26 | MACD の長期移動平均。 |
| MACD Signal Length | 9 | シグナルラインの期間。ヒストグラムは MACD からこのラインを引いた値です。 |
| Volume | 1 | 基本の注文数量（ロット）。ドテン時にはこれに建玉が加算されます。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが EMA とシグナルライン付き MACD の2つの指標ブロックに給電し、2つのコンバーターが MACD と Signal の値を取り出し、数式ブロックが両者を引いてヒストグラムを作ります。
- 指標値型と数値型の2つの前値ブロックが1本前の値を4つの比較ブロックへ渡し、そこで2つの傾きが決まります。
- 各論理積が EMA の条件、ヒストグラムの条件、ポジションの条件を結び付けるため、既に保有している側を積み増す注文は出ません。
- 数式ブロックが共通の数量定数にポジションの絶対値を加え、2つのポジション変更ブロックへ渡します。これがすべてのシグナルをドテンに変えています。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
