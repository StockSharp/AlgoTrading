# Elder Impulse System 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

亚历山大·埃尔德用两项指标同时给每根K线上色：指数移动平均线的斜率代表趋势，MACD 柱状图的斜率代表其背后的动能。两者同时向上时该K线为绿色，图表买入；两者同时向下时为红色，图表卖出。委托数量等于 Volume 加上当前持仓，因此每个信号都会把已有仓位反手。

![schema](schema.svg)

## 策略概览

- EMA 与 MACD 各线均基于单一品种的已完成K线计算，柱状图直接在图中用 MACD 减 Signal 得到。
- 两个前值方块保存上一根K线的 EMA 与柱状图，使图表能与当前读数对比，判断二者各自的方向。
- K线颜色由这一对斜率决定：EMA 向上且柱状图向上为绿色，EMA 向下且柱状图不上升为红色，其余情况为中性并被忽略。
- 原始策略成交后会停手 65 根K线。该暂停依赖计数器，而 Designer 的方块不保存这种状态，因此图中省略；持仓判断本身也能防止同方向重复入场。

## 入场与出场规则

- **做多入场**: EMA 高于一根K线之前的数值，柱状图也高于一根K线之前的数值，且持仓不是多头。订单买入 Volume 加持仓绝对值：空仓时开多，持空时一次完成反手。
- **做空入场**: EMA 低于一根K线之前的数值，柱状图不高于一根K线之前的数值，且持仓不是空头。订单卖出 Volume 加持仓绝对值：空仓时开空，持多时反手。
- **离场**: 没有单独的离场：相反的颜色会把持仓反手，而由于下单数量包含当前持仓，反手同时平掉旧仓并建立新仓。原策略同样没有止损和止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| EMA Length | 13 | 为K线上色的指数移动平均线周期。 |
| MACD Fast Length | 12 | MACD 的快线周期。 |
| MACD Slow Length | 26 | MACD 的慢线周期。 |
| MACD Signal Length | 9 | 信号线周期；柱状图等于 MACD 减去该线。 |
| Volume | 1 | 基础下单数量（手）；反手时再加上当前持仓。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块向 EMA 与带信号线的 MACD 两个指标方块供数；两个转换方块取出 MACD 与 Signal 数值，公式方块相减得到柱状图。
- 两个前值方块（一个为指标值类型，一个为数值类型）把上一根K线的读数送给四个比较方块，由它们判定两条斜率。
- 每个逻辑与把一个 EMA 条件、一个柱状图条件和一个持仓条件合在一起，只有不会加仓时才入场。
- 公式方块把持仓绝对值加到共用的数量常量上，再送入两个修改持仓方块——这正是让每个信号变成反手的关键。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
