# MA + ADX 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这是一张带强度过滤的趋势图。ExponentialMovingAverage 决定站在市场的哪一边，方向指数 DX 判断这段走势是否值得持仓，而一旦收盘价回到均线另一侧就立即离场。

![schema](schema.svg)

## 策略概览

- 收盘价与 ExponentialMovingAverage 比较：位于均线上方做多，下方做空。
- DirectionalIndex 方块输出 DX 值，与原始策略用 +DM 和 -DM 手工计算的公式一致；只有 DX 高于阈值时才允许入场。
- 入场只在空仓时发生，离场恰好平掉已有持仓，因此不会加仓。
- 离场不看趋势强度：只要收盘价回到均线另一侧，无论 DX 如何都会平仓。

## 入场与出场规则

- **做多入场**: 收盘价高于 EMA，DX 高于趋势强度阈值，且当前空仓。订单按基础数量买入并建立多头。
- **做空入场**: 收盘价低于 EMA，DX 高于趋势强度阈值，且当前空仓。订单按基础数量卖出并建立空头。
- **离场**: 只要某根K线收在 EMA 之下就平掉多头，收在 EMA 之上就平掉空头；平仓方块的数量取自当前持仓。原始策略没有止损止盈，其每笔交易后暂停一百根K线的规则也未移植，因此本图的交易频率高于源码。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| EMA Length | 20 | 决定方向的指数移动平均周期。 |
| DX Length | 14 | 衡量趋势强度的方向指数周期。 |
| Trend Strength | 25 | 允许开新仓所需的 DX 下限。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动两个指标以及提取收盘价的转换方块。
- 两个比较方块判断收盘价相对 EMA 的位置，并被复用：同一个信号既开一侧仓位，又平另一侧仓位。
- 持仓方块驱动三个与零的比较：空仓用于守护入场，多头和空头分别守护两个离场。
- 入场方块使用开仓条件并从共享常量取得数量，离场方块使用平仓条件并自行计算数量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
