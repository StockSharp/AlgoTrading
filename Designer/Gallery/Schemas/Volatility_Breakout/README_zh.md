# 波动率突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

手工搭建的通道：简单移动平均线给出中枢，Average True Range 给出宽度，收盘价越过 SMA 加减若干倍 ATR 即视为值得跟随的行情。通道随波动率呼吸，因此同一个倍数在平静与快速的市场中都保持意义。

![schema](schema.svg)

## 策略概览

- SMA 与 ATR 在已完成K线上使用相同周期，因此通道以均价为中心，并按近期真实波幅缩放。
- 两个公式方块拼出边界：上边界为 SMA 加倍数乘 ATR，下边界为 SMA 减去同样的数值。
- 策略始终持仓：反向突破会反手，若行情失败则由保护性止损提前平仓。

## 入场与出场规则

- **做多入场**: K线收盘价高于 SMA 加倍数乘 ATR，且持仓不是多头。订单买入基础数量加持仓绝对值：空头翻多，空仓则开多。
- **做空入场**: K线收盘价低于 SMA 减倍数乘 ATR，且持仓不是空头。订单卖出基础数量加持仓绝对值：多头翻空，空仓则开空。
- **离场**: 没有基于指标的离场。持仓由反向突破反手，或由挂在两个入场成交上的保护性止损方块提前平掉。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Indicator period | 20 | 定义通道中枢的 SMA 与定义通道宽度的 ATR 共用的周期。 |
| ATR multiplier | 2 | 突破边界距离移动平均线多少倍 ATR。 |
| Stop loss, % | 2 | 保护性止损，按入场价的百分比计。 |
| Volume | 1 | 基础下单数量（手）；反手时加上持仓绝对值。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块把数据送入两个指标，并通过转换方块取得收盘价，该价格既用于比较，也作为保护方块的价格来源。
- 一个常量保存倍数，两个公式方块根据 SMA、倍数与 ATR 计算上下边界。
- 两个比较方块把收盘价与边界对比，另外两个把持仓与零对比，每个逻辑与各取一个条件组成入场信号。
- 公式方块把反手数量算成基础数量加持仓绝对值，并送入两个修改持仓方块。
- 原策略的止损为2个绝对价格单位，这是针对其他品种校准的，在加密货币价格上会立即被打掉；本图改用2%的止损，在任何品种上都符合原意。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
