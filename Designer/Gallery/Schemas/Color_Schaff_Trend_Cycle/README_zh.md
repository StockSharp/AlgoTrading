# Color Schaff Trend Cycle 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Schaff Trend Cycle 是在 MACD 柱状图上再做一次随机指标，因此比普通振荡器反应更快，却仍然在零到一百之间运行。本图在该指标离开区间中部时交易，并由普通的 MACD 线判断这次突破是否值得跟随：只有 MACD 为正时的向上突破和 MACD 为负时的向下突破才会转化为订单。

![schema](schema.svg)

## 策略概览

- Schaff Trend Cycle 基于已完成K线计算，前值方块保存它上一根K线的读数，用来区分“刚刚突破水平”与“一直位于水平之上”。
- 两条水平线框出区间中部：自下向上穿过上轨是做多信号，自上向下穿过下轨是做空信号。
- MACD 线，即快慢两条指数移动平均线之差，只充当符号过滤器：为正允许做多，为负允许做空。
- 首次成交之后策略始终持仓：每个信号都会反手，因为下单数量是基础数量加上当前持仓的绝对值。

## 入场与出场规则

- **做多入场**: 上一根K线时指标等于或低于上轨，现在高于上轨，MACD 线为正，且持仓不是多头。订单买入基础数量加持仓绝对值：空头翻多，空仓则开多。
- **做空入场**: 上一根K线时指标等于或高于下轨，现在低于下轨，MACD 线为负，且持仓不是空头。订单卖出基础数量加持仓绝对值：多头翻空，空仓则开空。
- **离场**: 与原始策略一样，没有单独的离场方块也没有保护性委托：只有反向的水平突破到来并反手时才会离开持仓。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| STC smoothing length | 10 | Schaff Trend Cycle 的平滑周期；数值越大，指标越慢，突破越少。 |
| MACD fast EMA | 12 | MACD 过滤器中的快速指数移动平均线周期。 |
| MACD slow EMA | 26 | MACD 过滤器中的慢速指数移动平均线周期。 |
| Upper level | 60 | 做多信号所需向上突破的水平。 |
| Lower level | 40 | 做空信号所需向下突破的水平。 |
| Volume | 1 | 基础下单数量（手）；反手时加上持仓绝对值。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动 Schaff Trend Cycle 与 MACD，前值方块取得上一根K线的指标读数。
- 四个比较方块构成两次突破：前值与水平线比较，当前值与同一条水平线比较，两者合起来说明该线正是在这根K线上跨越了水平。
- 另有两个比较给出 MACD 线的符号，还有两个把持仓与共用的零常量比较，避免信号对已有持仓加仓。
- 每个逻辑与合并四个条件——指标此前的位置、当前的位置、MACD 符号与持仓——并触发一个修改持仓方块。
- 公式方块把反手数量算成基础数量加持仓绝对值，因此一张市价单既平掉旧方向又建立新方向，对应 C# 代码中连续发出的两张市价单。
- 与 C# 原版有两处差异值得了解。原版以 Schaff Trend Cycle 命名，实际却用十周期 RSI 代替；本图使用真正的 Schaff Trend Cycle 指标，因此信号符合名称而非原代码。
- 此外原版运行在四小时K线上，而图库随附的一个月历史数据在该周期下K线太少；本图改用五分钟K线。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
