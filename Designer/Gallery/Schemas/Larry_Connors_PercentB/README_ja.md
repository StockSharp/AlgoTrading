# ラリー・コナーズの Bollinger %B 戦略ダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

ボリンジャーバンド内での終値の位置をバンド幅に対する割合で表した Bollinger %B を使う、買いのみの平均回帰ダイアグラムです。ラリー・コナーズの発想は「弱い足が1本あっても何も証明しない」というもので、%B がバンドの下側に2本連続でとどまるのを待って買い、%B が上側へ戻るまで保有します。

![schema](schema.svg)

## 戦略の概要

- BollingerPercentB 指標が、元の戦略でバンドから手計算していた処理を1ブロックで行います。目盛りは0〜100なので、古典的なしきい値 0.35 と 0.8 は 35 と 80 と記述します。
- 前値ブロックが1本前の足の値を保持し、これが「弱い足1本」を「2本連続」の条件に変えます。
- 戦略は買いのみです。弱さを買い、その同じ買い建玉を売り戻すだけで、売り建てはしません。
- ポジションが両方の判断に加わるため、エントリーは積み増しにならず、エグジットはノーポジションで発火しません。

## エントリーとエグジットの条件

- **ロングエントリー**: 1本前の足の %B と現在の足の %B がいずれも下側しきい値を下回り、かつ買い持ちでないとき。注文は1ロットを買います。
- **ショートエントリー**: このダイアグラムは売り建てを行いません。売りブロックは既存の買い建玉を手仕舞うためだけに使われます。
- **エグジット**: 買い持ちの状態で %B が上側しきい値を上抜けたとき。注文は同じ1ロットを売り、ポジションをゼロに戻します。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Bollinger Period | 20 | %B の基礎となるボリンジャーバンドの期間。 |
| Bollinger Deviation | 2 | ボリンジャーバンドの標準偏差の倍率。 |
| Low %B | 35 | これを下回ると %B がバンド下側とみなされるしきい値。2本連続で成立する必要があります。 |
| High %B | 80 | これを上回ると %B が回復したとみなされ、買い建玉を閉じるしきい値。 |
| Volume | 1 | 注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが指標ブロックに値を渡し、その値は比較ブロックと前値ブロックの両方へ流れます。
- 同じ下側定数との比較2つが現在足と1本前の足の条件を作り、3つ目の比較がエグジット用に %B と上側定数を比べます。
- さらに2つの比較がポジションとゼロを比べます。エントリーには「買い持ちでない」、エグジットには「買い持ち」を用います。
- 2つの論理積がポジション変更ブロックを起動し、いずれも共通の定数から数量を受け取ります。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
