# 布林带与 ADX 突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

只有当市场确实在朝某个方向走时，突破才值得参与。本图等待收盘价落在布林带之外——这说明相对近期波动率而言，本次波动异常之大——再向 ADX 询问背后是否存在趋势。两者一致时，就沿突破方向开仓，并在价格回到中轨时放弃这笔交易。

![schema](schema.svg)

## 策略概览

- 布林带基于单一品种的已完成K线计算：上轨与下轨标出突破水平，中轨（同周期的移动平均）标出离场位置。
- ADX 只衡量趋势强度、不指明方向，因此纯粹作为过滤器使用：低于阈值时任何突破都被忽略。
- 当前持仓参与两个入场判断，两个平仓方块设为平仓而非开仓，因此各自只能作用于对应的方向。
- 原策略在任何成交后会自锁一百根K线，连离场也一并封住。这样的计数器在方块中没有对应物，因此图中省略：中轨离场始终有效，这本身也更合理。

## 入场与出场规则

- **做多入场**: 收盘价高于布林带上轨，ADX 高于阈值，且当前空仓。以市价买入一手。
- **做空入场**: 收盘价低于布林带下轨，ADX 高于阈值，且当前空仓。以市价卖出一手。
- **离场**: 多头在第一次收盘价跌破中轨时平仓，空头在第一次收盘价升破中轨时平仓。与原策略一致，没有止损和止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Bollinger Length | 20 | 布林带及其中轨的平滑周期。 |
| Bollinger Width | 2.0 | 决定带宽的标准差倍数。 |
| ADX Length | 14 | 平均趋向指数（ADX）的周期。 |
| ADX Threshold | 25 | ADX 高于该水平才认为趋势足够强，可以交易突破。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块向两个指标方块和一个收盘价转换方块供数；另外三个转换方块从同一个布林带数值中取出上轨、下轨与中轨，还有一个取出 ADX 线。
- 五个比较方块承担判断工作：两个用于突破，两个用于回到中轨，一个用于把趋势强度与阈值常量对比。
- 每个逻辑与把一个突破条件、趋势过滤和持仓判断合在一起，触发开仓模式的修改持仓方块，数量取自共用常量。
- 两个离场比较驱动设为平仓的修改持仓方块，它们无需自带数量，方块会平掉已有的仓位。
- 原始代码手工计算趋势强度，实际上是未经平滑的 DX。图中改用标准 ADX，即同一数值经威尔德平滑后的版本，因此穿越阈值的时点会略有差异。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
