# Bollinger Bands と ADX のブレイクアウト戦略ダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

ブレイクアウトは、相場が実際にどこかへ向かっているときにだけ乗る価値があります。このダイアグラムは終値が Bollinger Bands の外側で引けるのを待ち（直近のボラティリティに比べて値動きが異常に大きいという合図です）、その背後にトレンドがあるかを ADX に尋ねます。両者が一致したときにブレイクの方向へ建て、価格がミドルバンドへ戻った時点で手放します。

![schema](schema.svg)

## 戦略の概要

- Bollinger Bands は単一銘柄の確定足で計算します。上下のバンドがブレイク水準を、同じ期間の移動平均であるミドルバンドがエグジット水準を示します。
- ADX は方向を示さずトレンドの強さだけを測るため、純粋なフィルターとして使います。しきい値を下回る間はどのブレイクも無視されます。
- 現在のポジションは両方のエントリー判定に加わり、2つの決済ブロックは新規ではなく決済モードのため、それぞれ担当する側でのみ作動します。
- 元の戦略は約定のたびに 100 本ぶん自らを封じ、エグジットまで止めてしまいます。そうしたカウンターに相当するブロックがないため省略しました。結果としてミドルバンドでのエグジットは常に働き、その方が理にかなっています。

## エントリーとエグジットの条件

- **ロングエントリー**: 終値が上バンドを上回り、ADX がしきい値を超え、ポジションがないとき。成行で1ロットを買います。
- **ショートエントリー**: 終値が下バンドを下回り、ADX がしきい値を超え、ポジションがないとき。成行で1ロットを売ります。
- **エグジット**: 買い建ては終値が初めてミドルバンドを下回った足で、売り建ては初めて上回った足で決済します。元の戦略と同じく損切りも利食いもありません。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Bollinger Length | 20 | Bollinger Bands とそのミドルラインの平滑期間。 |
| Bollinger Width | 2.0 | バンド幅を決める標準偏差の倍率。 |
| ADX Length | 14 | Average Directional Index（ADX）の期間。 |
| ADX Threshold | 25 | この水準を超えた ADX を、ブレイクを取れるだけ強いトレンドとみなします。 |
| Volume | 1 | 注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが2つの指標ブロックと終値コンバーターに給電し、さらに3つのコンバーターが1つの Bollinger 値から上・下・ミドルの各バンドを取り出し、もう1つが ADX ラインを取り出します。
- 判定は5つの比較ブロックが担います。ブレイク用が2つ、ミドルバンドへの回帰用が2つ、しきい値定数とのトレンドフィルター用が1つです。
- 各論理積がブレイク条件、トレンドフィルター、ポジション判定を結び、新規モードのポジション変更ブロックを起動します。数量は共通の定数から取ります。
- 2つのエグジット比較は決済モードのポジション変更ブロックを動かします。ブロックが建玉をそのまま閉じるため、これらに数量の指定は不要です。
- 元のコードはトレンドの強さを手計算しており、実際には平滑化されていない DX です。ダイアグラムでは同じ値を Wilder 平滑した標準の ADX を使うため、しきい値を超える時点はわずかにずれます。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
