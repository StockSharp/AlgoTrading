# Диаграмма стратегии ловушки ложного пробоя
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Диаграмма торгует возврат цены внутрь предыдущего двадцатисвечного диапазона после краткого выхода за одну из его границ. Два раздельных затвора ограничивают повторные входы, а SMA немедленно закрывает открытую позицию.

![schema](schema.svg)

## Обзор стратегии

- Завершённые минутные свечи разделяются на потоки High, Low и Close.
- Highest(20) и Lowest(20), за каждым из которых стоит Previous value со Shift = 1, задают диапазон без текущей свечи.
- High выше предыдущей верхней границы при Close ниже неё означает ложный пробой вверх; зеркальное условие по Low означает ложный пробой вниз.
- Flag для продажи и Flag для покупки используют общий N values на 500 завершённых свечей; каждая сторона пропускает одно событие до следующего общего сброса.
- Рыночный вход фиксированным объёмом 1 разрешён только из нулевой позиции, а условия SMA(20) уменьшают открытую позицию на тот же объём.

## Правила входа и выхода

- **Вход в лонг**: Low ниже минимума предыдущих двадцати свечей, Close вернулся выше этой границы, и затвор покупки принял событие. Купить одну единицу по рынку только из нулевой позиции.
- **Вход в шорт**: High выше максимума предыдущих двадцати свечей, Close вернулся ниже этой границы, и затвор продажи принял событие. Продать одну единицу по рынку только из нулевой позиции.
- **Выход**: Уменьшить лонг на одну единицу при Close ниже SMA(20) либо уменьшить шорт на одну единицу при Close выше SMA(20). Выходы выполняются сразу и не проходят через паузу входов. Стоп-лосса и тейк-профита в диаграмме нет.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Candles Series | 00:01:00 | Завершённые минутные свечи для расчёта диапазона, сигналов и выходов. |
| Highest Length | 20 | Число максимумов свечей в скользящей верхней границе. |
| Highest Source | Not set | Дополнительное поле входа индикатора не выбрано; Candle high подключён напрямую. |
| Lowest Length | 20 | Число минимумов свечей в скользящей нижней границе. |
| Lowest Source | Not set | Дополнительное поле входа индикатора не выбрано; Candle low подключён напрямую. |
| SMA Length | 20 | Число цен закрытия в скользящей средней для выхода. |
| SMA Source | Not set | Дополнительное поле входа индикатора не выбрано; Candle close подключён напрямую. |
| Cooldown N | 500 | Число завершённых свечей до выдачи общего сигнала сброса паузы. |
| Entry Volume | 1 | Фиксированный рыночный объём каждого входа и уменьшающего выхода. |

## Детали диаграммы

- Highest и Lowest получают числовые значения High и Low, а SMA — Close; все три индикатора выдают только сформированные значения.
- Previous value сдвигает оба индикатора диапазона на одно обновление, поэтому проверяемая свеча не участвует в расчёте собственной границы.
- Финальный такт вычисления приходит в оба AND ложного пробоя только после обновления полей свечи, индикаторов, позиции и сравнений.
- Каждое необработанное событие ложного пробоя взводит общий N values. Через 500 следующих завершённых свечей его выход сбрасывает оба Flag; до этого каждый Flag глушит повторы своей стороны.
- OpenPosition не позволяет выставить новую заявку при открытой позиции. При этом событие ложного пробоя всё равно может взвести паузу, поскольку ветка паузы расположена перед торговым действием.
- Два выхода по SMA проверяют знак позиции и используют рыночные ReduceOnly-действия объёмом 1. Chart получает свечи, обе предыдущие границы диапазона, SMA и все исполнения входов и выходов.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
