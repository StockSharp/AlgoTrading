# Choppiness Index 突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Choppiness Index 不告诉你行情往哪走，只告诉你行情究竟有没有在走。本图把它当作开关：指数处于低位时市场有趋势，就按收盘价相对简单移动平均线的位置开仓；指数回到震荡区间时，无论盈亏都平掉持仓。

![schema](schema.svg)

## 策略概览

- Choppiness Index 基于十四根已完成K线计算，以百分比表示：数值低代表方向明确，数值高代表区间震荡。
- 二十周期简单移动平均线只提供方向，本身不作过滤，因为是否允许交易已由市场状态判断决定。
- 只有空仓时才入场，因此一段趋势只产生一笔交易，而不会不断加仓。
- 没有止损也没有止盈：开仓的那个指数同样负责结束这笔交易。

## 入场与出场规则

- **做多入场**: Choppiness Index 低于趋势阈值，K线收盘价高于简单移动平均线，且持仓为零。订单买入一手并开多。
- **做空入场**: Choppiness Index 低于趋势阈值，K线收盘价低于简单移动平均线，且持仓为零。订单卖出一手并开空。
- **离场**: 一旦 Choppiness Index 升破震荡阈值，就平掉持仓：多头用平仓模式的卖单，空头用平仓模式的买单。原始代码同样没有止损与止盈。有两处刻意与原代码不同。原代码的阈值是 99 与 99.5，这会让入场过滤器永远打开、离场条件永远无法满足，因此本图改用指标文档中的经典数值 38.2 与 61.8，这也正是该策略自身 README 所描述的取值。原代码两笔交易之间五百根K线的停顿同样被省略，因为这种计数器在方块中没有忠实的对应实现。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SMA Length | 20 | 为入场提供方向的简单移动平均线周期。 |
| Choppiness Length | 14 | Choppiness Index 的平均周期。 |
| Trending Threshold | 38.2 | 允许入场时指数必须低于的数值。 |
| Choppy Threshold | 61.8 | 指数高于该值即视为震荡并平仓。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期；原版为1分钟K线，本图使用随附历史数据的5分钟K线。 |

## 图表详情

- K线方块给 Choppiness Index、移动平均线以及提取收盘价的转换方块供数。
- 两个比较方块把指数变成两个状态标志——低于一个阈值为趋势，高于另一个阈值为震荡——另外两个比较收盘价与移动平均线。
- 持仓方块与零常量比较三次，分别得到入场用的空仓判断以及离场用的多头、空头判断。
- 四个逻辑与驱动四个修改持仓方块：两个开仓并从共享常量取数量，另两个只负责平掉已有持仓。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
