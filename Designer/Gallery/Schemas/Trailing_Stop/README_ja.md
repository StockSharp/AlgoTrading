# Trailing Stop（EMA クロス）戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

見どころがエントリーではなくエグジットにある、短いトレンド系ダイアグラムです。2本の指数移動平均が方向を決めますが、シグナル側は決して手仕舞いを行いません。ポジション変更ブロックは新規建てのみを担当し、ポジション保護ブロックが利食いか損切りまで玉を運びます。保護ブロックのトレーリング設定はオフのままです。元の戦略はトレーリング幅を宣言しているだけで、実際には使っていないためです。

![schema](schema.svg)

## 戦略の概要

- 短期と長期の ExponentialMovingAverage を同じローソク足系列で計算します。
- エントリーはノーポジションのときだけ行うため、既存の建玉をドテンしたり積み増したりしません。
- 2つのエントリーブロックは自分の約定を保護ブロックへ渡し、保護ブロックが約定価格に対する百分率で利食いと損切りを置きます。
- この保護ブロックが唯一の出口で、ダイアグラム自身にエグジットシグナルはありません。

## エントリーとエグジットの条件

- **ロングエントリー**: 短期 EMA が長期 EMA を上抜き、かつポジションがちょうどゼロのとき。注文は1ロットを買い、買い建てを作ります。
- **ショートエントリー**: 短期 EMA が長期 EMA を下抜き、かつポジションがちょうどゼロのとき。注文は1ロットを売り、売り建てを作ります。
- **エグジット**: 保護ブロックが建値から 2% の利食い、または 1% の損切りで手仕舞います。どちらかに達するまでは、エントリーがノーポジションを要求するため、反対方向のクロスは無視されます。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Fast EMA Length | 6 | 短期指数移動平均の期間。 |
| Slow EMA Length | 18 | 長期指数移動平均の期間。 |
| Take Profit, % | 2 | 建値に対する利食い幅（％）。 |
| Stop Loss, % | 1 | 建値に対する損切り幅（％）。 |
| Volume | 1 | 注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックは2つの指標ブロックに値を供給し、同時に保護ブロックが監視する価格も渡します。
- クロスブロックは短期 EMA が上抜けたとき true、下抜けたとき false を出すため、論理否定だけで同じ出力から売りシグナルが得られます。
- ポジション判定はゼロ定数との比較1つで足り、2つのポジション変更ブロックはさらに「新規のみ」モードで動作します。
- 2つのエントリーブロックの自己約定が保護ブロックへ配線されており、これが約定を利食い注文と損切り注文の組に変えています。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
