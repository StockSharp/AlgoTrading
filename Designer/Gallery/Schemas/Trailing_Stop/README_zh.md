# Trailing Stop（EMA 交叉）策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这是一张重点在离场而非入场的简短趋势图。两条指数移动平均线决定方向，但信号链路本身从不平仓：修改持仓方块只负责开仓，把交易带到止盈或止损的是持仓保护方块。该方块的移动止损开关保持关闭，因为原始策略虽然声明了移动止损距离，却从未使用。

![schema](schema.svg)

## 策略概览

- 快线与慢线两条 ExponentialMovingAverage 基于同一条K线序列计算。
- 只有在空仓时才入场，因此已有持仓既不会反手也不会加仓。
- 两个入场方块都把自己的成交送入保护方块，由它按成交价的百分比挂出止盈与止损。
- 该保护方块是离场的唯一途径；这张图没有自己的离场信号。

## 入场与出场规则

- **做多入场**: 快线 EMA 上穿慢线 EMA，且持仓恰好为零。订单买入一手并建立多头。
- **做空入场**: 快线 EMA 下穿慢线 EMA，且持仓恰好为零。订单卖出一手并建立空头。
- **离场**: 保护方块按入场价的 2% 止盈或 1% 止损平仓。在两者之一触发之前，反向交叉会被忽略，因为入场要求空仓。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Fast EMA Length | 6 | 快速指数移动平均线的周期。 |
| Slow EMA Length | 18 | 慢速指数移动平均线的周期。 |
| Take Profit, % | 2 | 止盈距离，按入场价的百分比计。 |
| Stop Loss, % | 1 | 止损距离，按入场价的百分比计。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时驱动两个指标方块，并为保护方块提供其跟踪的价格。
- 交叉方块在快线上穿时输出 true、下穿时输出 false，因此一个逻辑非就从同一输出得到做空信号。
- 与零常量的一次比较即可作为持仓判断，两个修改持仓方块还额外设为“仅开仓”模式。
- 两个入场方块的自有成交都接入保护方块，正是它把一次成交变成一对止盈与止损订单。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
