# 布林带 + RSI 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

两个经典工具在这里回答两个不同的问题。Bollinger Bands 说明价格偏离自身均值的程度，Relative Strength Index 说明推动这段偏离的动能是否已经耗尽。只有两者同时成立才会入场，而价格一旦回到中轨就立刻离场。

![schema](schema.svg)

## 策略概览

- Bollinger Bands 和 Relative Strength Index 都基于单一品种的已完成K线计算。
- 布林带一次向图中提供三个数值：上轨、下轨和中间的移动平均。
- 入场需要收盘价位于轨道之外，同时 RSI 处于对应的极端区间，单一条件永远不够。
- 中轨就是目标：价格回到中轨即平仓，因此图中不会继续持有已经完成回归的头寸。

## 入场与出场规则

- **做多入场**: K线收盘价低于布林带下轨，RSI 低于超卖水平，且当前无持仓。订单买入一手，开多。
- **做空入场**: K线收盘价高于布林带上轨，RSI 高于超买水平，且当前无持仓。订单卖出一手，开空。
- **离场**: 收盘价重新回到中轨之上时平多，回落到中轨之下时平空。两个离场都使用处于平仓模式的修改持仓方块，只有存在相应方向的持仓时才会触发；图中没有保护性止损。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Bollinger Length | 20 | Bollinger Bands 的平滑周期。 |
| Bollinger Width | 2 | 决定轨道宽度的标准差倍数。 |
| RSI Length | 14 | Relative Strength Index 的平滑周期。 |
| RSI Oversold | 30 | 低于该水平即视为超卖。 |
| RSI Overbought | 70 | 高于该水平即视为超买。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块分出三条支路：布林带方块、RSI 方块和读取收盘价的转换方块。
- 三个转换方块把布林带的取值拆成上轨、下轨和中间移动平均。
- 六个比较方块构成条件：价格与两条轨道、RSI 与两个水平、持仓与零常量。
- 每个逻辑与把一个轨道条件、一个 RSI 条件和持仓判断合并，触发修改持仓方块，其数量取自共享常量。
- 原始策略在每次交易后会暂停固定数量的K线；图中没有计数K线的方块，因此省略了这段暂停，离场时机完全由中轨决定。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
