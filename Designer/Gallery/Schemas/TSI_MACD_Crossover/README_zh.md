# TSI 与信号线交叉策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

True Strength Index 是经过两次平滑的动量指标，转向偏慢却很少说谎。与自身的指数信号线搭配时，它的表现像一条缓慢的 MACD：交叉给出方向，两线之间的距离说明这次转折有多可信。本图只接受该距离已经超过最小值的交叉，从而把真正的多空易手与两线互相擦碰区分开来。

![schema](schema.svg)

## 策略概览

- 一个 True Strength Index 方块同时承载两条线；两个转换方块从同一个数值中取出 TSI 线与信号线。
- 交叉方块比较两条线并给出交叉方向，逻辑非把同一个输出转换成向下交叉。
- 一个公式计算两线之间的绝对间距，比较方块要求它至少达到最小间距，交叉才被接受。
- 持仓判断决定是否允许入场，下单数量为共享数量加上持仓绝对值，因此反向信号一笔单即可反手。

## 入场与出场规则

- **做多入场**: TSI 线上穿信号线，两者间距不小于最小间距，且持仓不是多头。订单买入共享数量加上已有空头的规模，于是一笔市价单同时平空并开多。
- **做空入场**: TSI 线下穿信号线，两者间距不小于最小间距，且持仓不是空头。订单卖出共享数量加上已有多头的规模。
- **离场**: 与原策略一样，没有独立的离场规则，也没有保护性止损：仓位一直持有，直到反向交叉把它反手。这里做了两处简化。原策略每次入场后要等十根K线才重新查看信号，而没有任何方块能在K线之间保存计数器，因此该暂停被去掉；同方向的重复入场仍由持仓判断阻止。原策略反手时会发出两笔市价单，瞬间使规模翻倍；这里由数量公式在一笔单中完成同样的工作。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| TSI First Length | 25 | True Strength Index 的第一次平滑周期。 |
| TSI Second Length | 13 | True Strength Index 的第二次平滑周期。 |
| TSI Signal Length | 7 | 在指标上绘制的指数信号线周期。 |
| Min spread | 2 | 交叉成立所需的指标与信号线之间的最小绝对间距。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 01:00:00 | 整张图使用的K线周期。原策略运行在四小时K线上；一个月的历史留下的完成K线太少，双重平滑指标形成后已无余量交易，因此本图缩小到一小时K线。 |

## 图表详情

- K线方块驱动 True Strength Index 方块，其复合数值由两个转换方块拆成指标本身与信号线。
- 交叉方块把指标接在上方输入、信号线接在下方输入，所以向上交叉时输出为真，向下交叉时为假。
- 间距公式与它的比较每根K线都会计算，而交叉方块只在交叉时才发声，因此每个逻辑与恰好在发生过滤后交叉的那一根K线上触发。
- 两个修改持仓方块的数量都来自同一个公式，它把持仓绝对值加到共享数量常量上。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
