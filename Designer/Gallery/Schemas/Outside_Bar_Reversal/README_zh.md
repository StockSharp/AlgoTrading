# 外包线反转策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

外包线是把前一根K线整个区间都吞下的K线：同一根K线里既创出更高的高点，也创出更低的低点。多空双方在一根K线内都得到了机会，最终一方胜出，因此本图直接从该K线的实体读出胜方——阳性外包线做多，阴性外包线做空。随后由收盘价的简单移动平均线决定何时放手这笔交易。

![schema](schema.svg)

## 策略概览

- 外包线由基础方块搭成：转换方块读取已完成K线的最高价、最低价、开盘价和收盘价，两个前值方块保存前一根K线的最高价与最低价。
- 两个比较构成形态——高点高于前高、低点低于前低——两者必须同时成立。
- 方向取自K线自身的实体，而非趋势过滤：收盘高于开盘则买入，低于开盘则卖出。
- 简单移动平均线不参与入场，只作为离场线使用，与原始策略一致。

## 入场与出场规则

- **做多入场**: 该K线同时突破了前一根的两个极值，收盘价高于自身开盘价，且当前空仓。订单买入一手并开多。
- **做空入场**: 该K线同时突破了前一根的两个极值，收盘价低于自身开盘价，且当前空仓。订单卖出一手并开空。
- **离场**: K线收盘低于移动平均线即平多，收盘高于移动平均线即平空，两者都通过处于平仓模式的修改持仓方块完成，与原策略相同。没有止损也没有止盈，因为原代码里也没有。未能照搬的是原策略在每次入场和离场之后数百根K线的停顿：用方块搭出计数器必须把信号回接到图中，那会让数据流形成环路。因此这里每根外包线都会执行，成交次数明显更多。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SMA Length | 20 | 用于平仓的简单移动平均线周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。原策略基于1分钟K线，这里改用5分钟以匹配随附的历史数据。 |

## 图表详情

- K线方块分出五条支路：开盘价、最高价、最低价、收盘价四个转换方块，再加移动平均线。
- 最高价和最低价各自同时走两条路——直接进入比较方块，以及进入前值方块——于是比较把本根K线的极值与前一根的极值放在一起。
- 每个逻辑与汇集四个标志：更高的高点、更低的低点、实体方向，以及由持仓方块与零常量比较得到的持仓判断。
- 两个入场方块都发送市价单，数量取自同一个常量；两个离场方块直接由与均线的比较触发，只有在有持仓可平时才动作。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
