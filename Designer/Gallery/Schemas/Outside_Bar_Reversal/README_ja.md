# アウトサイドバー・リバーサル戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

アウトサイドバーとは、1本前の足の値幅をまるごと飲み込む足のことです。同じ1本の中で高値を更新し、安値も更新します。買い方も売り方も1本の足の中で機会を得て、どちらかが勝ったわけですから、このダイアグラムは勝者を足の実体そのものから読み取ります。陽線のアウトサイドバーは買い、陰線のアウトサイドバーは売りです。その後は終値の単純移動平均線が手放しどきを決めます。

![schema](schema.svg)

## 戦略の概要

- アウトサイドバーは基本ブロックだけで組み立てています。変換ブロックが確定足の高値・安値・始値・終値を取り出し、2つの前値ブロックが1本前の足の高値と安値を保持します。
- 形を決めるのは2つの比較、すなわち高値が前の高値より上、安値が前の安値より下であり、両方が同時に成り立つ必要があります。
- 方向はトレンドフィルターではなく足の実体から取ります。始値より高く引ければ買い、低く引ければ売りです。
- 単純移動平均線はエントリーに関与せず、エグジットのラインとしてのみ使われます。元の戦略と同じです。

## エントリーとエグジットの条件

- **ロングエントリー**: その足が1本前の高値と安値の両方を抜き、自身の始値より高く引け、かつポジションがゼロのとき。注文は1ロットを買い、買い建玉を作ります。
- **ショートエントリー**: その足が1本前の高値と安値の両方を抜き、自身の始値より低く引け、かつポジションがゼロのとき。注文は1ロットを売り、売り建玉を作ります。
- **エグジット**: 足が移動平均線を下回って引ければ買い建玉を、上回って引ければ売り建玉を、いずれもクローズモードのポジション変更ブロックで手仕舞います。ここは元の戦略と同じです。元のコードに損切りも利確もないため、ダイアグラムにもありません。省いたのは、元の戦略がエントリーとエグジットのたびに置く数百本の休止です。バーを数える仕組みはシグナルをダイアグラムに戻さないと作れず、それではグラフが循環してしまいます。そのためここではすべてのアウトサイドバーを執行し、売買回数は明らかに多くなります。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| SMA Length | 20 | 手仕舞いに使う単純移動平均の期間。 |
| Volume | 1 | 注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。元の戦略は1分足ですが、同梱の履歴データに合わせて5分足にしています。 |

## ダイアグラムの詳細

- ローソク足ブロックは5つの枝に分かれます。始値・高値・安値・終値の4つの変換ブロックと、移動平均線です。
- 高値と安値はそれぞれ同時に2方向へ進み、比較ブロックと前値ブロックの両方に入ります。こうして比較はこの足の極値を1本前の極値と突き合わせます。
- それぞれの論理積は4つのフラグを集めます。より高い高値、より低い安値、実体の向き、そしてポジションブロックとゼロ定数から作るポジション判定です。
- 2つのエントリーブロックは成行注文を出し、数量は共通の定数から取ります。2つのエグジットブロックは移動平均との比較から直接起動し、手仕舞う建玉があるときだけ動きます。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
