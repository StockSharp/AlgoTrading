# 三重 EMA 排列策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

三个周期差别很大的 ExponentialMovingAverage 方块使用同一批K线，它们的先后顺序被视为趋势。短周期在中周期之上、中周期在长周期之上即为上升；顺序相反即为下降。策略始终持仓，并用一笔订单完成反手。

![schema](schema.svg)

## 策略概览

- 只用价格：没有振荡指标，也没有波动率过滤，仅看三条指数均线的相对位置。
- 多头状态是短线在中线之上且中线在长线之上；空头状态是短线不高于中线且中线不高于长线。两者之间均线纠缠时不产生信号。
- 当前持仓约束每一次入场，因此持续数百根K线的排列也只会产生一笔订单。
- 没有单独的离场：订单数量等于基础数量加上持仓绝对值，一笔订单即可平掉旧方向并建立新方向。

## 入场与出场规则

- **做多入场**: 短周期 ExponentialMovingAverage 高于中周期，中周期高于长周期，且当前不是多头。订单买入「数量 + 持仓绝对值」：空仓时开多，持空时反手做多。
- **做空入场**: 短周期 ExponentialMovingAverage 不高于中周期，中周期不高于长周期，且当前不是空头。订单卖出「数量 + 持仓绝对值」：空仓时开空，持多时反手做空。
- **离场**: 没有专门的离场方块。只有出现相反排列才会离开持仓，而反手数量意味着该图不会有任何一根K线处于空仓状态。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Short EMA period | 100 | 最快的 ExponentialMovingAverage 周期。 |
| Middle EMA period | 250 | 中间的 ExponentialMovingAverage 周期。 |
| Long EMA period | 500 | 最慢的 ExponentialMovingAverage 周期。 |
| Volume | 1 | 基础下单数量（手）；反手时再加上持仓绝对值。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 一个K线方块供给全部三个指标方块，因此三条均线始终基于同一批已完成K线计算。
- 四个比较方块构成两种状态：多头排列使用两个严格“大于”比较，其空头取反使用两个“小于等于”比较。
- 每个逻辑与把两个均线比较与「持仓对比零常量」合并，并触发一个修改持仓方块。
- 一个公式方块把持仓绝对值加到数量常量上，再送给两个下单方块，正是它把入场变成了反手。
- 本图使用五分钟K线。持仓判断会在排列持续期间阻止重复入场，且图中没有绘制保护方块。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
