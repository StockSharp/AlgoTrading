# 最简 DeMarker 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

DeMarker 衡量每根K线相对前一根向上和向下延伸的幅度，输出 0 到 1 之间的数值。本图买的不是极值本身，而是从极值返回的过程：数值从超卖水平之下回升到该水平则买入，从超买水平之上回落到该水平则卖出。原策略使用小时K线并在两笔交易之间等待四根K线；本图改用五分钟K线并省去等待，因为持仓判断本身已经阻止同方向的重复入场。

![schema](schema.svg)

## 策略概览

- DeMarker 基于单一品种的已完成K线计算，取值始终在 0 与 1 之间，0.5 为中性中值。
- 前值方块保存上一根K线的读数，因此本图反应的是回到中性区间的动作，而不是停留在其中。
- 当前持仓参与两个判断：只有在持仓不是多头时才买入，只有在持仓不是空头时才卖出。
- 原策略的四根K线冷却没有复现；如需要，可以在不改动信号部分的前提下补上。

## 入场与出场规则

- **做多入场**: 上一根K线的 DeMarker 低于超卖水平，当前值等于或高于该水平，且持仓不是多头。订单买入一手：空仓时开多，持空时平空。
- **做空入场**: 上一根K线的 DeMarker 高于超买水平，当前值等于或低于该水平，且持仓不是空头。订单卖出一手：空仓时开空，持多时平多。
- **离场**: 与原策略一样，没有离场方块，也没有保护性止损：由于所有订单数量相同，反向信号即可把持仓归零。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| DeMarker Length | 14 | DeMarker 振荡器的平滑周期。 |
| Oversold | 0.2 | 超卖水平：自下方回到该水平即为买入信号。 |
| Overbought | 0.8 | 超买水平：自上方回到该水平即为卖出信号。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期；原策略为一小时。 |

## 图表详情

- K线方块把数据送入含 DeMarker 的指标方块，前值方块取同一输出向前一根K线。
- 四个比较方块组成两次回归：前值越过水平线，当前值回到水平线。
- 另外两个比较方块把持仓与零常量对比，每个逻辑与把三个条件合成一个信号。
- 两个修改持仓方块都发送市价单，数量取自同一个共享常量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
