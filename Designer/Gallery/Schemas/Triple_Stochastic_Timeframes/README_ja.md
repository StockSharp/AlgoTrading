# 3時間軸ストキャスティクス戦略図
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この図は、60分足、15分足、5分足で形成済みの Stochastic(5,3) モメンタムを組み合わせます。1時間ごとに3つの %K-%D 差を同期し、上位2時間軸と一致する5分足モメンタムの転換を取引します。

![schema](schema.svg)

## 戦略の概要

- 確定した3つのローソク足ストリームが60分、15分、5分のデータを供給し、より短い時間足から構築できます。
- 各ストリームで Stochastic %K(5) を計算し、SMA(3) で平滑化して %D を得た後、%K から %D を引きます。
- 時間足の差が3ストリームの最新値を採取し、各60分足の終了時に Sync が3値の完全な組を出力します。
- 同期済み5分足差の前回値でゼロラインの転換を検出し、現在ポジションで保有量を1単位以内に抑えます。
- 2つのアクションはいずれも1単位の成行操作で、Strategy trades が全約定をチャートへ送ります。

## エントリーとエグジットの条件

- **ロングエントリー**: 前回のエントリー差がゼロより大きく、現在値がゼロ以下で、上位2つの差がともに正、かつロングではないとき、成行で1単位買います。
- **ショートエントリー**: 前回のエントリー差がゼロより小さく、現在値がゼロ以上で、上位2つの差がともに負、かつショートではないとき、成行で1単位売ります。
- **エグジット**: 独立した決済分岐はありません。有効な反対方向の1単位アクションは、反対側の1単位ポジションをゼロまで閉じます。その後の有効なシグナルで別方向を建てられます。ストップロス、テイクプロフィット、待機期間はありません。

## ダイアグラムの詳細

- すべての指標は形成済みの値だけを出力します。SMA(3) は対応する %K を受け取るため、各差は %K からその3値平均を引いた値です。
- 時間足の差が3つの数値保持ブロックを起動してから値を Sync に渡すため、中間とエントリーの保持ブロックはその時点の最新値を提供します。
- Sync は完全な組ごとに内容を消去して3つの整列値を出力します。Previous value ブロックは、次の1時間比較に使う同期済みエントリー差を1つ保持します。
- ポジションは同期判断と同時に採取されます。ゼロ以下なら買い、ゼロ以上なら売りを許可し、同方向への積み増しを防ぎます。
- チャートは5ストリーム、すなわち5分足、3つの連続 %K-%D 差、全戦略約定を受信します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
