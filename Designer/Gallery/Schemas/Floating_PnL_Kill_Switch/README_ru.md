# Схема стратегии аварийного выхода по плавающему PnL
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Схема окружает входы по возврату CCI денежным аварийным контуром. Входы видны как лимитные заявки по закрытию часовой свечи; когда нереализованный результат достигает любой границы, схема снимает все рабочие заявки и выводит позицию в ноль по рынку.

![schema](schema.svg)

## Обзор стратегии

- Завершённые часовые свечи поступают в CommodityChannelIndex с периодом 30, а их закрытие задаёт цену лимитной заявки.
- Для лонга предыдущий CCI должен быть ниже −100, а текущий — вернуться к −100 или выше. Шорт зеркально возникает при возврате сверху через +100.
- Покупка разрешена при Position <= 0, продажа — при Position >= 0, поэтому встречный сигнал сокращает позицию, а не наращивает её в ту же сторону.
- Каждое исполнение сбрасывает кулдаун на четыре свечи. Ограниченный счётчик должен снова дойти до порога до следующего входа.
- Order registering выставляет лимитную заявку по закрытию завершённой свечи без округления рассчитанной цены.
- P&L change сравнивает нереализованный результат с +300 и −200. Любая граница запускает Mass order cancellation и Modify position с ClosePosition.

## Правила входа и выхода

- **Вход в лонг**: Предыдущий CCI был ниже −100, текущий не ниже −100, Position не является лонгом, и после последнего исполнения прошло четыре свечи. По текущему закрытию выставляется лимитная покупка.
- **Вход в шорт**: Предыдущий CCI был выше +100, текущий не выше +100, Position не является шортом, и кулдаун завершён. По текущему закрытию выставляется лимитная продажа.
- **Выход**: Ценовых тейка и стопа нет. При нереализованной прибыли 300 или убытке −200 аварийный контур запрашивает отмену всех рабочих заявок стратегии и одновременно отправляет рыночное действие ClosePosition.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Candle Time Frame | 01:00:00 | Таймфрейм завершённых свечей для CCI, кулдауна и цен лимитных заявок. |
| CCI Length | 30 | Число часовых значений в CommodityChannelIndex. |
| CCI Level | 100 | Абсолютный порог CCI, симметрично используемый как +Level и −Level. |
| Signal Cooldown, candles | 4 | Число завершённых свечей после последнего исполнения до разрешения новой сделки. |
| Order Volume | 1 | Объём каждой лимитной заявки на вход. |
| Target Profit, money | 300 | Нереализованная прибыль в валюте счёта, запускающая аварийную ликвидацию. |
| Cut Loss, money | -200 | Граница нереализованного убытка в валюте счёта; обычно отрицательная. |

## Детали диаграммы

- Previous value хранит предыдущее значение CCI, поэтому вход означает возврат через порог, а не повторяющееся пребывание в экстремальной зоне.
- Кулдаун начинается от реального исполнения стратегии, а не от сигнала или попытки регистрации; счётчик ограничен значением четыре.
- Лимитные входы по закрытию намеренно показывают жизненный цикл отложенной заявки. Она может остаться рабочей, и при ликвидации Mass order cancellation действительно есть что снимать.
- Цель и лимит убытка — абсолютные суммы нереализованного результата в валюте счёта. Это аварийная надстройка вокруг CCI, а не процентная защита цены.
- Массовая отмена действует на все заявки этой стратегии, поскольку входы Security и Portfolio не подключены. Затем Modify position закрывает оставшуюся сторону.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
