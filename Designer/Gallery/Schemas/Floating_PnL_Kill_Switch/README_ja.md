# 含み損益キルスイッチ戦略ダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

このダイアグラムはCCIの戻りシグナルに金額ベースの緊急層を加えます。エントリーは時間足終値の指値注文として表示され、含み損益がどちらかの境界に達すると、すべての稼働注文を取り消してから成行でポジションを閉じます。

![schema](schema.svg)

## 戦略の概要

- 確定1時間足が期間30のCommodityChannelIndexへ入り、終値が指値価格になります。
- ロングは前のCCIが−100未満、現在が−100以上へ戻ることを要求し、ショートは+100上方からの戻りを対称に扱います。
- 買いはPosition <= 0、売りはPosition >= 0でのみ許可され、反対シグナルは既存エクスポージャーを減らします。
- 各約定で4本のクールダウンをリセットし、上限付きカウンターが再び閾値に達するまで次の注文を止めます。
- Order registeringは確定足終値に、価格丸めなしで指値注文を置きます。
- P&L changeは含み損益を+300と−200に比較し、どちらもMass order cancellationとClosePositionを起動します。

## エントリーとエグジットの条件

- **ロングエントリー**: 前のCCIが−100未満、現在が−100以上、Positionがロングではなく、最新約定から確定足4本が経過すると、現在終値に買い指値を置きます。
- **ショートエントリー**: 前のCCIが+100超、現在が+100以下、Positionがショートではなく、クールダウン完了時に現在終値へ売り指値を置きます。
- **エグジット**: 価格ベースの利益確定やストップはありません。含み益300または含み損−200で、全稼働注文の取消を要求し、同時に成行ClosePositionを送ります。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candle Time Frame | 01:00:00 | CCI、クールダウン、指値価格に使う確定足の時間軸。 |
| CCI Length | 30 | CommodityChannelIndexに含める時間足値の数。 |
| CCI Level | 100 | +Levelと−Levelに対称利用するCCI絶対閾値。 |
| Signal Cooldown, candles | 4 | 最新約定後に必要な確定足の本数。 |
| Order Volume | 1 | 各指値エントリー注文の数量。 |
| Target Profit, money | 300 | 緊急清算を起動する口座通貨の含み益。 |
| Cut Loss, money | -200 | 口座通貨の含み損境界。通常は負値です。 |

## ダイアグラムの詳細

- Previous valueが前のCCIを保持するため、エントリーは極端領域での反復条件ではなく閾値への戻りです。
- クールダウンはシグナルや登録試行ではなく実約定から始まり、4で上限になります。
- 終値での指値入場は保留注文のライフサイクルを意図的に示し、清算時のMass order cancellationに実作業を与えます。
- 目標と損失境界は口座通貨の含み損益額で、CCIエンジンへの緊急追加層であり価格%保護ではありません。
- SecurityとPortfolioを指定しないため全戦略注文を取り消し、その後Modify positionが残る側を閉じます。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
