# Aroon Oscillator 变号提示策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Aroon Oscillator 判断最近若干根K线中的最高价与最低价谁更新近，并给出 -100 到 +100 之间的数值。本图交易的不是极值本身，而是离开极值的那一刻：数值回升到下限之上则买入，回落到上限之下则卖出。原策略使用四小时K线；本图改用五分钟K线，这样随附的一个月历史数据才有足够的K线产生交易。

![schema](schema.svg)

## 策略概览

- AroonOscillator 基于单一品种的已完成K线计算，取值在 -100 到 +100 之间波动。
- 前值方块保存上一根K线的读数，因此真正的穿越水平线与仅仅停留在水平线之上被区分开来。
- 两个方向刻意不对称：强势下行动能减弱时做多，强势上行动能减弱时做空。
- 当前持仓参与两个判断，因此订单绝不会为已有持仓加仓。

## 入场与出场规则

- **做多入场**: 上一根K线的 AroonOscillator 处于下限或更低，当前值高于下限，且持仓不是多头。订单买入一手：空仓时开多，持空时平空。
- **做空入场**: 上一根K线的 AroonOscillator 处于上限或更高，当前值低于上限，且持仓不是空头。订单卖出一手：空仓时开空，持多时平多。
- **离场**: 与原策略一样，没有离场方块，也没有保护性止损：由于所有订单数量相同，反向信号即可把持仓归零。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Aroon Length | 9 | Aroon Oscillator 回溯的K线数量。 |
| Down Level | -50 | 下限水平：自下向上穿越即为买入信号。 |
| Up Level | 50 | 上限水平：自上向下穿越即为卖出信号。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期；原策略为四小时。 |

## 图表详情

- K线方块把数据送入含 AroonOscillator 的指标方块，前值方块取同一输出向前一根K线。
- 四个比较方块组成两次穿越：前值与水平线比较，当前值与同一水平线比较。
- 另外两个比较方块把持仓与零常量对比，每个逻辑与把三个条件合成一个信号。
- 两个修改持仓方块都发送市价单，数量取自同一个共享常量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
