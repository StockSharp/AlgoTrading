# Quote Momentum Sync 戦略ダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

終値から次の終値へと測るモメンタム。本ダイアグラムは、確定したばかりのローソク足の終値を一つ前の終値と比較し、前のローソク足がすでに向かっていた方向へ、価格単位で一定量以上の値動きがあることを求めます。すべての値は同じ5分の拍子で取得されるため、基準価格・方向フィルター・ポジション確認は常に同期しており、異なる時点の値からシグナルが組み立てられることはありません。

![schema](schema.svg)

## 戦略の概要

- ダイアグラムが購読する市場データは、取引対象銘柄の確定した5分足のみであり、以降の処理はすべてその拍子で動きます。
- 前値（Previous value）は単一の数値ではなく直前のローソク足そのものを保持し、2つのコンバーターがそこから終値と始値を読み出します。
- この直前の終値が基準価格です。一方の式はそこにモメンタムステップを加算し、もう一方は同じステップを減算して、当該バーのロング用トリガー水準とショート用トリガー水準を与えます。
- 3つ目のコンバーターが確定したばかりのローソク足の終値を読み出し、2つの比較がそれを2つの水準と突き合わせます。
- 方向フィルターは直前のローソク足の形です。その終値を自らの始値と比べ、陽線ならロングのみ、陰線ならショートのみを許可します。
- ポジション（Position）ブロックをゼロと比較することで口座がノーポジションかどうかが分かり、既存のポジションに積み増すのではなく、保有中はダイアグラムが手を出さないようにします。
- 2つの論理条件が方向・モメンタム・ノーポジションを束ね、それぞれがポジション変更（Position modify）を駆動して、ノーポジションの状態からのみ固定数量の成行で新規建てを行います。
- ポジション保護（Position protection）は新規建ての約定と現在の終値を受け取り、固定率のテイクプロフィットまたはストップロスでトレードを手仕舞います。ダイアグラムに他の決済手段はありません。

## エントリーとエグジットの条件

- **ロングエントリー**: 直前のローソク足が自らの始値より上で引け、確定したばかりのローソク足が直前の終値にモメンタムステップを加えた水準より上で引け、かつポジションがノーポジションであること。ポジション変更（Position modify）が注文数量を成行で買います。
- **ショートエントリー**: 直前のローソク足が自らの始値より下で引け、確定したばかりのローソク足が直前の終値から同じステップを引いた水準より下で引け、かつポジションがノーポジションであること。ポジション変更（Position modify）が注文数量を成行で売ります。
- **エグジット**: ダイアグラムに決済シグナルはありません。新規建てが約定した時点から、そのトレードはポジション保護（Position protection）に委ねられ、建値から0.5%の利益または0.5%の損失で手仕舞われます。保護の価格はローソク足の終値を基準に算出されるため、水準の判定は1バーにつき1回です。またポジションを保有している間は逆方向の判定は無視され、次の新規建てはポジションが再びノーポジションになるまで待ちます。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candles | 00:05:00 | ダイアグラム全体が動作するローソク足系列のタイムフレーム。 |
| Momentum Step | 5 | エントリーが許可されるために、確定したローソク足が直前の終値から超えなければならない距離（価格単位）。 |
| Order Volume | 0.01 | 発注サイズ（ロット数）。 |
| Take Profit, % | 0.5 | テイクプロフィットまでの距離（建値に対する%）。 |
| Stop Loss, % | 0.5 | ストップロスまでの距離（建値に対する%）。 |

## ダイアグラムの詳細

- 前値（Previous value）は数値ではなくローソク足を保持するよう設定され、各フィールドはその後にコンバーターが読み出します。これによって基準価格と方向フィルターが同一のバーから得られます。
- エントリー条件は、しきい値との差分ではなく2つの価格水準として記述されています。これは同じ計算を反対側から見たものであり、どの水準が各エントリーを生んだのかをチャート上に示すことができます。
- どちらのエントリーブロックもノーポジションの状態からのみ建てるため、保有中にシグナルが繰り返し出ても影響はなく、ドテンや積み増しのための発注は行われません。
- すべての定数はローソク足系列によってトリガーされるため、バーごとに値を出力します。発火しない定数があると、その比較に第2オペランドが渡されず、条件は決して組み上がりません。
- モメンタムステップは価格そのものの単位で表した絶対的な距離であり、パーセンテージではありません。そのため価格の桁が異なる銘柄では設定し直す必要があります。一方、テイクプロフィットとストップロスはパーセンテージなので、そのまま引き継げます。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
