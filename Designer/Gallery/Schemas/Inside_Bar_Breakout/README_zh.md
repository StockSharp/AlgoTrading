# 内包线突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

内包线是整个波动区间都落在前一根K线区间之内的K线：多空双方都停止发力，行情被压缩。本图等待紧接着的那根K线走出该区间，并顺着突破方向入场，随后由简单移动平均线接管这笔交易，决定行情何时结束。

![schema](schema.svg)

## 策略概览

- 两个K线形态方块各带一条三根K线的公式：不受约束的第一根、严格包含其中的内包线，以及突破K线。
- 做多公式要求突破K线的最高价高于内包线的最高价，做空公式要求其最低价低于内包线的最低价。
- 收盘价的简单移动平均线是唯一的指标：它不参与入场，只作为离场线使用。
- 持仓判断确保只有空仓时才执行突破，因此一个形态只产生一笔交易。

## 入场与出场规则

- **做多入场**: K线形态方块报告出现了内包线，且其最高价刚被下一根K线突破，同时持仓为零。订单买入一手并开多。
- **做空入场**: K线形态方块报告出现了内包线，且其最低价刚被下一根K线跌破，同时持仓为零。订单卖出一手并开空。
- **离场**: 当K线收盘低于移动平均线时平多，收盘高于移动平均线时平空，两者都通过处于平仓模式的修改持仓方块完成，与原始策略一致。无法照搬的是原策略的无限等待：那里会记住内包线的极值，多少根K线之后的突破都算数，而这里形态方块只看固定长度的窗口，所以突破必须出现在内包线之后的那一根K线上。这是该形态最常见的情形，但迟到的突破会丢失。原策略两笔交易之间数百根K线的停顿同样没有对应方块，已被省略。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SMA Length | 20 | 用于平仓的简单移动平均线周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时给两个形态方块、移动平均线以及从K线中取出收盘价的转换方块供数。
- 每个形态方块含三条公式，对应形态中的每一根K线，只有在完成突破的那根K线上才输出真。
- 持仓方块与零常量比较，每个逻辑与把该保护与两个突破信号之一合并。
- 两个入场方块都发送市价单，数量取自同一个常量；两个离场方块直接由移动平均线比较触发，只有在有持仓可平时才动作。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
