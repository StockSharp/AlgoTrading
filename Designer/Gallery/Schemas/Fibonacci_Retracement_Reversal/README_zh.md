# 斐波那契回撤反转策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

最近二十根K线的摆动区间按黄金比例切分，得到的两个回撤位被当作反转区。收盘落在下方水平且为阳线时买入，收盘落在上方水平且为阴线时卖出，离场由 SimpleMovingAverage 决定。

![schema](schema.svg)

## 策略概览

- Highest 与 Lowest 使用同一窗口，给出摆动高点与低点，两者之差就是衡量水平位的区间。
- 买入位在摆动高点下方 0.618 个区间处，卖出位在摆动低点上方 0.618 个区间处；只要收盘价与水平位的距离小于区间的百分之二，就算站在该水平位上。
- 两个距离都按区间的比例计算，因此该图在任何品种和任何价格量级上表现一致。
- 入场还需要方向一致的K线实体和空仓状态；所有离场都交给 SimpleMovingAverage，因为原策略既无止损也无止盈。

## 入场与出场规则

- **做多入场**: 收盘价落在下方回撤位的缓冲区内，K线为阳线（收盘高于开盘），且当前空仓。方块买入一手并开多。
- **做空入场**: 收盘价落在上方回撤位的缓冲区内，K线为阴线（收盘低于开盘），且当前空仓。方块卖出一手并开空。
- **离场**: 只要某根K线收在 SimpleMovingAverage 之下就平掉多头，收在其上就平掉空头；两个离场方块都处于平仓模式，只有确有持仓时才会触发。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Swing lookback | 20 | 计算摆动高点与低点所用的K线数量。 |
| MA period | 20 | 作为离场基准的 SimpleMovingAverage 周期。 |
| Fibonacci ratio | 0.618 | 把两个水平位放进摆动区间的回撤比例。 |
| Level buffer | 0.02 | 水平位两侧入场区的半宽，以摆动区间的比例表示。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 一个K线方块同时供给 Highest、Lowest 和 SimpleMovingAverage，另外还有两个转换器取出收盘价与开盘价。
- 两个公式方块把价格换算成收盘价到各水平位的距离并除以区间，于是一个缓冲常量即可服务两侧。
- 每个入场都经过三个标志的逻辑与：水平位、K线实体，以及与零常量比较后的持仓。
- 两个离场方块直接由与移动平均的比较触发，并设为平仓模式；四个下单方块共用同一个数量常量。
- 有意的简化：原策略使用1分钟K线，并在每笔交易后停顿500根K线，这一点无法用方块表达，因此本图使用5分钟K线，条件重新满足即再次交易。持仓会是数根K线而非数天；调大均线周期可以延长持仓。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
