# ボリンジャー・リバージョン戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

ボリンジャーバンドの外での終値は、まもなく戻される行き過ぎとみなします。下バンドを下回れば買い、上バンドを上回れば売り、価格が中央線に戻るまでだけポジションを保有します。同じバンドを使うブレイクアウト型のダイアグラムとは逆に、値動きに逆らって入り、反対側のバンドではなく中央線を目標にします。

![schema](schema.svg)

## 戦略の概要

- BollingerBands は一度だけ計算され、上バンド・下バンド・中央の移動平均という3つの値として読み出されます。
- エントリーはノーポジションのときだけ行うため、バンドの外での終値が続いても既存のポジションには積み増しません。
- エグジットはエントリーと対称で、中央線が目標となり、手仕舞いブロックは保有ポジションと同じ数量を送ります。
- バンド幅と期間をパラメーターとして公開しているので、同じダイアグラムで値動きの穏やかな銘柄にも荒い銘柄にも対応できます。

## エントリーとエグジットの条件

- **ロングエントリー**: ローソク足が下バンドより下で引け、ポジションがゼロのとき。注文は基準数量を買い、値動きに逆らって買いポジションを建てます。
- **ショートエントリー**: ローソク足が上バンドより上で引け、ポジションがゼロのとき。注文は基準数量を売り、値動きに逆らって売りポジションを建てます。
- **エグジット**: 買いポジションは中央線以上で引けた最初の足で、売りポジションは中央線以下で引けた最初の足で手仕舞います。損切りも利食いもありません。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Bollinger Period | 20 | ボリンジャーバンドの平滑化期間。 |
| Bollinger Width | 2 | 標準偏差で表したバンド幅。 |
| Volume | 1 | 注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラムが使用する5分足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが指標と終値の変換ブロックを動かし、さらに3つの変換ブロックが指標値からバンドと中央線を取り出します。
- 4つの比較ブロックが終値を信号に変えます。下バンドの外、上バンドの外、下から中央線への復帰、上から中央線への復帰です。
- ポジションブロックはゼロとの比較3つに繋がり、2つのエントリーと2つのエグジットを守ります。
- エントリー側のブロックは新規建て条件で1つの数量定数を共有し、エグジット側のブロックは手仕舞い条件でポジションそのものから数量を決めます。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
