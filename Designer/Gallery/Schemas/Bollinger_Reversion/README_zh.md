# 布林带回归策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

收盘价落在布林带之外被视为即将回吐的拉伸：该图在下轨之下买入、在上轨之上卖出，并且只把仓位持有到价格重新触及中轨为止。与同样基于布林带的突破图不同，这里逆势入场，目标是中轨而不是对面的轨道。

![schema](schema.svg)

## 策略概览

- BollingerBands 只计算一次，被读取三次：上轨、下轨和中间的移动平均。
- 只有空仓时才会入场，因此连续多根收在带外的K线不会追加已有仓位。
- 离场与入场对称：中轨即目标，平仓方块发送的数量恰好等于当前持仓。
- 带宽和周期都作为参数暴露，因此同一张图既适用于平静的品种，也适用于波动大的品种。

## 入场与出场规则

- **做多入场**: K线收在下轨之下，且当前空仓。订单按基础数量买入，逆势建立多头。
- **做空入场**: K线收在上轨之上，且当前空仓。订单按基础数量卖出，逆势建立空头。
- **离场**: 多头在首次收于中轨或其上方时平仓，空头在首次收于中轨或其下方时平仓。原始策略没有止损止盈；五百根K线的暂停和每笔三百根K线的持有上限都未移植，而且由于暂停时间长于持有上限，源码中每笔交易实际上都是按时间平仓的，回归中轨的离场从未真正触发。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Bollinger Period | 20 | 布林带的平滑周期。 |
| Bollinger Width | 2 | 以标准差表示的带宽。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | K线周期：原始策略使用1分钟K线，本图使用5分钟K线。 |

## 图表详情

- K线方块驱动指标和收盘价转换方块，另外三个转换方块从指标值中取出上下轨与中轨。
- 四个比较方块把收盘价变成信号：跌破下轨、突破上轨、自下方回到中轨、自上方回到中轨。
- 持仓方块驱动三个与零的比较，用于守护两个入场和两个离场。
- 入场方块使用开仓条件并共享一个数量常量，离场方块使用平仓条件并直接按持仓确定数量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
