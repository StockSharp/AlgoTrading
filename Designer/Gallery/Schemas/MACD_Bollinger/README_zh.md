# MACD 与布林中轨策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

两个最常见的指标各司其职：MACD 决定站在市场哪一边，布林中轨判断价格何时偏离合理值足够远、可以便宜地站到那一边。上下轨被有意舍弃——原策略买的是跌破中轨的回调，而不是通道突破。

![schema](schema.svg)

## 策略概览

- 唯一的趋势过滤器是 MACD 线相对信号线的位置：在上方只做多，等于或低于则只做空。
- 入场价必须与布林中轨相差千分之一，并且方向与趋势相反：上升趋势买入下探，下降趋势卖出冲高。
- 该间隙按轨道数值的比例给出，而不是固定点数，因此该图适用于任何品种。
- 离场完全不等价格：只要 MACD 两条线互换位置，持仓就被平掉。

## 入场与出场规则

- **做多入场**: MACD 线在信号线上方，K线收盘价低于布林中轨减去间隙，且当前不是多头。订单买入一手：空仓时开多，持空时平空。
- **做空入场**: MACD 线等于或低于信号线，K线收盘价高于布林中轨加上间隙，且当前不是空头。订单卖出一手：空仓时开空，持多时平多。
- **离场**: MACD 线跌到信号线或其下方即平多，升到信号线之上即平空；两个离场方块都处于平仓模式，只有确有持仓时才动作。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| MACD fast period | 12 | MACD 内部快速移动平均的周期。 |
| MACD slow period | 26 | MACD 内部慢速移动平均的周期。 |
| MACD signal period | 9 | MACD 信号线的周期。 |
| Bollinger period | 20 | BollingerBands 的平滑周期；只读取它的中轨。 |
| Bollinger width | 2.0 | BollingerBands 的标准差倍数；因为上下轨未被使用，所以不影响规则。 |
| Middle band gap | 0.001 | 入场价需要偏离中轨的距离，以轨道数值的比例表示。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 一个K线方块供给 MACD、BollingerBands 和收盘价转换器；另外三个转换器从指标值中取出 MACD 线、信号线和中轨。
- 一个间隙常量加两个公式方块把中轨变成买入位和卖出位，因此一个外露参数即可同时移动两个阈值。
- 每个入场都是三个标志的逻辑与：MACD 比较、轨道比较，以及与零常量比较后的持仓。
- 两个离场方块直接挂在 MACD 比较之后并处于平仓模式；四个下单方块的数量都取自同一个常量。
- 有意的简化：原策略还订阅了一个从未使用的 AverageTrueRange，因此没有绘制 ATR 方块；它在成交后还会禁止入场100根K线，这一点无法用方块表达——本图在条件重新满足时即会再次入场。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
