# CCI戻りの保留注文ストラテジー・ダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

このダイアグラムはCCIが極端領域から戻る動きを、短寿命の指値注文で取引します。実行価格はLevel 1のBid/Askではなく確定足終値を使うため、それらのフィールドがなくても再現できます。

![schema](schema.svg)

## 戦略の概要

- 1時間足がCCI(30)へ入り、Previous valueが−100下方からの戻りと+100上方からの戻りを判定します。
- Position方向、約定後4本のクールダウン、共通の保留注文ラッチが両側を制限します。
- Order registeringは終値に価格丸めなしで1件の指値注文を置きます。
- 登録OrderがN valuesを起動し、ローソク足を数え、4本後に未約定ならOrder cancellationが取り消します。

## エントリーとエグジットの条件

- **ロングエントリー**: 前CCI <= −100、現在 > −100、Positionがロングでなく、クールダウン済みで保留注文がないとき、終値に買い指値を置きます。
- **ショートエントリー**: 前CCI >= +100、現在 < +100、Positionがショートでなく、クールダウン済みで保留注文がないとき、終値に売り指値を置きます。
- **エグジット**: 固定ストップや目標はありません。反対のCCI戻りによる注文がPositionをゼロへ近づけます。寿命内に約定しない注文は取り消されます。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candle Time Frame | 01:00:00 | CCI、クールダウン、注文価格、寿命に使う足種。 |
| CCI Length | 30 | CommodityChannelIndexの値数。 |
| CCI Level | 100 | +Levelと−Levelの対称な極端境界。 |
| Signal Cooldown, candles | 4 | 最新約定後に必要な確定足数。 |
| Order Volume | 1 | 各保留指値注文の数量。 |
| Pending Lifetime, candles | 4 | 未約定注文が有効でいられる最大確定足数。 |

## ダイアグラムの詳細

- フォルダー名はギャラリー上の位置名を保ちますが、Level 1は未接続で、closeを明示的な再生可能価格にします。
- 実際に登録されたOrderが保留状態を設定し、Finishedが約定・取消・失敗時に解除します。
- クールダウンと注文寿命は別の設定で、前者は約定後、後者は未約定注文を測ります。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
