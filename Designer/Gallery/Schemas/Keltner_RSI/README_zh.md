# Keltner RSI 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这是一张围绕肯特纳通道中轴线构建的均值回归图。价格跌破 EMA 且 RSI 偏弱时买入，价格站上 EMA 且 RSI 偏强时卖出；当价格重新穿越均线且 RSI 越过中位数时了结持仓。原始策略计算了 ATR 通道带却从未读取，因此本图省略它们，只保留真正决定交易的部分。

![schema](schema.svg)

## 策略概览

- 20 周期 ExponentialMovingAverage 是肯特纳通道的中轴线，也是整张图唯一的价格参照。
- 14 周期 RSI 提供第二重判断：低于 45 印证了被买入的抛售，高于 55 印证了被卖出的推升。
- 两个入场都要求空仓，两个离场都使用平仓方块，因此四条分支不会争夺同一笔持仓。
- 相对原版有两处简化：未被使用的 ATR 通道带被去掉；每次成交后 120 根K线的冷却没有计数方块，因此本图交易更频繁。

## 入场与出场规则

- **做多入场**: 收盘价低于 EMA，RSI 低于做多入场水平，且持仓为零。订单按市价买入共享数量并开多。
- **做空入场**: 收盘价高于 EMA，RSI 高于做空入场水平，且持仓为零。订单按市价卖出共享数量并开空。
- **离场**: 当收盘价重回 EMA 上方且 RSI 高于中位数时平掉多头；当收盘价重回 EMA 下方且 RSI 低于中位数时平掉空头。与原始代码一样没有止损和止盈——代码中声明的止损百分比从未被使用。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| EMA Length | 20 | 作为通道中轴线的 ExponentialMovingAverage 周期。 |
| RSI Length | 14 | RelativeStrengthIndex 的平滑周期。 |
| RSI Long Entry | 45 | 做多入场要求 RSI 低于该水平。 |
| RSI Short Entry | 55 | 做空入场要求 RSI 高于该水平。 |
| RSI Exit Level | 50 | 平仓时 RSI 需要越过的中位水平。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时喂给 EMA、RSI 以及提取收盘价的转换方块。
- 两个比较方块把收盘价与 EMA 对比，另外四个把 RSI 与三个水平对比，持仓方块则与零常量比较。
- 两个逻辑与用价格条件、RSI 条件和空仓判断组成入场，驱动设为开仓的修改持仓方块。
- 另外两个逻辑与组成离场，驱动设为平仓的修改持仓方块：它们无需数量，且各自只处理自己能平掉的一侧。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
