# Схема стратегии Paired Bar Direction
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Два инструмента, один бар. Схема считывает направление одной и той же пятиминутной свечи на торгуемом инструменте и на втором, эталонном, и покупает только там, где они расходятся: эталонный бар закрылся ростом, а торгуемый — снижением. Позиция отдаётся обратно, как только цена закрывается выше максимума предыдущего бара.

![schema](schema.svg)

## Обзор стратегии

- Схему питают два блока свечей. Торгуемый работает на собственном инструменте стратегии, эталонный наведён на заданный инструмент переменной Security, поэтому пара задаётся настройкой, а не схемой связей.
- Обе серии настроены только на завершённые свечи, поэтому незавершённый бар никогда не влияет на решение.
- Sync держит по одной линии на инструмент и выпускает обе свечи вместе по пятиминутному такту. Два потока приходят независимо, и только после такого удержания обе свечи относятся к одному и тому же бару — а именно это и делает их сравнение осмысленным.
- Конвертеры извлекают открытие и закрытие из каждой выпущенной свечи, сводя каждый инструмент к двум числам, которые говорят, куда пошёл его бар.
- Два сравнения читают эти числа: закрытие эталона выше его открытия означает, что эталонный бар закрылся ростом; закрытие торгуемого ниже его открытия означает, что торгуемый бар закрылся снижением.
- Previous value хранит торгуемую свечу на шаг назад, а конвертер читает из неё максимум. Блок хранит саму свечу, и поле читается уже после — такой порядок даёт значение на каждом баре.
- Позиция привязывается к бару переменной, которая выдаёт значение по триггеру свечи, а затем дважды сравнивается с нулём: значение меньше или равно нулю допускает вход, больше нуля — выход.
- Два логических элемента AND управляют двумя блоками Position modify — один открывает с условием Open position, другой закрывает с Close position, — а панель графика показывает торгуемые свечи, уровень выхода, заявки и сделки.

## Правила входа и выхода

- **Вход в лонг**: На выпущенном баре эталонный инструмент закрылся выше собственного открытия, торгуемый — ниже собственного открытия, а позиция меньше или равна нулю. Логический элемент AND срабатывает, и Position modify покупает объём заявки по рынку с условием Open position, поэтому бар, повторяющий тот же расклад при уже открытой позиции, ничего не добавляет.
- **Вход в шорт**: Короткой стороны нет. Схема работает только в лонг: нисходящий бар на торгуемом инструменте читается как скидка для покупки, но никогда как повод продавать.
- **Выход**: Пока позиция больше нуля, выпущенный бар с закрытием выше максимума предыдущего бара запускает выходной логический элемент, и второй Position modify закрывает по рынку с условием Close position. Ни стоп-лосса, ни тейк-профита нет: максимум предыдущего бара — это всё правило выхода, а поскольку блок закрывает открытое, а не продаёт фиксированный размер, выход не может перевернуть позицию в шорт.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Reference Instrument | TONUSDT@BNBFT | Инструмент, направление бара которого подтверждает вход; он должен быть доступен от подключения наравне с торгуемым. |
| Reference Candles | 00:05:00 | Таймфрейм эталонных свечей. |
| Traded Candles | 00:05:00 | Таймфрейм торгуемых свечей. |
| Sync Interval | 00:05:00 | Такт, по которому Sync выпускает оба инструмента; держите его равным таймфрейму свечей, иначе выпущенная пара — не тот бар, который предполагают сравнения. |
| Order Volume | 1 | Размер заявки, в лотах. |

## Детали диаграммы

- Оба блока Position modify настроены так, чтобы не требовать онлайн-подключения, поэтому одна и та же схема одинаково ведёт себя и на истории, и на живом потоке.
- Вход намеренно несёт условие Open position. Без него блок отрабатывал бы каждое изменение позиции, через которое он срабатывает, и один сигнал превратился бы в поток заявок.
- Каждая константа в схеме — ноль и объём заявки — запускается выпущенной свечой. Переменная выдаёт значение по своему триггеру, а не по собственному значению, поэтому незапущенная константа оставила бы соседние сравнения немыми на весь прогон.
- Оба конца каждой линии Sync подключены. Значение, отправленное в блок и не забранное из него, оставляет его в ожидании линии, которая никогда не закроется, и стратегия вообще не стартует.
- Уровень выхода рисуется на графике отдельной линией, поэтому бар, закрывшийся выше него, читается прямо с панели рядом с последовавшей сделкой.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
