# EMA 交叉配合 RSI 与 MACD 的短线策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这是一套不轻信交叉的短线趋势策略。快线 EMA 上穿或下穿慢线只是扳机；在下单之前，价格还必须位于一条慢得多的趋势 EMA 的正确一侧，RSI 必须处在工作区间之内而非极端位置，MACD 线也必须仍朝交易方向移动。每一笔持仓都交给止损与止盈保护，因此短线仓位不会无限期挂着。

![schema](schema.svg)

## 策略概览

- 三条指数移动平均线分工不同：快慢一对负责发出信号，长周期那条决定究竟允许做哪一边。
- 交叉方块只在快线换边的瞬间触发，因此同一段趋势不会产生连续入场。
- RSI 在这里是极端值过滤器而非信号：只有当指数停留在上下边界之间时交叉才被接受，从而避开已经走完的行情。
- MACD 线与自己一根K线之前的值比较，因此动能必须与交叉方向一致，而不是仅仅存在。
- 持仓判断意味着入场只能开仓，绝不会加仓。

## 入场与出场规则

- **做多入场**: 快线 EMA 上穿慢线 EMA，K线收于趋势 EMA 之上，RSI 位于上下边界之间，MACD 线高于一根K线之前，且持仓为零。订单按市价买入共享数量。
- **做空入场**: 快线 EMA 下穿慢线 EMA，K线收于趋势 EMA 之下，RSI 位于上下边界之间，MACD 线低于一根K线之前，且持仓为零。订单按市价卖出共享数量。
- **离场**: 持仓保护方块以成交价为基准，用百分比止损或止盈了结每一笔交易。原策略把两个价位都按真实波幅均值来算，止损为两倍 ATR，止盈为风险的两倍，但保护方块只接受固定值，因此在本品种上用同一量级的百分比替代了 ATR 距离；若要恢复动态计算，就得在图中重算价位并手工发单。另有两点被舍弃：每次交易后停歇十根K线，没有方块能跨K线计数；以及反向信号翻仓，这里由止损与止盈结束交易。原策略运行在三十分钟K线上，本图使用随附历史数据的五分钟K线。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Fast EMA Length | 12 | 产生交叉的快速指数移动平均线周期。 |
| Slow EMA Length | 26 | 与快线交叉的慢速指数移动平均线周期。 |
| Trend EMA Length | 55 | 决定允许做哪一边的趋势指数移动平均线周期。 |
| RSI Length | 14 | 相对强弱指数的平滑周期。 |
| RSI floor | 35 | RSI 区间的下边界；低于它则认为行情已经走完。 |
| RSI ceiling | 65 | RSI 区间的上边界；高于它则认为过热。 |
| Take profit, % | 1 | 止盈相对成交价的距离，以百分比计。 |
| Stop loss, % | 0.5 | 止损相对成交价的距离，以百分比计。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动全部五个指标以及读取收盘价的转换方块；MACD 使用与 EMA 组合相同的十二和二十六周期。
- 交叉方块的上输入接快线、下输入接慢线，一个逻辑非把同一个输出变成做空所需的下穿信号。
- RSI 区间由两个与常量的比较组成，两个入场条件共用；MACD 动能判断把该线与一根K线之前的历史值方块相比。
- 每个逻辑与汇集交叉、趋势方位、RSI 的两个边界、动能判断和空仓判断，然后触发从共享常量取数量的入场方块。
- 两个入场方块都把自己的成交送入持仓保护方块，正是它负责平仓。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
