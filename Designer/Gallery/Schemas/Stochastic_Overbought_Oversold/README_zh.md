# 随机指标超买超卖策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

随机指标的 %K 线衡量收盘价在最近高低区间中的位置，本图正是在区间两端做反向操作。关键在于 %K 进入区域的那一刻，而不是它停留在区域内的整段时间，因此用一个前值方块把水平判断变成水平穿越，一个信号只产生一张订单。

![schema](schema.svg)

## 策略概览

- %K 线基于单一品种的已完成K线计算；平滑后的 %D 线不参与决策，这与原始策略一致。
- 三根K线的窗口使 %K 非常敏感，能频繁触及两个区域，本例的交易次数正来源于此。
- 超卖与超买水平在图中是常量，可以修改和优化；原始代码中它们被固定为 20 和 80。
- 所有订单数量相同，因此逆向信号只会平掉现有持仓，而不会反手加大仓位。

## 入场与出场规则

- **做多入场**: 前一根K线的 %K 等于或高于超卖水平，当前值低于该水平，且持仓不是多头。订单买入一手：空仓时开多，持空时平空。
- **做空入场**: 前一根K线的 %K 等于或低于超买水平，当前值高于该水平，且持仓不是空头。订单卖出一手：空仓时开空，持多时平多。
- **离场**: 没有单独的离场方块：由于所有订单数量相同，反向的水平穿越即可平仓。原始策略在成交后还会暂停固定数量的K线；图中没有计数K线的方块，因此由水平穿越承担这一职责，避免在区域内的每根K线上重复下单。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| %K Length | 3 | 计算 %K 时所用的最高价与最低价窗口长度。 |
| Oversold | 20 | %K 线向下穿越即产生买入的水平。 |
| Overbought | 80 | %K 线向上穿越即产生卖出的水平。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块把数据送入 %K 指标方块，其输出同时进入比较方块和前值方块。
- 四个比较方块构成两次穿越：前值与水平、当前值与同一水平。
- 持仓方块两次与零常量比较，为买入侧给出“非多头”判断，为卖出侧给出“非空头”判断。
- 每个逻辑与把穿越的两个部分与持仓判断合并，触发修改持仓方块；两个方块的数量取自同一个常量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
