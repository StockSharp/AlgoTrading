# 均线交叉策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这是最古老的趋势图：快速指数移动平均线对慢速指数移动平均线，两者每次交叉都会把持仓反向。保护方块补上了交叉本身给不了的东西——按百分比设置的止损，在行情走反时平掉持仓。

![schema](schema.svg)

## 策略概览

- 快慢两条指数移动平均线基于单一品种的已完成K线计算。
- 交叉方块只在快线真正穿越慢线的那根K线上输出，穿越方向区分做多与做空。
- 持仓保护方块盯住每根已完成K线的收盘价，一旦价格偏离入场价达到设定百分比即平仓。

## 入场与出场规则

- **做多入场**: 快速 EMA 上穿慢速 EMA，且持仓尚未做多。订单买入 Volume 加上当前持仓的绝对值：空仓时开多，持空时直接反手做多。
- **做空入场**: 快速 EMA 下穿慢速 EMA，且持仓尚未做空。订单卖出 Volume 加上当前持仓的绝对值：空仓时开空，持多时直接反手做空。
- **离场**: 要么反向交叉用一笔订单完成反手，要么在K线收盘价比平均入场价差出设定百分比时由保护性止损平仓。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Fast EMA length | 20 | 快速指数移动平均线的周期。 |
| Slow EMA length | 80 | 慢速指数移动平均线的周期。 |
| Stop loss, % | 2 | 保护性止损与入场价的距离（百分比）。 |
| Volume | 1 | 基础下单数量（手）；反手时会加上当前持仓。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动两个指标方块，它们的输出在交叉方块中汇合。
- 交叉输出是做多信号，对它取逻辑非即为做空信号，各自再与持仓和零的比较做逻辑与。
- 公式方块计算 Volume 加持仓绝对值，送入两个修改持仓方块的数量输入，因此一笔市价单即可反手。
- 两个修改持仓方块把各自的成交送入保护方块，转换方块把每根已完成K线的收盘价送到它的价格输入，所以止损在K线收盘时判断。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
