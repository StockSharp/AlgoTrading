# 线性回归通道策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

对最近五十根K线的收盘价做最小二乘拟合，再按回归标准误差的若干倍在直线两侧画出通道。价格跑到通道之外被视为走势过度延伸，只要通道斜率站在自己这一边，策略就做反向交易，等待价格回到直线。

![schema](schema.svg)

## 策略概览

- LinearReg 给出当前K线上的拟合直线值，LinearRegSlope 给出方向，StandardError 衡量收盘价围绕直线的常见离散程度。
- 上下轨为直线加减「偏差倍数 × 标准误差」，因此通道会随行情自动放宽或收窄。
- 斜率充当过滤器：只有在上升通道里才买跌破，只有在下降通道里才卖突破。
- 回归线就是获利目标；与原策略一致，没有止损也没有止盈。

## 入场与出场规则

- **做多入场**: 回归斜率大于零，收盘价低于下轨，且当前空仓。买单开一手多单。
- **做空入场**: 回归斜率小于零，收盘价高于上轨，且当前空仓。卖单开一手空单。
- **离场**: 收盘价自下方回到回归线即平多，自上方回到回归线即平空。两个离场方块均为平仓模式，没有持仓时不会动作。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| LinearReg Length | 50 | 拟合回归直线所用的K线数量。 |
| LinearRegSlope Length | 50 | 计算斜率所用的K线数量，建议与直线长度一致。 |
| StandardError Length | 50 | 计算标准误差所用的K线数量，建议与直线长度一致。 |
| Channel Deviation | 1.5 | 通道半宽，以回归标准误差为单位。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 一个K线方块驱动三个指标方块和一个收盘价转换方块，因此图中所有数值都来自同一根已完成K线。
- 两个公式方块用直线、标准误差和一个可优化的公共偏差常量构建上下轨。
- 六个比较方块把这些数值变成标志位：两个判斜率，两个判轨道，两个判回归线。
- 每个入场都是斜率、轨道与空仓三者的逻辑与；离场则由对应的比较方块直接接到平仓方块。
- 原策略在两次交易之间等待二十根K线，并按整个窗口计算离散度，而 StandardError 除以窗口长度减二，使通道约宽百分之二；若想还原原始宽度，可把偏差调到约 1.47。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
