# Диаграмма стратегии канала линейной регрессии
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

По последним пятидесяти закрытиям строится прямая методом наименьших квадратов, а вокруг неё откладывается канал шириной в несколько стандартных ошибок регрессии. Цена за пределами канала считается перерастянутым движением, и стратегия возвращает её к линии, пока наклон канала на её стороне.

![schema](schema.svg)

## Обзор стратегии

- LinearReg даёт значение подогнанной прямой на текущем баре, LinearRegSlope — её направление, StandardError — обычный разброс закрытий вокруг неё.
- Границы канала — это линия плюс и минус множитель отклонения, умноженный на стандартную ошибку, поэтому канал сам расширяется и сужается вслед за рынком.
- Наклон работает фильтром: провал покупается только в растущем канале, выброс продаётся только в падающем.
- Целью служит сама линия регрессии; ни стоп-лосса, ни тейк-профита нет — ровно как в исходной стратегии.

## Правила входа и выхода

- **Вход в лонг**: Наклон регрессии больше нуля, закрытие ниже нижней границы, позиция нулевая. Заявка на покупку открывает лонг в один лот.
- **Вход в шорт**: Наклон регрессии меньше нуля, закрытие выше верхней границы, позиция нулевая. Заявка на продажу открывает шорт в один лот.
- **Выход**: Лонг закрывается, как только закрытие снизу дотягивается до линии регрессии, шорт — как только оно дотягивается до неё сверху. Оба кубика выхода работают в режиме закрытия позиции и вхолостую не срабатывают.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| LinearReg Length | 50 | Число свечей, по которым строится линия регрессии. |
| LinearRegSlope Length | 50 | Число свечей для расчёта наклона; держите его равным длине линии. |
| StandardError Length | 50 | Число свечей для расчёта стандартной ошибки; держите его равным длине линии. |
| Channel Deviation | 1.5 | Полуширина канала в стандартных ошибках регрессии. |
| Volume | 1 | Объём заявки в лотах. |
| Candles | 00:05:00 | Таймфрейм свечей, на котором работает вся диаграмма. |

## Детали диаграммы

- Один кубик свечей питает три индикатора и конвертер цены закрытия, поэтому все значения схемы берутся из одной и той же завершённой свечи.
- Два кубика формул собирают границы из линии, стандартной ошибки и общей константы отклонения, которую можно оптимизировать.
- Шесть кубиков сравнения превращают числа в флаги: два по наклону, два по границам и два по возврату к линии.
- Каждый вход — логическое И из наклона, границы и нулевой позиции; выходы идут напрямую от своего сравнения к кубику закрытия позиции.
- Исходная стратегия выдерживает двадцать баров между сделками и считает отклонение по всему окну, тогда как StandardError делит на размер окна минус два, из-за чего канал примерно на два процента шире; чтобы получить исходную ширину, поставьте отклонение около 1.47.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
