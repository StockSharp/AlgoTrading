# RSI 買われすぎ・売られすぎ戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

教科書的な平均回帰のダイアグラムです。相対力指数が直近の値動きの行き過ぎを測り、指数が極端な水準に達したところで逆方向に仕掛けます。ポジションの判定により、同じ方向に積み増すことを防ぎます。

![schema](schema.svg)

## 戦略の概要

- 相対力指数は単一銘柄の確定足で計算されます。
- 2つのしきい値がゾーンを分けます。売られすぎ水準を下回れば売られ過ぎ、買われすぎ水準を上回れば買われ過ぎと判断します。
- 現在のポジションがすべての判断に加わるため、既存のポジションを増やさない場合にのみ新規に入ります。

## エントリーとエグジットの条件

- **ロングエントリー**: RSI が売られすぎ水準以下で、かつポジションが買いではないとき。注文は1ロットを買い、ノーポジションなら新規の買い、売り持ちならその手仕舞いになります。
- **ショートエントリー**: RSI が買われすぎ水準以上で、かつポジションが売りではないとき。注文は1ロットを売り、ノーポジションなら新規の売り、買い持ちならその手仕舞いになります。
- **エグジット**: 専用のエグジットブロックはありません。すべての注文が同じ数量のため、反対のシグナルがポジションを閉じます。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| RSI Length | 14 | 相対力指数の平滑化期間。 |
| Oversold | 30 | この水準以下で指数を売られすぎと判断します。 |
| Overbought | 70 | この水準以上で指数を買われすぎと判断します。 |
| Volume | 1 | 注文数量（ロット）。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが、相対力指数を持つ指標ブロックにデータを渡します。
- 2つの比較ブロックが指数としきい値の定数を比べ、もう2つがポジションとゼロを比べます。
- それぞれの論理積が指数の条件とポジションの条件を結び、ポジション変更ブロックを起動します。
- 2つのポジション変更ブロックはいずれも成行注文を出し、共通の定数から数量を取得します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
