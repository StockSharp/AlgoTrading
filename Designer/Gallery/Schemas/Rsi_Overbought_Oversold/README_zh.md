# RSI 超买超卖策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

教科书式的均值回归图：相对强弱指数衡量最近走势的过度程度，当指数触及极端时策略反向操作。持仓判断可避免在同一方向不断加仓。

![schema](schema.svg)

## 策略概览

- 相对强弱指数基于单一品种的已完成K线计算。
- 两个阈值划分区间：低于超卖水平视为卖过头，高于超买水平视为买过头。
- 当前持仓参与每一次判断，只有在不会加仓的情况下才会入场。

## 入场与出场规则

- **做多入场**: RSI 等于或低于超卖水平，且持仓不是多头。订单买入一手：空仓时开多，持空时平空。
- **做空入场**: RSI 等于或高于超买水平，且持仓不是空头。订单卖出一手：空仓时开空，持多时平多。
- **离场**: 没有单独的离场方块：由于所有订单数量相同，反向信号即可平掉持仓。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| RSI Length | 14 | 相对强弱指数的平滑周期。 |
| Oversold | 30 | 达到或低于该水平即视为超卖。 |
| Overbought | 70 | 达到或高于该水平即视为超买。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块把数据送入持有相对强弱指数的指标方块。
- 两个比较方块把指数与阈值常量对比，另外两个把持仓与零对比。
- 每个逻辑与把一个指数条件和一个持仓条件合并，触发修改持仓方块。
- 两个修改持仓方块都发送市价单，数量取自同一个常量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
