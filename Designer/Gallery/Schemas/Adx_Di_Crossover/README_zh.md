# ADX 与 DI 交叉策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这是威尔斯·怀尔德方向性运动系统的完整图示。Average Directional Index 方块一次输出三个数值：+DI 线、-DI 线以及 ADX 线本身。两条方向线的交叉决定交易方向，而 ADX 线决定行情是否足够有趋势值得入场。

![schema](schema.svg)

## 策略概览

- 一个 AverageDirectionalIndex 方块驱动三个转换方块，从同一个复合指标值中取出 +DI、-DI 和 ADX 线。
- 交叉方块比较 +DI 与 -DI，只在两条线真正换位的那根K线上触发。
- ADX 线必须不低于阈值，因此震荡和没有方向的行情会被过滤掉。
- 公式方块把持仓的绝对值加到基础数量上，于是一张市价单既平掉旧方向又建立新方向。

## 入场与出场规则

- **做多入场**: +DI 上穿 -DI，ADX 线不低于阈值，且当前不是多头持仓。订单买入基础数量加上空头持仓的规模：持空时反手，空仓时开多。
- **做空入场**: +DI 下穿 -DI，ADX 线不低于阈值，且当前不是空头持仓。订单卖出基础数量加上多头持仓的规模：持多时反手，空仓时开空。
- **离场**: 没有单独的离场方块。持仓一直保留到方向线反向交叉，反手订单同时完成平仓与反向开仓。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| ADX Period | 14 | ADX 线与 +DI/-DI 共用的平滑周期。 |
| ADX Threshold | 15 | 被视为可交易趋势的最小 ADX 读数。 |
| Volume | 1 | 基础下单数量（手），实际下单量还会加上当前持仓规模。 |
| Candles | 00:15:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动指标方块，三个转换方块分别取出 Dx.Plus、Dx.Minus 和 MovingAverage。
- 交叉方块在 +DI 上穿时输出 true，下穿时输出 false，因此一个逻辑非就把同一个输出变成做空信号。
- 一个比较方块把 ADX 线与阈值常量对比，另外两个把持仓与零对比，每个方向各一个。
- 每个逻辑与把交叉信号、趋势过滤和持仓判断合并，触发修改持仓方块，其下单量来自公式方块。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
