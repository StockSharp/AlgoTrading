# N デイ・ブレイクアウト戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

タートルズの定番を骨格だけにしたものです。Highest と Lowest の2つの指標が直近 N 本の極値を保持し、いずれかを超えたローソク足を動き出しとみなします。ダイアグラムは常に建玉を持ち、反対方向のブレイクで転換します。

![schema](schema.svg)

## 戦略の概要

- Highest は確定足の高値を、Lowest は安値を読み取り、両者で参照期間のブレイクアウト・チャネルを作ります。
- どちらの値も1本分ずらしています。現在値には検証対象の足自身が含まれるため、ずらさなければ高値はせいぜいチャネルと等しくなるだけで、決して超えられません。
- 現在のポジションがすべてのエントリーを許可または遮断し、注文数量にはポジションの絶対値が加算されるので、1回の成行注文で建玉を転換できます。

## エントリーとエグジットの条件

- **ロングエントリー**: ローソク足の高値が1本前の Highest を上回り、かつポジションが買いでないとき。注文は基本数量にポジションの絶対値を加えて買い、売り持ちなら買いへ転換し、ノーポジションなら新規の買いになります。
- **ショートエントリー**: ローソク足の安値が1本前の Lowest を下回り、同じ足で買いのブレイクが発生しておらず、かつポジションが売りでないとき。注文は基本数量にポジションの絶対値を加えて売ります。
- **エグジット**: 損切りも利確も専用のエグジットもありません。反対方向のブレイクが建玉を転換するまで保有し続けます。元のコードも同じ動きです。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Lookback period | 20 | ブレイクアウト・チャネルを作るバーの本数。Highest と Lowest で同じ長さを使います。 |
| Volume | 1 | 基本の注文数量（ロット）。転換時にはポジションの絶対値が加算されます。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが2つの指標に、また2つの変換ブロックを介して現在足の高値と安値に、データを渡します。
- 2つの前値ブロックが Highest と Lowest の値を1本分遅らせます。これがこの戦略の肝です。
- 比較ブロックが2つのブレイク判定を作り、別の2つがポジションとゼロを比べます。論理否定が買いのブレイクを売りより優先させ、元コードの else-if 分岐を再現します。
- 数式ブロックが転換用の数量を「基本数量＋ポジションの絶対値」として計算し、2つのポジション変更ブロックに渡します。
- 元の戦略はコードで一度も使われない移動平均と損切り率を宣言し、既定では1分足で1500本のチャネルを使います。本ダイアグラムでは未使用のパラメーターを省き、戦略の README と最適化範囲が示すとおり5分足で20本のチャネルを採用しました。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
