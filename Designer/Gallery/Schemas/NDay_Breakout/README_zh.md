# N 日突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

海龟交易法的经典思路，只保留内核：Highest 与 Lowest 两个指标记录最近 N 根K线的极值，一旦某根K线越过其中之一，就视为行情启动。图表始终持仓，遇到反向突破即反手。

![schema](schema.svg)

## 策略概览

- Highest 取每根已完成K线的最高价，Lowest 取最低价，两者共同构成回看周期的突破通道。
- 两个读数都向后平移一根K线，因为当前值本身已包含正在检验的那根K线；不平移的话，最高价最多只能与通道相等，永远无法超越。
- 当前持仓对每次入场都有否决权，下单数量还会加上持仓绝对值，因此一张市价单即可完成反手。

## 入场与出场规则

- **做多入场**: K线最高价高于上一根K线的 Highest 值，且持仓不是多头。订单买入基础数量加持仓绝对值：空头翻多，空仓则开多。
- **做空入场**: K线最低价低于上一根K线的 Lowest 值，同一根K线上多头突破未触发，且持仓不是空头。订单卖出基础数量加持仓绝对值。
- **离场**: 没有止损、没有止盈，也没有专门的离场：持仓一直保留到反向突破将其反手为止，与原始代码一致。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Lookback period | 20 | 构建突破通道的K线数量；Highest 与 Lowest 使用相同长度。 |
| Volume | 1 | 基础下单数量（手）；反手时加上持仓绝对值。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块把数据送入两个指标，并通过两个转换方块取得当前K线的最高价与最低价。
- 两个前值方块把 Highest 与 Lowest 的读数延迟一根K线，这正是该策略的关键所在。
- 比较方块生成两个突破标志，另外两个把持仓与零对比；逻辑非让多头突破优先于空头突破，与原代码的 else-if 分支一致。
- 公式方块把反手数量算成基础数量加持仓绝对值，并送入两个修改持仓方块。
- 原策略声明了一条均线和一个止损百分比，但代码从未使用，且默认在1分钟K线上使用1500根通道；本图舍弃这些无效参数，改用5分钟K线与20根通道，符合该策略 README 与优化区间的建议。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
