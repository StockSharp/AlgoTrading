# Лимитный вход по MFI с отменой по времени
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Long-only схема показывает полный жизненный цикл одной отложенной заявки. Выход MFI(14) из перепроданности регистрирует покупку ниже close, N values отсчитывает пять завершённых свечей, Order cancellation снимает неисполненный лимит, а исполнения проходят через устаревший Trades for order в защиту позиции 1%/1%.

![schema](schema.svg)

## Обзор стратегии

- Пересечение MFI вверх через 20 моделирует сохранённый в исходнике факт посещения зоны перепроданности.
- При Position == 0 событие ставит одну покупку объёмом один по Close × (1 − 0,5/100).
- Флаг одного жизненного цикла запускает пятисвечный таймер и не пропускает новую заявку до его завершения, поэтому старый timeout не снимет новую.
- Если лимит исполнился, Trades for order передаёт его сделки защите; иначе таймер отменяет именно зарегистрированную заявку.

## Правила входа и выхода

- **Вход в лонг**: MFI пересекает вверх границу 20 после пребывания ниже неё при нулевой позиции. Buy limit ставится на 0,5% ниже завершённого close.
- **Вход в шорт**: Короткого входа нет, как и в C#-стратегии.
- **Выход**: Исполненный вход закрывается при +1% или −1%. Неисполненный снимается через пять завершённых свечей; сигнальная свеча считается первой, как немедленное увеличение возраста заявки в коде.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Candle Time Frame | 00:05:00 | Интервал завершённых свечей для MFI, цены и счётчика отмены. |
| MFI Period | 14 | Число свечных значений в MoneyFlowIndex. |
| MFI Oversold Level | 20 | Уровень MFI, пересечение которого вверх вооружает вход. |
| Replay Entry Offset, % | 0.5 | Отступ схемы ниже close; дефолт C# — 0,1%, а 0,5% делает отмену видимой в replay. |
| Order Volume | 1 | Объём единственной отложенной покупки. |
| Cancel After Candles | 5 | Число завершённых свечей от регистрации до попытки отмены. |
| Take Profit, % | 1 | Процент прибыли от исполнения для защиты позиции. |
| Stop Loss, % | 1 | Процент убытка от исполнения для защиты позиции. |

## Детали диаграммы

- Дефолтный отступ C# равен 0,1%. Свечной эмулятор исполняет лимит, если его цена попала в Low..High, поэтому на пятиминутном BTCUSDT такой отступ почти всегда наливается сразу. Схема использует 0,5%, чтобы отмену было видно, и явно указывает исходное значение.
- Trades for order устарел; Designer рекомендует выход Trades у Order registering. Здесь он показан ровно один раз ради самого legacy-кубика, и копировать его в новые схемы не следует.
- Флаг жизненного цикла сбрасывается таймером, а не исполнением. Поэтому ещё работающий старый таймер не увидит через сокет Order новую заменяющую заявку и не снимет её.
- Исходник требует паузу 20 баров между сигналами. Компактная схема не воспроизводит отдельный cooldown; пятибарный lifecycle-lock всё равно запрещает перекрывающиеся входы.
- Несмотря на имя папки источника, исполняемый C# не содержит усредняющих заявок. В схеме также один вход и нет Chart panel, как требует отрецензированный план.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
