# 時間取消付きMFI指値エントリー
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

このロング専用図は1本の保留注文の全ライフサイクルを示します。MFI(14)が売られ過ぎを抜けると終値下に買いを登録し、N valuesが確定足5本を数え、Order cancellationが未約定を取り消し、約定は旧Trades for order経由で1%/1%保護へ渡ります。

![schema](schema.svg)

## 戦略の概要

- MFIが20を上抜けることで、元コードの売られ過ぎ訪問記憶を表現します。
- Position == 0ならClose × (1 − 0.5/100)に数量1の買いを登録します。
- 単一ライフサイクル・フラグが5足終了まで新注文を拒否し、古いtimeoutによる新注文取消を防ぎます。
- 約定すればTrades for orderが保護へ渡し、未約定ならタイマーがその注文だけを取り消します。

## エントリーとエグジットの条件

- **ロングエントリー**: フラット時にMFIが20を上抜け、確定終値の0.5%下へ買い指値を置きます。
- **ショートエントリー**: C#と同じくショート入口はありません。
- **エグジット**: 約定後は+1%または−1%で退出します。未約定は確定5足後に取り消し、信号足を最初の1本として数えます。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candle Time Frame | 00:05:00 | MFI、価格、取消カウンターの確定足周期です。 |
| MFI Period | 14 | MoneyFlowIndexの足数です。 |
| MFI Oversold Level | 20 | 上抜けで入口を有効にするMFI水準です。 |
| Replay Entry Offset, % | 0.5 | 終値下の距離。C#は0.1%、リプレイは0.5%です。 |
| Order Volume | 1 | 保留買いの数量です。 |
| Cancel After Candles | 5 | 取消までの確定足数です。 |
| Take Profit, % | 1 | 約定からの利益率です。 |
| Stop Loss, % | 1 | 約定からの損失率です。 |

## ダイアグラムの詳細

- C#既定は0.1%です。足マッチングはLow..High内ならほぼ即約定するため、リプレイで取消を見せる本図は0.5%を使います。
- Trades for orderは非推奨で、Order registeringのTrades出力が推奨です。歴史的教材としてここだけ1回使います。
- 約定ではなくタイマーがフラグを解除するため、古いタイマーが置換後の新注文を取り消せません。
- 元コードの20足クールダウンは簡略化で省略しますが、5足ロックが保留入口の重複を防ぎます。
- フォルダー名に反してC#に平均化注文はなく、本図も入口1本でChart panelを含みません。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
