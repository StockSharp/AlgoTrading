# 十字星反转策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

十字星是开盘价与收盘价几乎相同的K线：多空双方整根K线都在互相抵消。本图把这种犹豫量化为实体与全幅的比值，再用十字星之前的两个收盘价决定方向，因为十字星本身并不指示方向。唯一的离场依据是简单移动平均线。

![schema](schema.svg)

## 策略概览

- 一个公式方块计算实体减去全幅乘以阈值，结果为负说明实体小于允许的比例。
- 用乘法而不是除法来表达该判断，同时复制了原始代码的保护：当最高价等于最低价时比较的是零与零，不会判定为十字星。
- 两个前值方块读取前一根和前两根K线的收盘价：下降视为下行波段并买入，上升视为上行波段并卖出。
- 原始策略在成交后还会封锁所有信号数百根K线；这里没有计数K线的方块，因此省略该暂停并在此说明。

## 入场与出场规则

- **做多入场**: 刚收完的K线是十字星，前一根收盘价低于前两根收盘价，且持仓为零。订单买入一手，开多。
- **做空入场**: 刚收完的K线是十字星，前一根收盘价高于前两根收盘价，且持仓为零。订单卖出一手，开空。
- **离场**: K线收在移动平均线之下时，处于平仓模式的修改持仓方块平掉多头；收在均线之上时平掉空头。原始策略既没有止损也没有止盈，本图同样没有。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Doji Threshold | 0.1 | 实体与全幅之比的上限，低于该值仍算十字星。 |
| SMA Length | 20 | 用于平仓的简单移动平均线周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期；原策略跑在1分钟K线上，这里换成随图库提供的5分钟历史数据。 |

## 图表详情

- K线方块分别送入开、高、低、收四个转换方块以及移动平均线。
- 四个价格与阈值常量汇入同一个公式方块，再由一次与零的比较得到十字星标志。
- 收盘价另外进入两个前值方块，它们的输出互相比较，给出最近一段走势的方向。
- 每个逻辑与把十字星标志、一个方向条件和持仓判断合并并触发入场；两个平仓方块则直接由与均线的比较触发。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
