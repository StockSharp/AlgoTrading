# Диаграмма стратегии расширения ATR
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Сигналом здесь служит сама волатильность. Average True Range сравнивается со своим же значением на предыдущей свече: если он вырос хотя бы в заданное число раз, движение началось, и схема присоединяется к нему в ту сторону, куда указывает простая скользящая средняя. Когда диапазон во столько же раз сжимается, движение считается законченным и позиция закрывается.

![schema](schema.svg)

## Обзор стратегии

- Average True Range измеряет размах последних свечей, а кубик предыдущего значения хранит показание свечой раньше, чтобы их можно было сравнить.
- Расширение — это ATR не ниже предыдущего ATR, умноженного на коэффициент; сжатие — зеркальное условие: предыдущий ATR выше текущего ATR, умноженного на тот же коэффициент.
- Простая скользящая средняя отвечает только за сторону: закрытие выше неё превращает расширение в лонг, ниже — в шорт.
- У обоих кубиков входа стоит условие открытия позиции, у обоих кубиков выхода — условие закрытия, поэтому схема держит одну позицию и никогда её не наращивает.

## Правила входа и выхода

- **Вход в лонг**: Волатильность расширяется, свеча закрылась выше простой скользящей средней, позиция плоская. Заявка покупает общий объём по рынку.
- **Вход в шорт**: Волатильность расширяется, свеча закрылась ниже простой скользящей средней, позиция плоская. Заявка продаёт общий объём по рынку.
- **Выход**: Волатильность сжимается: ATR, умноженный на коэффициент, опускается ниже предыдущего ATR. Открытая сторона закрывается по рынку соответствующим кубиком закрытия; стоп-лосса и тейк-профита нет — ровно как в исходной стратегии.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| ATR Period | 14 | Период усреднения Average True Range, измеряющего волатильность. |
| MA Period | 20 | Период простой скользящей средней, задающей направление входа. |
| Expansion ratio | 1.05 | Во сколько раз новый ATR должен превзойти предыдущий, чтобы это считалось расширением; обратная величина служит порогом сжатия, закрывающим позицию. |
| Volume | 1 | Объём заявки в лотах, общий для обоих кубиков входа. |
| Candles | 00:05:00 | Таймфрейм свечей, на котором работает вся диаграмма. |

## Детали диаграммы

- Кубик свечей питает ATR, скользящую среднюю и конвертер, снимающий цену закрытия.
- Кубик предыдущего значения хранит ATR прошлой свечи, а две формулы домножают на него коэффициент: одна собирает уровень расширения, другая — уровень сжатия.
- Два кубика сравнения превращают эти уровни в признаки расширения и сжатия, ещё два ставят закрытие против скользящей средней.
- Каждое логическое И объединяет волатильность, направление и сравнение позиции с нулём и запускает один из двух кубиков входа; признак сжатия сам по себе запускает оба кубика закрытия, а их направление решает, какую сторону они вправе закрыть.
- Две вещи из C#-оригинала не перенесены: пауза в пятьсот баров после каждой сделки, для которой нет подходящего кубика, и минутные свечи, заменённые пятиминутными — именно такая история поставляется с галереей.
- Неиспользуемый параметр Lookback из оригинала тоже опущен: код его ни разу не читает.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
