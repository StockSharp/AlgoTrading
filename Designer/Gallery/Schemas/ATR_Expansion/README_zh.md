# ATR 扩张策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这里的信号就是波动率本身。Average True Range 与它前一根K线的数值相比较：一旦放大到设定的倍数，说明行情已经启动，图便沿着简单移动平均线所指的方向入场。当波幅按同样的倍数收缩时，行情被视为结束，持仓随即平掉。

![schema](schema.svg)

## 策略概览

- Average True Range 衡量最近几根K线的振幅，前值方块保存上一根K线的读数，以便两者比较。
- 扩张是指 ATR 不低于前一个 ATR 乘以倍数；收缩则是镜像条件：前一个 ATR 高于当前 ATR 乘以同一倍数。
- 简单移动平均线只负责方向：收盘价在其上方时扩张视为做多信号，在下方时视为做空信号。
- 两个入场方块带开仓条件，两个出场方块带平仓条件，因此图始终只持有一笔仓位，绝不加仓。

## 入场与出场规则

- **做多入场**: 波动率正在扩张，K线收盘价高于简单移动平均线，且当前空仓。订单以市价买入共享数量。
- **做空入场**: 波动率正在扩张，K线收盘价低于简单移动平均线，且当前空仓。订单以市价卖出共享数量。
- **离场**: 波动率收缩，即 ATR 乘以倍数低于前一个 ATR。无论持有哪一方向，都由对应的平仓方块以市价平掉；与原始策略一样，没有止损也没有止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| ATR Period | 14 | 衡量波动率的 Average True Range 的平滑周期。 |
| MA Period | 20 | 决定入场方向的简单移动平均线周期。 |
| Expansion ratio | 1.05 | 新的 ATR 需要比前一个大多少倍才算扩张；其倒数即为平仓所用的收缩阈值。 |
| Volume | 1 | 两个入场方块共用的下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动 ATR、移动平均线以及读取收盘价的转换方块。
- 前值方块保存上一根K线的 ATR，两个公式方块把倍数乘进去：一个得到扩张水平，另一个得到收缩水平。
- 两个比较方块把这些水平变成扩张标志与收缩标志，另外两个把收盘价与移动平均线对比。
- 每个逻辑与把波动率、方向和持仓为零的比较合在一起，触发两个入场方块之一；收缩标志单独触发两个平仓方块，方块的方向决定它们能平掉哪一边。
- C# 原版中有两点没有搬过来：每笔交易后五百根K线的暂停没有对应方块，以及一分钟K线被换成五分钟K线，因为图库随附的历史数据就是五分钟的。
- 原版中未使用的 Lookback 参数同样被略去，因为代码从未读取它。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
