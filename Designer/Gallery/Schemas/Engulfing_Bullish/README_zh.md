# 看涨吞没 + SMA 过滤策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

吞没形态说明控制上一根K线的一方刚刚被压倒。单看这一点出现得太频繁，因此用一条简单移动平均线决定在哪里采纳信号：看涨吞没只在均线下方买入，看跌吞没只在均线上方卖出。同一条均线也是平仓的目标位。

![schema](schema.svg)

## 策略概览

- 两个蜡烛形态指标方块直接使用内置的 Bullish Engulfing 与 Bearish Engulfing 形态，无需自己编写公式。
- 基于收盘价的简单移动平均线把行情分成便宜的一半和昂贵的一半。
- 形态只在便宜的一半买入、只在昂贵的一半卖出，这让本图成为均值回归而非突破的示例。
- 持仓判断保证只有在空仓时才会依据形态下单。

## 入场与出场规则

- **做多入场**: 形态方块报告出现看涨吞没，K线收盘价低于移动平均线，且当前无持仓。订单买入一手，开多。
- **做空入场**: 形态方块报告出现看跌吞没，K线收盘价高于移动平均线，且当前无持仓。订单卖出一手，开空。
- **离场**: K线收盘价升到均线之上即平多，跌到均线之下即平空，两者都通过处于平仓模式的修改持仓方块完成。原始策略在与入场同侧的均线位置离场，并依靠数百根K线的暂停来持有仓位；图中没有计数K线的方块，因此改用回到均线作为离场条件，这是仍能合理交易的最接近规则。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SMA Length | 20 | 用于过滤形态并平仓的简单移动平均线周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块分出四条支路：两个形态指标、移动平均线，以及读取收盘价的转换方块。
- 两个比较方块把收盘价放到均线的某一侧；同样这两个信号既作入场过滤，也作离场触发。
- 持仓方块与零常量比较，其结果同时保护两个入场。
- 每个逻辑与把形态、过滤条件和持仓判断合并，触发修改持仓方块；两张入场订单的数量取自共享常量，而两个平仓方块不需要数量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
