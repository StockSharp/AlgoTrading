# Схема пересечения средних с синхронизацией
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема синхронизирует часовую свечу с завершёнными значениями быстрой и медленной экспоненциальных средних и только затем проверяет их пересечение. По первому сигналу она открывает одну единицу, а на каждом встречном сигнале использует удвоенный базовый объём, поэтому позиция разворачивается без увеличения размера.

![schema](schema.svg)

## Обзор стратегии

- Одна серия завершённых часовых свечей подаётся одновременно в EMA(20) и EMA(50), поэтому ценовая база обеих средних одинакова.
- Кубик Sync формирует часовую группу из свечи, быстрой EMA и медленной EMA; решение по неполной группе не принимается.
- Кубик Crossing выдаёт `true`, когда быстрая EMA поднимается выше медленной, и `false`, когда опускается ниже; кубик NOT превращает второе значение в сигнал шорта.
- Проверки знака позиции выбирают открытие базовым объёмом из нуля или разворот удвоенным базовым объёмом со встречной стороны.
- График получает синхронизированную свечу, оба синхронизированных значения EMA и все исполнения стратегии.

## Правила входа и выхода

- **Вход в лонг**: Когда синхронизированная EMA(20) пересекает EMA(50) снизу вверх, схема покупает один базовый объём из нулевой позиции или два базовых объёма из шорта, оставляя лонг размером в один базовый объём.
- **Вход в шорт**: Когда синхронизированная EMA(20) пересекает EMA(50) сверху вниз, схема продаёт один базовый объём из нулевой позиции или два базовых объёма из лонга, оставляя шорт размером в один базовый объём.
- **Выход**: Отдельного стопа, цели или выхода по времени нет. Следующее встречное пересечение запускает рыночный разворот, объём которого закрывает текущую единицу и открывает одну единицу в новом направлении.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Fast EMA Length | 20 | Период быстрой экспоненциальной скользящей средней. |
| Slow EMA Length | 50 | Период медленной экспоненциальной скользящей средней. |
| Candles | 01:00:00 | Таймфрейм завершённых свечей, используемых обеими средними. |
| Sync interval | 01:00:00 | Временной диапазон, в котором Sync группирует свечу и оба значения индикаторов. |
| Base volume | 1 | Размер позиции при открытии из нуля; для разворота автоматически используется удвоенное значение. |

## Детали диаграммы

- Выход свечей сначала обновляет снимок позиции, константы нуля и объёма, затем подаётся в EMA(20) и EMA(50); последнее соединение свечи приходит в третий вход Sync и завершает часовую группу после обоих вычислений.
- Sync Input 1 получает EMA(20), Input 2 — EMA(50), а Input 3 — свечу. Все три парных выхода подключены, и после выдачи полной группы кубик очищает её.
- Sync Output 1 и Output 2 подаются в Crossing Input Up и Input Down. Output 3 проходит через конвертер ClosePrice и одновременно даёт свечи графику.
- Четыре логических маршрута различают нулевую, длинную и короткую позиции для двух направлений пересечения. Повторный сигнал своей стороны не может увеличить позицию.
- Четыре кубика Modify position отправляют рыночные заявки: два блока открытия используют базовый объём, а два блока разворота — формулу `2 × базовый объём`.
- Поскольку каждая открытая позиция начинается с базового объёма, объём разворота равен `abs(position) + базовый объём` и сохраняет модуль экспозиции.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
