# 带同步的均线交叉策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该图表先把小时 K 线与快、慢指数移动平均线的完整数值同步，再判断交叉。首次信号开仓一单位，之后每个反向信号使用两倍基础数量，因此能够反转方向而不扩大仓位。

![schema](schema.svg)

## 策略概览

- 同一组已完成的小时 K 线同时输入 EMA(20) 和 EMA(50)，使两条均线具有相同的价格基础。
- Sync 方块把 K 线、快 EMA 和慢 EMA 组成一个小时分组；分组不完整时不会作出交叉判断。
- 当快 EMA 上穿慢 EMA 时，Crossing 方块输出 `true`；下穿时输出 `false`，NOT 方块把后者转换为做空触发。
- 仓位符号检查会在空仓时选择基础数量开仓，在持有反向仓位时选择两倍基础数量反转。
- 图表接收同步后的 K 线、两条同步 EMA 以及策略的全部成交。

## 入场与出场规则

- **做多入场**: 同步后的 EMA(20) 上穿 EMA(50) 时，空仓买入一个基础数量；持有空头时买入两个基础数量，最终保留一个基础数量的多头。
- **做空入场**: 同步后的 EMA(20) 下穿 EMA(50) 时，空仓卖出一个基础数量；持有多头时卖出两个基础数量，最终保留一个基础数量的空头。
- **离场**: 没有独立的止损、目标或定时离场。下一次反向交叉提交市价反转，其数量先平掉当前一单位，再在新方向开出一单位。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Fast EMA Length | 20 | 较快指数移动平均线的周期。 |
| Slow EMA Length | 50 | 较慢指数移动平均线的周期。 |
| Candles | 01:00:00 | 两条均线共同使用的已完成 K 线周期。 |
| Sync interval | 01:00:00 | Sync 用于组合 K 线和两个指标值的时间范围。 |
| Base volume | 1 | 空仓开仓数量；反转时自动使用该数值的两倍。 |

## 图表详情

- K 线输出先更新仓位快照、零值和数量常量，然后输入 EMA(20) 与 EMA(50)；K 线的最后一条连接进入 Sync 的第三输入，在两次计算完成后结束小时分组。
- Sync Input 1 接收 EMA(20)，Input 2 接收 EMA(50)，Input 3 接收 K 线。三个配对输出全部已连接，每个完整分组输出后会被清除。
- Sync Output 1 和 Output 2 分别进入 Crossing Input Up 与 Input Down。Output 3 经过 ClosePrice 转换器，同时向图表提供 K 线。
- 四条逻辑路径针对两个交叉方向区分空仓、多头和空头状态。同方向的重复信号不会增加仓位。
- 四个 Modify position 方块提交市价单：两个开仓方块使用基础数量，两个反转方块使用公式 `2 × 基础数量`。
- 由于每次开仓都以基础数量开始，反转数量等于 `abs(position) + 基础数量`，所以仓位绝对值保持不变。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
