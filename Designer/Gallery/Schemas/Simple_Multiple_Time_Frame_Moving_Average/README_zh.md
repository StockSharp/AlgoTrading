# Simple Multiple Time Frame Moving Average 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

名字承诺了两个周期，但它所依据的 C# 策略只订阅了一条四小时序列，并在其上计算两条长度不同的 ExponentialMovingAverage。真正被交易的是两者斜率的一致：短均线与长均线同时向上时持多，同时向下时持空，方向不一致时不动仓位。

![schema](schema.svg)

## 策略概览

- 两个 ExponentialMovingAverage 方块（一短一长）作用于同一条K线序列；本图保留这唯一的订阅，不去杜撰第二个周期。
- 每条均线的斜率通过与向前一根的前值方块比较得到：所谓上升，就是均线站在它此前所在位置的上方。
- 所有订单都使用固定的共享数量，因此反向信号只能把仓位打平；要开到另一边，需要下一根K线上再出现一次同方向信号，这正是源代码的行为。
- 这里的条件是状态而非事件：每根收完的K线都会重新检查，所以使用比较方块和逻辑与，不需要穿越方块。

## 入场与出场规则

- **做多入场**: 快 ExponentialMovingAverage 高于自己前一根的值，慢线同样如此，且持仓不是多头。修改持仓方块以市价买入共享数量：空仓时开多，持空时平空。
- **做空入场**: 快 ExponentialMovingAverage 低于自己前一根的值，慢线同样如此，且持仓不是空头。修改持仓方块以市价卖出共享数量：空仓时开空，持多时平多。
- **离场**: 没有单独的离场规则：由反向信号平仓，也就是两条均线同时掉头的时刻。原始策略既无止损、止盈，也无交易间隔，本图同样如此。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Fast EMA length | 5 | 快 ExponentialMovingAverage 的周期。 |
| Slow EMA length | 20 | 慢 ExponentialMovingAverage 的周期。 |
| Volume | 1 | 下单数量（手）；同一个常量供给两个修改持仓方块。 |
| Candles | 04:00:00 | 整张图使用的K线周期；原策略用四小时，这里予以保留，在随附的一个月历史上约为两百根K线。 |

## 图表详情

- K线方块同时喂给两个指标方块，每个指标再喂给一个以指标值为类型的前值方块。
- 四个比较方块把两条均线及其延后副本变成上升与下降的标志。
- 持仓方块与零常量比较两次，提供避免给已有持仓加码的判断。
- 每个逻辑与把一个快线条件、一个慢线条件和一个持仓条件合在一起，触发从共享数量常量取值的修改持仓方块。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
