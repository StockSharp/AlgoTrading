# 一目均衡表云层突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

名字来自一目均衡表的云层，但这张图背后的策略实际交易的是最快的一对线：转换线 Tenkan-sen 与基准线 Kijun-sen。两者都是各自周期内最高价与最低价的中点，因此它们的交叉本身就是紧凑的趋势信号，而云层被有意排除在判断之外。

![schema](schema.svg)

## 策略概览

- 一个 Ichimoku 方块生成全部五条线；两个转换方块只取出 Tenkan-sen 和 Kijun-sen，云层的线不参与规则。
- 交叉方块只在 Tenkan-sen 真正穿越 Kijun-sen 的那根K线上输出，因此持续的趋势不会反复下单。
- 每次入场都与当前持仓结合，这正是避免在已有方向上继续加仓的关键。

## 入场与出场规则

- **做多入场**: Tenkan-sen 上穿 Kijun-sen，且持仓不是多头。订单按固定数量买入：空仓时开多，持空时平空。
- **做空入场**: Tenkan-sen 下穿 Kijun-sen，且持仓不是空头。订单按固定数量卖出：空仓时开空，持多时平多。
- **离场**: 没有单独的离场方块，也没有保护性止损：由于所有订单数量相同，反向交叉只把持仓拉回零而非反手，另一方向要等到再下一次交叉才建立。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Tenkan period | 9 | Tenkan-sen 的周期，即该数量K线内最高价与最低价的中点。 |
| Kijun period | 26 | Kijun-sen 的周期，算法相同但窗口更长。 |
| Senkou Span B period | 52 | Senkou Span B 的周期；不参与规则，只影响指标完全形成所需的K线数量。 |
| Volume | 1 | 下单数量（手）；开仓与平仓使用同一数值。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动一个 Ichimoku 指标方块，两个转换方块从复合指标值中取出 Tenkan 与 Kijun 的数值。
- 两条线在交叉方块中汇合，其输出即做多信号，对它取逻辑非即得做空信号。
- 持仓方块与零常量比较两次，得到「持仓 <= 0」和「持仓 >= 0」两个判断。
- 每个逻辑与把一个交叉信号与一个持仓判断合并并触发修改持仓方块；两个方块都发送市价单，数量取自同一个常量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
