# 一目均衡表 雲ブレイクアウト戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

名前は一目均衡表の雲に由来しますが、このダイアグラムの戦略が実際に売買するのは最も速い一対の線、転換線 Tenkan-sen と基準線 Kijun-sen です。どちらも各期間の高値と安値の中値なので、その交差だけで簡潔なトレンドシグナルになり、雲はあえて判断から外しています。

![schema](schema.svg)

## 戦略の概要

- 1つの Ichimoku ブロックが5本すべての線を作り、2つの変換ブロックが Tenkan-sen と Kijun-sen だけを取り出します。雲の線はルールに関与しません。
- クロスブロックは Tenkan-sen が Kijun-sen を実際に横切った足でのみ出力するため、続いているだけのトレンドでは注文が繰り返されません。
- すべてのエントリーに現在のポジションが組み合わされ、これがすでに持っている側へ積み増すことを防ぎます。

## エントリーとエグジットの条件

- **ロングエントリー**: Tenkan-sen が Kijun-sen を上抜け、かつポジションが買いではないとき。注文は固定数量を買い、ノーポジションなら新規の買い、売り持ちならその手仕舞いになります。
- **ショートエントリー**: Tenkan-sen が Kijun-sen を下抜け、かつポジションが売りではないとき。注文は固定数量を売り、ノーポジションなら新規の売り、買い持ちならその手仕舞いになります。
- **エグジット**: 専用のエグジットブロックも保護ストップもありません。すべての注文が同じ数量のため、反対方向のクロスはポジションを反転させずフラットに戻し、逆側はその次のクロスで初めて建てられます。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Tenkan period | 9 | Tenkan-sen の期間。指定した本数のローソク足における高値と安値の中値です。 |
| Kijun period | 26 | Kijun-sen の期間。同じ計算をより長い窓で行います。 |
| Senkou Span B period | 52 | Senkou Span B の期間。ルールには関与せず、指標が完成するまでに必要な本数にだけ影響します。 |
| Volume | 1 | 注文数量（ロット）。建玉にも手仕舞いにも同じ値を使います。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが1つの Ichimoku 指標ブロックに値を渡し、2つの変換ブロックが複合指標値から Tenkan と Kijun の値を読み出します。
- 2本の線はクロスブロックで出会い、その出力が買いシグナル、論理否定が売りシグナルになります。
- ポジションブロックはゼロ定数と2回比較され、ポジション <= 0 とポジション >= 0 の判定を作ります。
- それぞれの論理積がクロスの信号とポジションの判定を結び、ポジション変更ブロックを起動します。2つのブロックはいずれも成行注文を出し、共通の定数から数量を取得します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
