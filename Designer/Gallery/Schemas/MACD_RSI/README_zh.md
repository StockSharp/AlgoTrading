# MACD + RSI 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

MACD 给出方向，RSI 给出时机。当 MACD 线位于信号线之上时，图表等待相对强弱指数跌入超卖区并买入这次回调；镜像规则则在 MACD 位于信号线之下时卖出超买的 RSI。一旦两条 MACD 线交换位置，持仓即被交回。

![schema](schema.svg)

## 策略概览

- 趋势判断使用水平比较而非交叉：关键在于 MACD 线当前位于信号线的哪一侧，因此只要趋势延续，过滤条件就一直有效。
- 在该趋势内部的入场刻意逆势——RSI 必须已经朝反方向拉伸，于是图表买的是回调，而不是追突破。
- 离场使用同一对线：MACD 跌破信号线平掉多单，升破信号线平掉空单。
- 与原策略一样，图中没有止损也没有止盈，MACD 反转是唯一的离场方式。

## 入场与出场规则

- **做多入场**: MACD 线位于信号线之上，RSI 低于超卖水平，且当前没有持仓。订单以市价买入一手。
- **做空入场**: MACD 线位于信号线之下，RSI 高于超买水平，且当前没有持仓。订单以市价卖出一手。
- **离场**: MACD 首次跌破信号线的那根K线平掉多单，首次升破的那根K线平掉空单；两个平仓方块从持仓中读取数量。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| MACD Fast Length | 12 | MACD 内部快速 EMA 的周期。 |
| MACD Slow Length | 26 | MACD 内部慢速 EMA 的周期。 |
| MACD Signal Length | 9 | 把 MACD 平滑成信号线的 EMA 周期。 |
| RSI Length | 14 | 相对强弱指数的平滑周期。 |
| RSI Oversold | 30 | 低于该水平即视为超卖，允许做多。 |
| RSI Overbought | 70 | 高于该水平即视为超买，允许做空。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 一个指标方块承载带信号线的 MACD；两个转换方块从中取出 Macd 和 Signal 数值，另一个指标方块在同样的K线上计算相对强弱指数。
- 两个比较方块把 MACD 线与信号线对照，另两个把 RSI 与阈值常量对照，还有一个把持仓与零对照。
- 每个逻辑与合并趋势条件、RSI 条件和空仓判断，然后触发只在空仓时开仓的修改持仓方块。
- 趋势比较被复用为离场触发，因此两个平仓方块无需额外逻辑。原策略两次交易之间150根K线的暂停没有对应方块而被省略，所以重新入场比代码更频繁。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
