# Схема стратегии «Лимитный сеточный стрэддл»
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема начинает каждый цикл сетки двумя симметричными лимитными заявками вокруг последней завершённой пятиминутной свечи. Исполнение стартовой заявки планирует один дополнительный уровень в том же направлении, абсолютный тейк-профит закрывает полученную позицию, а отложенная команда массового снятия убирает оставшиеся заявки.

![schema](schema.svg)

## Обзор стратегии

- Когда позиция нулевая, лимитная заявка на покупку ставится на 100 ценовых единиц ниже закрытия свечи, а заявка на продажу — на 100 единиц выше.
- Исполнение любой стартовой заявки оставляет встречную стартовую заявку активной и планирует один уровень сетки в том же направлении на следующую завершённую свечу.
- Дополнительный уровень покупки находится на 350 единиц ниже стартового исполнения, а уровень продажи — на 350 единиц выше.
- Каждое исполнение стартовой или сеточной заявки поступает в Position protection с абсолютным тейк-профитом 300 и без стоп-лосса.
- Защитный выход планирует массовое снятие на следующую завершённую свечу. Подтверждение снятия разрешает новый цикл сетки.

## Правила входа и выхода

- **Сторона покупки**: В начале цикла с нулевой позицией зарегистрировать лимитную покупку по `Close - Start Offset`. После её исполнения на следующей завершённой свече зарегистрировать ещё одну покупку по `Average Fill Price - Grid Distance - Step Distance`.
- **Сторона продажи**: В начале цикла с нулевой позицией зарегистрировать лимитную продажу по `Close + Start Offset`. После её исполнения на следующей завершённой свече зарегистрировать ещё одну продажу по `Average Fill Price + Grid Distance + Step Distance`.
- **Ожидающие заявки**: Исполнение стартовой заявки не снимает встречный лимит. Оставшиеся стартовые и сеточные заявки активны до этапа массового снятия.
- **Выход**: Position protection отправляет рыночную заявку на выход, когда закрытие свечи достигает цели в 300 ценовых единицах от защищаемого исполнения. Граница стоп-лосса отключена.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Candles | 00:05:00 | Таймфрейм завершённых свечей, управляющих циклом. |
| Start Offset | 100 | Расстояние от закрытия свечи до каждой стартовой заявки в ценовых единицах. |
| Grid Distance | 300 | Базовое расстояние от стартового исполнения до дополнительного уровня той же стороны. |
| Step Distance | 50 | Прибавка к Grid Distance для дополнительного уровня. |
| Take Profit | 300 | Абсолютное расстояние от защищаемого исполнения до цели прибыли. |
| Stop Loss | 0 | Абсолютное расстояние стопа; ноль отключает границу стоп-лосса. |
| Trailing Stop Loss | false | Оставляет перемещение стоп-лосса отключённым. |
| Use Market Orders | true | Отправляет защитные выходы рыночными заявками. |
| Volume | 1 | Объём каждой стартовой и сеточной лимитной заявки. |

## Детали схемы

- Позиция снимается на каждой завершённой свече и сравнивается с нулём. Кубик Flag разрешает только одну симметричную стартовую пару на цикл сетки.
- Четыре кубика Order registering выставляют стартовые и сеточные лимиты покупки и продажи. Между двумя стартовыми заявками нет кубиков точечного снятия.
- Стартовое исполнение сохраняется в Variable. Delay на два события поглощает породившую исполнение свечу и выдаёт сохранённую сделку на следующей завершённой свече, поэтому новая заявка регистрируется вне обработчика исполнения.
- Из сохранённой сделки извлекается `Order.AveragePrice`; затем Formula применяет `Grid Distance + Step Distance`, что при стандартных значениях равно 350.
- Position protection обрабатывает каждое поступившее исполнение отдельно. Этот ограниченный пример не рассчитывает общую средневзвешенную цель для нескольких исполнений сетки.
- Защитное исполнение взводит ещё один Delay на два события. Его выход вызывает Order mass cancellation, и только успешный результат сбрасывает Flag цикла.
- График показывает пятиминутные свечи, все четыре потока заявок и каждое исполнение либо выход стратегии.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере и настройте расстояния и объём под масштаб цены и волатильность инструмента перед реальной торговлей.
