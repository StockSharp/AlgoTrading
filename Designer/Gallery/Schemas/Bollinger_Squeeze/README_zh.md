# 布林带挤压突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

基于布林带的突破图：以二十周期均线为中轴，上下各偏离 1.8 个标准差画出通道，收盘价跑出通道被视为行情启动，而不是可以逆势的过度。每张订单的数量都包含当前持仓，因此信号触发的是反手而不是加仓。

![schema](schema.svg)

## 策略概览

- 布林带基于单一品种的已完成K线计算，只有上轨和下轨参与判断。
- 这是突破而非回归：突破上轨买入强势，跌破下轨卖出弱势，方向与本图库中的 Bollinger_Bands 示例相反。
- 每张订单的数量等于基础数量加上当前持仓的绝对值，因此反向信号用一张单完成平仓与反向开仓。
- 尽管名字里有挤压，图中并没有挤压过滤：原始 C# 策略计算了相对带宽，却从未在任何条件里使用，本图忠实还原代码的实际行为。

## 入场与出场规则

- **做多入场**: K线收盘价高于布林带上轨，且持仓不是多头。订单买入基础数量加上当前持仓规模：空仓时开多，持空时反手做多。
- **做空入场**: K线收盘价低于布林带下轨，且持仓不是空头。订单卖出基础数量加上当前持仓规模：空仓时开空，持多时反手做空。
- **离场**: 没有单独的离场方块，也没有保护方块：只有当价格收在另一侧轨道之外、反手订单改变方向时，才会离开原有持仓。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Bollinger Period | 20 | 计算布林带所使用的K线根数。 |
| Bollinger Width | 1.8 | 标准差倍数，决定上下轨与中轨的距离。 |
| Volume | 1 | 基础下单数量（手），实际下单还会加上持仓规模。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时驱动布林带指标方块和读取同一根K线收盘价的转换方块。
- 两个指标值类型的转换方块从指标唯一的输出中取出上轨和下轨。
- 两个比较方块把收盘价与上下轨对比，另外两个把持仓与零常量对比，每个逻辑与把一个轨道条件和一个持仓条件合在一起。
- 公式方块计算基础数量加持仓绝对值，并供给两个修改持仓方块，这正是把入场变成反手的关键。
- 原代码每次入场后保持的十根K线暂停未被还原：可用方块中没有K线计数器，因此只能依靠持仓判断来限制交易频率。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
