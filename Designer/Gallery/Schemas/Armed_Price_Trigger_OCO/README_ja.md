# 価格トリガーを作動させる仮想 OCO 戦略図
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

このダイアグラムは、確定した5分足から計算したドンチャンチャネルの上下に、2つの仮想ブレイクアウトトリガーを維持します。ライブ板の最良売気配と最良買気配を最新のチャネル境界と比較し、先に条件を満たした側が成行でポジションを建て、その後は割合指定の利食いと損切りで管理します。

![schema](schema.svg)

## 戦略の概要

- 確定5分足を Donchian Channels(20) に入力し、上側と下側のブレイクアウト境界を生成します。
- 板が更新されるたびに、形成済みの最新チャネル値を取得し、注文板から `BestAsk.Price` と `BestBid.Price` を読み取ります。
- `Armed` が有効でポジションがゼロの間だけ、上側ブレイクで買い、下側ブレイクで売ることができます。
- 各方向の Flag ブロックは最初の有効なパルスだけを通し、ポジション変化によって両方のワンショットゲートがリセットされるまで重複を抑えます。
- ポジション保護は約定したエントリーを利食い1%または損切り0.6%で決済し、チャートにはローソク足、2本のチャネル境界、全約定を表示します。

## エントリーとエグジットの条件

- **ロングエントリー**: `Armed` が true、ポジションがゼロ、かつ最良売気配が最新のドンチャン上限以上になったとき、`Volume` の成行買いを送信します。
- **ショートエントリー**: `Armed` が true、ポジションがゼロ、かつ最良買気配が最新のドンチャン下限以下になったとき、`Volume` の成行売りを送信します。
- **エグジット**: ライブ板がエントリー約定価格から1%の利益目標、または0.6%の損失しきい値に達したとき、保有ポジションを決済します。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Channel Length | 20 | Donchian Channels が使用する確定足の本数です。 |
| Armed | true | 2方向のブレイクアウトエントリーを有効にする主スイッチです。 |
| Take Profit, % | 1 | エントリー約定価格から利益目標までの割合です。 |
| Stop Loss, % | 0.6 | エントリー約定価格から損失しきい値までの割合です。 |
| Volume | 1 | どちらのエントリー方向にも使用する成行注文数量です。 |
| Candles | 00:05:00 | チャネル計算に使用する確定足の時間枠です。 |

## ダイアグラムの詳細

- UpperBand と LowerBand のコンバーターが2本のドンチャン境界を抽出します。2つの Variable ブロックが値を保持し、各板更新と同じ因果コンテキストで最新値を出力します。
- Donchian Channels(20) が形成されるまでは境界変数に保存値がなく、エントリー比較は動作しません。
- 板コンバーターの `BestAsk.Price` と `BestBid.Price` が、2つの比較にライブ価格を供給します。
- 各エントリーゲートは、対応する価格比較、`position = 0`、公開パラメーター `Armed` の3つの真偽値を組み合わせます。
- 2つの Flag ブロックは、取引所に待機注文を置かずにワンショットの仮想 OCO 動作を実現します。一方が約定すると、ゼロでないポジションが保護による決済まで両方のエントリーを遮断します。
- 2つの Modify position ブロックはいずれも成行注文を使用します。エントリー約定は Position protection に直接渡され、Market depth がエグジット水準の判定価格を供給します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
