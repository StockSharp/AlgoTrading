# EMA + MACD + RSI 组合策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

三项独立检查全部一致，本图才会交易。EMA 50 与 EMA 200 的相对位置决定允许做哪一边，MACD 线与信号线的交叉决定何时动手，而 RSI 必须落在中间区带——动能已经出现，但行情尚未走到极端。每个被接受的信号都用一张市价单完成反手。

![schema](schema.svg)

## 策略概览

- 趋势过滤是两条指数均线的水平比较：EMA 50 位于 EMA 200 之下时不买，位于其上时不卖。
- 入场取决于事件而非状态：只有 MACD 线穿越信号线的那根K线才能开仓，因此趋势持续期间图表不会反复触发。
- RSI 区间让这套组合更谨慎。做多要求 RSI 高于买入水平且仍低于上边界，做空要求 RSI 低于卖出水平且仍高于下边界，从而跳过已经走完的行情。
- 原策略使用30分钟K线；为配合随附的样本历史数据，本图改用5分钟K线。成交后暂停十根K线的规则没有对应方块而被省略，因此重新入场比代码更频繁。

## 入场与出场规则

- **做多入场**: EMA 50 高于 EMA 200，MACD 线上穿信号线，RSI 高于买入水平且仍低于上边界，且当前不是多头持仓。订单买入基础数量加上未平空头，一张市价单即可把空头反手为多头。
- **做空入场**: EMA 50 低于 EMA 200，MACD 线下穿信号线，RSI 低于卖出水平且仍高于下边界，且当前不是空头持仓。订单卖出基础数量加上未平多头，一张市价单即可把多头反手为空头。
- **离场**: 与原策略一样，没有离场方块也没有保护：持仓一直保留到出现镜像信号，同一张订单完成平旧仓与开新仓。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Fast EMA length | 50 | 承载短期趋势的快速指数均线周期。 |
| Slow EMA length | 200 | 作为比较基准的慢速指数均线周期。 |
| MACD fast length | 12 | MACD 内部快速 EMA 的周期。 |
| MACD slow length | 26 | MACD 内部慢速 EMA 的周期。 |
| MACD signal length | 9 | 把 MACD 平滑成信号线的 EMA 周期。 |
| RSI length | 14 | 相对强弱指数的平滑周期。 |
| RSI buy level | 40 | RSI 需高于该水平，做多信号才被接受。 |
| RSI sell level | 60 | RSI 需低于该水平，做空信号才被接受。 |
| RSI upper bound | 70 | RSI 区间上边界；高于它则认为做多已经太晚。 |
| RSI lower bound | 30 | RSI 区间下边界；低于它则认为做空已经太晚。 |
| Volume | 1 | 基础下单数量（手）；反手时再加上已有持仓。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 一个K线方块驱动四个指标方块：两条指数均线、带信号线的 MACD 以及相对强弱指数。
- 两个转换方块把 MACD 数值拆成 Macd 和 Signal 两条线；交叉方块把这一对变成看涨触发，“非”方块将其取反得到看跌触发。
- 八个比较方块构成过滤条件：一对用于均线，四个用于 RSI 区间，两个用于持仓与零的比较。
- 每个逻辑与合并五个条件后触发修改持仓方块，公式方块把基础数量与持仓绝对值相加，使一张市价单即可完成整个反手。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
