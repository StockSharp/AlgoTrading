# Схема стратегии с объединением входа по MACD и усреднения
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема объединяет новое пересечение разности EMA и ценовое событие усреднения в один поток входов в лонг. Каждая покупка равна одной единице, в одном цикле позиции допускается не более пяти входов, а восстановление на два процента выше последней цены исполнения закрывает весь учтённый объём.

![schema](schema.svg)

## Обзор стратегии

- Завершённые пятиминутные свечи передают цену закрытия и сформированные значения EMA(12) и EMA(26).
- Формула `Fast EMA - Slow EMA` создаёт используемую схемой линию MACD, а Crossing определяет её пересечение нуля вверх.
- Пересечение нуля вверх открывает первый лонг, только когда Position не положительна, а счётчик входов равен нулю.
- Пока открыт лонг, закрытие не менее чем на пять процентов ниже последней цены входа добавляет одну единицу, если учтено меньше пяти входов.
- Combination сводит ровно эти два булевых события входа к триггеру одного рыночного кубика Buy.
- Закрытие не менее чем на два процента выше последней цены входа продаёт весь учтённый размер позиции. Затем счётчик исполнения сбрасывается для следующего цикла.

## Правила входа и выхода

- **Первый вход в лонг**: разность EMA(12) и EMA(26) пересекает ноль вверх, Position меньше или равна нулю, а Entries in Current Long равен нулю. Рыночная покупка одной единицы.
- **Усредняющий вход**: Position положительна, счётчик ниже Maximum Entries, а завершённая свеча закрылась на уровне или ниже `Latest Entry Fill × (1 - Averaging Drop / 100)`. Рыночная покупка ещё одной единицы.
- **Выход**: при положительной Position завершённая свеча закрылась на уровне или выше `Latest Entry Fill × (1 + Take Profit / 100)`. Весь учтённый объём продаётся по рынку, после чего счётчик сбрасывается.
- **Область работы**: схема работает только с лонгом и управляет единицами, открытыми её собственным потоком входов. Входа в шорт и стоп-лосса нет.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Серия свечей | 00:05:00 | Завершённые пятиминутные свечи для всех решений. |
| Период быстрой EMA | 12 | Период быстрой экспоненциальной скользящей средней. |
| Поле быстрой EMA | Не задано | Альтернативное поле входных данных индикатора не выбрано. |
| Период медленной EMA | 26 | Период медленной экспоненциальной скользящей средней. |
| Поле медленной EMA | Не задано | Альтернативное поле входных данных индикатора не выбрано. |
| Максимум входов | 5 | Максимальное число покупок по одной единице в одном цикле лонга. |
| Просадка для усреднения | 5 | Снижение в процентах от последней цены входа, необходимое для следующей покупки. |
| Тейк-профит | 2 | Рост в процентах от последней цены входа, необходимый для полного выхода. |
| Объём входа | 1 | Фиксированный рыночный объём каждой первой или усредняющей покупки. |

## Детали диаграммы

- Candles выдаёт только завершённые значения и может строить пятиминутную серию из сохранённых свечей меньшего интервала.
- Оба кубика EMA выдают только сформированные значения. Поэтому первая пригодная разность MACD появляется после прогрева медленной EMA.
- Формула `a - b` получает быструю и медленную EMA, а Crossing сравнивает результат с переменной нуля.
- Position задаёт проверки направления, а отдельная переменная Entries in Current Long обеспечивает требование нулевого счётчика и предел в пять входов.
- Каждое исполнение Buy передаёт среднюю цену заявки в Latest Entry Fill. Поскольку каждая заявка входа исполняется один раз, это цена исполнения для обоих процентных уровней.
- Отложенная ветвь счётчика прибавляет объём исполненной заявки после каждого Buy. Исполнение полного выхода передаёт ноль в тот же счётчик до решения на следующей свече.
- Булевый Combination имеет два подключённых входа: Fresh MACD Entry и Averaging Entry Below Step Five. Entry Volume выдаётся после обеих ветвей, чтобы кубик действия получил итог текущей свечи.
- На график поступают свечи, обе EMA, линия MACD, последняя цена входа, уровень усреднения, уровень тейк-профита и все исполнения входов и выходов.

## Использование

Импортируйте `Three_Signals_Combined.json` в Designer, предоставьте историю, достаточную для формирования EMA(26), и проверьте пятиминутную настройку на выбранном инструменте. До реальной торговли оцените риск пяти входов и отсутствие стоп-лосса.
