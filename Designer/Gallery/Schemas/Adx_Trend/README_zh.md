# ADX 趋势均线穿越策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该图交易跨越长周期简单移动平均线的那根K线，但只在 ADX 确认市场确实处于趋势时才动作。若K线开盘在均线一侧、收盘在另一侧，即视为穿越，随后把持仓转向收盘所在的一侧。原版使用 1 分钟K线，本图采用随附历史数据的 5 分钟K线。

![schema](schema.svg)

## 策略概览

- 200 周期 SMA 是基准线，前值方块保存它上一根K线的数值，因此开盘价与当时的均线比较、收盘价与当前均线比较。
- 两个比较的异或恰好在跨越均线的K线上为真——这正是原始代码对“穿越”的定义，而不是两条指标线的交叉。
- 周期 50 的 ADX 过滤每一次入场：行情平淡时穿越均线的K线会被忽略。
- 没有止损也没有止盈——只有反向穿越才会反手，下单数量为共享数量加上当前持仓的绝对值。

## 入场与出场规则

- **做多入场**: ADX 高于阈值，K线穿越了均线，收盘价高于当前 SMA，且持仓不是多头。订单买入共享数量加上已有空头的数量，一笔订单即可平空并开多。
- **做空入场**: ADX 高于阈值，K线穿越了均线，收盘价等于或低于当前 SMA，且持仓不是空头。订单卖出共享数量加上已有多头的数量。
- **离场**: 没有独立的离场：持仓一直保留，直到反向穿越将其反手，这与原始代码一致——原代码既未实现止损，也未实现止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| ADX Length | 50 | 平均趋向指数的平滑周期。 |
| ADX Threshold | 25 | 允许入场所需超过的 ADX 数值。 |
| SMA Length | 200 | 与K线比较的简单移动平均线周期。 |
| Volume | 1 | 加上现有持仓之前的下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 两个转换方块读取已完成K线的开盘价与收盘价，移动平均线和 ADX 则直接基于K线计算。
- 前值方块把 SMA 延后一根K线；使用旧值与当前值的两个比较由异或连接，这就是穿越判定。
- 逻辑非把“收盘高于均线”转换为做空条件，因此一个比较方块服务于两个方向。
- 公式方块把持仓绝对值加到共享数量上，使一笔市价单即可完成平旧仓、开新仓。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
