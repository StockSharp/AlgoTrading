# RSI + 威廉指标双重穿越策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

两个振荡指标必须在同一根K线上达成一致。只有当 RSI 跌破 30 的同时威廉指标跌破 -80 时才买入；只有当 RSI 升破 70 的同时威廉指标升破 -20 时才卖出。单纯停留在区域内并不算数：上一根K线两者都必须仍在区域之外，因此每个指标还额外保存了前一根K线的值。原代码中180根K线的冷却期没有照搬，因为在5分钟周期上，它会在每笔交易后让策略沉默十五个小时。

![schema](schema.svg)

## 策略概览

- RSI 14 与威廉指标 14 使用同一品种的同一批5分钟K线计算。
- 前值方块保存两个指标前一根K线的读数，从而把刚刚进入区域与已经在区域里待了几个小时的情形区分开。
- 只有空仓时才入场，而把持仓带回空仓的是 RSI 的中轴 50。

## 入场与出场规则

- **做多入场**: RSI 低于超卖水平而上一根K线仍等于或高于它，同时威廉指标低于其超卖水平而上一根K线仍等于或高于它；且当前无持仓。以市价买入一手。
- **做空入场**: RSI 高于超买水平而上一根K线仍等于或低于它，同时威廉指标高于其超买水平而上一根K线仍等于或低于它；且当前无持仓。以市价卖出一手。
- **离场**: 只要 RSI 回到中轴 50 之上就平掉多头，回落到中轴之下就平掉空头；两个离场都由平仓方块完成，因此各自只影响真正持有的方向。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| RSI Length | 14 | 相对强弱指数的平滑周期。 |
| RSI Oversold | 30 | 做多信号要求 RSI 向下击穿的水平。 |
| RSI Overbought | 70 | 做空信号要求 RSI 向上击穿的水平。 |
| Williams %R Length | 14 | 威廉指标的回溯周期。 |
| Williams %R Oversold | -80 | 做多信号要求威廉指标向下击穿的水平；该指标取值范围为 -100 到 0。 |
| Williams %R Overbought | -20 | 做空信号要求威廉指标向上击穿的水平。 |
| RSI Midline | 50 | 放弃持仓时的 RSI 中性水平。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 每个指标各接一对比较方块，一个用当前值、一个用前值，这样描述穿越就不必使用交叉方块——交叉方块会让两次穿越来自不同的K线。
- 每个逻辑与汇合五个标志：两个 RSI 比较、两个威廉指标比较，以及由持仓方块与零比较得出的空仓状态。
- 两个入场方块只在没有持仓时开仓，并从同一个常量取得下单数量。
- 另外两个比较方块把 RSI 与中轴对照并驱动平仓方块，这是图中唯一的离场方式。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
