# 三时间框架 RSI 一致策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该图表等待五分钟、十五分钟和三十分钟蜡烛上的已形成 RSI 值，在每次慢周期收盘时采集三个值，并将它们作为一个同步组进行判断。三个值都低于 30 时开仓或反转为多头；都高于 70 时开仓或反转为空头。

![schema](schema.svg)

## 策略概览

- 三个已完成蜡烛流分别在 5、15 和 30 分钟周期上计算独立的 RSI(14)。
- 三十分钟 RSI 事件采集每个流的最新值。Sync 以 30 分钟为间隔组合三份样本，并在发布后将其清空。
- 每个已形成的三十分钟 RSI 值只触发一次决策，并且只在三个同步输出均已更新其比较后执行。
- 三个 RSI 全部低于买入阈值时形成多头设置，全部高于卖出阈值时形成空头设置。
- 持仓门会阻止沿当前持仓方向再次下单。反向设置发送两单位市价反转单；空仓入场使用一单位。
- 没有独立的止损、止盈、定时退出或冷却。下一次合格的反向设置是唯一退出方式，并立即建立新方向。

## 入场与退出规则

- **多头入场**：同步的 Fast RSI、Middle RSI 和 Slow RSI 必须严格低于 30，且 Position 必须小于或等于零。以市价买入 `Base Volume + abs(sign(Position))`：空仓时一单位，持有该图表建立的一单位空头时两单位。
- **空头入场**：三个同步 RSI 必须严格高于 70，且 Position 必须大于或等于零。以市价卖出相同的计算数量：空仓时一单位，持有该图表建立的一单位多头时两单位。
- **退出**：多头只由合格的空头设置关闭，空头只由合格的多头设置关闭。反转单同时关闭一单位敞口并在新方向开立一单位。
- **持仓范围**：归一化公式面向该图表创建的持仓。如果外部持仓的绝对大小超过一份基础数量，两单位反转单不一定能达到目标状态。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 快速蜡烛序列 | 00:05:00 | Fast RSI 使用的已完成五分钟蜡烛。 |
| 中速蜡烛序列 | 00:15:00 | Middle RSI 使用的已完成十五分钟蜡烛。 |
| 慢速蜡烛序列 | 00:30:00 | 安排同步决策的已完成三十分钟蜡烛。 |
| Fast RSI 长度 | 14 | 快速蜡烛流上 RSI 的平均长度。 |
| Fast RSI 数据源 | 未设置 | 未选择其他指标输入字段。 |
| Middle RSI 长度 | 14 | 中速蜡烛流上 RSI 的平均长度。 |
| Middle RSI 数据源 | 未设置 | 未选择其他指标输入字段。 |
| Slow RSI 长度 | 14 | 慢速蜡烛流上 RSI 的平均长度。 |
| Slow RSI 数据源 | 未设置 | 未选择其他指标输入字段。 |
| 买入阈值 | 30 | 允许多头入场的一致性严格上界。 |
| 卖出阈值 | 70 | 允许空头入场的一致性严格下界。 |
| 基础数量 | 1 | 目标敞口与空仓入场大小；反转使用默认大小的两倍。 |

## 图表细节

- 每个 Candles 块只发布已完成值，并可由已存储的更小周期蜡烛构建自己的周期。每个 RSI 只有完成自身 14 值预热后才开始发布。
- Fast RSI 与 Middle RSI 比 Slow RSI 更早形成。三个 indicator value 类型的 Variable 由每个 Slow RSI 事件触发，因此不完整的预热区间不会停留在 Sync 队列开头。
- Sync 恰好连接三对输入和输出，Interval 为 `00:30:00`，并启用 Clear Sockets。输出以统一决策时间携带最新快速 RSI、最新中速 RSI 和当前慢速 RSI 样本。
- 六个 Comparison 块应用严格的 `< Buy Threshold` 和 `> Sell Threshold` 检查。只有六个比较都处理完当前组后，布尔发布脉冲才会到达两个五输入 AND 门。
- Current Position 在多头路径上用 `<=` 与零比较，在空头路径上用 `>=` 与零比较。这些检查允许空仓入场或反转对向持仓，并抑制同向重复入场。
- Formula 计算 `Base Volume + abs(sign(Position))`。在所维护的敞口下，空仓结果为 1，持仓结果为 2；即使存在多个数据订阅，数值也保持有界。
- Buy 和 Sell 的 Modify position 块使用 NoCondition 市价动作，因为方向与资格已由外部门确定。图中没有保护块或 Chart 块。
- 阈值有意与 RSI 长度及蜡烛序列分离。更改周期或长度会改变预热时间；Sync 在判断前仍会等待一组新的三份样本。

## 使用方法

将 `.json` 文件导入 Designer，使用足够形成三十分钟 RSI 的历史数据在回测器中运行，并在实盘交易前针对交易品种调整三个蜡烛序列、RSI 长度、阈值和基础数量。
