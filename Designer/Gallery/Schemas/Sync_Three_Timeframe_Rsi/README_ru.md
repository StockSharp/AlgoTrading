# Схема стратегии согласования RSI трёх таймфреймов
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема ждёт сформированные значения RSI на пяти-, пятнадцати- и тридцатиминутных свечах, снимает все три значения при каждом закрытии медленного таймфрейма и оценивает их как одну синхронную группу. Согласование ниже 30 открывает или разворачивает лонг, а согласование выше 70 — шорт.

![schema](schema.svg)

## Обзор стратегии

- Три потока завершённых свечей независимо считают RSI(14) на таймфреймах 5, 15 и 30 минут.
- Событие тридцатиминутного RSI выбирает последнее значение каждого потока. Sync объединяет три выборки с интервалом 30 минут и очищает их после выпуска.
- Решение принимается один раз на каждое сформированное значение тридцатиминутного RSI и только после обновления сравнений всеми тремя синхронными выходами.
- Все три RSI ниже порога покупки формируют сетап в лонг. Все три RSI выше порога продажи формируют сетап в шорт.
- Гейты позиции не допускают ещё одну заявку в уже занятом направлении. Встречный сетап отправляет рыночный разворот объёмом две единицы, а вход из нуля использует одну единицу.
- Отдельных стоп-лосса, тейк-профита, выхода по времени и паузы нет. Следующий квалифицированный встречный сетап является единственным выходом и сразу устанавливает новое направление.

## Правила входа и выхода

- **Вход в лонг**: Синхронизированные Fast RSI, Middle RSI и Slow RSI должны быть строго ниже 30, а Position — меньше или равна нулю. По рынку покупается `Base Volume + abs(sign(Position))`: одна единица из нуля либо две единицы из созданного схемой шорта объёмом одна единица.
- **Вход в шорт**: Все три синхронизированных RSI должны быть строго выше 70, а Position — больше или равна нулю. По рынку продаётся тот же рассчитанный объём: одна единица из нуля либо две единицы из созданного схемой лонга объёмом одна единица.
- **Выход**: Лонг закрывается только квалифицированным сетапом в шорт, а шорт — сетапом в лонг. Разворотная заявка одновременно закрывает экспозицию в одну единицу и открывает одну единицу в новом направлении.
- **Область позиции**: Нормализованная формула рассчитана на позиции, созданные этой схемой. Если внешняя позиция по модулю больше одного базового объёма, разворотная заявка объёмом две единицы не обязательно достигнет целевого состояния.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Быстрые свечи | 00:05:00 | Завершённые пятиминутные свечи для Fast RSI. |
| Средние свечи | 00:15:00 | Завершённые пятнадцатиминутные свечи для Middle RSI. |
| Медленные свечи | 00:30:00 | Завершённые тридцатиминутные свечи, назначающие синхронные решения. |
| Период Fast RSI | 14 | Период усреднения RSI на быстром потоке свечей. |
| Поле Fast RSI | Не задано | Альтернативное поле входных данных индикатора не выбрано. |
| Период Middle RSI | 14 | Период усреднения RSI на среднем потоке свечей. |
| Поле Middle RSI | Не задано | Альтернативное поле входных данных индикатора не выбрано. |
| Период Slow RSI | 14 | Период усреднения RSI на медленном потоке свечей. |
| Поле Slow RSI | Не задано | Альтернативное поле входных данных индикатора не выбрано. |
| Порог покупки | 30 | Строгая верхняя граница согласования, разрешающего лонг. |
| Порог продажи | 70 | Строгая нижняя граница согласования, разрешающего шорт. |
| Базовый объём | 1 | Целевая экспозиция и размер входа из нуля; разворот использует вдвое больший объём. |

## Детали диаграммы

- Каждый кубик Candles выдаёт только завершённые значения и может построить свой таймфрейм из сохранённых меньших свечей. Каждый RSI начинает выдачу только после собственного прогрева на 14 значениях.
- Fast и Middle RSI формируются раньше Slow RSI. Три Variable типа indicator value запускаются каждым событием Slow RSI, поэтому неполные интервалы прогрева не остаются в начале очереди Sync.
- У Sync подключены ровно три пары входов и выходов, Interval равен `00:30:00`, а Clear Sockets включён. Выходы несут последнее быстрое, последнее среднее и текущее медленное значения RSI с единым временем решения.
- Шесть кубиков Comparison применяют строгие проверки `< Buy Threshold` и `> Sell Threshold`. Булевый импульс разрешения поступает в оба пятиходовых AND-гейта только после обработки текущей группы всеми шестью сравнениями.
- Current Position сравнивается с нулём через `<=` для ветки лонга и `>=` для ветки шорта. Эти проверки разрешают вход из нуля или разворот встречной позиции и подавляют повторные входы в том же направлении.
- Formula вычисляет `Base Volume + abs(sign(Position))`. При поддерживаемой экспозиции результат равен 1 из нуля и 2 в позиции, оставаясь ограниченным при нескольких подписках на данные.
- Кубики Buy и Sell Modify position используют рыночные действия NoCondition, поскольку направление и допустимость уже определены внешними гейтами. Кубиков защиты и графика нет.
- Пороги намеренно отделены от периодов RSI и серий свечей. Изменение таймфрейма или периода меняет время прогрева; Sync всё равно ждёт свежую тройку выборок перед оценкой.

## Использование

Импортируйте файл `.json` в Designer, прогоните его в тестере с историей, достаточной для формирования тридцатиминутного RSI, и настройте три серии свечей, периоды RSI, пороги и базовый объём под инструмент перед реальной торговлей.
