# 一目均衡表转换线与基准线交叉策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这里完整地使用了一目均衡表系统：快线组给出信号，云层决定该信号是否被允许。转换线 Tenkan-sen 与基准线 Kijun-sen 的交叉是触发条件，只有当收盘价与交叉方向位于云层 Kumo 的同一侧时才建仓。

![schema](schema.svg)

## 策略概览

- 一个 Ichimoku 方块生成全部线条，四个转换方块从其复合值中取出 Tenkan-sen、Kijun-sen、Senkou Span A 和 Senkou Span B。
- 两个公式方块把两条 Senkou 线折算成云层的上沿与下沿，于是每一侧只需一个比较就能判断收盘价与云层的关系。
- 只有空仓时才入场，并且检查了两遍：一次是持仓与零的比较，一次是下单方块自身的「仅开仓」条件。
- 离场使用独立方块：反向交叉或收盘价跌回云层之内都会让持仓归零，平仓数量取自持仓本身。
- 原始代码在成交后忽略500根K线内的所有信号，连离场也一并推迟；这些方块搭不出K线计数器，因此该暂停被省略，本图的交易频率高于原版。

## 入场与出场规则

- **做多入场**: Tenkan-sen 上穿 Kijun-sen，收盘价高于云层上沿，且持仓为零。订单按固定数量买入并建立多头。
- **做空入场**: Tenkan-sen 下穿 Kijun-sen，收盘价低于云层下沿，且持仓为零。订单按固定数量卖出并建立空头。
- **离场**: 当 Tenkan-sen 重新下穿 Kijun-sen 或收盘价跌破云层下沿时平掉多头；空头则完全镜像。平仓数量取自持仓，因此本图回到空仓而非反手；与原始代码一样，没有止损也没有止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Tenkan period | 9 | Tenkan-sen 的周期，即该数量K线内最高价与最低价的中点。 |
| Kijun period | 26 | Kijun-sen 的周期，算法相同但窗口更长。 |
| Senkou Span B period | 52 | Senkou Span B 的周期，即云层中较慢的那条边界。 |
| Volume | 1 | 开仓的下单数量（手）；离场按已开仓规模平掉。 |
| Candles | 00:01:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动 Ichimoku 指标以及一个取收盘价的转换方块。
- Tenkan-sen 与 Kijun-sen 在交叉方块中汇合，其输出即多头交叉，对它取逻辑非即得空头交叉。
- 两个云层比较被入场与离场共用：位于云层之上既开多也平空，位于云层之下则相反。
- 每个入场都要经过与空仓判断组合的逻辑与，而每个离场都经过逻辑或，因此交叉或云层跌破任一发生即可触发平仓方块。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
