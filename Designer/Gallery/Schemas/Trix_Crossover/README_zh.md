# TRIX 交叉策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这里的 TRIX 不是现成指标，而是在图中手工搭建的序列，与原策略的做法完全一致：三重指数移动平均加上它的单根K线相对变化率。触发条件是快速序列穿越零轴，慢速序列必须朝同一方向变化并超过阈值，最后由百分比止盈止损了结交易。

![schema](schema.svg)

## 策略概览

- 原料是两条基于收盘价的三重指数移动平均，周期为 9 和 21；两个前值方块各自保存它们前一根K线的数值。
- 慢速 TRIX 由公式方块得出：均线减去前值，再除以该前值，正是原策略在代码中计算的每根K线相对变化率。
- 快速 TRIX 穿越零轴被画成快速均线与自身前值的交叉。价格均线为正数，因此相对变化率的符号等同于差值的符号，交叉方块是精确替代，还省去了一次除法。
- 慢速 TRIX 的阈值使本图避开横盘：只有当慢速序列朝同一方向每根K线变化超过 0.05% 时，快速序列的转向才被接受。
- 原策略使用4小时K线，止盈1500、止损500，单位为绝对价格；本图为配合随附样本历史改用5分钟K线，两个距离按同样的三比一比例改成入场价的百分比。
- 内置 Trix 指标被刻意弃用：它是三次连续平滑再乘以常数的结构，数值与信号都不同于本策略所依据的三重指数移动平均。

## 入场与出场规则

- **做多入场**: 快速 TRIX 上穿零轴，即快速三重均线在下跌后转为上行，慢速 TRIX 高于阈值，且当前不是多头持仓。订单以市价买入一手：空仓时开多，持有等量空头时平空。
- **做空入场**: 快速 TRIX 下穿零轴，即快速三重均线在上涨后转为下行，慢速 TRIX 低于负阈值，且当前不是空头持仓。订单以市价卖出一手：空仓时开空，持有等量多头时平多。
- **离场**: 持仓保护方块按入场价的百分比在止盈或止损处平仓；其余情况下持仓保留到反向信号，由于所有订单数量相同，该信号即可平仓。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Fast TEMA length | 9 | 构成触发序列的快速三重指数均线周期。 |
| Slow TEMA length | 21 | 构成确认序列的慢速三重指数均线周期。 |
| Volume | 1 | 下单数量（手）；同一常量供给两个下单方块。 |
| Take profit, % | 1.5 | 止盈距离，占入场价的百分比。 |
| Stop loss, % | 0.5 | 止损距离，占入场价的百分比。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- 转换方块从K线中取出收盘价并供给两个指标方块，同一数值也作为当前价格送入保护方块。
- 每条均线后面各有一个前值方块：快速的一对进入交叉方块，慢速的一对进入把差值除以前值的公式方块。
- 交叉方块给出向上转折的信号，“非”方块把它反转为向下转折；两个比较方块把慢速序列与正、负阈值常量对照。
- 每个逻辑与合并转折、确认与持仓判断，然后触发修改持仓方块；两个方块都把各自的成交送入持仓保护方块。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
