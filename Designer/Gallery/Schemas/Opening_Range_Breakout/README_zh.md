# Opening Range Breakout（布林带突破 + EMA 过滤）策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

示例沿用了原策略的名称，但其中并没有开盘区间：它实际交易的是由慢速 EMA 确认的布林带突破。价格走出通道构成触发条件，EMA 判断这次突破是顺势还是逆势，中轨则负责把交易带回终点。

![schema](schema.svg)

## 策略概览

- 布林带与 50 周期 EMA 使用同一批半小时K线计算，所有判断都基于已完成K线的收盘价。
- 只有顺势的突破才算数：收盘价高于上轨时还必须高于 EMA，低于下轨时还必须低于 EMA。
- 布林带中轨是多空两侧共同的离场条件，因此持仓时间正好等于价格远离自身均值的时间。图中没有止损，也没有止盈。

## 入场与出场规则

- **做多入场**: K线收盘价高于布林带上轨，且同一收盘价高于 EMA，同时当前空仓。修改持仓方块以市价买入公共数量。
- **做空入场**: K线收盘价低于布林带下轨，且同一收盘价低于 EMA，同时当前空仓。修改持仓方块以市价卖出公共数量。
- **离场**: 第一根收在中轨下方的K线平掉多头，第一根收在中轨上方的K线平掉空头；两个平仓方块都工作在平仓模式，只有存在持仓时才动作。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Bollinger Length | 20 | 布林带的平滑周期，也是中轨的周期。 |
| Bollinger Width | 2 | 以标准差表示的通道宽度；原始代码固定为 2。 |
| EMA Length | 50 | 决定允许朝哪个方向交易突破的 EMA 周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:30:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块供给布林带、EMA 以及提取收盘价的转换方块；另外三个转换方块把指标拆成上轨、下轨和中轨。
- 六个比较方块覆盖全部逻辑：两个用于通道，两个用于 EMA 过滤，两个用于回到中轨。
- 两个入场逻辑与方块都要求空仓，因此入场绝不会给已有持仓加码；平仓方块直接连到中轨比较方块。
- 与 C# 原版相比缺少两点：动作之间 10 根K线的暂停在 Designer 中没有对应方块；以及即时反手——本图先在中轨平仓，随后再在合适的K线上开反向仓。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
