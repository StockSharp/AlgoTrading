# Level 1を使うEMAクロス指値エントリー図
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この図はTwoDLimitsStrategyのEMA(14)/EMA(50)シグナルを保ちつつ、注文管理を可視化します。確定した5分足ごとにLevel 1を保持し、最良気配より外側へ指値を置き、平均線が逆交差すると未約定注文を取り消します。

![schema](schema.svg)

## 戦略の概要

- 確定5分足が高速EMA(14)と低速EMA(50)へ入り、2個のCrossingが上下両方向を検出します。
- BestBidPriceとBestAskPriceはLevel 1から非同期で届き、価格計算前に各足で保持されます。
- 買いは最良買気配より0.02%下、売りは最良売気配より0.02%上に置き、Order cancellationの動作を確認できます。
- 約定ごとにN valuesの100本クールダウンを開始し、完了まで新規入力とPosition protectionへの価格を止めます。
- 完了後は0.3%ストップと0.6%利確でPosition protectionが動作します。

## エントリーとエグジットの条件

- **ロングエントリー**: EMA(14)がEMA(50)を上抜け、Positionがゼロまたはショート、買気配が正でクールダウン完了なら、保持したbidより下に買い指値を置きます。数量はabs(Position)+基本数量なので、一度の約定でショートを閉じロングを開けます。
- **ショートエントリー**: EMA(14)がEMA(50)を下抜け、Positionがゼロまたはロング、売気配が正でクールダウン完了なら、保持したaskより上に同じネット反転数量で売り指値を置きます。
- **エグジット**: 逆方向のEMA交差は、まだ有効な反対側指値を取り消します。入場約定から100本後、Position protectionが0.3%ストップまたは0.6%利確で終了し、反対指値の約定でも反転できます。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candle Time Frame | 00:05:00 | EMA、気配取得、クールダウン計数、保護判定に使う確定足の時間枠。 |
| Fast EMA Length | 14 | 高速指数移動平均に含める5分値の数。 |
| Slow EMA Length | 50 | 低速指数移動平均に含める5分値の数。 |
| Quote Offset | 0.02% | 最良気配から外す割合。買いはbidより下、売りはaskより上です。 |
| Base Volume | 1 | 反対ポジションを相殺した後に新規で建てる基本数量。 |
| Cooldown, candles | 100 | 各約定後、入力と保護を再開するまで待つ確定足数。 |
| Stop Loss | 0.3% | 入場約定価格から保護ストップまでの割合。 |
| Take Profit | 0.6% | 入場約定価格から利益目標までの割合。 |

## ダイアグラムの詳細

- C#原典は成行で入りますが、この図は登録と取消のライフサイクルを示すため意図的にLevel 1指値を使います。
- 元の200/400価格ステップは、再生時のBTCUSDT価格に対する約0.3%/0.6%として1:2比率を維持します。
- 原典は約定後100本の間ストップも利確も検査しません。価格ゲートでこの順序を再現します。
- 気配ラッチが非同期Level 1を足単位のEMA判断に整列します。再生銘柄に価格刻みがない場合に備え価格丸めは無効です。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
