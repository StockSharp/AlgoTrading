# Larry Connors 3 Day High/Low 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

拉里·康纳斯的 3 Day High/Low 在上涨行情中买入短暂回调。价格必须站在慢速 SimpleMovingAverage 之上、跌破快速均线，并连续出现三根最高价和最低价都低于前一根的K线。首次收盘站上快速均线即离场。原版使用日线，本图改用五分钟K线，以便与随附的日内历史数据相匹配。

![schema](schema.svg)

## 策略概览

- K线形态方块囊括了完整的四根K线结构：连续三根K线，每根的最高价和最低价都低于前一根。
- 50 周期 SimpleMovingAverage 判定行情向上，因此只在大方向一侧买入回调。
- 5 周期 SimpleMovingAverage 既是入场闸门（价格在其下方说明回调仍在进行），也是离场触发。
- 策略只做多。原版还限制入场次数并要求两笔交易间隔十五根K线；方块中没有计数器，因此本图的交易频率高于源代码。

## 入场与出场规则

- **做多入场**: 形态方块报告三次更低的高点与更低的低点，收盘价高于慢速 SMA、低于快速 SMA，且持仓为零。订单按市价买入共享数量并开多。
- **做空入场**: 没有做空一侧。康纳斯的规则只买入上涨行情中的回调，因此图中不设卖出入场。
- **离场**: 首次收盘站上快速 SMA 即平掉多头。平仓方块按当前持仓量发送市价单；与原始代码一样，没有止损也没有止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Slow SMA Length | 50 | 慢速 SimpleMovingAverage 的周期，用作上涨行情过滤。 |
| Fast SMA Length | 5 | 快速 SimpleMovingAverage 的周期：价格在其下方开仓，首次收在其上方平仓。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时喂给形态指标、两条移动平均线以及提取收盘价的转换方块。
- 两个比较方块把收盘价与两条均线对比，持仓方块则与零常量比较。
- 一个逻辑与把形态标志、两个均线条件和空仓判断合在一起，触发设为开仓的修改持仓方块。
- 另一个设为平仓的修改持仓方块由收盘价重新站上快速均线触发；它无需数量，因为它平掉当前全部持仓。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
