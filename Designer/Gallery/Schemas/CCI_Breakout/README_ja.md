# CCI ブレイクアウト戦略のダイアグラム
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

商品チャネル指数はほとんどの時間を -100 から +100 の間で過ごすため、この帯を抜けることは行き過ぎではなく動き出しの合図と見なします。ダイアグラムは指数を1本前のローソク足の値と比べ、これによって「水準」が「ブレイクアウト」になります。戦略は常に建玉を持ち、どのシグナルも単なる手仕舞いではなくドテンです。

![schema](schema.svg)

## 戦略の概要

- 1つの指標ブロックが商品チャネル指数を計算し、前値ブロックが1本前の値を保持します。この組み合わせにより、水準の上にいるだけでなく、水準を越えたことを表現できます。
- 2つの水準はふつうの定数ブロックなので、ブレイクアウトの帯を広げたり狭めたりでき、他のパラメーターと同様に最適化できます。
- 注文数量は基準数量に現在ポジションの絶対値を足した値で、1本の成行注文が反対建玉の決済と新規建玉を同時に行います。
- 元の戦略はシグナルのたびに2本のローソク足を見送りますが、この計数はブロックで表現できないため省略しました。そのため本ダイアグラムは元のコードより1〜2本早くドテンすることがあります。
- 元の戦略は1時間足で動きますが、付属のサンプル履歴に合わせて5分足に縮尺しています。

## エントリーとエグジットの条件

- **ロングエントリー**: 1本前のローソク足で CCI が上側水準以下に終わり、現在はそれを上回っており、かつ買い持ちではないとき。注文は基準数量に建っている売り玉を加えて買い、ポジションをロングに反転させます。
- **ショートエントリー**: 1本前のローソク足で CCI が下側水準以上に終わり、現在はそれを下回っており、かつ売り持ちではないとき。注文は基準数量に建っている買い玉を加えて売り、ポジションをショートに反転させます。
- **エグジット**: 専用のエグジットはありません。戦略は常に市場にとどまり、反対方向のブレイクアウトが現在の建玉を閉じて新しい建玉を作ります。元のコードにもストップやテイクプロフィットはありません。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| CCI Length | 20 | 商品チャネル指数の平滑化期間。 |
| Upper level | 100 | ロングのブレイクアウトで指数が上抜ける必要のある水準。 |
| Lower level | -100 | ショートのブレイクアウトで指数が下抜ける必要のある水準。 |
| Volume | 1 | 基準の注文数量（ロット）。ドテン時はこれに建玉が加算されます。 |
| Candles | 00:05:00 | ダイアグラム全体が用いるローソク足の時間軸。 |

## ダイアグラムの詳細

- ローソク足ブロックが商品チャネル指数を駆動し、その出力は比較ブロックと前値ブロックの両方に流れます。
- 各方向につき2つの比較ブロックが、現在値と前の値を同じ水準定数と突き合わせ、元コードのブレイクアウト条件をそのまま再現します。
- 各論理積が現在値・前値・ポジション判定を結び、ポジション変更ブロックを起動します。
- 計算式ブロックが基準数量とポジションの絶対値を足し、2つの発注ブロックに供給するため、1本の成行注文でドテンが完了します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
