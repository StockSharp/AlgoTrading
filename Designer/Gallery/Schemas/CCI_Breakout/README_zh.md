# CCI 突破策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

商品通道指数大部分时间停留在 -100 与 +100 之间，因此走出这条带子被视为行情启动，而不是超买超卖。图中把指数与它上一根K线的读数作比较，这才把“水平”变成“突破”，而且策略始终持仓：每个信号都是反手，而不仅仅是平仓。

![schema](schema.svg)

## 策略概览

- 一个指标方块计算商品通道指数，前值方块保存上一根K线的读数，两者配合描述的是穿越水平，而不只是停留在水平之上。
- 两个水平都是普通常量方块，因此突破带可以放宽、收窄，并像其他参数一样参与优化。
- 下单数量为基础数量加上当前持仓的绝对值，一张市价单即可平掉反向持仓并建立新仓。
- 原策略在每个信号后跳过两根K线；该计数器无法用方块表达，这里省略，因此本图可能比源代码早一两根K线反手。
- 原策略使用1小时K线；为配合随附的样本历史数据，本图改用5分钟K线。

## 入场与出场规则

- **做多入场**: 上一根K线的 CCI 等于或低于上轨水平，当前已高于它，且当前不是多头持仓。订单买入基础数量加上未平空头，从而反手做多。
- **做空入场**: 上一根K线的 CCI 等于或高于下轨水平，当前已低于它，且当前不是空头持仓。订单卖出基础数量加上未平多头，从而反手做空。
- **离场**: 没有单独的离场：策略始终在市场中，反向突破同时完成平仓与开仓。原始代码同样没有止损和止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| CCI Length | 20 | 商品通道指数的平滑周期。 |
| Upper level | 100 | 做多突破需要向上穿越的水平。 |
| Lower level | -100 | 做空突破需要向下穿越的水平。 |
| Volume | 1 | 基础下单数量（手）；反手时再加上已有持仓。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块驱动商品通道指数，其输出同时进入比较方块和前值方块。
- 每个方向使用两个比较方块，把当前读数和前一根读数与同一个水平常量对比，精确复现源代码的突破条件。
- 每个逻辑与把当前读数、前值读数和持仓判断合并，然后触发修改持仓方块。
- 公式方块把基础数量与持仓绝对值相加，供给两个下单方块，因此一张市价单即可完成整个反手。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
