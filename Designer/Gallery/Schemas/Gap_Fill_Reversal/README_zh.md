# 跳空回补反转策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该图先度量前一根K线收盘价与下一根K线开盘价之间的跳空，再等待这根K线朝相反方向收出实体。向下跳空后收阳做多，向上跳空后收阴做空，离场则交给 SimpleMovingAverage 判断。

![schema](schema.svg)

## 策略概览

- 跳空幅度以前收盘价的百分比表示，因此同一个阈值在任何价格水平上都保持同样含义。
- 只有跳空还不算信号：偏离前收盘价开出的这根K线必须收回来，这正是策略名称中的反转实体。
- 多空两边共用一条离场线 SimpleMovingAverage；与原始代码一样，没有止损也没有止盈。
- 图表运行在1分钟K线上，与原策略一致，所以这里的跳空是相邻两分钟之间的小幅断层，而不是隔夜跳空。

## 入场与出场规则

- **做多入场**: 开盘价与前收盘价的距离不小于 Min Gap %，开盘价低于前收盘价，K线收在自身开盘价之上，且当前没有持仓。订单以市价买入一手。
- **做空入场**: 开盘价与前收盘价的距离不小于 Min Gap %，开盘价高于前收盘价，K线收在自身开盘价之下，且当前没有持仓。订单以市价卖出一手。
- **离场**: 第一根收在 SimpleMovingAverage 之下的K线平掉多单，第一根收在其之上的K线平掉空单；两个平仓方块会自行按持仓量计算数量。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Min Gap % | 0.02 | 前收盘价与新开盘价之间的最小距离，以前收盘价的百分比表示。 |
| SMA Length | 20 | 用于平仓的 SimpleMovingAverage 平滑周期。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:01:00 | 整张图使用的K线周期。 |

## 图表详情

- 两个转换方块读取K线的开盘价和收盘价，前值方块保存上一根K线的收盘价。
- 公式方块把开盘价与前收盘价的距离换算成百分比，一个比较方块把它与阈值常量对照。
- 另外四个比较方块给出跳空方向和实体方向；每个逻辑与把跳空条件、实体条件和空仓判断合并后再触发下单方块。
- 离场一对方块将收盘价与均线比较，驱动两个平仓方块。原代码中两次交易之间500根K线的暂停在方块中没有对应实现，因此本图的交易频率高于代码。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
