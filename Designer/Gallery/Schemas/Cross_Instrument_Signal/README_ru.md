# Схема стратегии с межинструментальным сигналом
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема синхронизирует завершённые четырёхчасовые свечи TONUSDT@BNBFT и BTCUSDT@BNBFT. TONUSDT формирует сигнал темпа изменения с периодом 20, а BTCUSDT — собственный фильтр простой скользящей средней с периодом 20. Схема рассчитана на выбранный Strategy Security BTCUSDT@BNBFT; внутренний числовой фиксатор `0/1`, общее состояние разрешения входа и защита по исполнениям управляют этой длинной экспозицией.

## Обзор стратегии

- Две независимые переменные инструментов настраивают только четырёхчасовые подписки TONUSDT и BTCUSDT. Завершённые свечи выравниваются до принятия решения, поэтому импульс TON и трендовый фильтр BTC всегда относятся к одному синхронизированному интервалу.
- TON ROC(20) задаёт бычье состояние выше нуля и становится условием выхода при значении не выше нуля. BTCUSDT допускает вход, когда его Close не ниже SMA(20), а Close ниже SMA(20) становится условием выхода.
- Для входа в лонг одновременно нужны четыре условия: `TON ROC(20) > 0`, `BTC Close >= BTC SMA(20)`, внутренний фиксатор показывает флэт и общее состояние `Cooldown is ready` разрешает вход. Собранное снаружи логическое И запускает рыночную покупку NoCondition объёмом 1.
- Действие входа снимает общее разрешение и запускает Entry Cooldown N, а дискреционная сигнальная продажа снимает то же разрешение и запускает Signal-exit Cooldown N. Соответствующий таймер возвращает разрешение через восемь синхронизированных пар свечей; проверка поколения подавляет завершение старого таймера после более нового сброса. Выходы этого состояния не ждут, а защитные выходы его не сбрасывают.
- Исполнение рыночной покупки BTCUSDT переводит фиксатор в лонг и включает процентную защиту: тейк-профит 2% и фиксированный, нескользящий стоп-лосс 2.5%. Исполнение дискреционного закрытия либо активация и исполнение Take/Stop возвращают фиксатор во флэт. Короткая позиция не открывается.

## Правила входа и выхода

- **Вход в лонг**: На синхронизированной паре завершённых четырёхчасовых свечей внешнее логическое И запускает рыночную покупку NoCondition объёмом 1, если TON ROC(20) выше нуля, BTC Close не ниже BTC SMA(20), фиксатор показывает флэт и общее состояние `Cooldown is ready` разрешает вход. Действие торгует выбранным Strategy Security, который должен быть BTCUSDT@BNBFT и совпадать с параметром свечей Traded Security.
- **Вход в шорт**: Входа в шорт нет. Дискреционная продажа использует ReduceOnly, MarketOrder и объём 1, поэтому может только уменьшить экспозицию выбранного Strategy Security; защита Take и Stop также закрывает лонг.
- **Выход**: Когда фиксатор показывает лонг, условие `TON ROC(20) <= 0` или `BTC Close < BTC SMA(20)` запускает рыночную продажу ReduceOnly без ожидания общего состояния паузы. Тейк-профит 2% или фиксированный стоп-лосс 2.5% также может закрыть экспозицию рыночной заявкой; стоп не подтягивается.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Traded Security | BTCUSDT@BNBFT | Инструмент только для подписки на свечи торгуемого актива. Выбранный Strategy Security должен иметь то же значение BTCUSDT@BNBFT, поскольку действия и сделки стратегии используют Strategy Security. |
| Signal Security | TONUSDT@BNBFT | Инструмент только для подписки на сигнальные свечи; его импульс участвует в сигнале, но ни одно действие не адресуется этой переменной. |
| BTC Candles Series | 04:00:00 | Серия завершённых четырёхчасовых свечей BTCUSDT для Close, SMA(20), решений по состоянию и графика. |
| TON Candles Series | 04:00:00 | Серия завершённых четырёхчасовых свечей TONUSDT для ROC(20) и синхронизированных решений. |
| BTC SMA Length | 20 | Период SimpleMovingAverage, рассчитанной по завершённым свечам BTCUSDT. |
| TON ROC Length | 20 | Период RateOfChange, рассчитанного по завершённым свечам TONUSDT. |
| ROC Threshold | 0 | Нулевой уровень, разделяющий состояние положительного импульса для входа и неположительного сигнала для выхода. |
| Entry Cooldown N | 8 | Число синхронизированных пар свечей, которое таймер действия входа отсчитывает перед возвратом общего разрешения. |
| Signal-exit Cooldown N | 8 | Число синхронизированных пар свечей, которое таймер дискреционного сигнального выхода отсчитывает перед возвратом общего разрешения. |
| Order Volume | 1 | Фиксированный объём для рыночной покупки NoCondition и рыночной продажи ReduceOnly выбранного Strategy Security. |
| Take Profit | 2% | Процент роста от цены исполненного входа, при котором срабатывает тейк-профит. |
| Stop Loss | 2.5% | Процент снижения от цены исполненного входа, при котором срабатывает стоп-лосс. |
| Trailing Stop Loss | false | Отключено, поэтому стоп-лосс 2.5% остаётся фиксированным и не следует за благоприятным движением цены. |
| Use Market Orders | true | Включено, поэтому тейк-профит и стоп-лосс закрывают позицию рыночными заявками. |

## Детали диаграммы

- Отдельные кубики [Переменная](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/data_sources/variable.html) типа «инструмент» питают только независимые свечные подписки TONUSDT@BNBFT и BTCUSDT@BNBFT. Заявочные действия и Сделки стратегии используют Strategy Security; выберите там BTCUSDT@BNBFT, чтобы он совпадал с параметром свечей Traded Security.
- Два кубика [Свечи](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/data_sources/candles.html) выдают только завершённые четырёхчасовые свечи. Кубик [Синхронизация](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/common/sync.html) объединяет два потока с интервалом `04:00:00` до передачи любого инструмента в цепочку принятия решений.
- Один кубик [Индикатор](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/common/indicator.html) рассчитывает RateOfChange 20 для TONUSDT, а другой — SimpleMovingAverage 20 для BTCUSDT. Кубики сравнения задают положительное и неположительное состояния ROC, а также положение BTC Close относительно средней.
- Числовая Unit-[Переменная](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/data_sources/variable.html) служит фиксатором состояния: `0` означает флэт, `1` — лонг. Buy MyTrade записывает `1`; MyTrade дискреционной продажи, а также события активации и MyTrade Take/Stop записывают `0`. Кубики логических условий объединяют это состояние с синхронизированными сигналами.
- Два привязанных к действиям таймера N значений задают Entry Cooldown N и Signal-exit Cooldown N равными 8. Любое из двух действий снимает одно общее разрешение входа; его таймер может вернуть `Cooldown is ready` через восемь синхронизированных пар, а проверка поколения отбрасывает устаревшее завершение прежнего таймера. Внешнее логическое И входа имеет один вход паузы. Оно запускает покупку [Изменить позицию](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/positions/modify.html) с NoCondition, MarketOrder и объёмом 1; сигнальный выход без этого входа запускает отдельную продажу ReduceOnly, MarketOrder и объёмом 1.
- [Защита позиции](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/positions/protect.html) получает исполнения покупки и дискреционного закрытия: покупка включает Take Profit `2%` и фиксированный Stop Loss `2.5%`, а исполнение закрытия сбрасывает устаревшее состояние защиты. Trailing Stop Loss равен `false`, Use Market Orders — `true`. График получает оба синхронизированных потока свечей, BTC SMA(20), TON ROC(20), потоки заявок Take и Stop и все исполнения BTC из Сделок стратегии.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
