# 枢轴点反转策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

经典的场内枢轴点在每根K线上都用滚动窗口重新计算：最近六十根K线的最高价、最低价与当前收盘价共同得出枢轴 P、支撑 S1 与阻力 R1。该图在这个区间的边缘做反向交易，并在枢轴处兑现。

![schema](schema.svg)

## 策略概览

- Highest 与 Lowest 用同一窗口取代上一交易时段的区间，因此价位随行情移动，而不是每天固定一次。
- P = (High + Low + Close) / 3，S1 = 2P - High，R1 = 2P - Low，再用窗口区间百分之二的缓冲把两个区域各自加宽。
- 入场还要求K线方向一致：支撑处需阳线，阻力处需阴线。
- 枢轴本身就是目标：收盘价越到枢轴另一侧即平仓。

## 入场与出场规则

- **做多入场**: K线最低价探入 S1 区域（Low <= S1 + 缓冲），收盘价高于开盘价，且当前空仓。买单开一手多单。
- **做空入场**: K线最高价触及 R1 区域（High >= R1 - 缓冲），收盘价低于开盘价，且当前空仓。卖单开一手空单。
- **离场**: 收盘价高于枢轴时平多，低于枢轴时平空。两个离场方块均为平仓模式，没有持仓时不会动作。原始代码既无止损也无止盈，本图保持一致。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| Highest Length | 60 | Highest 指标的窗口长度，即取最高价所用的K线数量。 |
| Lowest Length | 60 | Lowest 指标的窗口长度，建议与 Highest 保持一致。 |
| Zone Buffer | 0.02 | 入场区域的宽度，按窗口区间的比例计算，0.02 即百分之二。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时驱动 Highest、Lowest 指标以及开、高、低、收四个转换方块。
- 三个公式方块把这五个数字变成枢轴、含缓冲的支撑和含缓冲的阻力；缓冲值单独作为常量，可供优化。
- 每个入场都是三个比较的逻辑与：触及价位、K线方向、持仓为零。
- 两个离场方块由收盘价与枢轴的简单比较触发，使用平仓模式而非固定数量。
- 原策略使用一分钟K线，并在每次交易后停顿五百根K线；本图改用随附历史数据支持的五分钟K线，且没有这一停顿。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
