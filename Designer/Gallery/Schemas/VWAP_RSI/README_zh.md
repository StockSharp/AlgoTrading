# VWMA 与 RSI 回归策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

成交量加权移动平均显示资金真正成交的位置，RSI 则判断价格远离它是否已经过头。图形只在 RSI 超卖时于均线下方买入，只在 RSI 超买时于均线上方卖出，并持仓直到价格回到均线的另一侧。

![schema](schema.svg)

## 策略概览

- 这里的均线是32根K线的滚动 VolumeWeightedMovingAverage，而不是日内 VWAP。尽管名字如此，原策略用的正是这个指标：它按每根K线的成交量给收盘价加权。
- 相对强弱指数基于收盘价计算，只用于确认入场，本身不会开仓。
- 两个指标方块都只输出已形成的值，这可以防止图形在最初几根K线上按未成形的均线交易。
- 原策略在每次交易后停止处理100根K线，这同时冻结了离场，使持仓至少保持8小时。Designer 没有锁定计数器，因此该暂停未被移植：这里价格一旦穿回均线另一侧就立即平仓。

## 入场与出场规则

- **做多入场**: 收盘价低于 VWMA，RSI 低于超卖水平，且当前空仓。订单按设定数量买入。
- **做空入场**: 收盘价高于 VWMA，RSI 高于超买水平，且当前空仓。订单按设定数量卖出。
- **离场**: 当收盘价回到 VWMA 上方时平掉多头，回到其下方时平掉空头。与原策略一样，没有止损也没有止盈。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| VWMA Length | 32 | 成交量加权移动平均的K线数量。 |
| RSI Length | 14 | 相对强弱指数的平滑周期。 |
| Oversold | 30 | 低于该水平即视为超卖。 |
| Overbought | 70 | 高于该水平即视为超买。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块直接驱动成交量加权均线（该指标需要K线的成交量），并通过取收盘价的转换方块驱动 RSI。
- 两个比较方块判断收盘价位于均线的哪一侧，这两个信号同时服务于入场与离场。
- 另外两个比较方块把 RSI 与阈值常量对比。
- 持仓方块与零比较三次，为逻辑与方块提供空仓、多头、空头三个标志。
- 每个入场逻辑与合并三个条件——均线一侧、RSI 极值和空仓——并触发带“开仓”条件的修改持仓方块；离场使用带“平仓”条件的方块，不需要数量。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
