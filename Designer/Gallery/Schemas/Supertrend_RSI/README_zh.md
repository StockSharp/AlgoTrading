# Supertrend + RSI 策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

带有振荡指标刹车的趋势跟随图。SuperTrend 是一条跟随价格并随之翻转的 ATR 通道线，负责判定方向；RSI 负责判定行情是否还有空间：只有当 RSI 仍在中线之下才做多，仍在中线之上才做空。离场完全不靠信号，而是对入场成交挂上固定百分比的止盈与止损。

![schema](schema.svg)

## 策略概览

- SuperTrend 由十周期 ATR 乘以三构成，线条棘轮式地跟在价格后面，只有收盘价击穿它时才转向。
- RSI 在这里是刹车而非反转信号：只有当振荡指标仍处于 50 线的平静一侧时才允许入场，从而避开已经拉伸过度的行情。
- 入场只在空仓时进行，既有持仓与零的显式比较，也有下单方块自身的开仓条件。
- 全部离场交给保护方块，2% 止盈与 1% 止损正是原策略所启用的组合。

## 入场与出场规则

- **做多入场**: 收盘价高于 SuperTrend 线，RSI 低于 50 中线，且当前空仓。订单以市价买入共享数量，保护方块立刻为该成交挂上止盈与止损。
- **做空入场**: 收盘价低于 SuperTrend 线，RSI 高于 50 中线，且当前空仓。订单以市价卖出共享数量，保护方块同样挂上两个离场单。
- **离场**: 没有信号离场，也没有反手：先被触发的那张保护单平仓——2% 止盈或 1% 止损。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| SuperTrend ATR Period | 10 | SuperTrend 内部 ATR 的周期；数值越大通道越宽，翻转越少。 |
| SuperTrend Multiplier | 3 | SuperTrend 的 ATR 倍数，即跟踪线与中价的距离。 |
| RSI Length | 14 | 相对强弱指数的平滑周期。 |
| RSI Midline | 50 | 入场过滤所对照的 RSI 水平；原代码比较的正是 50，而不是它声明的超买超卖水平。 |
| Take Profit, % | 2 | 止盈相对入场价的距离（百分比）。 |
| Stop Loss, % | 1 | 止损相对入场价的距离（百分比）。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时驱动 SuperTrend、RSI 和读取同一根K线收盘价的转换方块。
- 收盘价与 SuperTrend 输出的比较得到上升趋势标志，对它取逻辑非得到下降趋势标志，因此两个方向不会在同一根K线上同时触发。
- 一个共享的 50 常量供给两个 RSI 比较方块，移动中线即可同时调整两个过滤条件。
- 每个逻辑与合并三个条件——趋势、振荡指标与空仓——并触发同样设有开仓条件的修改持仓方块。
- 两个修改持仓方块把各自的成交交给保护方块，由它挂出止盈与止损单，价格取自当前K线的收盘价。
- 原代码在两笔交易之间保持的一百根K线暂停未被还原：可用方块中没有K线计数器，因此保护单平仓后立即可以再次入场。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
