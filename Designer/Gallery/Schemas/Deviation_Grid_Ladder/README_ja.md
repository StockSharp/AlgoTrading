# EMA偏差グリッド階段戦略図
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

この図はC#のEMA(30)/StandardDeviation(14)平均回帰信号とREADMEのグリッド案を結合します。1.5σ偏差で成行可能な近い指値と2.5σの保留追加段を置き、元コードのEMA ± 0.5σ帰還境界で退出します。

![schema](schema.svg)

## 戦略の概要

- 確定5分リプレイ足がEMA、標準偏差、および両指標更新後に同期した終値を更新します。
- EMA − 1.5σを下抜け、Position <= 0なら−1.5σと−2.5σに買いを置き、上側はPosition >= 0で対称です。
- 近い段は通常すぐ約定し、遠い段はより強い動きを待ちます。
- ロングはClose > EMA + 0.5σ、ショートはClose < EMA − 0.5σで、コードどおり決済します。
- 各退出は両方の遠い注文を取り消し、反対信号も前側の古い遠い段を除去します。

## エントリーとエグジットの条件

- **ロングエントリー**: EMA − 1.5σを下抜けてPosition <= 0なら、EMA − 1.5σとEMA − 2.5σに数量1の買い指値を登録します。
- **ショートエントリー**: EMA + 1.5σを上抜けてPosition >= 0なら、EMA + 1.5σとEMA + 2.5σに数量1の売り指値を登録します。
- **エグジット**: ロングはClose > EMA + 0.5σ、ショートはClose < EMA − 0.5σでClosePositionを実行し、2段約定時も全数量を自動計算します。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| Candle Time Frame | 00:05:00 | 確定足周期。5分はC#既定4時間からのリプレイ適応です。 |
| EMA Length | 30 | 中心EMA期間で、実際のC#パラメータです。 |
| Standard Deviation Length | 14 | 幅の期間。14はC#リテラルです。 |
| Near Entry Deviation | 1.5σ | 元コードの入口倍率1.5です。 |
| Far Grid Deviation | 2.5σ | READMEから追加した第2保留段です。 |
| Mean-Reversion Exit Deviation | 0.5σ | 元コードの帰還境界0.5です。 |
| Volume per Rung | 1 | 各近・遠段の独立数量です。 |

## ダイアグラムの詳細

- C#のStrategyParamはEmaLengthとCandleTypeだけです。期間14、倍率1.5と0.5はリテラルで、本図では学習用に公開します。
- C#既定は4時間足です。5分足は1か月で十分な形成と偏差イベントを得るリプレイ適応です。
- Three Level Gridという名前でも実行コードの入口は1.5σだけです。2.5σ段はREADME由来と明示します。
- 元コードは2本の即時成行で反転します。本図では近い段が旧ポジションを平らにし、遠い段が後で反転を完成できます。
- Crossingは越境ごとに1組だけ作り、取消により残存追加注文が後で無管理ポジションを開くのを防ぎます。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行し、実運用の前にパラメーターやブロック自体を自分の銘柄に合わせて調整してください。
