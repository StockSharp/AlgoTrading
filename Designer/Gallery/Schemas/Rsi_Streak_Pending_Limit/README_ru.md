# Схема стратегии «Отложенные лимиты по серии RSI»
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема дожидается устойчивой крайней зоны RSI и затем выставляет лимитную заявку на откат. Она проверяет текущее и два предыдущих завершённых значения RSI, допускает одну отложенную заявку на каждый непрерывный заход в зону, снимает заявку при выходе RSI из зоны и защищает каждое исполнение процентными выходами.

![schema](schema.svg)

## Обзор стратегии

- Завершённые пятиминутные свечи поступают в RSI с периодом 14 и дают цену закрытия для расчёта отложенных заявок.
- Нижняя зона находится ниже 30, верхняя — выше 70. Кубик N values планирует проверку после трёх завершённых обновлений RSI.
- В момент проверки кубики Formula вместе оценивают текущий RSI, два предыдущих значения и ограничение по позиции. Прерванная серия не создаёт вход.
- Лимит на покупку ставится на 0,2% ниже закрытия сигнальной свечи, лимит на продажу — на 0,2% выше.
- Отдельные кубики Flag разрешают только одну заявку за непрерывное пребывание в каждой крайней зоне.
- Исполненные входы получают тейк-профит 1,5% и стоп-лосс 1%; при срабатывании оба выхода отправляются рыночными заявками.

## Правила входа и выхода

- **Вход в лонг**: После трёх обновлений все три значения RSI должны быть ниже 30, а Position — меньше или равна нулю. Выставляется одна лимитная покупка по `Close × (1 − Pending Offset / 100)`.
- **Вход в шорт**: После трёх обновлений все три значения RSI должны быть выше 70, а Position — больше или равна нулю. Выставляется одна лимитная продажа по `Close × (1 + Pending Offset / 100)`.
- **Отложенная заявка**: Неисполненный лимит на покупку снимается, когда RSI поднимается выше 30; лимит на продажу — когда RSI опускается ниже 70. То же событие сбрасывает Flag этой стороны для следующего захода в зону.
- **Выход**: После исполнения отложенной заявки Position protection закрывает её экспозицию при благоприятном движении 1,5% или неблагоприятном движении 1% рыночной заявкой.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Свечи | 00:05:00 | Таймфрейм завершённых свечей для сигналов и расчёта цен. |
| Период RSI | 14 | Период усреднения индекса относительной силы. |
| Поле RSI | Не задано | Альтернативное поле входных данных индикатора не выбрано. |
| Перепроданность | 30 | Строгая верхняя граница серии для входа в лонг. |
| Перекупленность | 70 | Строгая нижняя граница серии для входа в шорт. |
| Число совпадений (N) | 3 | Число завершённых обновлений RSI в интервале подтверждения. |
| Смещение лимита, % | 0.2 | Расстояние от закрытия сигнальной свечи до лимитной цены. |
| Объём | 1 | Размер каждой отложенной заявки на вход. |
| Тейк-профит, % | 1.5 | Благоприятное движение от исполненного входа для включения защиты. |
| Стоп-лосс, % | 1 | Неблагоприятное движение от исполненного входа для включения защиты. |
| Скользящий стоп | false | Оставляет границу стопа фиксированной. |
| Рыночные выходы | true | Отправляет сработавшие защитные выходы рыночными заявками. |

## Детали диаграммы

- Текущий RSI поступает в два кубика Previous value со сдвигами 1 и 2. Все три значения берутся только с завершённых свечей.
- Общий кубик N values взводится любой крайней зоной и считает три обновления RSI. Его выход одновременно выбирает значения обеих формул оценки входа.
- Оценка лонга отрицательна только тогда, когда все три RSI ниже 30 и Position не положительна. Оценка шорта отрицательна только тогда, когда все три RSI выше 70 и Position не отрицательна.
- Если за интервал подтверждения RSI покинул зону, соответствующая оценка не будет отрицательной и сигнал регистрации не появится. Следующий заход может начать новый интервал.
- Кубики Formula рассчитывают две лимитные цены от закрытия, а Order registering отправляют неокруглённые лимитные заявки объёмом одна единица.
- Order cancellation хранит последнюю заявку каждой стороны и срабатывает сразу после обратного пересечения границы этой зоны.
- Заявка объёмом одна единица против существующей встречной позиции в одну единицу сначала обнуляет экспозицию; для позиции в новом направлении нужен ещё один подтверждённый заход.
- График показывает пятиминутные свечи, RSI с двумя уровнями, оба потока отложенных заявок и все исполнения или выходы стратегии.

## Использование

Импортируйте файл `.json` в Designer, прогоните его в тестере на исторических данных и настройте уровни RSI, смещение лимитов, расстояния защиты и объём под инструмент перед реальной торговлей.
