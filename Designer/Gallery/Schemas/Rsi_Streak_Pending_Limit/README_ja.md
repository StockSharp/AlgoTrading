# RSI 連続極値ペンディング指値ストラテジー図
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

このダイアグラムは、RSI が極端なゾーンに継続して留まるのを待ってから、押し戻りを狙う指値注文を出します。現在の RSI と直前の確定値 2 個を確認し、連続した 1 回のゾーン滞在につき保留注文を 1 件に制限します。RSI がゾーンを離れると注文を取り消し、約定ごとにパーセント指定の決済保護を設定します。

![schema](schema.svg)

## ストラテジーの概要

- 確定した 5 分足を期間 14 の RSI に入力し、保留注文の価格計算にはその終値を使います。
- 下側ゾーンは 30 未満、上側ゾーンは 70 超です。N values ブロックが、確定 RSI の更新 3 回後に判定を予定します。
- 判定時には Formula ブロックが、現在の RSI、直前の 2 値、ポジション条件を同時に検査します。途中で途切れた並びからはエントリーしません。
- 買い指値はシグナル終値の 0.2% 下、売り指値は 0.2% 上に置きます。
- 方向別の Flag ブロックにより、極端なゾーンへの連続滞在中は注文を 1 件だけ許可します。
- エントリー約定には 1.5% の利確と 1% の損切りを設定し、発動時はいずれも成行注文で決済します。

## エントリーとエグジットの条件

- **ロングエントリー**: 3 回更新後の判定で、3 個の RSI がすべて 30 未満、かつ Position がゼロ以下であることを要求します。`Close × (1 − Pending Offset / 100)` に買い指値を 1 件登録します。
- **ショートエントリー**: 3 回更新後の判定で、3 個の RSI がすべて 70 超、かつ Position がゼロ以上であることを要求します。`Close × (1 + Pending Offset / 100)` に売り指値を 1 件登録します。
- **保留注文**: 未約定の買い指値は RSI が 30 を上回ると取り消し、未約定の売り指値は RSI が 70 を下回ると取り消します。同じイベントでその方向の Flag をリセットし、後のゾーン進入に備えます。
- **エグジット**: 保留注文が約定すると、Position protection が約定価格から有利に 1.5% または不利に 1% 動いた時点で、成行注文により対象エクスポージャーを決済します。

## パラメーター

| パラメーター | 既定値 | 説明 |
|---|---|---|
| ローソク足 | 00:05:00 | シグナルと価格計算に使う確定足の時間枠です。 |
| RSI 期間 | 14 | 相対力指数の平均期間です。 |
| RSI 入力フィールド | 未設定 | 指標用の別入力フィールドは選択されていません。 |
| 売られ過ぎ | 30 | ロング用 3 値系列の厳密な上限です。 |
| 買われ過ぎ | 70 | ショート用 3 値系列の厳密な下限です。 |
| 一致回数 (N) | 3 | 確認区間で数える確定 RSI 更新数です。 |
| 保留オフセット、% | 0.2 | シグナル足終値から指値までの距離です。 |
| 数量 | 1 | 各保留エントリー注文の数量です。 |
| 利確、% | 1.5 | 約定したエントリーから保護を発動する有利方向の変化です。 |
| 損切り、% | 1 | 約定したエントリーから保護を発動する不利方向の変化です。 |
| トレーリングストップ | false | ストップ境界を固定したままにします。 |
| 成行注文を使用 | true | 発動した保護決済を成行注文として送信します。 |

## ダイアグラムの詳細

- 現在の RSI は、シフト 1 と 2 の 2 個の Previous value ブロックへ渡されます。3 値はいずれも確定足だけから取得します。
- 共通の N values ブロックはどちらかの極端なゾーンで作動し、RSI 更新を 3 回数えます。その出力が同じ判定点で両方のエントリースコアを読み取ります。
- 3 個の RSI がすべて 30 未満で Position が正でない場合だけロングスコアが負になります。3 値がすべて 70 超で Position が負でない場合だけショートスコアが負になります。
- 確認区間中に RSI がゾーンを離れた場合、対応スコアは負にならず、注文登録のトリガーも生じません。後の極端なゾーン進入から新しい区間を開始できます。
- Formula ブロックが終値から 2 種類の指値を計算し、Order registering ブロックが価格丸めなし、数量 1 の指値注文を送信します。
- Order cancellation は方向ごとの最新注文を保持し、RSI がそのゾーン境界を戻って横切ると直ちに動作します。
- 1 単位の反対ポジションに対する 1 単位の注文は、まずエクスポージャーをゼロにします。新方向のエクスポージャーには、もう一度確認済みのゾーン進入が必要です。
- チャートには 5 分足、2 本の水準を含む RSI、両方向の保留注文、ストラテジーのすべての約定と決済を表示します。

## 使い方

`.json` ファイルを Designer に読み込み、バックテスターで過去データを使って実行してください。実運用前に、RSI 水準、保留オフセット、保護距離、数量を対象銘柄に合わせて調整します。
