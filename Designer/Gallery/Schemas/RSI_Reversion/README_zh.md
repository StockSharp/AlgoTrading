# RSI 回归策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

该图并不在 RSI 达到极值时立刻反向，而是等指数掉头的那一刻：RSI 从超卖区回到超卖水平之上时买入，从超买区跌回超买水平之下时卖出。一张订单携带足以反手的数量，因此策略要么空仓，要么只持有一个方向。

![schema](schema.svg)

## 策略概览

- 相对强弱指数基于已完成K线计算，前值方块保存上一根K线的读数，两者配合即可捕捉指数重新进入正常区间的那一根K线。
- 50周期的 SimpleMovingAverage 保留自原始策略：它不参与方向判断，只是把交易推迟到自身形成之后。
- 当前持仓参与两侧判断，订单数量等于基础数量加上已有持仓，因此一张市价单即可完成平仓与反手。

## 入场与出场规则

- **做多入场**: 上一根K线的 RSI 低于超卖水平，当前 RSI 等于或高于该水平，SMA 50 已形成，且持仓不是多头。订单买入基础数量加上已有空头数量：空头翻多，空仓则开多。
- **做空入场**: 上一根K线的 RSI 高于超买水平，当前 RSI 等于或低于该水平，SMA 50 已形成，且持仓不是空头。订单卖出基础数量加上已有多头数量：多头翻空，空仓则开空。
- **离场**: 没有单独的离场方块：反向的回归信号用同一张订单平掉旧仓并建立新仓。原始策略同样没有止损和止盈，而交易后暂停十根K线的规则未被移植，因为图中的方块无法在K线之间保持状态。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| RSI Length | 14 | 相对强弱指数的平滑周期。 |
| SMA Length | 50 | 负责预热的简单移动平均周期。 |
| Oversold | 30 | 做多时指数需要回升到的水平。 |
| Overbought | 70 | 做空时指数需要回落到的水平。 |
| Volume | 1 | 基础下单数量（手）。 |
| Candles | 00:05:00 | 整张图使用的K线周期。 |

## 图表详情

- K线方块同时驱动两个指标，RSI 输出上的前值方块提供上一根K线的读数。
- 每个方向使用两个比较方块，把前值与当前值分别与阈值常量对比，逐字复现源码中的条件。
- SMA 与零的比较对应源码中的保护判断；由于指标方块只输出已形成的值，交易在五十根K线之后开始。
- 公式方块把持仓绝对值加到数量常量上，两个修改持仓方块按该数量发送市价单。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
