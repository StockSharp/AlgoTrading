# Схема сопровождаемого лимитного входа по EMA
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Схема сохраняет пересечение EMA(12)/EMA(26) и подтверждение Momentum(10) из Franks4HourLimitOrdersStrategy, но явно показывает исполнение: лимит начинается на close сигнальной свечи, следует за последующими close через Order replacing, пока сторона актуальна, и снимается при обратном пересечении.

![schema](schema.svg)

## Обзор стратегии

- Завершённые свечи поступают в две экспоненциальные средние и Momentum; Crossing срабатывает только при реальной смене порядка EMA.
- Для бычьего креста нужны положительный Momentum и Position <= 0, для медвежьего — отрицательный Momentum и Position >= 0.
- Order registering ставит первый лимит по закрытию сигнальной свечи без округления к шагу цены.
- Combination хранит новейшую заявку после каждого Order replacing, поэтому сопровождение и отмена всегда получают живой объект.
- Перестановка разрешена только пока сохраняются нужные порядок EMA и знак Momentum, а не выполняется безусловно.

## Правила входа и выхода

- **Вход в лонг**: EMA(12) пересекает EMA(26) снизу вверх, Momentum положителен, Position нулевая или короткая. Лимитная покупка по close имеет объём abs(Position)+1, объединяя закрытие шорта и открытие лонга из кода в один нетто-разворот.
- **Вход в шорт**: EMA(12) пересекает EMA(26) сверху вниз, Momentum отрицателен, Position нулевая или длинная. Лимитная продажа по close использует то же правило нетто-разворота.
- **Выход**: Обратный крест EMA снимает отложенную заявку и может выставить встречную. Исполненную позицию дополнительно защищают схемные стоп 1% и цель 3%; исполнение защиты отменяет оставшуюся ссылку на лимит.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Candle Time Frame | 00:05:00 | Интервал завершённых свечей: в галерее пять минут, в C# по умолчанию четыре часа. |
| Fast EMA Length | 12 | Число значений в быстрой ExponentialMovingAverage. |
| Slow EMA Length | 26 | Число значений в медленной ExponentialMovingAverage. |
| Momentum Length | 10 | Число значений Momentum, знак которого подтверждает пересечение. |

## Детали диаграммы

- C# входит рыночными заявками и не управляет отложенными. Регистрация, перестановка и отмена лимита — сознательная демонстрационная замена способа исполнения.
- Неисполненный лимит переносится к close каждой новой свечи только пока порядок EMA, знак Momentum и сторона позиции сохраняют сетап.
- Дефолт исходника — четыре часа. Здесь по умолчанию пять минут, потому что месячной истории H4 едва хватает для формирования EMA(26); параметром можно вернуть 04:00:00.
- Базовый объём 1 и Position protection со стопом 1% и тейком 3% — фиксированные добавки схемы, а не параметры конструктора стратегии.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
