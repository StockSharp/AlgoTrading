# Схема стратегии двух активов с собственными средними
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Эта схема синхронизирует завершённые пятнадцатиминутные свечи BTCUSDT@BNBFT и TONUSDT@BNBFT, сравнивает закрытие каждого инструмента с рассчитанной для него простой скользящей средней за 20 периодов и использует противоположные соотношения для управления длинной и короткой экспозицией BTCUSDT. Рабочий цикл дополняют знаковый фиксатор, обновляемый исполнениями, одноступенчатые рыночные развороты, обычные выходы и локальный фиксированный стоп 2%.

## Обзор стратегии

- Отдельные переменные типа Security настраивают только подписки на свечи BTCUSDT и TONUSDT. Торговые действия и поток сделок стратегии используют выбранный Strategy Security, который должен быть задан как BTCUSDT@BNBFT в соответствии с параметром Traded Security.
- В кубик Sync поступают только завершённые пятнадцатиминутные свечи. Каждая синхронизированная пара передаёт BTC Close и BTC SMA(20) по одной ветви, а TON Close и TON SMA(20) — по другой; решение начинается только после формирования обеих средних.
- Соотношение для лонга строго требует `BTC Close < BTC SMA(20)` вместе с `TON Close > TON SMA(20)`. Соотношение для шорта строго требует `BTC Close > BTC SMA(20)` вместе с `TON Close < TON SMA(20)`. Равенство не удовлетворяет ни одному полному соотношению.
- Числовой знаковый фиксатор хранит управляемое схемой состояние BTC: `-1` означает шорт, `0` — флэт, `1` — лонг. Из флэта полное соотношение отправляет рыночный вход объёмом одна единица. Из противоположного состояния объём действия становится равным двум единицам: существующая единичная экспозиция закрывается, а в новом направлении устанавливается одна единица одним рыночным действием.
- Полное противоположное соотношение имеет приоритет над обычным выходом. В остальных случаях нахождение BTC строго с выходной стороны собственной средней закрывает текущую сторону рыночным действием ReduceOnly объёмом одна единица. Каждое синхронизированное решение завершается до того, как сохранённое закрытие BTC поступает в локальный фиксированный рыночный стоп 2%.

## Правила входа и выхода

- **Вход в лонг**: Если в синхронизированной паре завершённых свечей выполняются `BTC Close < BTC SMA(20)` и `TON Close > TON SMA(20)`, кубик допуска покупки принимает состояние флэта или шорта. Он отправляет рыночную покупку NoCondition с Volume 1 из флэта либо с Volume 2 из единичного шорта, чтобы сразу развернуться в единичный лонг BTC.
- **Вход в шорт**: Если в синхронизированной паре завершённых свечей выполняются `BTC Close > BTC SMA(20)` и `TON Close < TON SMA(20)`, кубик допуска продажи принимает состояние флэта или лонга. Он отправляет рыночную продажу NoCondition с Volume 1 из флэта либо с Volume 2 из единичного лонга, чтобы сразу развернуться в единичный шорт BTC.
- **Выход**: Лонг закрывается единичной рыночной продажей ReduceOnly, когда BTC Close строго выше BTC SMA(20) и полного соотношения для шорта нет. Шорт закрывается единичной рыночной покупкой ReduceOnly, когда BTC Close строго ниже BTC SMA(20) и полного соотношения для лонга нет. Проверки отсутствия передают полное противоположное соотношение ветви разворота объёмом две единицы. Локальная защита также может закрыть любую сторону фиксированным рыночным стопом 2%; Take Profit 0 отключает цель по прибыли.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Traded Security | BTCUSDT@BNBFT | Инструмент используется только подпиской на свечи торгуемой стороны. Задайте Strategy Security тем же значением BTCUSDT@BNBFT, потому что все торговые действия и поток сделок стратегии используют Strategy Security. |
| Signal Security | TONUSDT@BNBFT | Инструмент используется только второй подпиской на свечи. Его соотношение цены и средней участвует в решениях, но ни одно торговое действие не адресовано этой переменной. |
| BTC Candles Series | 00:15:00 | Серия завершённых пятнадцатиминутных свечей BTCUSDT для синхронизации, BTC Close, BTC SMA(20), проверок защиты и графика. |
| TON Candles Series | 00:15:00 | Серия завершённых пятнадцатиминутных свечей TONUSDT для синхронизации, TON Close, TON SMA(20) и графика. |
| BTC SMA Length | 20 | Период SimpleMovingAverage, рассчитанной по синхронизированным завершённым свечам BTCUSDT. |
| TON SMA Length | 20 | Период SimpleMovingAverage, рассчитанной по синхронизированным завершённым свечам TONUSDT. |
| Base Volume | 1 | Стандартный объём рыночного входа. Объём действия рассчитывается как `Base Volume * (1 + abs(latch))`, поэтому вход из флэта использует Base Volume, а разворот — удвоенный Base Volume; при заданном значении это Volume 1 и Volume 2. |
| Take Profit | 0 | Абсолютное нулевое значение отключает защиту по тейк-профиту. |
| Stop Loss | 2% | Неблагоприятное процентное расстояние от цены защищаемого исполнения, при котором срабатывает стоп-лосс. |
| Trailing Stop Loss | false | Отключено, поэтому стоп 2% остаётся фиксированным и не следует за благоприятным движением цены. |
| Use Market Orders | true | Включено, поэтому сработавший стоп закрывает защищаемую экспозицию рыночной заявкой. |

## Детали диаграммы

- Два кубика [Переменная](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/data_sources/variable.html) типа Security передают значения только соответствующим кубикам [Свечи](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/data_sources/candles.html). Кубик [Синхронизация](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/common/sync.html) выравнивает завершённые потоки с интервалом `00:15:00` до передачи любой ветви в цепочку решений.
- Каждая синхронизированная свеча разделяется на Close и сформированное значение [Индикатора](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/common/indicator.html). Четыре кубика строгого сравнения строят противоположные соотношения для лонга и шорта из Close каждого инструмента и его собственной SMA(20).
- Числовая Unit-переменная хранит знаковый фиксатор. Исполнение покупки записывает `1`, исполнение продажи — `-1`, а обычный или защитный выход — `0`. Сравнения состояния разрешают вход из флэта и разворот с противоположной стороны; формула объёма — `Base Volume * (1 + abs(latch))`.
- Допуски соотношений для лонга и шорта запускают действия [Изменить позицию](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/positions/modify.html) с NoCondition и MarketOrder. Отдельные рыночные действия ReduceOnly выполняют обычные выходы. Каждый допуск обычного выхода также требует ложности полного противоположного соотношения, поэтому разворот и единичное закрытие не могут быть запрошены для одной синхронизированной пары.
- [Защита позиции](https://doc.stocksharp.com/ru/topics/designer/strategies/using_visual_designer/elements/positions/protect.html) получает исполнения входов, разворотов и обычных выходов. Take Profit равен `0`, Stop Loss — `2%`, Trailing Stop Loss — `false`, Use Market Orders — `true`, защита выполняется локально. Синхронизированное закрытие BTC сначала сохраняется и поступает в защиту только после того, как обе сигнальные ветви завершили решение для этой пары.
- График получает синхронизированные потоки свечей BTCUSDT и TONUSDT, BTC SMA(20), TON SMA(20), поток стоп-заявок и все исполнения BTCUSDT из кубика Strategy trades.

## Использование

Импортируйте файл `.json` в Designer, прогоните схему на исторических данных в тестере, затем подстройте параметры или сами кубики под свой инструмент, прежде чем торговать вживую.
