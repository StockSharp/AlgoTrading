# KDJ 智能交易系统策略图
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

这是 MetaTrader 的 KDJ 顾问移植版。J 线在这里由随机振荡指标的 %K 与 %D 之差重建，方向完全由这个差值决定：差值转正、或差值已为正而 %K 继续上行时买入，反向条件则卖出。有两处针对随附历史数据做了调整：原策略的4小时K线改为1小时，使一个月的数据仍有足够的K线；以点数计的止损止盈改为百分比，适用于任何品种。

![schema](schema.svg)

## 策略概览

- 随机振荡指标（%K 周期30、%D 周期6）在这里充当 KDJ，差值 K - D 扮演 J 线的角色。
- 入场有两种方式：差值上下穿越零轴，或 %K 沿着差值符号已经指出的方向移动。
- 只有空仓时才开仓，因此既不加仓也不反手；结束交易的是保护方块。

## 入场与出场规则

- **做多入场**: K - D 为正，并且上一根K线上它为负（即本根K线完成零轴上穿），或 %K 高于上一根K线的值；同时必须无持仓。以市价买入一手。
- **做空入场**: K - D 为负，并且上一根K线上它为正（即本根K线完成零轴下穿），或 %K 低于上一根K线的值；同时必须无持仓。以市价卖出一手。
- **离场**: 与原策略一样完全没有信号离场：持仓保护方块以市价单在 2% 止盈或 1% 止损处了结交易，这相当于代码中 450 点与 250 点的百分比等价形式。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| %K Length (KDJ period) | 30 | %K 线的周期，即原顾问中的 KDJ 周期。 |
| %D Smoothing | 6 | %D 线的平滑周期。 |
| Take profit, % | 2 | 止盈距离，按入场价的百分比计算。 |
| Stop loss, % | 1 | 止损距离，按入场价的百分比计算。 |
| Volume | 1 | 下单数量（手）。 |
| Candles | 01:00:00 | 整张图使用的K线周期；原策略为4小时。 |

## 图表详情

- 两个转换方块把随机指标拆成 %K 与 %D 两条线，公式方块把它们相减。
- 前值方块保存上一根K线的 K - D 与 %K，这样无需交叉方块即可识别零轴穿越与斜率。
- 四个逻辑与方块构造出每个方向的两种入场方式，并且已经带上空仓标志；逻辑或再把每一侧的两条支路合并为一个触发信号。
- 两个入场方块都把各自的成交送入持仓保护方块，因此每一笔成交立刻获得止损与目标。

## 使用方法

将 `.json` 文件导入 Designer，在回测器中用历史数据运行，然后根据自己的交易品种调整参数或方块，确认无误后再用于实盘。
